## 关键链路核对

| 改动 | 核对结果 |
| --- | --- |
| 常驻推理线程 | 单图和批量共用部署实例容量，仅向空闲槽交接；满载立即拒绝，无等待队列、自动重试或额外业务磁盘交换。完成后清除请求闭包；停机在途调用未退出时不释放模型和 mmap，最终进程退出由 Supervisor 管理。 |
| 文件位置解析 | 普通文件保留配置目录项，避免 Windows 原子替换时解析到 NTFS 删除区；父目录与显式链接仍检查。相同路径用于保存、写协调及 journal，未增加锁等待或重试。 |
| File Summary 并发 | 检查点是缓存，锁争用返回本批独立计算结果，保留 `complete` 状态；不会叠加另一调用的计数或覆盖其游标。同代际同规则争用可返回，规则、代际或相同游标不同结果仍报冲突。 |
| 目录监听 | 通知到达时文件被替换或消失不会使单个路径错误终止监听；路径范围、扩展名、隐藏项和递归筛选仍有效。 |
| 保留清理 | 只减少重复路径解析；每次调用仍扫描，文件身份、期限、最旧优先和删除前检查未改变，不存在隐藏执行间隔。 |
| HTTP 上传调用 | 同步查询和执行通过线程处理，不阻塞 HTTP 事件循环；调用仍等待本次真实结果。服务通过 SessionFactory 在操作内建立数据库会话，没有把活动 SQLAlchemy Session 跨线程共享。 |
| Preview / WebSocket | 失败上传释放对应资源，未知 transfer 与迟到分块不撤销已提交输入；断开竞争仍进入订阅、借用和上传的清理路径。默认 wsproto，关闭压缩，保留发送背压。 |
| 启动与发布 | 120 秒只用于单个 worker 初始化，不改变业务超时；CPU/NVIDIA 依赖均固定经验证的 Uvicorn/wsproto 版本，发行组装有覆盖。 |
| .NET 修改 | 只改变验收探针的持续时间和失败证据记录，未修改 SDK 生产调用实现或公开契约。非成功样本仍保留，探针不会把失败自动重放为同一次生产调用。 |

没有修改模型权重、分类阈值、检测规则或前后处理数学逻辑。没有 API schema、数据库结构或 LocalBuffer 布局变更。模型执行线程身份由每次新建改为常驻复用，已有真实 CUDA/TensorRT 结果回归证据；这不等于所有模型族和任务类型均做过真实精度验收。
