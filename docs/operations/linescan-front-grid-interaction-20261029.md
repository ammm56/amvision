# 3913 正面网格简化与图片交互验证

对象：`workflow-app-20261028070103` 草稿。未发布新版本、切换 Runtime 或修改 Trigger。节点边界见 [通用 ROI 节点](../nodes/roi-comparison-and-crop-decode.md)。

## 修改

原 `Create ROI → ROI Array` 的原因是首槽为不规则多边形，列位移为 `[343,-3]`、行位移为 `[4,500]`，而原 ROI Grid Create 只支持轴对齐矩形。直接换成矩形会把邻件或塑盒结构纳入比较范围。

现扩展通用 ROI Grid Create，直接编辑首槽多边形、行列向量及数量。草稿由95节点简化为90节点：移除首槽 Create ROI、托盘裁图的3个中间节点以及首槽值转换节点；首槽提取改为 ROI List Item Get。既有定位、比较阈值、条码搜索框、OpenVINO模型、结果关联和后续阶段布局保留。

首槽点从原托盘局部坐标显式换算为校正图坐标。18个多边形、bbox和面积逐项等价。ROI ID 使用 Grid 既有标准 `slot-01-01` 至 `slot-03-06`，不再使用 Array 的 `slot-r01-c01` 格式；下游由实际来源 ID 关联。

ROI Array 继续服务上游动态 ROI 的阵列需求，图片面板可独立编辑行、列步距和数量。它不修改上游首槽。两个节点共用已有线段/多边形交互能力，没有引入产品专用节点或后台线程。

## 参考图与准确性边界

`validation/front-registered/reference.png` 是2500×2048的正常正面参考图。当前扫描先通过托盘圆形结构配准到参考坐标，再逐槽比较阈值前景的缺失、多出、质心、主轴角差和越界比例。检测属于参考图规则比较，不是已训练的缺陷分类器或高度测量。

本次将原20000×16384正面BMP用面积插值缩小，与参考图逐像素比较：最大绝对差1，平均绝对差约0.0997。两者画面一致到灰度舍入精度；不据此声称文件逐字节相同。条码解码仍使用原分辨率局部图。

同类型、外观稳定、照明受控的重复工件可以复用该算法，产品形状、参考图和阈值需要重新配置。反光、背景暗结构、表面印字或材料变化可能影响前景。当前只有一张真实正常正面图，不能给出现场漏检率/误检率，也不能证明工件未翘起或已压到底。受控缺失、位移与旋转只验证算法响应，不等于真实缺陷验收。

## 已完成的验证

- 18个槽位新旧几何逐点相同。
- 真实概览原图、整盘平移、正向旋转、反向旋转均18槽通过。
- 受控缺失、6°倾斜均仅 `slot-02-03` 失败；横移25概览像素时该槽及相邻 `slot-02-04` 失败。
- 定位特征消失明确拒绝，没有固定坐标回退。
- 前端组件验证两个同类线段工具按参数绑定区分、带符号向量回写、多边形已有顶点编辑、派生区域禁止拾取。
- 浏览器独立组件验收使用真实参考图和实际处理器生成的 debug_preview：Grid 写回 `[343,-3]` / `[4,500]` 的两个分量，Array 写回对应向量；拖动首槽一个顶点后仍为14点。发现并修复单个多边形重复草稿层遮挡几何编辑手柄的问题。
- 后端相关回归54项、目录校验1项通过；前端图片查看器与预览数据回归28项通过。浏览器组件验收没有调用正式 Preview 服务，不能替代重启后的端到端验收。
- 正式草稿契约校验通过并保存。

首次实际 Preview 因开发服务仍加载旧 ROI Grid 实现而在矩形越界处失败，不作为新实现验收结果。标准服务接替因旧 LocalBuffer 锁缺少可验证版本信息被拒绝；后续需正常重启原开发服务后复测整条链和页面。此处状态随实际复测更新。
