# 图编辑间距与浮动层次

更新：2026-10-29。仅记录当前源码尺寸，不是扩大节点的新设计指令。以[当前基准](graph-editor-current-baseline.md)为准。尺寸在画布 100% 下定义，随画布缩放等比变化；设计对照须保持原页面缩放、节点宽高及布局，不得为了展示全部参数而强行放大整页节点。

| 对象 | 最新规范 |
| --- | --- |
| 组标题条 | 高 28px，距组框顶边 4px；左侧对齐组框，不贴合，也不留十几像素空白。 |
| 组操作 | 启用/禁用、锁定、名称、数量、颜色、删除；22px 按钮、7px 间隔、左右 8px 内边距。名称双击编辑，不增加铅笔或文字按钮。 |
| 组色 | 标题与整个组背景同色相，组面透明可见网格；禁用变淡、虚线，锁定与禁用独立。 |
| 参数行 | 沿用当前布局：最小高 34px，行间 6px，列间 7px；输入最小高 28px。高度由现有组件和内容计算，不在设计稿中另外拉高节点。 |
| 参数列 | 左侧标签，右侧输入、下拉、单选和复选框；勾选框 18px，靠右对齐。长路径、复杂字段换行，输入单独占满下一行。 |
| 字重 | 节点标题、端口、参数、数值正常字重 400；通过位置、边界、间距区分层次。 |
| 浮动层 | 网格画布 → 半透明组框 → 有柔和落影的节点和组标题 → 顶部/右下浮动工具 → 节点库/属性 → 小型弹层。 |
| 阴影 | 节点参考 0 10px 20px rgba(0,0,0,.24)；组标题和工具参考 0 10px 24px rgba(0,0,0,.18～.20)；面板阴影范围更宽。暗色仍有表面、边线和落影，不能扁平化或使用发光描边。 |

依据：[共享样式](../../../frontend/web-ui/src/shared/styles/index.css)、[参数组件](../../../frontend/web-ui/src/workflows/workflow-editor/components/WorkflowNodeParameterWidgets.vue)、[组组件](../../../frontend/web-ui/src/workflows/workflow-editor/components/WorkflowGraphGroupLayer.vue)。浏览器查看了当前塑盒流程并在独立参考页切换至 100% 核对层次；未修改、执行、保存或发布真实流程。

## 逐图门禁

1. 组标题条紧凑、与组框只有细小空隙；名称、数量、颜色、删除不分散。
2. 参数行留白一致，所有布尔控件在右侧，长字段另起一行；不得为了画面容纳而删除参数。
3. 节点、工具与面板有真实落影层次，网格仍清晰；主操作、选中和普通控件有主次。
4. 亮暗布局、字段、状态、连线一致；面板覆盖不挤压画布。
5. 生成图为视觉参考，实际开发尺寸以本规范及源码为准；不宣称 PNG 像素等同 CSS 测量。
