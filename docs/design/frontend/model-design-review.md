# 模型页面设计复核

更新：2026-10-25。参考为用户指定bak1模型13图和已确认项目/数据集配色母版，已逐图打开查看。当前浏览器模型页仅用于核对已有入口，不限制目标设计。

## 1. bak1逐图结论

| 原图 | 保留 | 修正 |
| --- | --- | --- |
| M01 detection | 任务筛选、版本与产物关系 | 平台预置标题下混入项目训练；按资源分清；右侧为按需抽屉 |
| M01 empty | 数据不足时说明下一步 | 去掉空分页、零值任务卡和重复主动作；保留基础模型入口 |
| M01 narrow | 收起导航、次要字段归详情 | 删除独立顶栏；抽屉覆盖，不挤压主表 |
| M02 parameters | 分步训练和参数组 | 去掉常驻摘要/兼容检查右栏；检查在最终步骤，参数按模型能力 |
| M03 running | 当前batch、已完成epoch、曲线、文件 | 37轮时曲线画到100不正确；best定义与指标分开；权重不提供图片预览 |
| M03 failed | 失败阶段、最后checkpoint、恢复入口 | 38/300不应97%；GPU型号/容量矛盾；不保证梯度累积能解决OOM |
| M04 empty | 缺模型/数据前置条件 | 去掉空比较篮和技术架构说明；一个有效下一步 |
| M04 compare | 固定数据与split、任务类型区分 | 比较条件还包括指标/映射/预处理；REST/WebSocket不占用户主界面 |
| M05 errors | 类别指标、曲线、GT与预测联动 | FN不可伪造预测置信度；表格均值需一致；图像检查面板非模态 |
| M06 version | 来源链、格式/精度、文件与引用 | 来源方向为数据→训练→版本；去长ID；详情放可关闭抽屉 |
| M07 TensorRT | 目标相关参数、输入与精度 | 版本只读；检查不默认全绿；不预言输出文件大小 |
| M08 failed | 环境不一致、阶段失败、保留日志 | 阶段时间与总时长一致；已知环境不匹配应预检阻止；不盲目建议升级最新 |
| M08 success | 阶段、数值校验、创建部署 | 校验阈值/范围明确；不能“CUDA兼容”代表任意GPU；右侧信息按需抽屉 |

## 2. 本批范围

12个场景，每个先生成亮色、检查，再用已检查亮色做暗色参考。列表、版本详情、训练参数与运行、转换/导入入口、转换参数与完成、导入检查、评估列表/详情/样本、共用异常状态板。向导其余步骤、资源生命周期和短屏是后续逐页交付，不计入本批。

修订后只将最终图放入`generated/模型/`，未把生成过程中的失败稿复制进去。目录保留24张PNG、一个总览、一个清单，无子目录；24份中文提示词集中在`prompts/模型完整设计请求/`。提示词是**合并局部修订后的当前规格**，不是未经整理的每次工具调用日志；清单记录对应规格哈希和最终图片哈希。

1. 训练任务列表及创建训练其余四步；基础模型选择、数据缺失/不兼容、初始化与恢复检查；完成、取消和日志抽屉。
