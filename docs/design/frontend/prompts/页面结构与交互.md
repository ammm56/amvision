# 页面结构与交互提示词

这是旧 `06-google-stitch-prompts.md` 的中文修订版，适用于 Google Stitch 或后续结构化界面设计。逐页内容统一引用本目录，不再并行定义另一套导航、字段与布局。交付仍以 Vue 3 为实现目标，本轮不生成产品代码。

## 项目级提示词

```text
为 AMVAR 本地优先工业视觉工作台整理可实现的页面结构和组件。用户包括视觉工程师、现场实施人员、流程工程师和操作员，目标是完成数据准备、训练转换、部署调用、Workflow 编排和结果查看。

完整遵循随附的中文通用要求与当前单页提示词。采用 Vue 3 可实现、离线可分发的布局。全局仅保留11个平级左导航，无独立顶栏；不要另造工作空间/自动化等导航分组。资源详情采用可关闭的右侧覆盖抽屉，不使用固定详情列；编辑器的可收起属性面板、居中对话框和全幅查看器分别处理。

复用同一套导航、表格、筛选、表单、对话框、抽屉、状态、图像查看器与节点编辑基础组件。布局优先对齐、间距和轻分隔，不在每项外面套卡片。亮暗主题同结构同数据，品牌 #00D992、主按钮白字、普通悬停和输入焦点中性灰。

页面事实以给定规格为准。区分资源、有限任务、长期运行实例；区分执行成功与业务 OK/NG；区分草稿保存、发布和生产实例切版。专业检查经 Workflow 节点包及专属界面扩展，不创建独立连接器或3D业务系统。

输出中文界面和中文设计说明，技术名称保持英文。每页说明入口、主操作、数据来源、可见字段、容器、状态、关闭返回行为、权限及窄屏变化。规划能力明确标在交付说明中，不虚构 API、节点和可运行代码。
```

## 交互补充提示词

```text
为当前页面补充交互说明，保持已选视觉结构不变。列表筛选保留用户条件，加载只替换当前内容区域；无数据、无匹配、断线和无权限分别处理。未完成的请求或校验不能画成成功。菜单支持键盘和滚动，长名称/路径不撑破控件。

资源抽屉从操作入口打开，关闭恢复原列表滚动和焦点，底层内容不重排；有未保存编辑时按真实保存规则保护。对话框关闭不等于取消后台任务，不能给没有取消契约的任务添加强制终止按钮。每个动作必须指向明确对象。

按1366×768补窄桌面结构，保持主操作和关键字段可达，次要列或明细可收起，不能靠缩小文字塞满。品牌动画遵循现有选择，不新增页面切换动画；静态图只表达最终状态。前端关闭、解码失败、点云显示失败不得停止生产 Runtime。
```

## 结构化交付检查

- 一个页面只有一个明确主场景；扩展能力不全部挤在首屏。
- 普通动作中文，协议/品牌/正式节点名英文，字段说明没有随意混写。
- 参考来源、页面属性、数据样例、缺失契约和待实现依赖可追踪。
- 没有固定右侧资源列、独立全局顶栏或新导航分组。
- 原始数据、算法结果、显示抽样、历史结果不混用。
- 未通过用户审阅的图只标待审，不进入“已确认组件库”。
