# 模型、训练与转换：页面设计与提示词

继承[通用要求](通用要求.md)。本文件恢复旧 M01–M08 内容，当前编号按新覆盖清单使用。模型目标能力与当前实现分别记录，当前可用性核对[支持矩阵](../../../reference/models/support-matrix.md)；图稿不证明服务已经支持。

## 下一轮范围与顺序（2026-10-25）

数据集主流程与代表状态已有56组亮暗稿，可以开始本分类详细设计；本文件仍是出图准备，尚未生成新版模型稿。以未来完整产品为目标，不因当前缺少接口而省略合理页面；当前实现差距另行记录。模型入口保持一个，训练、转换、导入、评估为页内类别，不扩展全局导航。

| 次序 | 主要设计内容 | 必须明确的关系 |
| --- | --- | --- |
| 1 | 模型工作台亮暗母版、模型/版本详情、空态 | 平台预置模型、项目模型、不可变版本、转换产物分别表达；模型名称不等于运行实例 |
| 2 | 创建训练分步表单、检查提交、训练列表与运行/完成详情 | 固定数据集版本与兼容导出，初始化/warm start/resume分开；任务与最终模型版本分开 |
| 3 | 转换配置、任务详情、检查与产物；转换区下方模型导入 | ONNX/OpenVINO/TensorRT等产物归属同一模型版本，导入检查与可部署状态分开 |
| 4 | 评估列表/创建/详情、类别指标、比较与错误样本 | 固定数据版本、split、阈值与评估口径，GT和预测分层；不能用一个“准确率”覆盖所有任务 |
| 5 | 版本/产物操作、依赖阻止、失败恢复与资源失效 | 删除任务历史与删除模型资产不同，训练/部署/Workflow引用需核对；不在设计图中发明强制解除能力 |
| 6 | 短屏、长列表/名称、只读、提交未知、断线/取消、设备或格式不兼容 | 保留上下文，恢复先查已有任务；模态抽屉整屏底层遮罩，结果图像检查面板非模态 |

预置模型仍按项目约定登记本地资源；“导入模型”属于项目训练产物/模型版本导入，不把两个入口混用。部署启停及实例容量属于部署分类，单次推理属于推理分类；模型详情提供明确跳转。异常/瑕疵模型可使用相同模型与评估结构；连接器、3D的定位测量执行继续在Workflow及自定义节点包中，不新增行业业务页面。

长参数配置和完整日志/曲线报告使用完整工作区或分步页面；元数据和补充诊断用可关闭抽屉，不把所有内容硬塞进一个弹窗。先查阅bak1的13张模型参考稿并逐页记录保留/修正，再定稿中文提示词和生成亮暗配对；不直接照搬旧顶栏、旧绿或固定右栏。

## M01 模型、版本与创建训练

- 来源：[模型工作台](../generated/bak1/03-models/M01_model-workbench_light_detection_v01.png)、[模型详情](../generated/bak1/03-models/M06_model-version-detail_light_build-matrix_v01.png)、[创建训练](../generated/bak1/03-models/M02_training-wizard_light_parameters_v01.png)。
- 保留：任务分类、资源列表、版本来源和转换产物关系；训练参数分组。
- 修正：平台预置模型与项目版本分清；版本详情为抽屉；预置模型不是用户上传入口。
- 容器：模型工作台，详情抽屉，创建训练对话框/分步表单；不凭旧概念新增路由。
- 状态：有数据、无数据、缺少导出、参数不兼容、详情开关、只读。

### 模型工作台与版本

```text
设计模型工作台，左侧模型选中。保留旧稿的任务切换与版本/训练/转换信息结构，以 classification、detection、segmentation、pose、obb 等实际支持的任务筛选模型。平台预置模型和项目模型版本明确分开。
主体展示名称、模型系列、任务、来源、版本、可用运行格式和更新时间；详情从行操作打开右侧覆盖抽屉，呈现训练来源、数据导出、类别/输入、转换文件和引用。完整 ID、checksum 和路径次级展开。不要把同一模型的 ONNX、OpenVINO、TensorRT 产物各画成不同模型，也不把已转换等同于在任意硬件可部署。导入模型区域归转换任务下面，不在顶部重复放一套表单。
```

### 创建训练

```text
设计创建训练的参数步骤。前置选择是任务/模型、兼容数据导出、初始化方式；当前参数按基础、设备与批次、后端高级项分组。epochs、batch、图像尺寸、device、AMP 等仅在后端支持时出现。
Auto Batch 开启时说明自动选择，关闭时显示明确整数 batch。warm start 与 resume 分开，resume 要求兼容 checkpoint。来源、train/val/test、类别及输出摘要放在确认步骤，不固定占据右列。预检查、保存草稿等未具备服务能力的操作不画成当前已可用。缺少可选 test 不得用 val 冒充 test。
```

## M02 训练详情

- 来源：[运行中](../generated/bak1/03-models/M03_training-detail_light_running_v01.png)、[失败](../generated/bak1/03-models/M03_training-detail_light_failed_v01.png)。
- 保留：epoch/batch、曲线、检查点、日志和恢复入口。
- 修正：曲线不超前，进度一致，设备显存合理；失败原因与建议有证据。
- 容器：完整任务详情，诊断按需抽屉。
- 状态：等待、训练、验证、完成、取消、失败、断线保留已完成指标。

```text
设计 YOLO11 训练详情。上部为资源名称、状态、返回和可用动作；摘要显示数据来源、设备、输入尺寸。当前 epoch 37/100，曲线横轴只到已完成 epoch，不延伸到100。train loss、val loss、主指标分别呈现，best 标记说明对应指标。当前 batch 与已完成 epoch 指标分开，ETA 明确为估计或暂无。
下部输出文件区区分 best checkpoint、latest checkpoint、指标和日志，不给权重文件图片预览按钮。失败变体保留最后有效曲线、失败阶段和 checkpoint，恢复训练入口取决于兼容性。不要无依据地用提高梯度累积作为显存不足必然解决方案。诊断抽屉可关闭，默认首屏不展示长堆栈。
```

## M03 转换、模型导入

- 来源：[旧转换参数](../generated/bak1/03-models/M07_conversion-wizard_light_tensorrt-parameters_v01.png)、旧模型工作台。
- 修正：目标选项按能力；导入放转换任务下方；详细检查不变成固定右栏。
- 容器：页内转换区和任务列表，下方导入模型区；长配置用对话框。

```text
设计模型页面的转换与导入区域。转换先选择来源版本、目标 ONNX/OpenVINO/TensorRT 等实际支持格式，再显示目标相关参数。static/dynamic shape 联动，precision、workspace、设备兼容性按真实后端解释，不能混用多个后端字段。
转换任务表在配置之后，导入模型作为表格下方独立区域，有清楚的文件/来源、任务、输入输出检查和导入动作。不要把导入模型置于页面最顶部。兼容检查的详情按需展开或抽屉打开；本机版本只读，不画成可任意选择安装的下拉。
```

## M04 转换详情

- 来源：[成功](../generated/bak1/03-models/M08_conversion-detail_light_tensorrt-success_v01.png)、[失败](../generated/bak1/03-models/M08_conversion-detail_light_tensorrt-failed_v01.png)。
- 保留：阶段、文件、验证、下一步；修正时间和数值校验口径。
- 状态：规划/执行/校验/完成/失败、部分产物、设备不兼容。

```text
设计模型转换详情。展示来源模型、目标格式、精度、实际目标环境、状态；主体为阶段时间线、输出文件和数值校验摘要。阶段耗时与总耗时合理对应，未知进度用阶段状态。成功后的主要动作是创建部署；失败时主要信息为失败阶段、原因、保留文件和有效处理入口。
数值校验摘要注明样例范围与阈值，只代表该次校验，不写真实准确率全面通过。TensorRT 兼容性包含实际版本和目标约束，不能仅凭 NVIDIA 或 SM 标记证明。完整日志、规格和 checksum 次级显示；诊断抽屉可关闭。
```

## M05 验证与评估

- 来源：[比较](../generated/bak1/03-models/M04_evaluation-center_light_tasks-compare_v01.png)、[空态](../generated/bak1/03-models/M04_evaluation-center_light_empty_v01.png)、[评估详情](../generated/bak1/03-models/M05_evaluation-detail_light_per-class-errors_v01.png)。
- 容器：模型页内目标功能/结果工作区，不新增全局导航。
- 属性：独立中心/比较页面为规划；实际任务与 API 逐项核对。
- 状态：缺前置条件、执行中、完成、部分失败、不可比较、错误样本检查。

```text
设计模型页内验证与评估的目标工作区。保留旧稿按模型、数据版本、split、运行后端筛选的列表，以及按类别指标和错误样本查看。比较只在任务、数据、阈值和评估口径一致时开放；比较篮按需打开，不空占右列。
评估详情以任务对应指标、类别表、PR 曲线或混淆矩阵、GT/预测样本为主体。AP 标清 IoU 口径；分类、分割、pose、OBB 不共用一个模糊准确率。FN 不伪造预测置信度。选择样本打开可关检查抽屉或大图。缺模型或数据时说明前置条件，不用假结果填空；运行中指标不冒充最终结果。
```
