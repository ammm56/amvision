## 后续出图顺序

1. 首批主结构核对后，补训练的模型/数据/初始化/检查，以及完成、取消与恢复。
2. 补转换来源/目标/检查及不同格式参数，导入文件/信息/完成和异常。
3. 补评估创建、运行、比较、其他任务指标；版本编辑/删除与依赖阻止。
4. 亮暗配对、1366×768短屏、长列表/名称、权限/断线/焦点与滚动。

固定右侧第三栏、任意预训练权重上传、通用准确率、未知进度假百分比、自动重复提交、所有格式通用兼容等均不进入新版。创建/执行任务与模型资产分开；普通状态描述不用内部类名和协议术语。
