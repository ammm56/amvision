# 部署与推理：页面设计与提示词

继承[通用要求](通用要求.md)。部署是长期实例，单次推理是调用；容量忙碌不是未启动。保持控制面、数据面和结果展示边界。

## R01 部署列表、创建与导入

- 来源：[部署列表](../generated/bak1/04-deployments-inference/R01_deployment-workbench_light_service-control_v01.png)、[空态](../generated/bak1/04-deployments-inference/R01_deployment-workbench_light_empty_v01.png)、[窄屏](../generated/bak1/04-deployments-inference/R01_deployment-workbench_light_narrow-1366x768_v01.png)。
- 保留：设备/后端、模式、状态、启停和推理入口。
- 修正：无凭空主备、重试预算、队列；导入是当前必要入口。
- 容器：全宽列表；创建/导入为对话框；详情为抽屉。
- 状态：空态、启动/运行/停止/故障、满载、坏包、分析中、配置变更待检查。

### 部署列表

```text
设计部署列表，左侧部署选中。页内主要入口为新建部署、导入部署实例和刷新；设备能力为次级入口。表格优先名称、模型任务、运行后端、设备、精度、同步/异步、实例数、状态和操作。完整 ID、PID、generation 在详情。
实例状态不使用有限任务成功/已取消，运行繁忙和满载仍与服务故障分开。支持的设备和精度来自实际能力，不编造 NPU 组合、端口或性能数据。默认不打开右侧详情，列表占满主区。
```

### 创建与导入

```text
设计导入部署实例的居中宽对话框。背景是完整部署列表并有遮罩。顶部标题、关闭和简短包摘要；正文按实例配置、运行配置、资源映射、检查问题排序。名称、设备、实例数采用标签在上、控件在下的统一网格。
运行配置按执行、生命周期和当前后端参数分组，只展示本例实际后端字段，不能混放 TensorRT 和 OpenVINO 选项。资源映射使用资源、包内来源、导入目标、处理方式四列，名称优先，长路径/ID 可展开复制；新建和复用有文字。
配置变化后提示需要重新检查，主动作变为检查配置，通过后再导入；冲突才出现副本选项。每条历史失败旁有独立清除按钮，清除仅移除提示，不重试或删除资源。底部取消和当前主动作固定可达，正文滚动。不使用已否决稿作为布局参考。
```

创建部署使用同样的字段网格，来源为已登记模型版本/运行文件，不沿用导入的包内资源映射。

## R02 部署详情

- 来源：[接口监测](../generated/bak1/04-deployments-inference/R02_deployment-instance_light_interface-monitoring_v01.png)、[故障](../generated/bak1/04-deployments-inference/R02_deployment-instance_light_failed_v01.png)。
- 容器：列表操作打开覆盖抽屉，按现有承载方式组织详情，不虚构新路由。
- 状态：真实健康、未探测、断线、启动失败、依赖被使用、同步满载。

```text
设计部署实例详情抽屉，右上可关闭。名称和真实状态在顶部，紧接来源模型、运行后端、设备、精度、实例容量与启停入口。局部类别为概览、接口、配置、诊断、引用，当前展示概览。
已有数据才展示时延、请求和资源占用；故障后曲线不能补零冒充正常采样。进程存活不等于接口可用，推理满载也不等于故障。接口示例来源于公开 API；LocalBuffer 引用不能显示成图片下载 URL。
停止前展示具体受影响引用。长错误、完整 ID、PID 和日志放诊断中；默认不画重试队列、恢复倒计时和自动切换后端。底层列表列宽不变。
```

## I01 推理与结果

- 来源：[旧推理工作区](../generated/bak1/04-deployments-inference/I01_inference-lab_light_sync-result_v01.png)。
- 保留：输入、部署目标、图片、对象列表和耗时。
- 修正：图中对象与计数一致、GT 仅有真值才显示；结果详情可关。
- 容器：输入紧凑区域＋大图主区；高级参数/结果详情按需展开，不强制三栏。
- 状态：未执行、执行中、结果、满载、超时、无图、解码失败、异步任务。

```text
设计推理工作区，左侧推理选中。正文上方选择部署实例并显示任务、运行后端、设备与同步/异步模式；输入与必要参数采用紧凑区域，主操作清楚写立即推理或提交异步任务。
大图占主要空间，支持适配、缩放、平移和叠加显隐，按任务呈现分类、boxes、masks、keypoints 或 OBB。结果对象和阶段耗时从可关闭的侧边详情查看；原始 JSON 次级展开。图像中的对象、列表行和计数一致；没有真值就不放 GT 开关。
满载明确是容量拒绝，不出现队列等待和自动重试。显示失败仅影响图片区域，不改业务响应。阶段时延标清是否包含传输，未知值不伪造毫秒数字。
```
