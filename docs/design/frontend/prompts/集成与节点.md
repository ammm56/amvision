## X01 触发入口列表与详情

- 来源：[旧触发源](../generated/bak1/05-workflows-integrations/X01_trigger-source_light_zeromq-mapping_v01.png)、[无 Runtime 空态](../generated/bak1/05-workflows-integrations/X01_trigger-source_light_empty-no-runtime_v01.png)。
- 保留：关联 Runtime、协议类型、字段映射、运行诊断。
- 修正：列表简洁；长 ID、原始计数、最近错误入详情；目录监听是正常后台能力。
- 容器：主列表＋操作列详情按钮打开右侧覆盖抽屉。
- 状态：运行/停用/故障、未触发、满载、无数据、长 ID、断线。

```text
设计集成页触发入口列表，左侧集成选中。表格只突出名称、类型、状态、触发时间、操作，操作列有详情；触发时间显示未触发或具体日期时间。不要恢复最近错误列、长 Trigger ID 和 Runtime ID，不在行内展示 running=true 等原始诊断串。
详情抽屉参照运行实例详情的信息层级：名称与状态、关联运行实例、最近触发时间、请求/成功/错误/超时/满载计数、最近错误，完整标识和原始诊断可展开复制。右上有关闭，底层列表宽度不改变。计数不可用显示暂无，不伪造0；满载是容量信息，不一概染红。
```

## X02 触发配置与结果绑定

- 来源：旧 X01 配置和映射区域。
- 容器：从列表进入配置抽屉/表单；复杂映射分步，不常驻大表单挤压列表。
- 状态：缺 Runtime、协议不支持、字段未匹配、契约变化、测试失败、无权。

```text
设计触发入口配置。顺序为选择运行实例、协议参数、输入映射、结果绑定。协议选项来自实际已注册 Adapter；保存和启用的前置条件分开，不因当前实例未运行就猜测一切配置都不可保存。
映射用来源字段、目标输入、类型和检查结果对齐表格，默认只展示相关字段。结果绑定下拉收起值使用中性文字，展开选中项使用品牌色，悬停中性灰。目录监听说明由后端自动执行，无需 SDK 调用配置；不要画一个 SDK 发送按钮。
契约变化时显示不匹配字段并提供明确修改入口，不自动重写映射。不把 WebSocket Preview 当成通用触发协议，不混用 ZeroMQ 请求/订阅/回执，不添加自动重投或高性能调用队列。
```

## N01 节点目录与详情

- 来源：[旧节点目录](../generated/bak1/05-workflows-integrations/N01_custom-node-catalog_light_opencv-pack_v01.png)、[空目录](../generated/bak1/05-workflows-integrations/N01_custom-node-catalog_light_empty_v01.png)。
- 保留：包/类别、定义列表、端口/参数/用途详情。
- 修正：核心与扩展来源分明，右侧可关闭，不显示未经实现证明的沙箱能力。
- 容器：页内类别筛选＋主列表＋按需详情；类别不是全局导航分组。

```text
设计节点目录，左侧节点选中。正文搜索与筛选支持用途、端口类型、Core/扩展包来源；主体列名称、用途、来源包、版本和状态，不以内部目录路径作为用户分类。
点开节点后右侧覆盖详情显示用途、输入输出类型/单位、参数、资源依赖与示例，内部 node_type_id 可复制。连接器专用节点留在 connector_nodes 等对应包，通用几何/文件/逻辑不带固定产品规则。未安装的能力不能画成可执行。目录为空时用一个扫描/安装说明，不同时堆三块空卡片。
```

## N02 节点包与诊断

- 来源：旧 N01 包详情，复用当前包管理契约。
- 状态：启用、禁用、加载失败、缺依赖、版本不兼容、被流程引用。
- 容器：目录局部包视图，包详情抽屉；不新建全局插件市场。

```text
设计节点包管理与诊断。包列表显示名称、版本、启用状态和加载结果，详情显示 manifest 声明、capabilities、输入参数定义、依赖、timeout 与实际隔离边界。普通使用说明优先，完整元数据可展开。
缺依赖或 schema 不兼容时给出具体原因和对应处理入口，扫描不等于自动启用。禁用有明确引用影响，不删除包文件。只有现有能力支持时才显示回滚，不用 UI 文案承诺任意代码沙箱。保持表格、抽屉、按钮与全站统一。
```
