## 4. 本轮存放规则

- 当前提示词在本目录，受 Git 管理，文件名使用页面类型。
- 旧图保存在 `generated/bak1/`，不改名、不覆盖、不重新压缩。
- 已生成项目图的实际英文请求属于生成历史，不拿它们代替当前中文规范；后续请求使用中文修订。
- 新图保存到 `generated/数据集/`、`generated/模型/`等直观目录；图片名为具体页面和主题，修订号仅在确有多个版本时加入。
- 图片及其实际请求、清单位于被 Git 忽略的 `generated/`；本目录文字文档不能替代图片资产备份。
