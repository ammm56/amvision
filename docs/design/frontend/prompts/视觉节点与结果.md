# 专业视觉节点与结果：页面设计与提示词

继承[通用要求](通用要求.md)和[视觉工作流扩展设计](../workflow-vision-ui-plan.md)。这些能力通过 Workflow 和节点包提供，不新增异常、连接器、3D 三套全局导航。旧图没有对应行业画面时不声称有旧图来源。

## V01 异常与瑕疵检查

- 来源：旧图像/流程工作区的空间分配；内容来自已有差分节点与目标异常能力。
- 属性：参考差分已有基础；学习型异常模型的训练/部署需独立核对。
- 容器：节点专属编辑器＋共享结果查看器。
- 状态：无参考、对齐失败、正常/异常/未知、无 mask、阈值改动待执行。

```text
设计异常检查节点的专业编辑器，背景保留 Workflow 上下文。入口明确选择参考差分、正常样本统计或已部署模型，不用一个 AI 开关混淆。主区为当前图与参考图/热图对照，叠加检查 ROI、排除区和缺陷区域；侧边是当前方法参数，下方为可与图像定位联动的区域结果表。
显示透明度、色标与算法阈值分开；修改算法参数后显式预览，不自动发布生产配置。正常、异常、未知及对齐失败有文字原因。异常分数不冒充概率，没有 mask 不补假热图。结果来自同一次执行，主题变化不改缺陷颜色或判定。
```

## V02 连接器二维标定、定位、PIN 与测量

- 来源：[连接器工程示例](../../../examples/workflows/connector-inspection.md)、[开发素材](../../../development/connector-development-assets.md)和已有节点 UI。
- 资源：`data/development/connector-inspection/synthetic-v1/`，使用前核对实际文件与参数。
- 容器：各自节点编辑器；不把所有准备/运行步骤挤入一个“万能检测”节点。
- 属性：现有功能优化；合成资源用于开发，不替代实物计量。
- 状态：资源缺失、标定无效、定位失败、缺 PIN、缺边缘、临界尺寸、超差、无结果。

### 标定

```text
设计连接器二维标定节点编辑器。中心显示所附开发标定图及实际选定点，旁边清楚列方法、图像来源、实际点距或对应量值、单位、拟合残差和有效区域。点对应表与图中编号联动，未选择或缺失的点不能假装有效。
已有标定可直接选择；创建、验证、应用各自明确。误差、有效范围和资源版本可查。合成标定图标注为开发样例，不写成现场独立参考量值；像素到物理平面映射与工件定位变换区别说明。校验失败不能呈现可保存的成功状态。
```

### 定位与坐标

```text
设计连接器定位节点编辑器。主区为参考模板和当前待检图，明确参考来源、搜索区域、参考原点与方向。搜索区域和本次匹配几何使用不同线型，定位有效性和原因配文字。
模板制作是工程准备，单次运行只使用已保存资源；不要求每件重复标定。图像像素坐标、工件坐标和标定物理坐标有简短明确的来源及单位，显示视角调整不改变几何变换。定位失败时停止可信测量，不把名义位置冒充实测位置。
```

### PIN 阵列

```text
设计 PIN 阵列检查节点编辑器。主图展示所附连接器合成图，阵列行列、稳定编号、预期空位、搜索带可配置，预期位置用虚线，实测边缘/中心用实线。表格列编号、是否找到、有效性和必要几何数据，点击某行高亮该 PIN。
不为每个 PIN 强制建立独立画布节点，也不把连接器业务参数写进通用图像节点。缺 PIN、异常匹配和缺边缘分别显示，未知不补0。使用真实样例中的数量、尺寸和图像，不凭空生成精度结论。
```

### 尺寸与判定

```text
设计连接器测量项配置与本次结果。主图展示尺寸箭头和对应几何，下方表格为测量定义、对象、名义值、上下限、单位、实测值、偏差和状态；当前只展开一个测量项的参数。
Pitch、Total Pitch、Width、Gap、Offset、Angle 等按已实现定义显示，不混成模糊长度。标定来源、坐标基准和补正来源可查。临界判定由后端原始数值与规则决定，显示四舍五入不能重新判断；缺测不填0或名义值。不把二维测量包装成3D共面度，也不把多个失败尺寸算成多个不良物料。
```

## V03 3D 与点云

- 来源：视觉扩展目标，旧图仅参考专业画布交互，不存在可直接复用的 bak1 点云业务图。
- 属性：开发中待核对；节点名/端口/数值未确认前只能画结构性规划。
- 容器：专业节点编辑器、App Mode、专用大视图；通用查看器与行业算法分开。

```text
设计 3D/点云节点的专业工作区。主区为有明确单位与坐标方向的点云，提供适配、方向视图、点大小、颜色字段和选区工具。配置按输入、配准基准、检查体积、测量项和结果组织；当前只展示一个明确步骤。
参考几何与本次点云叠加可切换，结果表选择与对应几何高亮联动。RGB、强度、法向或偏差着色只在字段存在时出现；无单位、点数不足、配准失败和遮挡分别说明，不伪造毫米测量。默认不自动旋转，视角不改算法参数。
资源不足或 WebGL 错误是局部显示错误，不判后台检测失败。大数据使用显示抽样，不能用抽样后的值冒充完整测量。没有已确认数据时不画正式节点 ID、精度或性能通过字样。
```

## V04 共享资源选择与管理

- 来源：当前连接器资源选择，面向通用图像、标定、模板、规则、参考几何统一扩展。
- 容器：节点内入口打开资源选择器；复杂制作进入节点专业编辑器，不另建行业系统。
- 状态：无资源、缺文件、版本失效、无权、引用阻止删除、参数变更未应用。

```text
设计节点资源选择器，按当前输入需要过滤图像、标定、定位模板、规则或参考几何。列表先显示名称、类型、版本、来源和有效性；选中项有预览与必要单位/坐标摘要，长路径和完整 ID 可复制。
选择只建立引用，不自动覆盖资源或切换已发布版本。新建和编辑进入对应节点专业界面，缺失或失效资源给出明确原因。跨项目和被引用删除遵循服务检查。不要同时显示全部资源类型和安装商店，不把普通资源选择变成复杂资产管理首页。
```
