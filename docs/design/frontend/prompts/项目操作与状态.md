# 项目操作与状态：页面设计与提示词

更新：2026-10-23。使用[通用要求](通用要求.md)及[项目分类完整设计](../project-pages-design.md)，延续项目概览和列表的同一套亮暗样式。下列是相关操作状态，不是新的左侧导航入口。

正常稿已生成 8 张；逐图问题及下一轮局部修订见[审查记录](../project-design-audit.md)。缺失状态已展开为[项目补充状态提示词](项目补充状态.md)，优先使用其中对应单一状态的具体要求。本文件保留正常操作模板，不能把后面的综合状态描述一次全部画进同一页面。

## P04 项目信息抽屉

来源：项目概览亮暗图；默认从右上“项目信息”打开。按完整产品目标显示元数据，缺少的公开字段作为接口实现要求补齐。

```text
在项目概览上设计“项目信息”右侧覆盖抽屉。使用所附概览作为背景，保持原导航、标题、资源条和正文的位置与宽度；不要把背景缩成两列。抽屉从右边缘展开约500px，占当前画面约三分之一，右上X关闭，覆盖住原来的右侧内容；背景有轻遮罩，抽屉自身清晰。
标题为项目信息。正文采用简洁标签和值，不使用输入框或卡片套卡片：项目名称“产线视觉验证”；项目说明“包装、托盘与条码联合检测”；项目 ID“line-vision-01”，右侧复制图标；来源“本地目录”；存储位置“projects/line-vision-01”，右侧复制图标，下方小字“相对于服务存储目录”；创建时间“2026-09-10 09:00”；更新时间“2026-10-23 10:32”。长值允许换行。不显示负责人、磁盘容量、原始JSON、token或删除按钮。
固定底栏左侧关闭按钮，右侧品牌绿白字“编辑项目”。顶部和底部细分隔，正文有适当空白。设计视口参照1920×1080，输出与背景同样的16:9比例，文字大小延续背景。中文文案，专有名称保持英文。日期锚点2026-10-23；仅使用指定时间样例。亮暗配对时保持所有位置和内容不变。
```

## P05 编辑项目抽屉

信息抽屉与编辑抽屉互相替换，不叠两层。名称、说明为目标可写字段；更新接口尚需实现。

```text
在相同项目概览上设计“编辑项目”右侧覆盖抽屉，与项目信息同宽、同位置、同遮罩。背景原主内容尺寸不改变。标题编辑项目，右上关闭X。正文仅有项目名称必填单行输入，值“产线视觉验证”；项目说明选填多行输入，值“包装、托盘与条码联合检测，包含包装缺陷与条码核对”。后者表示本次已修改内容。字段使用清楚的中文标签，中性灰边框，焦点也是中性灰，不能绿色描边。
字段下简短说明“仅修改名称和说明”。不提供项目ID、目录、来源、权限、自动启动、默认值恢复等可编辑项。底部固定取消和品牌绿白字“保存更改”，主按钮处于可保存状态。抽屉不铺满无意义分组和解释，正文留白舒适，保持成熟工业工作台密度。
参照1920×1080，完整16:9界面，无全局顶栏，不打开第二层面板。日期锚点2026-10-23但不新增日期。亮暗对应同一组数据和同一字段修改状态。
```

## P02 SDK 配置包对话框

按完整产品设计预览、资源范围选择与下载。资源选择在同一对话框中切换；文件由资源选择推导，不任意勾选文件。

```text
在项目概览上打开居中“生成 SDK 配置包”对话框，宽约800px、高约640px，轻遮罩，右上关闭X。背景布局不变，无右侧固定分栏。正文顶部项目“产线视觉验证”，服务地址“http://127.0.0.1:5600”。下面紧凑一行数量信息：Workflow Runtime 1、调用型 Trigger 1、模型调用配置 1；不是大数字统计卡。
小节“配置范围”显示“全部可调用资源”和“调整范围”次按钮，模型调用方式“同步调用”，已选复选框“包含未启用的触发入口”。调整范围进入同一对话框的资源选择视图。小节“配置文件”显示两行文件：“Config/config_pack-inspection.json”和“Config/config_model_deployment_20261023.json”，对应“Workflow 配置”和“模型配置”；文件行不显示复选框或删除。
文件下方中性说明：“目录监听触发源由后端自动执行，无需 SDK 调用配置，已省略。”另用较轻小字“配置包包含当前访问凭据”，不显示任何token。不把普通说明做成黄色警告或错误。
底栏取消与绿色白字“生成并下载”，当前为生成前的正常预览。完整16:9界面，参照1920×1080，中文可读，2026-10-23为日期锚点。亮暗配对保持文件、数字、按钮与位置不变。
```

## P06 删除项目：被阻止

对话框不支持一键停止生产服务或强制删除；资源名称需要实际目录映射，没有名称则显示可复制 ID。

```text
在项目列表上打开居中“暂时无法删除项目”对话框，宽约700px，右上X关闭，背景轻遮罩且内容不重排。对象“产线视觉验证”，项目 ID line-vision-01。简短提示“以下资源正在使用项目，请处理后重新检查”。
三行阻止项列表，不套三张卡片：部署实例｜包装缺陷推理｜运行中｜查看；应用 Runtime｜包装缺陷检测｜运行中｜查看；触发入口｜产线目录监听｜已启用｜查看。状态为正常的运行/启用，并不是故障。可以在标题附近使用一个低干扰警示图标，不把整个对话框染红。
固定底栏中性描边“关闭”与品牌绿白字“重新检查”。标题使用琥珀色警示图标，资源运行状态仍用绿色。背景项目列表使用“说明”列，当前项目有明确“当前”标识，只有一页时不显示可用翻页。不出现可点击的删除、强制删除、自动停止或无意义确认输入。参照1920×1080、16:9，日期锚点2026-10-23，不新增日期。
```

## P06 删除项目：允许确认

使用独立空项目，避免与产线项目正在运行的样例自相矛盾。

```text
设计“删除项目”确认对话框，居中宽约620px，背景是项目列表：仅有一行“临时验证项目”，说明“用于临时功能验证”，四项资源计数均为0、更新时间显示“—”，共1个项目，不显示分页箭头；沿用参考列表列宽和导航，不改成项目概览。背景轻遮罩，不改变主区布局。此图不使用有运行中服务的产线项目作为删除目标。
对话框右上关闭X，标题配小型红色删除图标；项目图标为中性线框，不用大面积绿色装饰。正文项目名“临时验证项目”，项目 ID“scratch-check”。说明“未发现活动资源。删除后将移除项目及其目录，此操作无法撤销。”下方一个字段“输入项目 ID 确认”，输入框中已经正确填写scratch-check，中性灰焦点。底栏中性“取消”与实红白字“删除项目”，危险底色#DC2626，亮暗一致。真实输入为空或不匹配时删除仍禁用，改为中性禁用样式并说明原因。危险按钮不使用品牌绿色，不添加一键停服、自动重试、回收站或恢复承诺。
完整16:9界面，参照1920×1080，当前日期2026-10-23，中文标签和清楚字号，保留简洁左导航与无独立顶栏。该图表达确认前状态，不表示实际删除已经发生。
```

## P01/P03 空态与读取状态

按所选单一状态分别生成；不能在一张普通页面上把全部错误摊开。

```text
使用同一项目母版，按指定状态生成一个页面：项目列表无数据时保留搜索和新建入口，主区“暂无项目”与创建引导；搜索无匹配时保留已有搜索词，只显示“未找到匹配项目”和清除搜索。空项目概览使用真实零数量、暂无最近更新/执行任务/常驻服务，保留正常资源入口和继续工作，不伪造记录。
部分读取失败只在对应区域显示“暂时无法读取”和重试，数量是“—”，不能用0替代错误。只读状态保留查看与复制，按权限移除写操作。长名称和1366×768状态允许换行、重排或隐藏次要列，不缩小整页文字。不存在或无权使用独立错误内容和返回项目列表，不显示其他项目填补空白。所有时间只表达有来源的观察时间。
```

## P05 保存与退出状态

保留编辑草稿是关键，不增加恢复默认或自动保存。

```text
使用编辑项目抽屉分别设计指定状态：名称为空时字段下显示“请输入项目名称”，保存禁用；保存中显示“保存中”，防重复提交；服务失败时保留两个输入的修改内容，在底部动作上方给出错误与手动重试。
退出有修改时，在现有抽屉上打开小型确认“放弃未保存的修改？”，正文“关闭后，本次修改不会保存。”，默认主操作继续编辑，另一操作放弃修改。无修改不弹确认。并发修改时显示“项目内容已更新，请核对最新内容”，保留草稿，不提供不经核对的强制覆盖。提交结果不明时提示正在核对，不能直接宣称未保存并自动重发。
每张只表达一个状态，保持亮暗一致、可读文本、中性输入焦点，不增加新页面或第二层抽屉。
```

## P02/P06 操作反馈状态

```text
沿用 SDK 或删除对话框，分别生成指定状态：SDK 没有可调用配置时说明缺少资源、禁用生成并提供资源入口；生成失败保留项目和文件范围，错误可重试；下载触发后提示“已开始下载”，不声称本机文件写入已完成。目录监听省略始终为普通说明。
删除预检失败时不允许继续删除；删除请求返回cleanup_pending时，“项目已移除”前使用小型绿色勾，仅代表列表移除，下面“文件清理待完成”使用琥珀时钟和浅琥珀提示区。保留操作标识与复制入口，底栏中性“关闭”和品牌绿白字“检查结果”；结果为deleted才显示全部完成。出现错误保留操作标识供排查，不凭HTTP成功宣称磁盘已清空。所有操作保持明确目标项目、清晰取消/关闭边界，不增加自动重试队列。
```
