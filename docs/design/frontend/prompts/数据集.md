## 共用数据与主题

默认样例是“工业零件检测”，版本 v3，detection，来源 COCO。1200 张图像、1800 个标注对象、2 个类别（bolt、nut）；train 960 张、val 240 张、test 未配置。对象数为 bolt 1080、nut 720；不能用对象数之和冒充样本数。v3 为设计样例版本名，不推断当前真实服务已有顺序编号。

来源 ZIP 示例包含 images/train、images/val 和 annotations 中两份共享 COCO JSON；JSON 通过 image_id 关联样本，不能画成每张图片都有独立同名 JSON。源包、版本资产、导出包的路径各自明确；版本资产目录须标为设计示例，不当作当前真实存储结构。

当前大图样例“part_0042.jpg”，1600×1200，train，3 个对象：2 个 bolt、1 个 nut。图上对象、列表和数量一致。示例图像是设计用数据，不是生产质量或计量验收证据。

第二行数据集“连接器分类”，classification，版本 v2，600 张、3 类，train 480 / val 120；第三行“包装瑕疵”，segmentation，版本 v1，320 张、2 类，train 256 / val 64。不要把一次失败导入当作成功建立的数据集。

亮暗使用同一图像、数据、布局、排序和展开状态。品牌 #00D992、主按钮白字、危险按钮 #DC2626，普通悬停和焦点中性灰；类别颜色按图例稳定分配，不全改成品牌绿。共享主题精确规则来自通用要求。

2026-10-24 配色修订：版本资产目录的普通文件夹、文件、展开箭头、排序箭头、导航和工具图标均为中性灰线性图标；选中目录才用品牌色及软底。移除亮蓝实心文件夹、蓝色普通文字与图标、无必要的蓝色说明横幅。此规则同样覆盖导入包、导出包目录树。照片中的蓝色 bolt 标注与橙色 nut 标注保持原有类别含义。

历史阶段：先补详情和向导，随后补齐其余步骤、关键异常及短屏，达到23组；管理列表、编辑及删除/清理补充后达到32组，见[管理规格](../dataset-management-states-design.md)与[复核第9节](../dataset-design-review.md)。本轮再补工作区、版本演进、多类型查看及共用状态24组，累计56组；当前结果以本页顶部、末尾索引及统一总览为准。
