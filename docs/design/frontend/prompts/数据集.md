# 数据集：页面设计与提示词

统一使用[通用要求](通用要求.md)。依据[数据集完整设计](../dataset-management-plan.md)与[当前页面规格](../page-specifications.md)。保留旧稿的紧凑表格、划分摘要和样本浏览；不把版本列表重新放回主页面。

## D01 数据集主页面

- 来源：[旧工作台](../generated/bak1/02-datasets/D01_dataset-workbench_light_populated_v01.png)、[旧空态](../generated/bak1/02-datasets/D01_dataset-workbench_light_empty_v01.png)、[窄屏](../generated/bak1/02-datasets/D01_dataset-workbench_light_narrow-1366x768_v01.png)。
- 保留：导入/导出业务路径、紧凑记录表、来源和划分摘要。
- 修正：旧图常驻版本表改由管理入口打开；普通页无大标题；不仿照当前页面堆满创建表单。
- 容器：主区导入记录/导出记录局部切换，页内管理数据集入口，创建时打开表单。
- 属性：已有能力的目标布局调整；预检查向导属于扩展，另见 D03。
- 状态：有记录、首次空、筛选无结果、执行中、失败、详情开关。

```text
设计数据集主页面，左侧数据集选中。保留旧稿精简、清晰的资源表格与数据划分信息，调整为以导入记录和导出记录为主体的工作台。内容上部左侧是导入记录、导出记录两个局部标签；右侧为管理数据集、创建导出、品牌绿实心导入数据集。下一行是搜索、任务类型、状态筛选和刷新。不要在首屏常驻导入和导出大表单。
当前选择导入记录。表格列为数据名称、任务、格式、样本数、数据划分、状态、导入时间、操作。设计样例共三行：工业零件检测，detection，COCO，1200，train 960 / val 240，已完成；连接器分类，classification，ImageNet，600，train 480 / val 120，已完成；包装瑕疵，segmentation，COCO，样本和划分暂为破折号，校验失败。时间使用 2026-10-23 且顺序合理。每行提供详情和适用操作，不展示长 ID。
本张默认关闭详情抽屉，表格占满可用内容宽度，右侧没有空白详情占位。版本只从管理数据集进入；成功记录可查看生成版本或创建导出，删除记录不删除版本、图片和标注。无需在默认主视图常驻删除说明和架构关系图。
```

## D02 管理数据集

- 来源：旧 D01 的版本摘要和 D04 的版本上下文；本轮是专门管理对话框，不复用已否决新稿。
- 容器：居中宽对话框；内部列表与详情切换，不叠加抽屉套对话框。
- 属性：已有版本列表/引用保护，显示名、分页、打开样本等按目标扩展标记。
- 状态：空态、搜索、无权、计数未知、被引用不可删除、删除后页码调整。

```text
设计管理数据集对话框，以数据集主页面为遮罩背景。标题和关闭按钮清楚。上方检索与任务筛选，下方紧凑版本列表，字段为名称、版本标识、任务、样本数、类别数、创建时间、操作。名称和版本不强制推断为 v1/v2，数据不足时用已知名称或短标识。
打开进入样本工作区；详情在当前对话框内切换并有返回列表；删除版本先列出对象和引用阻止原因。明确删除版本会删除其图片、标注和关联导入/导出记录，存在外部引用时阻止。没有删除整个数据集。默认列表状态不要常驻整段危险警告。
```

## D03 导入、导出及其详情

- 来源：[预检查](../generated/bak1/02-datasets/D02_import-wizard_light_preflight_v01.png)、[导入详情](../generated/bak1/02-datasets/D03_import-detail_light_success_v01.png)、[导出检查](../generated/bak1/02-datasets/D05_export-wizard_light_compatibility-check_v01.png)、[导出详情](../generated/bak1/02-datasets/D06_export-detail_light_success_v01.png)。
- 容器：创建为对话框或多步表单；记录详情是完整业务页/按需抽屉，出图需明确选择一种。
- 属性：基础导入/导出已有；上传后提交前预检查及可保存草稿是目标能力，不能当成当前 API。
- 状态：上传、检查、提交、后台执行、成功、失败、缺图/格式不符/压缩包损坏。

### 导入预检查

```text
设计数据集导入预检查的目标界面。表单按上传 ZIP、任务与格式、数据划分与类别、检查与提交组织。当前显示文件、识别格式、分页目录摘要、图片和标注计数、train/val/test、错误和警告；缺少可选 test 不报阻断错误。
阻断错误必须定位文件或规则并允许返回修改；通过检查后才可提交。任务与格式使用实际支持组合，例子选 detection / COCO。不展开百万文件，不绘制与样本数矛盾的目录计数。先画一个明确步骤，不把整个向导拼在一张图。
```

### 导入详情

```text
设计已完成的工业零件检测数据导入详情。上部为名称、成功状态与返回；阶段、类别、划分、校验报告和生成版本顺序清楚。1200 张图片，train 960、val 240，test 未配置。主要下一步为查看版本或创建导出。来源 ZIP、导入时间、完整路径在次级详情可复制。
删除按钮针对导入记录及受控暂存文件，保留数据集版本、图片、标注。警告不等于导入失败。错误长内容和原始元数据可展开，右侧如打开详情必须有关闭按钮。
```

### 创建导出

```text
设计创建数据导出表单。先选来源版本，再选任务/模型或目标格式，然后显示类别、划分和兼容性检查。明确这是训练输入文件准备；train、val、可选 test 依所选后端规则检查，不修改源版本。预计体积只标估算，包内文件预览是摘要，硬链接等内部细节不占主视图。
参数摘要位于表单底部，必要详细检查使用可关闭抽屉，不固定挤占右半屏。底部取消、创建导出，提交后显示后台任务和详情入口。
```

### 导出详情

```text
设计成功的数据集导出详情。来源版本、目标格式、任务、类别和划分摘要位于上部，主体为文件列表与必要校验结果，下载和用此导出创建训练是主要下一步。长路径、完整 checksum 和元数据可展开复制，避免满屏技术文本。
删除导出记录/产物与删除源版本分开，已有训练引用时按真实契约说明约束。失败变体保留来源、失败阶段和安全产物，不显示可用的训练按钮。
```

## D04 版本与样本工作区

- 来源：[旧样本网格](../generated/bak1/02-datasets/D04_dataset-version_light_samples_v01.png)。
- 容器：从管理数据集“打开”进入完整工作区；样本详情抽屉默认关闭。
- 属性：目标扩展，依赖样本 API、分页和缩略图。
- 状态：加载、空版本、无匹配、缺图、分页、无权、图像解码失败。

```text
设计数据集版本的只读样本工作区。保留旧图高密度样本网格和筛选的布局：正文资源名称与返回、版本摘要、局部标签样本/类别与划分/质量/来源；当前样本页用 split、类别、空标注筛选、网格/列表切换与分页。
主体是等比例工业样本缩略图，选中项边框清楚。右侧详情仅在主动打开时覆盖显示图像尺寸、split、对象列表和来源，并有关闭按钮。真值框显示类别和坐标，不添加模型置信度。复杂审阅进入大图，不把每张缩略图嵌入独立大卡片。
```

## D05 样本详情与标注查看

- 来源：旧 D04 图像检查区。
- 容器：专用大图/全幅工作区；不是标注制作器。
- 属性：规划，复用已有图像查看器并补数据契约。

```text
设计样本详情大图。主区域为原始比例图片与真值叠加，工具仅缩放、平移、适配、上一张/下一张和叠加显隐。按任务显示 boxes、masks、keypoints 或 OBB，不将它们混合成同一类标注。
对象列表可收起；选中行高亮对应几何。图片尺寸、split、类别和来源可查，错误标注有定位与原因；损坏图片显示局部错误，不用其他样本代替。不显示预测置信度，也不添加未实现的内建标注绘制工具。
```

## D06 类别、标注与数据划分

- 来源：旧 D03/D04 类别和划分信息；目标扩展。
- 容器：版本工作区局部页；修改作为派生版本操作，不原地改发布数据。

```text
设计数据版本的类别与划分页面。用清楚表格分别列类别名称、样本数、对象数、train/val/test 分布；缺失标注、空标注和未标注分开。选择类别可跳到对应样本筛选。
映射类别或调整划分属于显式创建派生版本，先显示规则、影响计数和检查，确认后提交后台任务；不能用一键按钮原地改已有版本。总计与各 split 自洽。未实现能力在设计图说明中标为规划，普通界面不展示内部实体教程。
```

## D07 质量检查

- 来源：旧导入校验和样本问题信息，扩展成版本质量工作区。
- 属性：规划，检查规则、任务、问题索引需 API 支持。

```text
设计数据质量检查页面。先呈现检查范围、规则和本次状态；报告按损坏图片、缺标注、非法坐标、类别问题、重复候选分组，主体为问题表和定位样本入口。当前只展开一种问题，选中行能看原图和定位信息。
问题数量和检查覆盖数量分开；尚未扫描不能显示无问题；重复候选不能自动判为应删除。检查取消或部分失败保留覆盖范围。修复是明确操作并生成可追溯版本，不自动删除或改写数据。
```

## D08 版本与来源

- 来源：旧版本和导出来源关系；目标扩展。
- 容器：版本工作区局部页，比较或依赖为按需抽屉。

```text
设计数据版本来源页面。以紧凑列表或简单关系图呈现导入来源、派生规则、时间与后续导出/训练引用，保持来源方向清楚。当前只读版本与准备创建的派生版本分开。
比较显示样本、类别和划分的具体变化，不只显示两个版本号。缺少可比较信息时说明原因；外部引用阻止删除时列出相关对象入口，不提供绕过引用的强制删除。不要暗示当前已经具备完整版本化数据管理。
```
