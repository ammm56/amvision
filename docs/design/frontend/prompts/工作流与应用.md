# Workflow 与应用：页面设计与提示词

继承[通用要求](通用要求.md)。依据[视觉扩展](../workflow-vision-ui-plan.md)和[当前页面规格](../page-specifications.md)。节点名、端口、连线以实际 Catalog/Workflow 文档为准。

## W01 应用列表与详情

- 来源：[应用列表](../generated/bak1/05-workflows-integrations/W01_flow-application-list_light_runtime-health_v01.png)、[空态](../generated/bak1/05-workflows-integrations/W01_flow-application-list_light_empty_v01.png)、[应用详情](../generated/bak1/05-workflows-integrations/W02_flow-application-detail_light_contract-runtimes_v01.png)、[故障详情](../generated/bak1/05-workflows-integrations/W02_flow-application-detail_light_failed_v01.png)。
- 保留：应用、版本、Runtime、Trigger 关系和运行入口。
- 修正：草稿应用可存在，长应用 ID 不放列表；业务 NG 不等于 Runtime 故障。
- 容器：列表、应用详情页、运行实例详情抽屉。

```text
设计 Workflow 应用列表。左侧应用选中，正文提供创建、导入、搜索和状态筛选。表格显示应用名称、草稿/发布状态、最新发布版本、运行实例数、触发数、更新时间和操作，名称下不重复 workflow-app 长 ID。打开图编辑器和详情是清楚的行操作。
详情页先呈现应用输入输出与发布版本，然后是运行实例和关联触发入口；选中实例用品牌软底，普通悬停中性灰。实例详情右侧覆盖展开，可关闭，显示接口、诊断和最近调用。业务 NG、一次调用失败、实例不可用分开。未发布应用也可以编辑，不凭空添加主备自动切换或 ZeroMQ 自动重投。
```

## W02 草稿、发布与历史

- 来源：旧应用详情的版本内容和当前编辑器版本管理契约。
- 容器：编辑器局部操作、发布对话框、历史抽屉。
- 状态：已保存/未保存、发布检查失败、历史加载、有未保存修改、引用失效。

```text
设计 Workflow 发布与历史版本界面，背景为已有图编辑器。发布对话框先显示版本说明、公开输入输出变化和依赖检查，确认后创建明确版本；不暗示保存草稿就切换生产 Runtime。
历史列表显示版本、时间、状态和载入动作，选中后可载入当前编辑画布；存在未保存修改时按现有保护流程处理。不新建另一套历史只读画布、自动备份或任意双版本差异功能。完整 ID 位于必要详情，界面名称短而直接。
```

## W03 图编辑与 Preview

- 来源：[旧图编辑](../generated/bak1/05-workflows-integrations/W03_workflow-editor_dark_preview-success_v01.png)、[窄屏编辑器](../generated/bak1/05-workflows-integrations/W03_workflow-editor_dark_narrow-1366x768_v01.png)。
- 保留：大画布、节点库、端口、节点组、属性和结果。
- 修正：全局顶栏取消；局部动作浮于画布；无未经实现的撤销/重做；图示必须有真实连线依据。
- 容器：可收起编辑面板，不是模态资源抽屉。
- 状态：空图、多选/组复制、运行中、成功、失败、只读、输入未填。

```text
设计 Workflow 图编辑器，左侧仍是简洁应用导航，图编辑选中。画布占满其余空间，图名、保存状态、预览、保存、发布、应用模式配置等局部工具位于画布边缘，不新增横跨全站的顶部栏。
节点库可展开，属性面板与结果可收起；不能遮罩锁死画布。画布使用低对比网格、清楚端口、连线与节点组。采用提供的真实 Workflow 节点和连线，模型节点引用已部署服务，不显示再次加载权重的配置。多选节点及完整组有清楚选择边界。
Preview 按节点显示本次状态、耗时和已收到的图片/值，失败定位到具体节点；原图输入和算法结果分开。没有本次结果时不补旧 OK。示例耗时必须来自样例记录，未知则省略。亮暗主题同时适配画布、节点、菜单和属性面板。
```

## W04 节点参数与结果编辑

- 来源：旧节点属性和当前 File Summary、Count By Rules、Value Display 等专属编辑器。
- 容器：节点内简洁字段＋按需专业编辑器。
- 状态：未应用/已应用、校验错误、无结果、过期结果、下拉展开、窄窗口。

```text
设计节点专属参数编辑界面。短字段直接显示；规则列表采用行列明确的表格编辑，不让下拉菜单被节点裁切。Source Path 表示 JSON 字段路径，不是磁盘文件路径；File Summary 的单批记录、MB、整数秒限额不冒充整个文件总量上限。
Value Display 的字段色与 OK/NG 状态色提供颜色选择器，每项字号和面板大小可配置，默认值保持已有行为。普通应用、取消、恢复默认、展开/收起按界面语言显示；节点正式英文名称保留。
节点内结果以可读摘要为主，复杂结果点击放大。参数修改与应用、预览执行、保存、发布边界清楚，不因打开编辑器自动改生产配置。
```

## W05 Runtime 运行监视

- 来源：旧图编辑布局；承载当前发布图只读观察语义。
- 状态：等待结果、执行完成、调用失败、断线、显示失败；不伪造逐节点实时运行进度。

```text
设计 Runtime 运行监视。正文为只读发布画布，保留必要的应用名称、返回、适配和面板开关，删除顶部堆叠的发布版本长 ID、generation 与 Runtime ID。画布、节点、菜单和结果同时响应亮暗主题。
本次执行完成后展示对应结果，未取得新结果时说明等待或结果时间，不将编辑态 Preview 的逐节点动画套给生产 Runtime。不能拖改发布图、参数或连线。技术身份可在详情复制，业务 NG 与执行失败分开。
```

## W06 App Mode 配置与显示

- 来源：当前应用模式及 Value Display 明确连线约定，非旧图独立新系统。
- 容器：编辑器内配置；运行页按配置呈现公开输入与结果栏目。
- 状态：纯图片、有显式数据绑定、多图、未执行、显示故障、只读。

```text
设计应用模式及其配置。配置名称为应用模式配置，不叫应用模式布局；栏目选择清楚显示图片、值或表格名称，不堆 Image Preview、core_io_image_preview、Body 等技术信息。
运行页面以图片结果为主。仅在图片明确连接 Display Data 时，在该图片左上角显示半透明垂直面板：OK/NG、生产总数、良品数量、不良数量、良品率，颜色、字号、面板大小服从 Value Display 配置。未关联图片只显示图片。独立 Value Display 栏目开关只控制该栏目，不能被误解成节点禁用或图片绑定开关。
公开输入按应用契约显示，配置不新增独立页面设计器。业务计数不从图片数量推断，NG/OK 规则由上游流程提供。缺值用暂无，不能以0代替缺测。
```

## W07 大图与大视图

- 来源：当前图像预览扩大视图，3D 属于目标扩展。
- 容器：专用全幅查看器，返回保持原页面位置。
- 状态：绑定/未绑定显示数据、解码失败、原始数据缺失、显示过期。

```text
设计图片双击后的专用大图界面。画布居中适配原图比例，缩放、平移、适配、关闭/返回动作简洁；同次结果中已绑定的 OK/NG 和生产数据仍在左上角垂直显示，半透明背景和字号遵循节点配置。没有绑定就没有统计面板。
保留原页面的结果身份、表格选择与叠加层，不重新执行工作流，不把缩放显示图当成原始测量数据。3D 大视图沿用相同的返回和数据绑定规则，点云单位、轴向和图例仍可见；不得用一张二维截图冒充可交互点云。
```
