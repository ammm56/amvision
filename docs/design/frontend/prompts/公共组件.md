## G03 控件、状态与危险操作

- 来源：旧 G03–G06 状态板；这些是设计参考，不是业务页面。
- 修正：真实状态与容量分开；删除规则逐资源区分，不能一律手输 ID。
- 状态：默认/悬停/选中/焦点/禁用/错误、列表空/无匹配/加载/断线、有限任务/长期实例。

### 控件状态

```text
生成一张中文公共控件状态板，明确这是设计参考。按按钮、输入、下拉、单选、多选、表格行、标签与错误提示分组，展示默认、悬停、选中、键盘焦点、禁用和错误。普通悬停与输入焦点中性灰；选中、主操作、勾选品牌绿；主按钮白字。
下拉收起值与多选标签中性，菜单选中项品牌软底，悬停与选中不能相同。亮暗分别生成，使用同样控件、文案和顺序，不在一张图塞入完整业务导航和多个业务页面。
```

### 列表与生命周期

```text
生成资源状态设计参考，保留相同表头和筛选结构，比较首次加载、无数据、筛选无结果和断线旧数据。空态给直接下一步，断线标明最后更新时间，不承诺无实现的离线缓存。
分别展示有限任务的等待、执行、成功、失败、取消，以及长期实例的停止、启动、运行、故障。只呈现实际状态语义，不将满载/正在工作等同于未就绪，也不为同步链路添加队列深度。颜色同时配文字与图标。
```

### 删除与停止

```text
生成危险操作组件参考，显示对象名称、具体影响范围、引用阻止原因、取消和明确动作。区分删除导入记录、删除数据版本、删除导出文件、停止部署、删除 Runtime、禁用节点包；不使用一套模糊删除提示。
删除导入记录保留版本和数据；删除版本清理图片标注及关联记录且外部引用阻止；停止可恢复，禁用不删除文件。是否手输名称依真实风险，不为所有动作强制输入长 ID。取消不被弱化，阻断条件存在时动作禁用。
```
