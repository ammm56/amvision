# 界面生成通用要求

更新：2026-10-25。与[设计系统](../design-system.md)、[修订要求](../redesign-brief.md)一致。所有页面提示词继承本文件；历史提示词中的独立顶栏、分组导航、旧暗绿色及“只遮主区、导航不受遮罩影响”不再生效。

## 1. 固定基础提示词

```text
为 AMVAR 本地优先工业视觉工作台生成一张高保真桌面 Web UI 设计图。使用中文描述和中文普通界面文案；AMVAR、Vision、Workflow、Runtime、Trigger、YOLO、ONNX、OpenVINO、TensorRT、CUDA、SDK、JSON、ROI、PIN 等专有名称保持英文。节点名称和公开参数沿用其正式名称，不任意翻译或改名。

这是专业工作站：清楚的表格、参数、图像、节点和结果优先。保留所附 bak1 旧图中该页面合理的内容结构和使用流程，按明确修正项调整。不要照搬当前已实现页面的排版，不要把项目列表结构套到其他业务页。

以未来完整产品能力设计页面，不因现有接口、字段、路由尚未实现删掉合理功能。当前代码仅用于记录开发差距，目标页面不显示开发进度或API缺失说明。依然遵守项目真实定位和架构边界，不添加无关的通用SaaS功能。

设计视口以 1920×1080 为参照，平视完整应用画面，无浏览器框、设备模型和外部背景。字体可读，间距有序，图像保持原始比例；文字太多时减少当前展开内容或使用合理滚动，不能缩成不可读小字。实际生成像素与设计视口分别记录。

左侧为简洁导航，展开约 220–232px，顶部 AMVAR 加品牌绿底白字的 Vision 词缀，展开时不另放图标。依次为项目、任务、数据集、模型、部署、推理、图编辑、应用、集成、节点、设置，均为平级入口，无分类标题，无全局项目选择器。展开状态的折叠按钮位于品牌右侧；折叠状态顶部仅保留AM Logo，点击Logo展开，不能另画一个展开按钮。正常静态图不显示悬停替换图标。底部仅保留账号。只有当前页面所属入口为选中态。

页面没有独立全局顶栏，不放全局搜索、面包屑、账号、项目切换、系统状态组成的顶部横栏。搜索、局部类别和动作在本页内容区自然排列，不恢复重复页面大标题和空标题高度。资源名称、抽屉标题、对话框标题、编辑器局部操作仍保留。

资源详情默认关闭；打开时是从右侧覆盖主内容的可关闭抽屉，有标题、关闭按钮和轻遮罩，底层列表列宽与位置不重排，抽屉关闭不留空白占位。数据集管理以列表和完整版本工作区承载，导入/导出长流程和详细报告使用完整页面；短元数据表单按需用抽屉，危险确认和部署导入等使用适合的对话框。图编辑器的节点库、属性和结果使用可收起的编辑面板，不能误改成阻断画布操作的模态抽屉。样本审阅和大图是完整工作区，不能一律挤入抽屉。

模态资源抽屉和对话框使用一个覆盖整个底层工作台的中性黑色半透明遮罩，包含品牌、左侧导航、底部账号和中间页面；导航不能绕过遮罩。亮色建议rgba(0,0,0,0.28)，暗色建议rgba(0,0,0,0.36)，以统一组件实际核对；图稿不作为精确透明度样本。保留表面原有轻微色差，不将背景抹成不透明灰块，不叠加多层遮罩，不使抽屉本身变暗。底层不可操作，关闭恢复来源焦点；有草稿先确认放弃。

需要与图像联动的样本/对象检查面板是非模态覆盖面板：整个工作台都不加遮罩，允许图像缩放、对象选择及面板联动，不限制焦点只能在面板内。它仍可关闭、不占固定右列。资源抽屉与图像检查面板必须在场景规格中标明，不能用“只给中间加遮罩”混合两种行为。

明确规划为独立页面的项目概览、任务详情和应用详情使用完整主区；上面的抽屉规则适用于按需补充信息与短表单，不用于取消这些独立页面。项目列表“查看”进入项目概览，主页面中的项目信息再按需打开抽屉。

亮暗主题使用同一布局、相同数据、相同行顺序和相同展开状态。品牌色均为 #00D992，主按钮白字，单选/多选选中使用品牌绿；普通悬停、输入焦点采用中性灰，与选中态明显区分。下拉收起值和多选标签为中性，菜单选中项可用品牌软底。状态颜色同时配文字或图标。

控件约 36–40px 高，表格常规行约 44px，间距以 4px 为基础，圆角主要为 4–8px。用留白、对齐与细分隔线分组，浮层才用轻阴影，不将每块内容包进大卡片。图标采用一致线性风格。

普通导航、工具按钮、返回/关闭/排序/折叠、文件夹和文件图标均使用中性灰线条，与正文同一灰阶，不使用蓝色、靛蓝、紫色或彩色实心文件夹。亮色标题 #202020、正文 #3D3D3D、辅助 #707070、普通图标 #626262，均为纯中性灰；暗色正文 #F2F2F2、普通图标 #A7A7A7。只有选中项及主要动作采用 #00D992，主按钮图标为白色；成功/警告/错误按实际状态配色。目录树选中行使用品牌软底与品牌色图标，未选中目录与文件保持灰色。普通说明使用灰色信息图标和中性背景，不画无必要的蓝色提示横幅。图像标注的类别色与界面图标色分开，不能因修正图标而把类别框改成灰色。

示例数据只用于设计；业务样例日期固定为 2026-10-23，与本轮文档更新日期分开。保持样本数、划分数、图中对象数、统计和阶段时间自洽；未知指标写暂无数据，不伪造精度、耗时或成功。所有静态示例与正式测试证据分开。

生成当前指定的一个页面状态，不把多个页面拼成海报。除组件状态板外，不同时展现所有空态、错误和成功。禁止营销大屏、装饰 KPI、蓝紫霓虹、玻璃球、服务器插画、无意义图表、重复按钮、长 ID 堆叠以及固定右侧详情分栏。
```

## 2. 主题补充提示词

### 亮色

```text
使用亮色外观：页面 #F6F7F9、主表面 #FFFFFF、次表面 #ECEFF2、强文字 #202020、正文 #3D3D3D、次要文字 #707070、细边框 #E4E7EC。主色固定 #00D992，主按钮和品牌词缀为白字。普通悬停和焦点是中性灰，不用旧暗绿色，也不将所有文字染绿。图片内容及数据叠加保留自身颜色。
```

### 暗色配对

```text
以本页已检查的亮色图为布局和数据参考，只切换暗色外观：页面 #101010、主表面 #171918、次表面 #242825、强文字 #FFFFFF、正文 #F2F2F2、次要文字 #A7B0AB、细边框 #3D3A39。品牌仍为 #00D992，主按钮白字；普通悬停和焦点为中性灰。保持字段、行数、内容顺序、图片、抽屉状态和几何位置不变，不擅自增减控件或重写数据。图片本身不加暗色滤镜。
```

## 3. 状态与窄屏补充

| 状态 | 补充要求 |
| --- | --- |
| 空列表 | 保留入口和筛选，说明下一步；不画空分页、重复零指标和无依据的导入按钮 |
| 无匹配 | 保留筛选值，提供清除筛选；与首次无数据区别 |
| 加载 | 局部行骨架；未知工作量不用假百分比；已有结果不随刷新清空 |
| 失败 | 原因、失败步骤、有效恢复动作；完整错误次级展开，不满屏红底 |
| 断线 | 明确最后更新时间和显示数据已过期；无数据不冒称有离线缓存 |
| 只读 | 查看路径保留，写动作按实际权限禁用或隐藏，原因简短 |
| 模态抽屉打开 | 覆盖主区，整屏底层共用单一遮罩，右上关闭、正文滚动、必要底部动作；底层宽度不变且不可操作 |
| 图像检查面板打开 | 非模态覆盖面板，导航和图像均无遮罩；可联动选对象、缩放和平移，关闭不留占位 |
| 窄屏 | 1366×768；按指定状态收起导航，次要列可隐藏，抽屉覆盖；不缩小文字或转成手机页面 |
| 大视图 | 图像/点云为主体，保留同次结果和显式数据绑定；不是重新执行 |

## 4. 功能与参考边界

- 旧图负责页面内容结构；项目新图只负责已确认的导航和样式。每次出图记录两者的角色。
- 新增页面按目标规格设计，并在清单注明规划能力和依赖。当前 UI 只用于核对字段、入口与已实现能力。
- 通用字段用直观中文；ModelBuild、node_type_id、generation 等内部信息放必要详情，不成为普通列表主标题。
- Preview、Runtime、Trigger、业务 OK/NG 和服务健康分别表达。模型节点引用部署服务；同步数据面不画队列、自动重投或无依据的等待。
- 连接器和 3D 的数值需有样例依据。合成图可用于开发，不能写“实物精度已验收”。
- 亮色品牌白字的对比度风险在设计记录中注明，不擅自改回暗绿；实际实现应核对字号、控件边界、非颜色提示及可达性。
