# 项目与任务：页面设计与提示词

统一使用[通用要求](通用要求.md)。当前页面与目标功能见[页面规划](../navigation-and-page-plan.md)。新建抽屉不是固定右列。项目信息/编辑/SDK/删除及异常状态的完整定义见[项目操作与状态](项目操作与状态.md)，P04–P06 不增加导航项。

## P01 项目列表与创建

- 来源：[旧项目列表](../generated/bak1/01-projects-tasks/P01_project-list_light_drawer_v01.png)、[旧项目概览](../generated/bak1/01-projects-tasks/P02_project-overview_light_active_v01.png)。当前中文设计见[项目总览](../generated/项目/设计总览.html)，新版待审阅。
- 保留：项目表格、当前项目、创建和 SDK 动作；“查看”进入独立 P03 项目概览。
- 修正：长 ID 放详情；新建表单不出现既有项目删除警告；不增加强制 KPI 首页。
- 容器：列表为主区，新建/简短项目信息为按需抽屉；项目概览不是列表抽屉。基本管理已有，额外资源计数、更新时间和独立查看页按契约补齐。
- 状态：列表有数据/空态/长名称、抽屉开关、无权、删除被引用阻止。

```text
设计项目列表。保持已确认的项目页面布局与主题。左侧项目选中，内容区搜索项目；右侧动作是生成 SDK 配置包、刷新和新建项目。主表格按项目名称、说明、必要资源摘要、更新时间、操作排列，选中行品牌软底并标记当前项目，悬停行中性灰。使用产线视觉验证、包装缺陷检查、连接器二维测量作为设计样例名称，不增加装饰统计。仅一页时隐藏前后翻页按钮或明确禁用。更新时间是项目元数据修改时间；没有可靠值显示—。
本次若为新建状态，从右侧覆盖展开新建项目抽屉，仅显示项目名称、项目说明、取消和创建；补关闭按钮，底层列表不缩窄。简短项目信息包含来源和可复制的完整 ID；操作栏“查看”则进入独立项目概览，不在当前列表展开大型固定详情列。删除依赖仅在实际删除操作时出现。无项目状态只保留清楚的创建引导。独立状态使用项目补充状态文档，不把所有状态混画在一起。
```

## P02 SDK 配置包

- 来源：旧项目图的 SDK 区；补充当前目录监听说明。
- 容器：项目动作打开独立对话框；不把配置清单塞入项目主列表。
- 状态：生成前资源清单、生成中、成功下载、失败、没有可调用资源。

```text
设计生成 SDK 配置包对话框。显示所属项目、服务地址、Workflow Runtime/调用型 Trigger/模型调用配置数量，以及预览的配置文件清单。默认全部可调用资源，“调整范围”在同一对话框中选择资源并联动必要依赖，再回到文件预览；接口缺口单列为开发要求。主操作为生成并下载，下载触发后显示“已开始下载”，不声称用户磁盘已写入完成。
目录监听触发源不以黄色警告或运行异常呈现，普通说明为“目录监听触发源由后端自动执行，无需 SDK 调用配置，已省略。”没有可调用配置时说明前置步骤并禁用生成；生成失败保留上下文和原因。凭据只说明是否包含，不显示token。
```

## P03 项目查看 / 项目概览

- 来源：[旧项目概览](../generated/bak1/01-projects-tasks/P02_project-overview_light_active_v01.png)；完整规格见[项目查看页面设计](../project-overview-design.md)。旧图 P02 对应本次 P03，当前 P02 仍为 SDK 配置包。
- 保留：项目内资源入口、最近资源、当前运行和继续工作；改为紧凑的正文组织。
- 修正：删旧顶栏、巨大统计卡片、内部类型名、无依据运行时长及队列告警；区分有限任务与常驻服务。
- 容器：由列表“查看”进入独立主页面，目标 `/projects/:projectId`；不增加导航项。项目信息/编辑仍按需打开可关闭抽屉。
- 状态：主视图亮暗配对；随后补空项目、长名称、部分失败、无权限、资源失效和窄屏。
- 能力：新页面规划，当前仅有项目列表和部分 summary；模型实体计数、跨资源最近更新、元数据更新和可靠深链接须补齐契约。图中数值仅为设计样例。

```text
设计从项目列表“查看”进入的项目概览，完整主内容页，左侧仍仅“项目”选中。参考旧 P02 的最近资源、当前运行、继续工作结构，导航和主题沿用已确认项目母版。没有全局顶栏、项目选择器或新增导航，不把该页做成列表右侧详情。
正文顶部左侧为返回箭头、项目名称“产线视觉验证”和说明“包装、托盘与条码联合检测”，右侧为同级次按钮项目信息、编辑项目和生成 SDK 配置包；只有进入 SDK 对话框后生成并下载才是主动作。完整 ID 等在按需抽屉中，当前抽屉关闭。资源名称不是重复页面大标题。
下面是一个紧凑的四等分资源入口条：数据集 12、模型 8、应用 5、部署 4，每项有进入箭头。计数使用适度字号，不做装饰 KPI、趋势或大图标。
主体以约 58:42 的两个普通内容模块呈现“最近更新”和“当前运行”。最近更新使用名称/类型、状态、更新时间及进入箭头，四条示例是工业零件检测（数据集导出、已完成、2026-10-23 10:32）、YOLO11 包装缺陷（模型版本、已创建、2026-10-23 09:18）、TensorRT FP16（模型转换、已完成、2026-10-22 16:47）、包装缺陷检测（应用版本、已发布、2026-10-22 15:22）。右上有查看全部；不画事件轴或虚构模型评分。
当前运行分成“正在执行的任务”和“常驻服务”：YOLO11 包装缺陷显示训练中、epoch 37/100、37% 的真实比例示例进度条；常驻服务显示包装缺陷推理（部署实例、运行中）和包装缺陷检测（Runtime、运行中）。常驻服务不使用进度条，不添加虚构 uptime、队列或自动重试提示。任务小节以“任务”跳转任务列表，服务小节分别以“部署”和“应用”跳转相应模块，不放含义不明的合并“查看全部”；链接统一品牌绿。
底部“继续工作”只是一行轻量动作：导入数据集、创建训练、创建部署、新建工作流。没有自动选择最新资源，没有四个大型装饰卡片。两块正文与底部动作形成清楚层级，保留舒适留白。主图未打开抽屉，也没有固定右侧详情栏。亮暗图的数据、行序、组件和布局完全相同。
```

## T01 任务列表

- 来源：[运行任务](../generated/bak1/01-projects-tasks/T01_task-center_light_running_v01.png)、[失败任务](../generated/bak1/01-projects-tasks/T01_task-center_light_failed_v01.png)、[空态](../generated/bak1/01-projects-tasks/T01_task-center_light_empty_v01.png)。
- 保留：类型/状态筛选、阶段进度、关联资源和详情入口。
- 修正：只列有限任务；不混入常驻部署或 Runtime；删重复零统计和架构教程。
- 容器：全宽列表，选中详情为可关抽屉，也可进入任务详情页。

```text
设计任务列表，左侧任务选中。局部筛选包含项目、类型、状态、时间和搜索，主体紧凑表格显示任务名称、类型、关联资源、阶段、进度、开始时间、耗时和操作。主场景为训练运行中、数据导入成功、转换失败三类任务；未知总量只显示阶段，不虚构进度或 ETA。
详情从行操作打开右侧覆盖抽屉，包含状态、阶段、简短错误或产物和打开详情。取消只对可取消的任务显示。没有通用新建任务按钮，没有把常驻实例画成待完成任务。失败强调错误摘要，不将整行涂红。
```

## T02 任务详情

- 来源：[转换失败任务](../generated/bak1/01-projects-tasks/T02_task-detail_light_conversion-failed_v01.png)。
- 保留：事件顺序、原因、来源和安全产物。
- 修正：版本名正确、时间一致；不默认出现自动重试；原始 JSON 次级展开。
- 状态：等待/执行/成功/失败/取消，未知进度、产物部分可用、日志加载失败。

```text
设计失败的模型转换任务详情，采用正文中的资源名称、状态和返回入口，不增加全局顶栏。上部先给失败阶段、原因与有效处理入口，再显示任务摘要和阶段时间线；下部为输出文件与日志，原始请求和响应折叠。
TensorRT Python 包版本不能写成 Python 解释器版本。成功步骤与失败位置明确，耗时相加合理；没有实际恢复策略时不画自动重试倒计时。打开来源模型、复制错误、查看日志是清楚的次操作。若生成运行状态，曲线和进度只到已完成位置。
```
