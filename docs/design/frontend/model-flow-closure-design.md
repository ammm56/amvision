# 模型操作去向与提交状态设计

更新：2026-10-26。本轮接续83组静态稿，针对操作入口、去向及状态确认重新核对。已修订1组、增加7组，累计90组、180张；本轮16张已逐张内部检查，待用户审阅。本轮不修改产品代码。

## 1. 核对发现

| 问题 | 影响 | 修正 |
| --- | --- | --- |
| 导出详情说明可回到导出记录，但列表没有入口 | 关闭面板后找不到生成中的任务 | 转换与导入顶部增加次要“导出记录”按钮，打开分页能力可扩展的抽屉，不增第五导航 |
| 校验失败只有查看差异按钮 | 无法理解数值偏差和失败规则 | 独立输出差异抽屉，与原任务输出、阈值和样本绑定 |
| 提交响应未知只有文字规则 | 容易重新提交重复任务 | 补确认中的完整向导；查询结果与创建任务分开 |
| 取消终态已有图，但缺确认入口 | 易误认为点击就已停止或删除产物 | 补确认模态，随后复用正在取消和已取消状态 |
| 导入检查通过与登记成功未充分区分 | 写文件失败容易被理解为已创建可用版本 | 补结果页失败状态，既有版本保留，失败文件不提供部署 |
| 首次没有模型只写复用规则 | 容易与筛选无结果混淆 | 独立首次空页，入口不重复 |
| 错误样本大图有图，列表入口未展开 | 无法核对筛选、对象和样本导航 | 补错误样本列表，与大图往返保留上下文 |

## 2. 交互约束

- 导出记录沿用“转换与导入”入口。表格区仍先转换、后导入，导入按钮仍在导入区；导出记录用短列表抽屉，记录变多时分页。详情替换抽屉内容并提供返回列表，不叠两层亮色抽屉和遮罩。
- 导出任务状态与导出文件状态分开。正在生成、失败、文件已清理均不可下载；关闭抽屉不取消。重新生成从详情明确发起新任务，检查源文件仍存在，不使用旧ZIP冒充本次生成。
- 数值差异来自本次校验记录，不由前端重新推理；本例0.732与0.720绝对差0.012，大于0.005。数值校验与任务精度评估不是同一概念。
- 响应中断后通过提交关联信息查询结果；查询到已有任务时打开详情。未查询到不等于确认未创建，不立即开放重复提交。只有后端明确确认未创建才能恢复提交。结果待确认时本次提交摘要只读，状态提示持续显示。这里不设计资源等待队列，也不改变Runtime/Trigger立即容量拒绝。
- 取消确认后禁用重复取消，保持最近进度；断线提示结果待确认。任务若先完成，显示真实已完成状态，不强写已取消。已取消保留已生成文件不等于登记新版本。
- 导入执行失败保留原项目模型与版本。暂存包有效时重新检查，失效时重新选文件，均新建显式任务；失败暂存清理范围与原模型资源分开。
- 错误样本列表的2张是明确选定的子集，不推导240图报告的P/R；对象级FP/FN与图像读取错误分开。大图返回保留筛选、当前页和滚动。不同任务按自己的错误类型呈现，不硬套检测FP/FN。
- 初次空态没有搜索、分页或零值KPI；已有模型经筛选为空仍使用保留筛选条件的共用状态。
- 按钮名称和交互状态使用中文，模型/框架/格式名称保留English；普通图标中性灰，品牌、危险和警告各有语义。
- 通用加载、断线、只读、取消中、保存冲突继续复用现有组件板。所有失败/已取消组合不再机械复制相同结构；新的数据语义和布局才需要独立代表图。
- 无权限时保留查看入口，写操作禁用并给出原因；删除前再次查引用、成功后恢复列表位置等沿用已有生命周期规范。
