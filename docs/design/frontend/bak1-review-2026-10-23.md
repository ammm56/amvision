## 1. 结论与证据

旧图的列表、筛选、任务诊断、资源追溯、参数分组、图画布和图像结果等主体结构大多可以继续使用。统一修正外壳和组件，并逐项纠正错误字段、示例与功能暗示；不整体推翻旧稿。

当前导航与色彩另以开发页面 `http://127.0.0.1:5601/projects` 和 `frontend/web-ui/src/shared/styles/tokens/brand.css` 等主题源码核对。当前页面只作为简洁导航和现行主题的证据，不替代旧稿主体结构。当前导航截图保存在新批次的 `references/current-navigation.png`。

- **导航**：项目、任务、数据集、模型、部署、推理、图编辑、应用、集成、节点、设置，11 个平级入口，无功能域标题或新五入口合并。
- **顶部**：没有独立全局栏，不恢复全局搜索、项目切换、状态、账号组合的顶部横栏。页面操作属于正文，普通页不恢复重复 h1。
- **抽屉**：旧宽屏右侧为展开状态；默认关闭，关闭后主内容全宽。新图用覆盖式抽屉、背景遮罩、标题和关闭按钮明确表示。图编辑属性/预览面板仍按编辑器自己的可收起面板处理。
- **主题**：品牌均为 `#00D992`，主按钮白字；普通 hover 和输入 focus 为中性色；selected 使用品牌软底。亮暗配对仅替换现有 token，不改变数据与布局。
- **状态**：业务 OK/NG、调用成功/失败、实例健康、满载拒绝分别表达；不凭设计新增同步链路队列、自动重投或模型节点加载模型。
- **规划边界**：数据集样本管理、独立评估等目标页面与当前功能区别标明；异常/连接器/3D 继续在 Workflow、节点包和专业节点 UI 中扩展。

## 3. 新母版范围

使用旧 P01 项目列表的资源表格与新建项目流程作为代表：保留项目名称、描述、资源数量、更新时间与操作；移除重复长 ID、无依据统计及新建表单中的删除依赖警告。SDK 配置包作为项目动作保留，具体导出配置由其自己的操作流程承载。

制作同一页面、同一组设计样例的亮色/暗色母版，并分别提供抽屉关闭/展开图。它们是同一视觉体系的四个状态，不是四个互相竞争的设计方案。样例名称与数量只用于视觉设计，不属于实际生产数据。

批次：`generated/项目/`。生成后逐张核对：导航顺序、无独立顶栏、主内容全宽、抽屉关闭入口与底部动作、亮暗数据一致、既定主色、文字与表单对齐。实际图片尺寸与目标 1920×1080 分开记录；栅格生成图不作为精确 CSS 或交互验收。
