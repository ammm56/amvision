# 设置状态覆盖与后续范围

更新：2026-11-02。28组56张有效图；静态图、本地原型、产品代码和真实异常验收分别记录。

| 页面 | 已有配对图与本地验证 | 剩余独立分支 |
|---|---|---|
| 偏好 | 正常页、主题切换、通用focus | 保存失败、完整英文、减少动态效果 |
| 启动页面 | 应用模式、项目页面、失效目标、离开确认；停止实例可选、无实例禁用、保存、恢复默认 | 无权限/无应用模式、保存失败/结果未知 |
| 运行状态 | 正常、首次加载、Worker部分异常、断线待确认、短屏、技术与消费者明细展开；刷新与Logo展开 | 整体就绪摘要扩展 |
| 关于 | 正常、通用长文本与链接样式 | 未知版本、减少动态效果验证 |
| 系统信息 | 正常及长路径字段、磁盘不重复累计 | 路径读取失败、容量未知、复制失败 |
| Python运行时 | 正常、NVIDIA profile依赖异常 | 随包Python、技术详情展开图 |
| 设备信息 | NVIDIA正常、CPU-only；安装与可用分离，可选NPU中性 | 驱动探测失败、要求NPU但不可用 |
| 会话与权限 | 正常页及通用折叠/表格 | 无项目、会话失效、权限收窄、长列表 |
| 用户管理 | 正常、创建、权限、Token表单/结果、密码重置、删除/撤销确认、只读、创建短屏；校验、指定撤销、Tab/Esc、滚动 | 普通用户启停确认、保护原因、过期Token、空/长列表、提交失败/结果未知 |
| 维护与诊断（未来） | 未出图 | 受管理目录、引用阻止、部分失败、脱敏导出和记录；生产JSONL不当缓存 |

正常状态使用短标签和值，异常给短原因和直接操作，技术细节按需展开。确认弹窗保留当前形态，遮罩覆盖完整背景且不挤压。短屏Logo展开，无独立展开图标；正文滚动，弹窗底部操作可达，表格横滚限于自身。未知数据不显示假成功、假0或假检查时间。

[QA](prototypes/settings/design-qa.md)已核对28组几何与本轮10项细节交互；本轮已覆盖现有设计集，上表剩余项继续按实际契约补充。
