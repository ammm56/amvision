# 图编辑：以当前实现为基准的局部优化

更新：2026-10-29。此前整页生成稿已被否决，不得继续作为母版、暗色配对或实现依据。本说明优先于此前图编辑方案中的重设计要求。

## 固定不变

- 左侧导航完整沿用现有 AppSidebar：位置、宽度、图标、字号、间距、选中样式、品牌与折叠交互不重新设计。展开 220px、折叠 64px；截图处于折叠状态就保持折叠，不能擅自展开成文字导航。
- 顶部名称与编辑按钮，以及节点组、刷新、应用模式、预览、保存、发布、属性面板、版本操作组，均沿用当前组件。不得用近似图标替换、改变比例、移动分组或增加独立顶栏。
- 节点宽度、高度计算、字号、控件密度、画布缩放和平移沿用当前实现。不能为把示例排成五张展示卡片而统一加宽、增高、放大或重新排布节点。
- 网格、金色直接连线及中点手柄、节点组、右下工具、小地图、节点/工具/面板的浮动阴影沿用当前实现。

## 允许的局部优化

- 节点组标题仍是当前紧凑浮条，与组框仅小间隔；启用、锁定、名称、数量、颜色、删除的布局不改。
- 参数行保持当前可用的间距；所有编辑控件在右侧，放不下的长字段按当前换行方式单独输入。实际页面已正确的部分不重复改造。
- 纠正设计稿中全加粗的节点文字、左侧勾选框、过大间隔和扁平化阴影，不据此扩大实际节点。
- 节点库保留已明确的局部改进方向：短来源名、用途分类、名称加简短描述，默认卡片并可切列表，单击添加。仅修改节点库内部，不带动导航、顶部或画布重设计。

## 后续设计方法

1. 在同一视口、同一主题、同一工作流、同一缩放和平移下保存实际页面作为基准。参考图必须包含现有导航和顶部，不从被否决稿反推。
2. 一次仅列出一个需要改变的局部。先给出局部前后对照，其余区域原样保留。
3. 核对导航与顶部不变、节点外框和可见范围不被放大、没有删除字段或改变拓扑。若局部改动不需要增加节点尺寸，则不得改变尺寸。
4. 局部成立后再放回整页、补对应暗色。不要批量生成尚未成立的母版或其变体。

100% 画布中的 CSS 尺寸与截图中的显示像素不是同一概念。不得把 34px 参数行、28px 组标题等原始尺寸直接强行套进低缩放的整页图；整个节点应随画布变换等比显示。
