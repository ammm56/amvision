## 1. 用户路径闭合

| 路径 | 已有独立设计图 | 后续行为 |
|---|---|---|
| 找节点 | 节点目录、高级筛选、无匹配 | 来源和用途即时筛选；高级条件点应用；清除恢复结果与第一页 |
| 了解节点 | Core详情、输入输出、参数、使用说明、复杂参数、短屏详情 | 只读；复制标识；专业配置回到图编辑；未声明类型/单位不编造 |
| 了解包 | 包列表、概览、版本、依赖、记录 | 本包依赖和反向依赖分开；节点版本与包版本分开；审计无删除 |
| 安装 | 选择文件、校验中、校验确认、安装中、成功、失败已恢复、结果待确认 | 确认前静态校验；确认后执行；未知结果只查询，不能重复提交 |
| 安装阻止 | 文件无效、版本冲突、兼容失败、依赖不满足 | 明确原因和下一步；不提供绕过校验、强制覆盖、自动pip/驱动安装 |
| 启用/禁用 | 启用确认、启用失败、禁用引用影响、禁用完成、运行引用阻止 | 状态以服务确认值为准；传递依赖和正在运行的引用纳入检查 |
| 回滚 | 确认、变更处理中、完成、失败已恢复、恢复失败 | 区分本次结果和当前可用状态；未恢复不能仍标原版本可用 |
| 状态变化 | 版本已变化、权限变化、结果待确认 | 版本变化重查；明确拒绝才写未执行；断线保留上次状态和时间 |
| 查问题 | 问题诊断、依赖缺失、注册冲突、外部依赖、无问题 | 原因、影响、下一步；技术信息按需展开；无问题不等于全系统健康 |
| 共享边界 | 加载中、连接中断、空包、只读、无权限、目录短屏 | 不显示假零；缓存注明时间；只读允许单包校验；Core不属于安装对象 |

## 2. 结构复用表

以下分支不需要新的页面结构，不能因为没有独立PNG而省略实现。所有主题和短屏规则同源。

| 分支 | 使用现有结构 | 文案和操作差异 |
|---|---|---|
| 普通筛选/清除、单条件选择 | 节点目录/高级筛选 | 已应用标签与计数同步；关闭面板不提交临时条件；重置不清除搜索词 |
| 无依赖、无操作记录、筛选无记录 | 节点包依赖/记录、目录无匹配 | 分别显示无节点包依赖/暂无操作记录/没有匹配记录；没有假页码 |
| 只剩Core节点 | 节点目录、Core详情 | 来源为Core；没有包安装/禁用/回滚控件；图编辑仍可使用Core |
| ZIP损坏、缺manifest、schema非法 | 安装文件无效 | 使用实际文件名和单条原因；未知包身份显示—；更换文件 |
| 包ID不一致、运行目录变化 | 安装版本冲突 | 显示真正冲突的字段，不能套用内容哈希不一致原因；无强制覆盖 |
| 相同版本、相同内容 | 校验确认/成功摘要 | 显示已存在且一致；关闭或查看节点包；不重复安装，不伪造新的安装成功记录 |
| API不兼容 | 安装兼容失败 | 使用真实API要求与当前值；Python行不满足与API行不满足不能混淆 |
| 依赖已禁用/版本不满足/未加载 | 安装依赖不满足、节点包依赖 | 当前列显示准确状态或版本；处理后重查，不自动启用其他包 |
| Python模块/厂商运行时缺失 | 外部依赖不可用 | 替换真实依赖名称、版本和架构；匹配安装说明；无自动修改环境 |
| 启用/禁用处理中 | 节点包变更处理中 | 标题和阶段随操作改变；未完成不显示完成；关闭抽屉不取消后台动作 |
| 启用成功 | 包详情已启用·已加载 | 仅服务确认后更新；不会自动启动Workflow Runtime |
| 禁用失败且恢复成功 | 回滚失败已恢复 | 改为禁用失败，展示当前启用/加载结果；恢复失败复用待修复结构 |
| 静态检查取消、尚未提交安装 | 选择文件/校验确认 | 返回可操作状态，不改已安装节点包；提交后不提供虚假的取消安装承诺 |
| 重复点击、请求处理中 | 对应处理中页 | 同一操作按钮禁用；不重发副作用请求；可关闭并从记录查询 |
| 另一个操作正在处理本包 | 变更处理中/版本已变化 | 显示占用操作；完成后重查，不强行并发变更 |
| 无缓存加载失败 | 连接中断 | 无旧表格与计数；显示加载失败、简短原因、重新连接；不冒充空目录 |
| 刷新中/重连中 | 原列表加紧凑进度 | 保留上次数据与时间；禁用重复提交；失败仍保留旧数据，不改变节点状态 |
| 丢失读取权限、会话失效 | 无访问权限及平台会话流程 | 移除可见缓存数据；失去写权限则仍可读取；不能把网络错误当403 |
| 未知schema、缺单位/frame | 复杂参数/输入输出/技术信息 | 原样展示类型，长值换行可复制，缺值为—；不猜测业务规则 |
| 复制成功/失败 | 原页轻量反馈 | 成功短提示，失败给手动选择复制；不新增对话框或静默失败 |

## 3. 本轮修订结果

- 依赖表清晰区分Connector自身版本与要求的OpenCV版本。
- 操作记录数量与分页一致；恢复成功与原操作失败分别表达。
- 安装失败、版本冲突没有重复更换文件入口；文件无效不猜身份。
- 未安装Connector/OpenCV不会出现在同页背景的已安装列表。
- Core和Value Display详情与背景选中行对应；Value Display为2输入、1输出。
- 处理图标中性，绿色用于完成或主操作；暗色禁用控件降低亮度。
- 抽屉覆盖整页背景，包括导航、品牌、头像；普通页面无模态遮罩。
- 连接中断保留旧数据及时间，表体滚动与分页关系明确；空包只保留一个安装主入口。
- 同组亮暗字段、版本、行数、按钮语义一致；中文规格已同步实际修订。

## 4. 实施前和交互验证

当前安装API仍是一体化提交；独立静态预校验、可查询进度、并发版本检查、运行引用保护和完整审计分页需补后端契约。审计接口当前limit截断不可当作完整总数。图中的未来包版本、厂商扩展、引用数和故障是设计样例。

Vue原型必须验证：键盘筛选及焦点循环、关闭抽屉返回触发控件、Esc、长表滚动与固定底栏、1366×768真实字号、同一背景遮罩、禁用控件、复制反馈。服务联调验证：明确失败/未知结果分离、权限变化、并发变更、依赖循环与传递引用、部分恢复失败。没有这些实测不能将静态设计称为生产验收。

本轮浏览器插件没有可用会话入口；核对使用现有截图、源码和生成图。没有执行真实节点包安装、禁用、回滚或重载。
