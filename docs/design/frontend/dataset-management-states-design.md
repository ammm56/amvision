# 数据集管理列表、编辑与删除状态设计

更新：2026-10-24。状态：九个场景、十八张亮暗配对已生成并逐张核对，待用户审阅；见[检查记录第 9 节](dataset-design-review.md)。目标为未来完整产品设计，不表示当前功能或服务契约已经实现。

## 1. 本批范围与顺序

沿用[数据集页面方案](dataset-pages-design.md)与已确认项目页风格，新增九个场景，每个场景先亮色、检查后再生成暗色。全部普通文案中文，COCO、YOLO、JSON、ZIP 等专有名称保持英文。共十八份完整中文规格保存在 `prompts/数据集完整设计请求/`。

| 顺序 | 场景 | 容器与主要目的 |
| --- | --- | --- |
| 1 | 数据集版本列表 | 现有版本局部标签；跨数据集检索，查看固定版本 |
| 2 | 导入记录列表 | 现有记录标签；执行事实与生成版本分别显示 |
| 3 | 导出记录列表 | 现有记录标签；任务状态与文件可用性分别显示 |
| 4 | 编辑数据集信息 | 右侧覆盖抽屉；只编辑名称与说明 |
| 5 | 删除导入记录-确认 | 对话框；清理记录与导入附件，保留生成数据 |
| 6 | 删除数据集版本-确认 | 对话框；无外部依赖时核对数据与关联记录影响 |
| 7 | 删除数据集版本-依赖阻止 | 对话框；列出引用并提供查看入口，没有强制删除 |
| 8 | 清理导出文件-确认 | 对话框；保留导出历史和来源版本，只清理文件 |
| 9 | 删除导出记录-确认 | 对话框；文件已清理的记录删除，无含糊的隐式级联 |

不增加新全局导航或独立顶栏。记录详情仍进入既有完整报告；更多操作按行打开，不用无用途复选框。批量操作不在本批引入。

## 2. 列表内容与动作

### 数据集版本

列为数据集、版本、任务、样本、来源、创建时间、状态、操作；过滤数据集名称、任务、状态。样例六行：工业零件检测 v3/v2/v1 分别 1200/1000/800 张；连接器分类 v2/v1 分别 600/500 张；包装瑕疵 v1 为 320 张。都是已可用版本，不用“已完成”代替资源可用性。默认按创建时间降序，日期与行顺序一致。

查看进入固定版本工作区；创建导出也固定该版本。删除版本在更多菜单。无批量动作时不放复选框；单行选中仅表示当前上下文。

### 导入记录

列为目标数据集、来源包、状态、样本、生成版本、提交时间、操作。样例四行：工业零件检测正在处理新导入，已完成 v3，包装瑕疵导入失败，以及工业零件检测已完成 v2。运行中与失败无生成版本，显示“—”；未知样本数不写零。状态配图标与文字，未知工作量不画假百分比。

每行主要动作详情；成功版本是可点击入口，失败记录不显示可用版本。终态记录更多中有删除记录；运行中不直接删除，先在详情处理取消。清除提示与删除执行记录不同。

### 导出记录

列为来源数据集/版本、目标格式、任务状态、导出文件、创建时间、操作。示例四行：工业零件检测 v3 正在导出；同版本导出完成且 ZIP 可用 470 MB；连接器分类 v2 历史已完成但文件已清理；包装瑕疵导出失败且无产物。

可用产物有下载入口；导出中、已清理、失败不提供可用下载。更多菜单按实际状态显示清理文件、删除记录等动作。源版本失效时重新导出不可用并说明原因，不能静默改用其他版本。

## 3. 编辑信息抽屉

从数据集列表或详情打开同一抽屉，底层表格不重排。名称必填、说明可选；所属项目和任务类型只读。改名不改变身份，不修改样本、版本与外部引用。正文简短，底部取消/保存固定可达。只在有有效变更时可保存；保存中阻止重复提交，失败保留输入，冲突提示重新核对。不把未提交表单值提前写入底层表格。关闭有改动表单需确认放弃，键盘焦点返回来源。

## 4. 删除和清理契约

| 动作 | 清理对象 | 保留对象 | 阻止条件 |
| --- | --- | --- | --- |
| 删除导入记录 | 记录、关联导入任务、上传 ZIP、导入暂存 | 已生成版本、图片、标注及其外部引用 | 任务仍运行或存在不能清理的引用 |
| 删除版本 | 版本及其专属图片/标注、关联导入/导出记录和对应可清理产物 | 其他版本和其独立引用；共享资产按引用关系处理 | 训练/评估/Workflow 等外部引用，或正在使用 |
| 清理导出文件 | ZIP 及该导出的其他产物 | 导出记录、检查结果、来源版本 | 正在导出或产物被外部任务引用 |
| 删除导出记录 | 导出记录和其已终结任务历史 | 来源版本、图片和标注 | 产物尚未清理、仍有外部引用或任务仍运行 |

删除导出记录前，若文件仍可用，先明确进入“清理导出文件”；不让“删除记录”暗中附带删除文件。本批记录删除图使用“文件已清理”的例子。清理后原有详情显示历史完成但文件不可用，与既有图一致。依赖阻止对话框复用同一形式，但标题和依赖目标必须是实际资源，不混称版本与产物引用。

危险操作只在确认框使用饱和红色按钮 `#DC2626`、白色文字，不用淡粉色冒充可执行删除。无依赖确认与依赖阻止是两个独立状态；阻止状态使用橙色警告及可查看引用，没有红色可执行按钮或强制删除。确认前预检、提交时再次核对依赖；静态预检结果不是永久删除许可。

取消/关闭不修改数据。提交中禁止重复操作；失败保留对象与影响摘要并显示原因。资源已移除但文件清理未完成时使用独立警告状态和清理详情，不冒称全部成功。此类结果状态已有规则，本批不额外生成全部过程图。

## 5. 配对与复核

逐张核对导航、局部标签、表格列、排序、计数、按钮语义、覆盖关系、版本身份、失败与未知状态。暗色由已核对亮色稿转换，字段、数据、位置和展开状态一致。普通文字和线性图标为中性灰；选中/主操作为品牌绿 `#00D992`，错误与危险红、阻止与清理警告橙；没有固定右侧空栏。

布局参照 1920×1080，图像输出以同参考图约 1672×941 的 16:9 比例为准，实际像素记入清单。不称为真实浏览器截屏，不据此宣称键盘交互、对比度、精确像素或生产验收通过。

每个场景只保留最终亮暗 PNG；过程图留在生成工具缓存，不放交付目录。同步中文规格、生成清单、设计总览、主文档当前计数和剩余范围，不覆盖 bak1 与项目图。
