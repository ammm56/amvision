## 本批设计与检查

本批交付节点库局部亮暗配对，实际工作台截图作为上下文。整页生成候选改变了禁用状态和参数，未收录。局部图不包含导航、顶部及画布，避免把这些固定区域重新生成。

节点库采用来源→用途分类→节点；默认卡片，可切列表。两种视图都保留名称和简短用途。单击添加，关闭旧右键菜单，不增加底部确认。正式名称保持英文；来源数量、类别、可用状态从Catalog读取。滚动不缩小字号，长名称换行，Batch后缀不能截断。

图稿只表现设计，不宣称卡片切换、键盘、滚动或面板定位已通过产品测试。

本批完成1组2张局部图，见[设计总览](generated/图编辑/设计总览.html)。亮暗内容与位置逐项核对；卡片名称采用常规字重，说明不含内部ID。来源和类别列保持紧凑，右侧为双列卡片。生成图是高分辨率局部示意，不等于实际控件放大；实现继续使用现有860×560面板上限，并通过真实视口验证文字换行、卡片行数及边缘避让。

本轮没有生成可替代现有工作台的整页母版。后续整页核对应在真实Vue组件中进行，不能再次让图像生成重画固定区域。需要生成新状态时，继续限于发生变化的面板或组件。

## 完整功能与后续状态

| 范围 | 状态与行为 | UI位置与边界 |
| --- | --- | --- |
| 节点检索 | 来源/类别、卡片/列表、搜索、无结果、禁用包、兼容端口筛选、缺失节点 | 同一节点库；不能把无法添加显示成正常可选 |
| 基本编排 | 单选、多选、框选、节点和完整组复制、连线替换/不兼容、组色/锁定/禁用、删除与撤销 | 现有画布；不增加底部操作条、不折叠节点参数 |
| 参数与资源 | 固定值/连线来源、长字段、JSON/规则/颜色、模型部署引用、缺资源/无权限 | 节点内与现有属性；复杂配置独立编辑区 |
| 逐节点预览 | 输入、运行中、成功、业务NG、失败、取消、满载、断线、过期结果 | 编辑器预览；节点状态与服务健康分别表达 |
| 结果 | 图片、值、表格、JSON、图库、大图、循环当前项和汇总 | 结果显示区域；未运行不能显示假结果 |
| 保存与发布 | 首次保存、修改保存、冲突、校验、缺依赖、发布失败、版本载入、离开保护 | 当前顶部入口；保存不等于发布，不自动切换Runtime |
| 应用模式 | 图片/值来源、显式Display Data关联、启用、排序、纯图、无效来源、大图一致 | 当前应用模式配置；不另建页面设计器 |
| 通用视觉 | ROI、阈值、轮廓、坐标、标定、几何、测量、规则 | 通用节点与专属编辑器；单位、无效值、缺图清楚 |
| 行业与扩展 | 连接器PIN/尺寸、异常/瑕疵、3D/点云 | 对应节点包；不新增同名行业全局导航，不把规划能力标成已实现 |
| 工业场景 | 短屏、长名称、大图、数百节点、离线/重连、只读、权限、恢复 | 保持画布密度和可达性；不隐式排队或修改高性能链路 |

下一步依次为节点库列表与无结果 → 参数/资源 → 基本编排 → 预览结果 → 保存发布/应用模式 → 专业编辑器 → 短屏和异常。每批只为新增结构出必要配对，已有组件保持当前实现。

2026-10-29按最新需求先推进[应用模式使用UI](graph-editor-app-mode-design.md)：已核对实际配置/运行页，完成配置与双图结果2组4图，当前分类累计3组6图。后续优先核对配置的统一排序、只读查看效果、手动输入和大图，再补等待/异常/短屏；节点库其余状态仍按上述清单保留。应用模式配置入口不移动，图编辑导航、工具栏及节点保持原样。
