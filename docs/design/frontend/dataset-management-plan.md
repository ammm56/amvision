# 数据集管理：对象与功能边界

更新：2026-10-24。当前布局以[数据集页面与交互设计](dataset-pages-design.md)为准。本文件维护数据对象、操作语义、服务约束及实现边界，不再要求“版本必须藏在管理对话框中”。

## 1. 目标与当前实现

目标是完整的数据集列表、版本、样本与标注浏览、数据结构、类别与划分、质量、来源、导入与导出。默认列表负责管理，点击“查看”进入完整版本工作区；记录标签负责执行历史。

现有页面已具备导入/导出和版本管理的一部分能力。样本检索、文件与标注联动、派生版本、质量报告等需要按目标契约补齐。设计文档不等于新 API、路由或持久化结构已经实现，不能以当前缺少接口为理由删掉合理目标功能。

## 2. 对象与操作

| 对象 | 作用 | 操作边界 |
| --- | --- | --- |
| Dataset | 同一用途的数据集身份 | 检索、名称/说明、查看其版本；本轮不新增整数据集一键删除 |
| DatasetVersion | 一次确定的媒体、标注和划分 | 浏览、导出、固定引用、依赖检查后删除；目标为可追溯不可变版本 |
| Import | 上传、检查、归一化的执行记录 | 状态、问题、生成版本；删除记录不删除数据版本 |
| Export | 从指定版本生成目标格式的产物 | 检查、文件、下载及训练引用；删除产物不连带删除上游版本 |
| Sample | 图片、点云或成组媒体及对应标注 | 只读审阅；变更形成新版本，不直接覆写被使用的数据 |
| Annotation | 与样本关联的类型化真值 | 类别、几何与来源；图上叠加和对象列表来自同一份结构 |
| Quality report | 对指定版本和规则的检查结果 | 覆盖、时间、问题定位；页面筛选不自动重新扫描 |

“最新版本”是浏览捷径，不是所有训练/评估/Workflow 的动态别名。公开引用始终固定版本。版本显示名不能替代稳定身份，也不能把生成时间误当成可验证的语义版本号。

数据结构区分样本逻辑组织、版本资产、来源包和导出包。COCO 共享标注文件可关联许多图片，不能假设一个图像只能配一个同名标注文件。

## 3. 删除与变更语义

- 删除导入记录：清理记录、关联导入任务、上传 ZIP 和暂存文件；保留数据集版本、图片和标注。
- 删除数据版本：删除版本、其图片/标注及关联导入/导出记录；有训练、评估、规则资源等外部引用时阻止并列出依赖。
- 清理导出文件：删除 ZIP 等产物，保留导出记录、检查结果和来源数据；正在导出或存在产物引用时阻止。
- 删除导出记录：仅对已终结、无外部引用且文件已清理的记录开放；若文件仍可用，先明确清理文件，不能隐式连带删除。无产物的失败/取消记录按实际清理状态处理。目标交互见[管理与删除规格](dataset-management-states-design.md)，服务实施需配套校验。
- 数据共享去重若实现，必须具备引用计数和清理契约；前端确认框不能保证磁盘安全。
- 调整划分、类别映射、排除样本、导入修正标注通过创建新版本完成；失败、取消或冲突不能覆盖原版本。
- 清除一条错误提示仅改变界面显示，不删除任务、资源或事实记录。

## 4. 样本与真值显示

缩略图和大图直接绘制实际标注。classification 标签、boxes、masks、keypoints、OBB 使用各自对应查看器与对象字段。真值不添加模型置信度；预测有单独来源与图层。

坐标使用原始图像基准；预览缩放、留白和显示旋转必须有一致变换。显示色不改变类别编码，隐藏图层不改变数据。对象过密可隐藏标签，但需明确可见对象数量。

空标注、未标注、缺少标注文件、解码失败和已确认无目标分别表达。质量检查报告说明范围与规则；未知或未检查不能标通过。类别样本数允许重叠，对象数不等于图片数。

外部标注工具负责制作和修正；平台负责导出交接、样本身份匹配、回传检查及新版本，不因此建设新的通用标注任务派发系统。

## 5. 新视觉类型

| 类型 | 数据与展示要求 |
| --- | --- |
| 异常 / 瑕疵 | 正常、异常、未知分开；可选缺陷区域；没有 mask 不伪造像素级真值 |
| 连接器 2D | 原图、参考值/公差、单位、标定或配方引用；合成真值与独立实物参考分开 |
| 深度 / RGB-D | 深度范围、无效值、单位、媒体配对；彩色可视化不替代原始数值 |
| 3D / 点云 | 点数、坐标系、单位、标注/参考几何；具体格式范围按能力登记 |
| 多视图 | 媒体与采集关系；不能由成组关系推断同步、标定或配准已经完成 |

这些类型复用数据集工作区与查看器；业务检测、计量、判定仍使用 Workflow 和对应节点包。标定图、参考图、模板等可独立作为 Workflow 资源，不强制登记为训练数据集。

## 6. 所需服务契约

| 能力 | 实施前要求 |
| --- | --- |
| 数据集 / 版本查询 | 项目授权、分页、稳定身份、摘要、来源和引用预检 |
| 样本检索 | 服务端筛选、排序、分页、媒体元信息；不以磁盘路径作唯一身份 |
| 文件结构 | 受控相对路径、懒加载子项、分页文件、样本关联；不暴露任意服务器文件系统 |
| 图像 / 标注读取 | 授权、原图/缩略图、尺寸限制、类型化标注与坐标约定、取消与失效 |
| 来源 / 导出结构 | 区分目录用途及清理状态；不存在的原包不可伪装仍可查看 |
| 派生版本 | 变更摘要、冲突检查、不可变来源、失败不覆盖及持久化迁移 |
| 质量任务 | 有界后台检查、取消/部分错误、覆盖范围、分页问题报告 |
| 外部标注交接 | 样本身份匹配、类别/格式校验、多余/丢失样本处理 |

百万级数据采用索引、分页、受控缩略图和后台摘要；打开页面不全盘扫描、不全量载入列表。长计算使用任务/Worker，不阻塞 HTTP。响应预算必须用目标磁盘和真实数据测量，不由设计图宣称。

## 7. 后续代码步骤

1. 对齐对象及查询契约，记录已有能力与缺口，设计必要迁移。
2. 实现数据集/版本列表和只读工作区，核对范围、筛选、返回和固定版本。
3. 接入样本、缩略图、标注叠加与大图；验证坐标、图层、缺图、资源释放。
4. 接入目录/文件与样本关联，验证共享标注、分页和清理后的状态。
5. 补导入/导出完整流程与记录详情，保留不同删除语义。
6. 补类别/划分、质量、派生版本与外部标注交接。
7. 按注册能力接入异常、计量与 3D 查看器，验证亮暗、短屏、离线、权限和规模。

每步按契约、自动检查、真实环境交互验证和文档同步推进。保持 Vue 3、离线发行、Preview 与 Runtime/Trigger 边界，不借数据集 UI 改造推理高性能数据面。
