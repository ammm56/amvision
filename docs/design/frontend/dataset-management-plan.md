# 数据集完整管理界面设计

更新：2026-10-22。目标设计，未新增后端接口、持久化结构或 Vue 路由。现有导入/导出、版本查询与删除继续沿用原实现；本文补齐标准管理能力，作为之后出图和实现依据。

## 1. 入口与页面层级

```text
数据集（平级导航，现有 /datasets）
  导入与导出表单
  导入记录 → 导入详情
  导出记录 → 导出详情
  管理数据集（现有对话框，扩展检索与打开操作）
    选择数据集 / 版本
      版本工作区（规划）
        样本 → 样本详情
        类别与标注
        数据划分
        质量检查
        版本与来源
```

“管理数据集”仍在页面操作区，版本列表不返回主页面重复显示。管理对话框负责查找、选择版本、查看基本信息和允许的删除；需要审阅大量图片时进入全幅版本工作区，关闭样本查看器返回原筛选和滚动位置。

版本工作区应可深链接，URL 携带稳定版本标识，tab/筛选使用查询状态；具体 Vue 路由在实现阶段统一登记。此处不创造新的公开 API 路径，也不把该工作区记为已存在。

## 2. 数据与操作边界

| 对象 | 作用 | 用户操作边界 |
| --- | --- | --- |
| Dataset | 同一主题/用途的数据集身份 | 检索、名称/说明；暂不增加“删除整个数据集” |
| DatasetVersion | 一次确定的样本、标注与划分 | 浏览、导出、引用、依赖检查后删除；目标为可追溯不可变版本 |
| Import | 上传、校验、归一化的执行记录 | 查看进度/问题；删除记录不删除已生成版本 |
| Export | 从版本生成指定训练格式的产物 | 查看、下载、训练引用、按依赖规则删除产物 |
| Sample | 图片、点云或成组媒体及标注 | 只读审阅先行；后续变更形成新版本，不直接覆写正在使用的数据 |
| Quality report | 对指定版本和规则计算的检查结果 | 显示来源与时间，不随界面筛选自动重跑，不修改样本 |

现有版本删除语义保留：删除版本及其图片、标注、关联导入/导出记录；有外部引用时阻止。导入记录删除清理记录、关联导入任务、上传 zip 与暂存文件，保留数据版本、图片和标注。导出产物删除不得连带删除上游版本。共享文件去重若以后实现，必须先完善引用计数与删除契约，不能只靠前端提示保证安全。

训练、评估、标定/配方引用的版本必须固定；对样本排除、标签修正、划分调整等操作，后续通过“创建新版本”提交变更摘要。当前尚无完整派生版本编辑能力，不先开放修改已有版本的按钮。

## 3. 管理数据集对话框

目标默认列：名称/版本、任务类型、样本数、类别数、更新时间、操作。名称优先，内部 ID 在次级信息或详情复制，避免满屏长 ID。缺少自定义名称时使用稳定回退名称，不猜测含义。

- 搜索支持名称与 ID；筛选项目、媒体/任务类型、可用状态。列表由服务端分页，不能只过滤首批数据。
- 每行提供“打开版本”“详情”“删除版本”，按真实权限和依赖决定可用性；删除确认列出阻断引用。
- 详情包含来源、文件规模、类别/划分摘要、关联导出/训练和完整 ID。
- 没有数据、没有匹配结果、列表加载失败分开显示；筛选无结果有清除筛选入口。
- 显示统计以后台摘要为准，不在打开对话框时同步遍历整个磁盘。

## 4. 版本工作区内容

### 4.1 固定上下文与操作区

显示返回入口、数据集名称、版本、任务/媒体类型和必要状态。区域内提供导出、进入训练/评估、创建新版本及版本详情；仅显示实际支持的动作，不恢复所有页面的大标题。

显示样本数、标注数、类别数、划分规模等必要摘要，不能把“图片数”“框数”“物料数量”混成一个总数。版本、质量报告、最近检查时间分别显示。

### 4.2 样本

主区支持缩略图网格与紧凑列表；筛选项目固定、划分、类别、标注状态、质量问题和名称。每个样本显示名称、媒体类型、划分、必要标签/问题。多标签展示数量与详情，避免把几十个类名塞入卡片。

| 控件 / 区域 | 目标行为 |
| --- | --- |
| 分页与筛选 | 服务端有界查询，筛选结果总数来源明确；无数据时保留筛选 |
| 缩略图 | 后台受控生成或读取，懒加载；原始大图仅在打开时加载；失败项可定位 |
| 样本选择 | 明确“本页选择”与“筛选全部”；后台不支持全集操作时只提供本页操作 |
| 样本详情 | 大图/对应媒体查看器、前后样本、标注层、来源、尺寸、原始元数据辅助区 |
| 批量处理 | 首期只读检查/导出选择；后续排除、重标、划分变更形成派生版本并展示差异 |
| 关联检查 | 数据集真值标注与模型预测使用独立图例，不能把预测默认为真值 |

浏览器离开页面释放图片对象、缩略图请求和查看器资源，不永久保留访问过的每张大图。百万样本规模不得通过返回全部文件列表来实现前端筛选。

### 4.3 类别与标注

- 类别表：名称、稳定类别标识、样本数/实例数、划分分布、显示色；颜色只影响显示。
- 分类标签、检测框、多边形/mask、关键点骨架、OBB 按真实任务查看；不以通用 JSON 编辑器替代标注检查。
- 检查未标注、空标注、类别不存在、越界、异常形状、关键点缺失、尺寸不一致；“无目标”与“标注遗漏”必须可区分，不能一律判错。
- 类别合并/重命名、标注修正属于派生版本能力，需有变更摘要和类别映射。直接覆写训练中版本不允许。
- 标注制作优先外部工具协作：导出待标注资料、记录来源、导入返回结果并校验匹配。平台不新建全功能标注系统或标注员任务派发平台。

### 4.4 数据划分

展示 train/validation/test 数量、比例、按类分布和未分配项。当前训练格式的划分行为按导入/导出契约展示。

未来重新划分需记录输入版本、随机种子/分组规则、类别约束和输出版本。来自同一工件、序列或采集组的样本按已提供分组信息隔离，避免近重复图跨训练与验证；没有分组信息时显示限制，不声称已消除泄漏。

查看比例不触发重新划分；训练和评估必须展示最终引用的划分。test 是否包含在导出中继续使用明确选项，不隐式训练 test 数据。

### 4.5 质量检查

目标分“文件与格式、标注、分布、重复/相似”四类结果。规则及可用检查项来自后台能力，耗时检查作为有限任务执行。

- 文件：无法解码、缺失、异常尺寸、位深/通道、配对媒体不完整。
- 标注：类别/坐标/单位/格式不合法，mask 与图像不匹配，缺少任务所需字段。
- 分布：类别或划分极少、空划分、标签不平衡；给出事实，不自动删样本。
- 重复：精确重复与近似相似分开；建议处理，不自动合并生产来源。
- 每个问题有严重程度、数量、样本筛选入口、检查规则与版本。报告过期、检查中、取消、部分失败必须可见。

### 4.6 版本与来源

展示版本列表、来源导入/派生版本、创建时间、样本/标注/划分变更摘要、导出与训练引用。首期只读来源链；未来比较版本显示增删样本和规则差异，不在浏览器扫描原始文件做全量对比。

新版本创建先显示修改摘要、预计范围与影响，后端成功后再跳转。失败不覆盖原版本；中途取消后的暂存清理、恢复策略必须由服务保证。已引用版本删除返回具体阻断资源并可跳转。

## 5. 新视觉任务的数据表现

| 类型 | 样本与标注界面 | 边界 |
| --- | --- | --- |
| 普通 2D 视觉 | 图片、分类/框/分割/关键点/OBB 与任务对应表格 | 当前格式按[数据格式参考](../../reference/datasets/README.md) |
| 异常/瑕疵 | 正常、异常、未知样本状态；可选缺陷区域/mask；采集条件和参考集合 | 未标注不等于正常；缺少缺陷 mask 不伪造像素级真值 |
| 连接器二维计量 | 原图、采集条件、已提供参考值/公差、标定/配方引用 | 计量模板不是训练标签；合成真值与独立实物参考量值明确区分 |
| 深度 / RGB-D | 深度数值范围、无效值、单位、RGB 与深度配对及已知映射 | 彩色深度图只是显示，不当作原始深度数值 |
| 3D / 点云 | 点数、坐标系、单位、有效点、可选颜色/法向、标注或参考几何 | 格式与读取范围待 3D 契约确认；不承诺所有 PLY/PCD/网格变体已支持 |
| 多视图 / 成组媒体 | 同一样本的文件关系和时间/采集标识 | 成组是数据关系，不自动推出已标定、同步或已配准 |

上述后三类及异常学习数据格式按注册能力分批实现。标准数据集管理只管理被纳入的数据，节点直接读取的本地参考图、点云或 JSONL 不自动登记为训练数据集。

标定图、参考图、模板和计量规则由 Workflow 的共享资源选择管理，按需链接数据集样本，不能迫使所有工位先建训练数据集才允许测量。

## 6. 所需服务契约与防呆

| 能力 | UI 实现前的服务约束 |
| --- | --- |
| 版本列表/详情 | 分页、按项目授权、摘要统计、引用预检、稳定版本身份 |
| 样本检索 | 服务端筛选/排序/分页、稳定样本身份、媒体元信息；不能把磁盘路径作为唯一主键 |
| 媒体查看 | 授权的原图/缩略图或受控引用、大小与尺寸限制、取消请求、资源不存在状态 |
| 标注与划分 | 类型化结构、单位与坐标约定、无标注语义、类别映射 |
| 派生版本 | 不可变来源、变更摘要、冲突检查、失败不覆盖、必要迁移与测试 |
| 质量任务 | 有界后台扫描、任务状态/取消/部分错误、分页报告；不阻塞 HTTP 请求 |
| 外部标注交接 | 样本身份匹配、格式/类别校验、丢失或多余样本的明确处理 |

禁止直接暴露任意服务端路径浏览。上传 zip 的大小、路径越界、解压与格式错误由服务校验；前端帮助用户定位问题，不能代替服务防护。重复点击提交有处理中状态，不自行对生产写入进行自动重试。

百万级数据只承诺设计采用分页、索引、后台摘要和有界读取；实际响应时间须用目标磁盘、样本及 API 测试，设计图不展示虚构毫秒值。

## 7. 出图与验证案例

1. 管理对话框：两个数据集、多个版本；名称优先、搜索/无结果、被训练引用时禁止删除。
2. 样本工作区：混合标注数量、长文件名、网格与列表、加载失败、只读权限。
3. 大图详情：框/分割/关键点/OBB 任一真实支持例，标注与预测分层。
4. 类别/划分/质量：不平衡与越界样本、检查进行中和部分失败、结果跳回相同样本。
5. 派生版本：变更摘要、不可修改来源、提交失败不污染旧版本；此图标为规划。
6. 异常数据：正常/异常/未知与缺少 mask；3D 数据：单位缺失和配对不完整；使用明确的开发样例。

只读浏览优先实现，随后完善版本派生与质量任务；页面开放顺序和门槛见[实施计划](frontend-design-roadmap.md)。
