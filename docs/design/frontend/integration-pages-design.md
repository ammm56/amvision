- 实际注册：directory-poll、directory-watch、plc-register、zeromq-topic；Mailbox可用时注册local-shared-memory。前端固定模板未覆盖目录轮询，且含当前没有对应Adapter的Webhook。不能把枚举或模板当成已实现能力，目标界面按服务能力显示。
- ZeroMQ和本机共享内存维持同步高性能请求/回复；支持image-ref.v1、value.v1、text.v1。ZeroMQ multipart由接入层转换为图像引用，不能直接把bytes当引用；不增加队列、隐式重试、Base64兼容或32-bit分支。

- 集成管理TriggerSource及外部协议入口；Workflow发布、Runtime启停/切版、执行记录仍在应用分类，节点包管理仍在节点分类。

## 4. 页面内容与操作契约

列表五列为名称、类型、状态、触发时间、操作。长ID、关联Runtime ID、最近错误、原始健康串进入详情。触发时间显示完整日期或已确认未触发；缺失/读取失败不能伪装成未触发。详情概览的请求/成功/错误/超时/满载/取消计数不是生产物料数量，不能假定互斥相加，缺失显示暂无。

创建主路径：关联实例 → 协议配置 → 输入映射 → 结果绑定 → 确认保存 → 已创建且停用 → 详情 → 明确启用。预检不执行Workflow、不写生产记录；配置有效不等于端到端运行验收。

协议分工：

- ZeroMQ：绑定地址、默认图片输入、响应超时、执行记录、返回诊断；完成后回复，没有SUB/topic。
- 本机共享内存：默认图片输入、响应超时、执行记录、诊断；数据类型为只读能力信息，连接参数由SDK配置提供，不为每个入口设置全局槽位池。
- 目录监听：服务端路径、过滤、递归/隐藏、变化类型、最小触发间隔、事件样本；高级项为轮询方式/间隔与权限策略。没有文件稳定时间和同步回包。
- 目录轮询：扫描间隔、文件稳定时间、批量、排序、去重、扫描进度。当前去重为path/file_name/file_name_and_size；修改时间可排序，不能虚构mtime去重。不是条码复检管理。

输入映射的目标名称/类型/必填来自实例契约，只编辑来源或固定值；重新推断不得默默覆盖人工设置。结果绑定来自公开输出，收起框中性文字、下拉选中品牌色；不支持回复的事件协议隐藏回复控件。图片与业务文件仍由Workflow节点保存。

编辑仅在停用时允许，后台再次核对状态、修订与输入输出契约；冲突不强制覆盖。读取最新若会放弃人工值，复用未保存确认。停用入口不等于停止Runtime或强杀已开始的执行。

启停期间禁重复动作；超时/断线为待确认，查询观察状态，不自动重发。满载是正常容量拒绝；地址占用显示短原因，停用后修改，不自动换端口或重启。删除只移除入口配置，保留应用、Runtime和文件；运行中阻止，结果未知先查询存在性。

详情关闭保持筛选/分页/选中/焦点。只读权限可查看授权信息、不显示修改动作；未授权资源不在客户端泄露。断线保留最近数据但明确过期，不能冒称服务运行或已停止。

## 5. 复用状态与后续验证

本轮约定的创建未知、关联资源变化、协议专题、长内容与短屏已补图。Webhook/MQTT、通用编辑、明确未创建终态等属于未来能力，不能凭图稿宣布接口已经可用。

字段校验、提交中、保存失败保留输入、未保存离开、轻提示、零搜索结果、骨架、无查看权限、删除后分页回退、复制成功和焦点恢复复用项目/应用规范，不为每句提示复制整页。

详情的信息层级与ID来源遵循[抽屉规则](integration-drawer-content-rules.md)。常用参数直接展示，映射/技术信息/原始错误按需展开。已保留完整能力而非删除字段。

目录轮询当前失败/超时后候选可能在后续扫描再次提交；不存在进度文件时从空进度开始。不得把无业务自动重试的同步调用约束泛化到轮询。规则修改与进度异常需人工确认的目标仍须实现和验证，见[事实与目标契约](integration-protocol-final-states-design.md)。
