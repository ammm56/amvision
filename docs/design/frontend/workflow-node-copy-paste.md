# Workflow 节点复制与粘贴

状态：已实现（2026-09-07）。本文描述当前 Vue 编辑器的单节点复制粘贴行为；验证范围与工具限制见文末。

## 交互

复制只记住节点，粘贴才在当前编辑图中新增节点。无需确认，不自动保存、发布或执行。

| 入口 | 行为 |
| --- | --- |
| 节点本体右键菜单第二项“复制” | 复制右键所指的节点；右键已经会选中该节点 |
| 选中节点后 Ctrl+C | 复制当前选中的节点 |
| 空白画布右键菜单第四项“粘贴” | 在此次右键位置新增副本 |
| Ctrl+V | 在鼠标当前位于画布的有效位置新增副本；鼠标位于侧栏、工具栏或画布外时，放在可见画布区域中心 |

节点本体菜单前三项为“添加节点、复制、删除节点”。空白画布菜单前四项为“添加节点、添加说明、预览、粘贴”，导出和导入仍在底部。没有已复制节点时，“粘贴”仍占第四项但禁用。端口、连线、App Entry/App Result、说明节点和组的专用菜单保持原行为。

复制完成关闭菜单，沿用现有状态提示显示“已复制节点”；粘贴完成关闭菜单、选中新节点、显示“已粘贴节点”，现有内容比较负责标记未保存。名称和参数不自动添加“副本”等后缀，唯一性由新 node_id 保证。

同一位置连续粘贴时，后续副本每次向右下错开 32 个画布坐标单位；改变目标位置或重新复制后重新计数。右键位置经过现有 screenToWorld 转换，新节点左上角落在目标点。键盘的中心回退位置按节点尺寸居中，并排除侧栏和工具栏遮挡区域。

## 复制内容

复制当前编辑节点的深拷贝快照，源节点在复制后继续修改或删除，不影响已经复制的内容。每次粘贴再次深拷贝，副本与源节点、其他副本之间没有共享的可变对象。

| 字段 | 处理 |
| --- | --- |
| node_id | 每次粘贴生成新的、不重复的 ID，复用现有 createGraphNodeId |
| node_type_id | 保留，适用于核心节点和自定义节点 |
| parameters | 保留实际参数及嵌套 JSON，不重新填入 Catalog 默认参数 |
| enabled | 保留 |
| metadata | 保留节点文档 metadata，不猜测或改写自定义字段 |
| ui_state | 保留节点外观字段；位置改为粘贴位置，宽度采用当前编辑视图实际宽度 |

复制前提交该节点尚未提交的 JSON 参数编辑，解析失败沿用现有错误提示，不以旧参数冒充当前内容，也不覆盖上一次成功复制的内容。普通文字输入框里的 Ctrl+C 仍复制文字，不触发节点操作。

不复制连线、Template 公开输入输出、Application bindings、组身份、说明节点或 App Mode 显示配置。不自动给副本连接源节点的上下游。粘贴位置落入节点组时，沿用现有完整包含规则计算成员关系。

图片、Mask、模型、部署等参数中的资源引用按原值保留，不复制二进制文件。预览图像、运行结果、对象 URL、执行状态、选择状态和编辑器缓存不进入节点快照。必填连接缺失、资源失效或节点定义不可用，继续由现有编辑器与保存/预览校验报告；复制粘贴不补造连接或资源。

## 剪贴板与快捷键边界

使用当前编辑器实例内的一个节点剪贴板，不调用系统剪贴板 API，不引入浏览器权限和后端接口。本期支持同一编辑图内单节点重复粘贴；切换 App、刷新、导入工作流、载入历史版本或退出编辑器时清空。跨页面、跨 App、多选子图和外部 JSON 剪贴板不属于本次实现。

Ctrl+C / Ctrl+V 只处理普通节点编辑操作。输入框、textarea、select、contenteditable（包括其子元素）、对话框、其他菜单和列表选择器中的快捷键交给原控件。中文输入法组合期间和按键自动重复事件不新增节点。不选中普通节点时 Ctrl+C 不覆盖节点剪贴板。

保存、发布、文档读取或替换期间沿用 documentBusy 禁用相关命令；菜单和快捷键调用同一组动作函数，不能仅依赖按钮 disabled。没有可粘贴内容时 Ctrl+V 不改变画布。只有真正处理节点命令时才阻止浏览器默认行为。

## 代码结构

- `components/WorkflowGraphContextMenu.vue`：新增 copy-node / paste-node 事件和可用状态，按上述顺序插入菜单项，显示 Ctrl+C / Ctrl+V 提示，沿用当前菜单样式。
- `context/useWorkflowContextMenu.ts`：当前 openNodeContextMenu 已先选中右键节点；复制应明确采用该菜单的 nodeId，避免依赖过期选中状态。
- `nodes/useWorkflowNodeClipboard.ts`：保存节点快照、管理粘贴位置与重复偏移，执行复制和粘贴，不管理完整工作流文档。
- `nodes/useWorkflowNodePicker.ts`：复用已经导出的 createGraphNodeId。不能调用当前 addGraphNode 来复制，因为它经页面回调使用 buildInitialNodeParameters 新建默认节点。
- `nodes/useWorkflowGraphNodeViews.ts`：复用 buildGraphNodeView 构建副本视图；当前实现已深拷贝节点，不自动注入默认参数。传入新 node_id 和粘贴后的 ui_state，不复制整个 GraphNodeView 的运行期引用。
- `parameters/useWorkflowNodeParameters.ts`：commitPendingNodeParameterDrafts 只清理本次成功提交的字段标记，提交复制节点不会清掉其他节点的 JSON 编辑标记。
- `shell/useWorkflowEditorKeyboard.ts`：在现有 Delete/Escape 入口增加复制粘贴，补齐可编辑祖先和组合输入识别；保留原删除与 Escape 行为。
- `pages/WorkflowEditorPage.vue`：接入菜单、键盘、画布鼠标位置、documentBusy、选择和分组更新，在文档替换和卸载路径清空剪贴板。
- `platform/i18n/messages.ts`：补齐中文、英文、日文、韩文的复制、粘贴及状态提示。

纯前端实现，保持 Vue 3、本地离线部署和现有 Workflow JSON 契约，不修改 Runtime、Trigger 或后端持久化结构。

## 实施与验收

1. 先实现节点快照与粘贴动作。验证新 ID、嵌套参数独立、位置与宽度正确、未自动补默认值，以及不复制连线和公开绑定。
2. 接入两个右键菜单。验证节点第二项复制、空白第四项粘贴、空剪贴板禁用，点击后仅改变当前编辑图。
3. 接入 Ctrl+C / Ctrl+V。验证文字复制粘贴不受影响、弹窗与输入法不误触、缩放平移后的落点正确、连续粘贴可区分。
4. 验证未提交 JSON 参数、文档切换、忙碌状态、分组归属及自定义节点；复制一个节点不能清除其他节点的参数编辑标记。
5. 用浏览器核对亮暗菜单、实际复制粘贴、保存刷新和 JSON 导出后的副本完整性。每一步通过后继续下一步。

新增测试统一放在根目录 `tests/frontend/workflows/test_*.ts`，验证实际快照、动作、快捷键和参数提交行为。
