更新：2026-10-25。目标为完整产品，现有服务能力不限制设计范围；实现差距与视觉稿分开记录。继承[通用要求](prompts/通用要求.md)、[设计系统](design-system.md)及项目、数据集已确认样式。

## 1. 入口与对象

全局仅保留“模型”。页内四项：模型版本、训练任务、转换与导入、评估。任务类型使用筛选，不增加全局子导航。项目上下文放在页内，不新增独立顶栏。

| 对象 | 用途与边界 | 主要去向 |
| --- | --- | --- |
| 平台预置模型 | 管理员登记的本地基础资源，不混入项目训练结果，不提供任意预训练权重上传 | 训练向导的模型选择器，独立基础模型抽屉 |
| 项目模型及版本 | 名称组织同一用途的多个不可变版本；内容来源为训练或导入 | 版本列表、详情抽屉、文件/来源/引用 |
| 训练任务 | 固定模型、数据集版本、导出格式、初始化方式与参数的执行记录 | 完整任务详情；完成后打开输出版本 |
| 转换产物 | 版本的运行格式与精度，不另算一个模型 | 版本详情内文件表；转换任务详情 |
| 模型导入记录 | 项目产物/模型包的检查与登记；不等同部署启动 | 转换任务列表下方的导入模型区 |
| 评估任务 | 固定输入版本/产物、数据、split、预处理与指标口径的有限任务 | 评估列表、报告、比较、样本检查 |
| 部署实例 | 加载指定产物的独立运行服务 | 跳转部署分类创建；本分类不提供启停面板 |

短元数据、环境和引用使用可关闭模态抽屉；整个底层导航与主区共同受一层遮罩弱化。长参数表单、训练/转换/评估报告使用完整页面。图像对象检查面板非模态，整页无遮罩。

## 2. 主任务路径

1. 从当前项目版本列表选择已有版本，或创建训练。
2. 训练五步：任务与模型 → 数据 → 初始化 → 参数 → 检查。数据固定版本和兼容导出，不直接读取可变原始目录。
3. 初始化明确区分从头训练、使用权重初始化（warm start）、恢复中断任务（resume）。resume 校验 checkpoint、模型结构、数据与参数兼容性；调整参数重新训练保留原任务，不伪称接续原迭代。
4. 提交一次后进入任务详情。取消是请求，收到确认前显示“正在取消”；断线不清空已有曲线，也不直接认定失败。
5. 完成后查看输出版本。原始权重、转换文件、评估报告和部署引用分开。
6. 创建转换四步：来源 → 目标 → 参数 → 检查。后端相关字段按目标切换，检查完成才允许提交。
7. 模型导入四步：文件 → 检查 → 信息 → 结果。入口和记录始终位于“转换与导入”内转换任务区之后；检查通过不等于部署运行成功。
8. 评估三步：模型与数据 → 评估规则 → 检查。完成后查看按类别报告、样本及比较。选择2–4个可比结果出现底部操作条，不常驻空比较栏。

## 4. 样例数据与指标

设计样例日期固定2026-10-23，非当前运行结果。项目“产线视觉验证”；数据“工业零件检测 v3”，1,200图，train960/val240，无test，类别bolt/washer。模型“零件检测 YOLO11-s v4”来源于80轮训练，best epoch72；后续v5正在训练第38轮，已完成37/100，当前batch12/60，曲线仅到37。图稿数值仅用于检查布局。

v4来源训练完成时间固定2026-10-22 18:32:54，早于2026-10-23的转换记录。v4评估：同一val240图、300个GT对象（bolt180、washer120）；mAP50–95为0.812，mAP50为0.946，P=0.912，R=0.925。类别AP为0.824和0.800，均值0.812；类别目标数与图片数分开。v3相同口径mAP50–95为0.786。比较精度允许不同运行后端，但必须显式列出后端/精度/预处理差异；性能比较还要求同设备、batch、输入、预热与计时范围，不直接比较异构设备延迟。

| 任务 | 报告口径 |
| --- | --- |
| detection | bbox AP、明确IoU范围、P/R及阈值；TP/FP/FN按固定匹配规则 |
| classification | Top-1/Top-k（k不超过类别数）、每类P/R/F1、混淆矩阵 |
| segmentation | bbox和mask指标分列；实例分割与语义分割不混用 |
| pose | keypoint AP/OKS、骨架与sigma；不以bbox AP代替关键点指标 |
| OBB | rotated IoU/AP，角度与坐标约定，GT和预测旋转框 |
| 异常检测 | 图像级/像素级指标分别表达，阈值与正常/异常定义固定；按插件能力启用 |

当前FN示例为一个GT、零个预测，预测置信度显示“—”；GT与预测显示开关都开启，不可生成虚构预测框。一般FN可能存在未匹配或被规则过滤的候选预测，查看器应保留真实候选及匹配规则，不能一概隐藏。当前FP示例是背景纹理被误识别为washer，零个GT、一个预测；不将真实目标误画成无GT的负样本。无test时仅显示val结果，最终测试入口不可用并用中性说明解释。未知/不适用指标为“—”，不是0；指标数值不因任务完成就统一着绿色。独立参考量值、连接器计量和3D测量属于Workflow及相应节点包，本分类不新增专用检测页面。

## 5. 转换、导入与恢复规则

- ONNX/OpenVINO/TensorRT/CoreML/ARM NPU作为长期目标按能力清单呈现，未安装适配器或不兼容时禁用并说明，不伪装当前已全部支持。
- TensorRT版本来自选定执行环境的只读信息，不允许表单任意“切换已安装版本”。FP16不要求INT8校准；INT8只有支持时出现，并要求固定代表数据与预处理。dynamic shape需min≤opt≤max，模型动态维度支持另查。
- 转换总耗时样例2分41秒：导出21秒、优化12秒、构建98秒、校验18秒、登记12秒。成功样例100张校验输入，最大绝对误差0.0018、门限0.005；只证明该次输出校验，不证明现场精度或跨设备兼容。
- 导入检查包含包完整性、路径、文件格式、任务、输入输出、类别顺序、来源和资源冲突。模型文件不可作为任意代码执行入口；外部不受信任序列化格式交给明确的隔离/受信任策略，UI不可承诺任意文件安全加载。
- 导入/转换/训练重试是显式新任务；提交响应未知先查询已有任务，不自动重复提交。模型不可用与服务满载分别表达，不改变Runtime/Trigger的立即容量拒绝。
- 删除任务历史保留已登记资源；版本或产物删除列出影响和引用，有外部依赖阻止。文件丢失/损坏标明具体产物，不能把所有格式一律置为不可用。
- 部分评估失败保留已处理/总数和失败明细，结果不得冒充全量；导出报告记录范围和状态。日志按需加载，错误摘要可复制，长堆栈默认折叠。

## 6. 布局和交互验收

1920×1080设计视口。导航顺序固定：项目、任务、数据集、模型、部署、推理、图编辑、应用、集成、节点、设置；无分组标题，无独立顶栏。AMVAR Vision品牌在左上，账号在左下。页内工具与内容自然衔接，主色#00D992，普通悬停/输入焦点中性，主按钮白字。

详情抽屉关闭保持列表筛选、分页和滚动；编辑有草稿先确认，模态只一层遮罩。完整工作区保留返回来源。短屏收起左导航、表格次要列在详情保留，正文滚动且底部动作可达；不缩小字号硬塞。加载/刷新不清空旧结果；权限变化恢复后重新检查，不自动重放写入。长日志、样本和曲线需要分页/虚拟化与有界数据窗口。

静态稿检查布局、数据、入口、主题配对与遮罩。键盘焦点、滚动、200%缩放、精确色值/对比度、真实性能和权限需后续Vue 3原型验收。样式不依赖CDN，运行链路和产品代码不在本次修改范围。

## 7. 完整性补充与后续核对

本轮优先补图范围已完成，主要操作路径可连续审阅；**不等同模型分类全部条件分支与交互已完成**。实际图稿和剩余项见[完整性结论](model-design-review.md#8-完整性结论与剩余范围)。

历史版本选择同步更新文件、指标、来源与操作对象。版本详情“创建部署”跳转部署配置的来源确认步骤，预填模型/版本，再明确选择产物；转换详情可预填该次产物，不在模型抽屉另设运行控制。模型包导出是版本的资源交接操作，与单文件下载、部署实例导出分别命名。

后续优先完善条件参数与完整终止状态，再补长列表、单项产物删除、草稿离开。已经共用布局的状态可直接以规则约束原型，不为同一结构重复生成大量图稿；结构或语义不同的分支仍需代表图。Vue 3原型单独核对焦点、滚动、短屏及真实状态恢复。
