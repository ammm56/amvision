## 1. 保留与修正

| 对象 | 处理方式 |
| --- | --- |
| `generated/bak1/` 大部分业务页面 | 保留合理的内容组织、功能与操作关系，统一风格 |
| 旧图导航 | 参考当前产品的简洁平级导航，取消分类标题与杂乱层级 |
| 旧图顶部 | 删除独立全局顶栏，页面操作留在内容区 |
| 宽屏图最右侧详情/配置 | 按已展开的抽屉理解，不能改成常驻详情栏 |
| 少数错误设计 | 按实际功能与最新要求逐项修正，不推翻全部旧图 |
| 未实现标准功能 | 继续保留明确的目标规划，不假称已交付 |
| 已否决生成图与历史 archive | 不用作新母版或风格来源 |

当前导航的项目、任务、数据集、模型、部署、推理、图编辑、应用、集成、节点、设置作为功能入口核对表。本轮不擅自将它们合并为五项，也不把项目管理藏入新加的项目选择器。导航视觉保持平级、简洁，具体尺寸用真实字体和屏幕验证。

## 2. 页面外壳

左侧导航与页面内容构成主要外壳，顶部没有单独一栏。品牌和账号沿用现有入口语义，点击品牌仍访问根路径，个人启动偏好保持有效。

页面内的搜索、筛选、页签和新建/导入等动作按该页任务组织，与正文属于同一个内容区。它们不是全局顶栏，也不强制所有页面套同一条工具带。已有普通页面隐藏的大标题和占位高度不恢复。

旧页面中的列表、表单、预览、图编辑等各自保留适用布局，不强制改成一个新的固定分栏模板。采用统一组件规则而不是强制统一页面形状。

## 3. 抽屉的交互与出图

| 状态 | 页面呈现 | 关键要求 |
| --- | --- | --- |
| 关闭 | 主内容使用完整可用宽度 | 不留固定空详情列，不默认显示某条记录详情 |
| 详情展开 | 从右侧打开选中资源详情，保留列表上下文 | 标题、关闭入口、当前对象清楚；完整 ID 和诊断放在详情 |
| 新建/编辑展开 | 右侧表单，必要时底部固定取消/保存 | 校验、处理中、失败与未保存保护明确 |
| 窄屏 | 抽屉可扩大至内容区宽度 | 不挤压列表形成不可用的窄栏，不遮挡关闭和主要动作 |

抽屉默认作为按需打开的浮层处理，不在首页长期占据一个固定列。若某个旧页面确有不同交互，需要逐页说明，不能从一张展开状态图推断所有页面都固定分栏。

键盘焦点进入抽屉、关闭后返回原操作位置；阻止误保存、误删除；关闭详情不停止 Runtime 或后台任务。浏览结果用抽屉，长时间图像/点云编辑可进入专属工作区，不层层套弹窗。

## 4. 风格统一

- 亮暗主题对应相同页面、相同数据、相同抽屉状态，不能借主题切换重新排版。
- 品牌色沿用 `#00D992`；选中和主要动作使用品牌语义，普通 hover 与输入 focus 使用中性色。
- 统一字体、字号层级、间距、控件高度、表格行高、圆角、分隔线、状态标签与表单对齐。
- 普通内容靠布局和轻分隔组织，避免厚阴影、卡片套卡片及装饰性统计。
- 图片内容不随主题染色，算法数据与显示数据分开；原图、叠加、标定单位与缺测状态明确。
- 品牌按钮白字继续遵守既定产品要求，但不能据此宣称所有小字对比度已通过无障碍验收。
- 新母版先从旧图挑选合理页面修订，不再使用刚才两批已否决图片。

## 5. 功能边界

完整功能清单继续由[页面内容规划](navigation-and-page-plan.md)、[数据集管理](dataset-management-plan.md)与[视觉工作流扩展](workflow-vision-ui-plan.md)维护。

数据集标准管理、异常瑕疵、连接器二维测量、3D/点云能力可以规划完整，但必须区分已有、开发中与规划。专业能力通过节点包、节点 UI、共用结果查看器和现有 Workflow 实现，不增加行业业务导航。

模型部署、Workflow Runtime、Trigger 是不同对象。Preview 的节点结果流和同步高性能调用不能因为 UI 重排而改变；不引入隐式磁盘保存、业务队列、自动重试或重复模型加载。

## 6. 后续步骤

1. **核对旧图**：按页面记录保留内容、外壳修正、风格差异和具体功能错误。旧图大部分合理作为起点，不预设全部重做。
2. **统一外壳规则**：简洁平级左导航、无独立顶栏、内容内操作；明确当前品牌和命名。
3. **明确抽屉状态**：同一代表页分别设计关闭和展开，保证右侧区域的性质不会再误读。
4. **制作亮暗参考**：在合理旧稿基础上统一组件风格；2026-10-23 已确认项目列表与新建项目的四个状态，仅作为项目设计及公共导航/主题参考。其他页面按自身旧稿与[中文提示词](prompts/README.md)设计，不直接套项目布局。
5. **逐页扩展**：按[后续页面批次](page-design-continuation-2026-10-23.md)先处理数据集管理、部署导入、触发详情，再覆盖图编辑、专业节点、App Mode 等。
6. **实施前验证**：核对真实字段、能力、权限、深链接、未保存保护、窄屏和键盘交互，再进入 Vue 3 实现。
