## 3. 新方案的必须项

- 主页局部标签：数据集、数据集版本、导入记录、导出记录；默认数据集列表。
- “查看”进入指定版本完整工作区，不打开管理弹窗。
- 版本工作区包含样本、数据结构、类别与划分、质量检查、版本与来源。
- 缩略图和大图直接绘制标注；对象列表与图像互相定位；真值与预测分开。
- 数据结构同时支持逻辑样本组织和受控文件目录，COCO 共享 JSON 不按同名文件强行配对。
- 导入/导出向导及详细报告保留完整页面；轻信息和短表单使用可关闭抽屉。
- 亮暗、导航、绿色品牌、灰色 hover/focus、红色危险动作与项目设计统一。

- 上传完成、提交前检查通过、正式生成版本完成是三个阶段；失败不能显示不存在的可用版本。
- 常规示例1200张图像、1800个对象，bolt1080、nut720；train960/1440对象，val240/360对象；test未配置。
- 缺图页显示声明数量，不误称已确认完整；源标注JSON解析成功不代表所有图片均存在。
- 格式不兼容是独立的包装瑕疵v1分割示例（320张），不混用工业零件计数。
- YOLO导出示例1200图像+1200标注TXT+1个data.yaml=2401文件；创建前470MB为估算，完成详情为历史示例值。
- 重试均由明确动作发起，不自动重复提交。产物已清理保留历史事实，禁用下载/训练，允许基于可用来源重新导出。
- 短屏稿折叠导航与结构；正文超出高度时滚动，底部操作可达。展开/收起文字必须与当前内容一致。

### 验证边界

本轮覆盖六个向导前置步骤、五种代表异常和两个短屏检查页。版本/记录列表、类别与划分管理、质量、版本来源以及其他异常仍需按完整方案继续设计，不把本批当成所有数据集页面完成。

逐图检查基于图像工具返回的原始图片。未修改产品实现，未启动浏览器原型或进行真实键盘、滚动、服务调用、精确颜色和对比度验收。短屏1366×768与常规1920×1080是布局参照，本轮实际PNG均为1672×941。生成图的小字、像素颜色及精确组件尺寸以实现阶段的设计token和真实渲染核对为准。

交付目录仅放最终同名图、总览和清单；不放被替代的试稿。完整中文规格合并修订，清单另记末次实际请求、引用图、尺寸及SHA-256。旧bak1和项目分类没有修改；生成工具缓存中的原图保留，交付目录不引用它们作为展示文件。
