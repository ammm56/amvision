## 3. 新方案的必须项

- 主页局部标签：数据集、数据集版本、导入记录、导出记录；默认数据集列表。
- “查看”进入指定版本完整工作区，不打开管理弹窗。
- 版本工作区包含样本、数据结构、类别与划分、质量检查、版本与来源。
- 缩略图和大图直接绘制标注；对象列表与图像互相定位；真值与预测分开。
- 数据结构同时支持逻辑样本组织和受控文件目录，COCO 共享 JSON 不按同名文件强行配对。
- 导入/导出向导及详细报告保留完整页面；轻信息和短表单使用可关闭抽屉。
- 亮暗、导航、绿色品牌、灰色 hover/focus、红色危险动作与项目设计统一。

### 8.4 继续出图前需要明确的规则

- **记录与文件操作**：导出使用“删除记录”还是“清理产物”需要分别定义影响、引用阻止和清理失败状态；不能用一个无解释的“删除”覆盖二者。导入记录删除保留版本，版本删除受外部依赖限制，既有规则保持。
- **选择与批量操作**：确定每张表/网格允许的操作、跨页选择范围、混合状态禁用原因及部分成功反馈；未提供批量动作的表不放无用途复选框。
- **版本变更**：确定映射合并/排除、划分比例与固定规则、样本分组及数据泄漏检查如何表达；预览受影响样本和统计，正式变更创建新版本。比较页明确来源、样本增减、类别/标注/划分差异，不做模糊的数字对照。
- **检查与任务状态**：检查覆盖范围、问题严重程度、未检查项、取消请求与实际取消分开；结果未知先查询已有任务，不引导重复提交；关闭详情不取消后台任务。
- **跨模块跳转**：导出详情进入训练时携带固定版本/导出及任务类型；质量问题打开对应样本后可返回原筛选和位置。资料已失效时显示明确原因，不能静默改用最新版本。

### 覆盖结论与限制

目标主流程已覆盖到管理、版本工作区、样本查看、创建新版本、比较、外部交接和记录/文件生命周期；共用状态矩阵明确空态、错误、只读、失效、冲突、提交未知、取消中与部分清理。状态板是独立示例，不是同时出现多种错误的产品页面。没有新增整数据集删除、内建通用标注制作或独立连接器/点云业务导航。

逐图检查修正了类别与对象名称混用、任务类型误写来源、RGB-D误写对象数、点云误带图像分辨率和固定分栏、删除范围误写成删除数据集，以及多余品牌装饰和不合适按钮色。示例统计与状态按规格核对；照片、框和坐标不是计量真值。

当前可进入用户审阅与交互原型；不能称全部运行状态、精确视觉像素、可访问性或服务功能已经验收。生成稿仍可能有微小字形、品牌图标或间距差异，尤其短屏应按统一组件恢复AM品牌图标与账号头像的区别；关键点遮挡说明按两主题共同规格实现。网格/缩略图实际实现须保持原图比例，不能照搬栅格稿的几何。

本轮未修改产品代码、实际数据和运行链路。工具返回图像用于静态视觉核对；本地总览以文件/链接检查为准，没有绕过浏览器本地文件限制，也未声称浏览器交互验收。生成源缓存不加入交付目录，最终图片与清单仍为Git忽略的本地资产。

文件核对结果：112张PNG及112份中文规格一一对应，56组均有亮暗，交付目录共114个文件且无子目录。尺寸、文件大小与SHA-256全部匹配；原64张中仅上述5张替换，其余59张不变，项目30张和bak1的59张校验不变。总览398个文件/锚点引用、56个唯一场景锚点，以及48份Markdown中的713个本地文件链接有效。本轮核对中间文件位于专用临时目录，完成后清理，不作为长期资产。
