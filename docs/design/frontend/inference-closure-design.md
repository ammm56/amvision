## 2. 状态规则

- 单项错误只改变该项，整批成功/失败/未执行计数来自任务快照；取消失败、取消未知、取消中与已取消分开。
- 批量大图的筛选范围、顺序、当前ID和位置须一致；过滤后当前项不在集合时提示并选首项，不越界。切换清除旧图片和旧结果，过期请求不覆盖新项；首尾按钮禁用。
- 记录删除与文件清理分开。清理任务保存独立标识、归属范围和残留文件；关闭提示后从列表“待清理”入口重新进入。重试只清理残留文件，不重复删除记录或执行推理。
- 已删除的文件再次清理视为完成；文件被替换、归属不符或路径越界时禁止删除并说明原因。原始输入、模型、部署及共享文件不在清理范围。
- 长JSON预览在读取前限制字节/行数，列表虚拟滚动；复制当前片段与完整下载分开，截断片段不能冒充完整JSON。长名称省略但可悬停、键盘聚焦及复制完整值。
- 零目标是执行成功；没有匹配任务是筛选空态。版本变更必须显式确认，不自动用新模型执行。无效批量输入修正后重新检查，检查失效时禁用提交。

## 3. 同构状态复用

| 变体 | 复用与差异 |
| --- | --- |
| 全部成功 / 全部失败 / 取消与完成竞态 | 任务详情终态表；状态与计数取实际结果，无取消后强制改写 |
| 无权限、格式不符、读取失败、输出空间不足 | 已有输入校验或执行失败容器；准确原因与有权限的恢复动作 |
| 清理权限不足、文件占用、文件已不存在 | 清理待完成/完成容器；不能声称全部删除成功 |
| 无标注/未知类别/缺少指标 | 各任务结果页显示实际数据；未知为—，不生成GT、默认OK/NG或0ms |
| 任务刷新/下载失败、结果过期 | 局部错误，不覆盖已成功推理；查询/下载仅重试对应操作 |

## 4. 原型验证步骤

静态图完成后，使用Vue 3主栈制作交互原型；图稿检查不等于以下步骤已通过。

1. 以现有状态矩阵建立输入→执行→结果、批量→单项→大图、取消→终态、删除→部分清理→重试的可点击路径。
2. 核对抽屉开关不重排画布、Esc关闭当前层、模态焦点约束与关闭后焦点返回；非模态不锁定背景。
3. 以键盘、1366×768及125%/150%系统缩放检查表格、按钮、长名称/JSON和底部操作，不使用图片缩放冒充响应式。
4. 注入延迟、断线、并发取消完成、切换样本旧响应、残留文件权限失败、二次清理；验证无重复执行、无错图、无误删。
5. 再连接真实API核对能力、字段和权限；当前设计中的未来动作必须先具备后端契约，不暗示已经实现。
