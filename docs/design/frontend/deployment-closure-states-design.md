## 2. 交互约束

- 启动预算耗尽且退出已确认与HTTP响应丢失分开；停止超时不等于已停止。待确认状态先查询，不重复提交。
- 导入回滚仅删除本次新建且仍由本次操作拥有的资源；复用资源不删。清理未完成保留可追踪记录。
- 导入记录删除不删除已登记的资源；导出记录删除删除对应包；只清理导出文件则保留记录。提交前重新检查占用，进行中操作不能直接清除。
- 取消导出先请求、再等待确认；请求未确认时显示取消中，不能提前显示已取消。已完成与取消并发时以服务最终结果为准。
- 后端属性由适配器与目标设备能力决定，未知不编造；CoreML及ARM NPU分别是其他目标环境样例，不是Windows可用性承诺。
- OpenVINO AUTO是显式设备策略，候选/启动辅助/运行回退单独配置，不能成为其他后端隐式降级。ONNX CPU节点执行与Provider整体回退区别处理，禁止策略不受支持时阻止提交。
- 日志使用有界分页及显示缓存；详情/引用长列表保留查询、分页、完整内容查看，关闭恢复原列表焦点和位置。

## 3. 可复用状态与实施验收

列表加载、筛选无结果、读取失败、只读权限、文件过期、复制反馈复用公共组件，但仍明确：加载不清空旧数据为零；筛选空态提供重置；失败保留筛选并可重试；只读禁用写操作并说明原因；文件缺失禁止下载但保留历史生成结果。

未保存退出使用统一确认，操作中导航不冒充取消。抽屉Esc/关闭按钮及焦点回归一致；模态约束焦点，背景不可点击。状态不只靠颜色表达，检查项提供文本，实时事件避免频繁打断读屏。

静态图不证明响应式、权限执行、并发一致性、键盘操作或服务性能。实现阶段验证目标1366×768和1920×1080、125%/150%缩放、亮暗、长名称/错误/日志/空权限与断连恢复。所有恢复操作重新校验当前资源版本与所有权。

## 4. 技术资料与设计选择

- [OpenVINO GPU](https://docs.openvino.ai/2026/openvino-workflow/running-inference/inference-devices-and-modes/gpu-device.html)：设备属性/性能提示由版本与硬件能力决定。
- [CoreML计算单元](https://apple.github.io/coremltools/source/coremltools.models.html)：CPU_AND_NE允许CPU及Neural Engine，不保证所有算子在Neural Engine执行；目标需macOS 13及以上。
- [ONNX Runtime CUDA](https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html)：GPU内存池限制不是进程总显存上限；Provider参数与TensorRT分离。
- [RKNN Toolkit2](https://github.com/airockchip/rknn-toolkit2/blob/master/README.md)：Rockchip产物与运行时属于厂商适配，不能泛化成所有ARM NPU共有参数。

这些资料用于核对参数含义，具体控件及拒绝策略是本项目的目标设计，不能据此声称当前适配器已支持。
