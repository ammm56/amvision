更新：2026-10-27。沿[推理页面规划](inference-pages-design.md)补齐任务专属结果和第二批操作状态，保持简洁导航、无独立顶栏、品牌绿与可关闭覆盖面板。本批16组32张亮暗图已完成逐张复核；后续补充后累计58组116张。当前为设计规格和静态图，不扩展实际服务接口。见[设计总览](generated/推理/设计总览.html)与[逐图复核](inference-design-review.md)。

## 1. 本轮复核与修正

首批六组主要覆盖单图detection。当前浏览器推理页仍是目标/请求堆叠布局，仅作能力背景，本轮没有提交真实请求。首批静态图可以延续，但不能直接复制检测参数、对象数量和框到所有模型任务。

| 边界 | 统一要求 |
| --- | --- |
| classification | 图像级Top-K类别/分数；不伪造目标框、对象数或业务OK/NG |
| instance segmentation | 独立实例mask及分数；像素面积与物理面积分开 |
| semantic segmentation | 类别像素层和面积；不伪造实例编号和对象数量 |
| pose | 点名/骨架来自模型元数据；未检出点不补坐标、不画关联连线 |
| obb | 原图坐标、角度单位/方向/范围明确，按适配器统一约定；不能仅旋转水平框装饰 |
| anomaly | 图像分数、判定阈值和热图；异常分数不冒充概率；调用成功与异常判定分开 |
| 异步/批量 | 显式创建任务，逐项统计和结果可追溯；不套到同步数据面 |
| 超时未知 | 未确定服务端结果前不重提；查询需要服务端请求标识/状态契约，当前图不证明已实现 |

分割的透明度、类别图层、关键点/连线显隐属于显示选项，改变不重新推理。模型阈值是否可写由契约决定，异常模型本例阈值只读。任务专属参数不通过一个可任意改错的任务类型下拉混搭。

## 3. 数据和结果口径

- 分类示例：connector_0088.jpg；normal 0.982、defect 0.014、unknown 0.004，Top-3总和1。本例为单标签分类；多标签模型不强制总和1，能力与显示另按模型契约。
- 实例分割示例：package_0038.jpg；scratch0.95、dent0.91，共2个实例；mask半透明，标签不冒充GT。
- 语义分割示例：1600×1200=1920000像素；background1536000(80%)、bolt288000(15%)、nut96000(5%)，总和100%；背景可隐藏但统计范围不变。无效像素应另列，不填到背景。
- 关键点示例：四角模板预期4点，返回3点，右下未检出，坐标/分数为空；不把数据集标注里的遮挡点直接复制成预测。
- OBB示例：两个connector，−30°和20°，图像坐标顺时针为正、范围[−90°,90°)，长边方向；其他后端须转换约定或明确显示，不能默认为同一角度定义。
- 异常示例：分数0.87，模型阈值0.60，判定异常；热图范围0–1由本示例契约给定，不默认所有异常模型归一化到相同范围。
- 批量进行中：120项=成功58+失败2+执行中2+未执行58；已处理60=58+2，进度50%。部分失败终态：成功118+失败2=120，已处理100%。未执行不等于失败，零对象成功不等于检测失败。
- 本批主要业务日期沿首批2026-10-23；实例满载图使用独立样例2026-10-27。生成和复核日期2026-10-27。时间、分数、耗时和输入大小均为设计样例，不作为实测或计量证据。

## 4. 操作链与异常恢复

1. 单图上传/已有文件等来源互斥，部署决定任务类型。配置→显式执行→本次结果，目标切换不污染旧结果来源。
2. 批量从任务列表进入两步向导：输入与参数→检查→提交→任务详情。检查通过前不执行；检查页摘要只读，修改返回前步并重新检查；提交中防重提；结果未知先查状态。创建中的文件列表分页，不在UI一次加载百万项。
3. 批量完成保留成功结果。以失败项新建任务是显式新任务，先回到输入检查，不覆盖原任务或自动重试。
4. 满载是容量拒绝，服务可仍正常；保留原图和输入，不画0ms、排队或恢复倒计时。
5. 请求超时不能直接判定执行失败。请求状态查询契约就绪后，才提供图中的查询动作；若无法确认，提示联系服务/查看诊断，仍不悄悄重复执行。
6. 损坏图片在输入处反馈，禁止执行；不能保留上一张图冒充当前输入。
7. 短屏收起导航、收紧间距，主动作和抽屉关闭固定可达；正文独立滚动，不能靠缩成小字隐藏布局问题。

- 视觉：正常右侧详情关闭；短屏详情为可关闭覆盖面板、无底层遮罩，关闭按钮中性。
