## 目标与事实

沿用已确认导航、主题和表格/覆盖抽屉。目录只读说明，图编辑负责实例参数；Core随服务发布，没有单独安装、启用、禁用或回滚。正常信息用字段和短标签，错误保留原因和下一步。

当前筛选支持来源、类别、包、端口、能力、运行方式。依赖状态包括安装、版本、启用和满足情况；反向依赖需要推导。审计和版本读取接口已有，完整历史分页/筛选是后续契约，不能将当前limit截断冒充总记录数。

相同包版本不同内容在当前lifecycle中明确拒绝；升级更改运行目录也被拒绝。分离的静态预校验和可查询操作进度是未来设计；来源确认前不执行入口代码。

Image Preview有四输入一输出；Value Display的Fields为1–32项，Path/Label必填，Precision为0–6。长结构参数在目录只读展示。

Camera Vendor Extension是未来扩展示例，不代表现有Camera Nodes已经支持MVS。现有manifest仅usb-uvc已实现、hikvision-mvs计划中。兼容失败的Connector0.2.0/Python3.13是情景样例，不是当前manifest。

## 交互复用与分支

- 普通筛选即时生效；高级筛选点应用提交，关闭不应用未提交值。已应用标签可清除，重置页码并保留搜索词。无匹配与无已安装包区分。
- 依赖分本包依赖/使用本包的节点包；满足需核对版本、启用和加载，不能把已安装等同可用。无依赖用中性文字。
- 审计不可删除；操作失败与恢复成功可同时存在。缺操作者显示—；完整事件ID及哈希展开查看，不能编造短ID。
- 非法ZIP、缺manifest、非法schema复用文件无效结构；ID不一致、运行目录变化复用冲突结构，替换准确原因，不允许强制绕过。相同版本同内容显示已存在且一致，不重复覆盖。
- Python/API不兼容复用兼容失败；节点包缺失/禁用/版本不满足复用依赖不满足。厂商或Python依赖缺失复用外部依赖，不提供自动pip/驱动安装。
- 启用/禁用/回滚处理中复用变更处理中，阶段来自实际动作。启用成功复用已启用已加载详情；禁用失败恢复成功复用失败已恢复结构。关闭不取消后台操作。
- 明确403且未执行使用权限变化；请求已送出但断线仍用结果待确认，禁止由权限变化推测结果。失去读权限后移除资源缓存可见内容，转无访问权限页。
- 初次加载用骨架；刷新保留旧数据加小进度。无缓存加载失败用连接中断的空内容变体，不显示假0；有缓存必须标记上次时间。
- 空包列表保留Core入口；只剩Core时目录来源为Core，筛选查看正常。无问题、筛选无匹配、无记录分别使用准确空态文案，不共用系统正常。
- 长字段换行并可复制；未知参数类型显示原始schema和类型名。单位/frame未声明显示—，不猜测。
