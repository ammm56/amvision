# 数据集页面与交互设计

更新：2026-10-24。状态：23 个场景已生成亮暗配对，共 46 张静态设计稿，待用户审阅，见[设计总览](generated/数据集/设计总览.html)。包含列表、样本与结构、大图、两类抽屉、两个向导的四步主状态、完成详情、五种关键异常与两种短屏布局。本文是当前数据集布局与交互的主要依据；取代“主页只显示导入/导出记录，管理数据集只能放对话框”的旧方案。

目标是未来完整的数据集管理体验，不受当前页面或 API 的实现进度限制。业务边界见[数据集管理约束](dataset-management-plan.md)，旧图依据见[逐图复核](dataset-design-review.md)，出图使用[中文提示词](prompts/数据集.md)。

## 1. 设计方向

保留 bak1 数据集工作台、导入检查、版本样本和导出详情的合理业务结构。公共导航、配色、文字、控件、抽屉与[项目设计](generated/项目/设计总览.html)统一，不能把项目列表的内容结构套到所有数据集页面。

数据集分类首先提供管理和查看，导入与导出是围绕数据集的操作，记录是执行历史。图片上的标注、数据结构与样本关系必须可见，而不是只能阅读 JSON 或数量。

本轮纠正：

- 默认进入数据集列表，不再默认只看导入记录。
- 管理功能直接属于主页面；删除“管理数据集”必经对话框和重复管理按钮。
- 查看进入完整版本工作区；样本、结构和标注审阅拥有足够空间。
- 导入与导出向导、详细报告使用完整页面。小型元数据表单和补充信息才使用右侧抽屉；危险确认使用对话框。
- 不增加独立顶栏、不增加左侧导航分类、不恢复常驻右侧详情分栏。

## 2. 信息架构与常用路径

左侧只有一个“数据集”入口。以下均为内容区局部标签或详情页，不新增左侧子导航：

```text
数据集
  数据集（默认列表）
    查看 → 指定版本工作区
      样本 → 大图与标注查看
      数据结构 → 目录、文件与样本关联
      类别与划分
      质量检查
      版本与来源
    详情 / 编辑信息 → 右侧抽屉
    导入新版本 → 导入向导
    创建导出 → 导出向导
  数据集版本（跨数据集检索版本）
    查看 → 同一个指定版本工作区
  导入记录 → 导入详情 → 查看生成版本
  导出记录 → 导出详情 → 下载 / 创建训练
```

主要路径：

1. 导入 ZIP → 识别结构 → 核对类别和划分 → 检查并提交 → 查看生成版本。
2. 在数据集列表点击“查看” → 筛选样本 → 图上核对标注 → 打开大图检查对象。
3. 在“数据结构”定位文件 → 查看对应样本和标注 → 返回时保持目录和选择状态。
4. 核对版本 → 选择导出格式 → 检查兼容性 → 导出文件 → 下载或创建训练。
5. 从质量问题定位样本 → 外部标注交接或创建新版本 → 检查变化 → 保留旧版本引用。

顶层“数据集版本”便于跨数据集查找；详情内“版本与来源”仅查看当前数据集的版本、来源和依赖。两者使用同一版本数据，不各维护一套对象。标签按需切换，一次只显示一张主表。

## 3. 数据集主页面

### 3.1 内容组织

内容区第一行左侧为“数据集 / 数据集版本 / 导入记录 / 导出记录”；右侧为适合当前标签的主操作。数据集标签主要操作为“导入数据集”，不常驻大表单，不重复写“数据集管理”大标题。

第二行提供名称搜索、任务类型、可用状态筛选和刷新。当前项目范围以紧凑页内文字表达；不新增全局项目选择栏，也不隐式混合多个项目的数据。

主体为紧凑表格：

| 列 | 含义 |
| --- | --- |
| 数据集 | 名称及必要说明，长名称截断并可完整查看 |
| 任务 | classification / detection / segmentation / pose / OBB 等对应类型 |
| 最新版本 | 最新创建且可用的版本；创建中的版本在版本列表显示，不能替代可用版本 |
| 样本 / 类别 | 明确基于所显示版本的数量，不把标注对象数当图片数 |
| 数据划分 | train / val / test 紧凑摘要；未配置 test 为中性状态 |
| 更新时间 | 明确为数据集内容或版本更新，不混用导入任务开始时间 |
| 操作 | 查看、更多；更多含详情、编辑信息、导入新版本、创建导出 |

列表不展开完整文件路径、长 ID、类名全集和全部运行统计。最新版本用于浏览入口，训练、评估和 Workflow 已保存引用仍绑定明确版本，不自动升级。

单击行选择；点击名称或“查看”打开工作区。复选框只表示批量选择，不兼任打开详情。选中行使用品牌软底，普通悬停为中性灰；右侧详情仅由明确动作打开，关闭后主表完整恢复。

### 3.2 管理范围

- 编辑名称与说明：短表单抽屉；保存错误保留输入，冲突不静默覆盖。
- 创建数据集：通过首次导入建立；无需为了填充界面再增加空壳创建流程。
- 导入新版本：指定已有数据集，显示目标名称和来源。
- 删除版本：在版本管理处明确执行，检查外部引用；不把删除记录和删除版本混为一个动作。
- 不新增整数据集一键删除。本轮重点为管理、查看及版本操作，整数据集删除需另行确定契约。
- 有正在处理的导入/导出时，显示一条紧凑任务入口；需要查看多任务时进入任务页，不固定铺第三张大表。

### 3.3 版本和记录标签

版本表字段：数据集名称、版本、样本数、任务、来源、创建时间、状态、查看/导出/删除版本。切换或打开版本始终使用稳定标识，名称重复时可区分。

导入/导出记录表保留状态、时间、规模和详情入口。导入失败无生成版本时不能显示“查看版本”；导出完成但文件已清理时不能伪装可下载。记录详情是完整报告页面，补充原始参数才进入抽屉。

## 4. 版本工作区：默认看样本

### 4.1 固定上下文

页内一行：返回、数据集名称、版本选择、任务类型；右侧“创建导出”和更多操作。名称是资源标题，不是全局顶栏。版本选择明确显示来源和创建时间，切换后取消旧请求，避免新版本文字配旧版本图片。

下方用一行摘要显示样本数、标注对象数、类别数、train/val/test。只展示本版本真实可用指标，未知统计不写零。局部标签为“样本 / 数据结构 / 类别与划分 / 质量检查 / 版本与来源”。

### 4.2 样本网格与列表

- 默认网格，缩略图直接叠加真实标注；工具区包含 split、类别、标注状态、质量问题、名称搜索、网格/列表、标注显隐。
- 卡片包含等比例图片、文件名、划分和必要对象数；不堆复杂阴影卡片和长技术字段。
- 框直接绘制在对应目标上；类别标签避开目标主体，密集标注可隐藏文字而保留框。
- 图像留白用于保持比例，不裁切掉目标；不把所有原图强行拉伸成固定比例。
- 单击选择样本；“查看”或双击打开专用大图。键盘可打开同一查看器；复选框单独用于批量操作。
- 信息按钮打开可关闭右侧抽屉，显示尺寸、划分、对象列表和来源；主网格位置不重排。需要精确检查时进入大图，不依赖抽屉小图。
- 类别筛选决定样本集合；标注图层显隐只改变当前图像绘制，二者不混淆。显示“当前可见 / 全部对象”避免隐藏对象被误认为不存在。
- 缩略图加载失败只影响该项，保留文件名和重试；缺文件、未标注、已确认无目标分别表达。

### 4.3 大图与标注联动

主要画面为原始比例图片，页内工具为上一张/下一张、适配、缩放、平移、标注显隐。类别颜色稳定，选中对象增加明显轮廓与编号，不能仅依赖颜色。

图上点击对象与对象列表选择互相定位。放大后的线宽和标签可读，坐标由原图映射；缩放、平移和图像留白不能改变标注位置。显示任务需要的原始几何值和单位，类别真值没有模型置信度。框列表明确采用 X / Y / 宽 / 高顺序，单位 px；不能用四个未标明含义的数代替字段说明。

大图默认不覆盖数据面板；对象/样本信息通过右侧可关闭检查抽屉展开，关闭恢复全幅。对象列表使用紧凑行，点击后在未被遮挡的画布区域定位目标，不将选中目标放在抽屉背后。原始标注文本作为次级只读内容，可复制或查看对应文件。

返回后恢复版本、筛选、页码、样本选择、滚动位置。上一张/下一张沿用进入查看器时的筛选与排序，不跳出集合。此处是标注查看，不添加内建画框制作工具来替代外部标注系统。

## 5. 数据结构：目录、文件、图片和标注互相对应

这是工作区的独立主要视图，不能只在导入检查中显示一次目录树。

内容区提供“样本结构 / 文件结构”切换：

| 视图 | 展示内容 | 限制 |
| --- | --- | --- |
| 样本结构 | split → 样本 → 图像、标注、配对媒体及关联元数据 | 是逻辑组织，不假称每个样本都有独立标注文件 |
| 文件结构 | 当前版本受控资产的相对目录、文件类型、大小和关联样本 | 来自资源清单，不暴露任意服务器磁盘目录 |
| 来源包结构 | 导入详情中的原 ZIP 目录 | 与归一化版本区别；来源包清理后说明不可用，不伪造现存文件 |
| 导出包结构 | 导出详情中的目标格式目录 | 不与源版本文件混为同一份 |

文件结构主视图左侧是可收起的目录树，中间为当前目录文件表；它们共同构成文件浏览工具，不是右侧固定详情栏。右侧详情仅在点击信息时覆盖打开，有关闭按钮。

文件表显示名称、类型、大小、关联样本与必要状态。选择图片可打开带标注的大图；选择标注文件显示其关联样本列表，点击其中一项定位图像与对应对象。XML/TXT 单图标注与 COCO 共享 JSON 都需要适用，不能硬编码同名一对一配对。大 JSON 只读分页摘要，不把整个文件加载进浏览器。

目录与文件按需展开、分页或虚拟化；节点数量明确是直接子项还是整棵目录统计。过滤无结果与空目录分开。数据结构、样本浏览和统计基于相同版本，不互相拼接不同来源的计数。

## 6. 类别、划分、质量与版本

| 视图 | 主要内容 | 下一步 |
| --- | --- | --- |
| 类别与划分 | 类别、样本数、对象数、train/val/test 分布；空标注与未标注摘要 | 查看对应样本；配置映射或重新划分时进入创建新版本 |
| 质量检查 | 覆盖范围、规则、时间、问题类型、受影响样本、未检查项 | 定位样本；重新检查；外部处理后导入新版本 |
| 版本与来源 | 版本列表、导入/派生来源、变更摘要、导出与训练等引用 | 切换查看、比较、导出、删除版本 |
| 新版本操作 | 来源版本、输入变更、类别映射/划分规则、预期影响 | 检查并提交后台任务；失败不影响源版本 |
| 外部标注交接 | 选定样本范围、格式、类别、样本匹配、返回结果差异 | 导出待处理资料、导入回传结果并创建新版本 |

不同类别的“样本数”可能重叠，不能将其相加当作图片总数；对象数与图片数始终分开。未配置 test 不是错误。检查尚未完成不能显示“全部通过”；近似重复只提供候选，不自动删除。

当前数据集真值、模型预测、人工修订建议使用不同来源说明与图层。普通数据查看不自动运行模型或质量扫描。

## 7. 导入与导出

### 导入向导

完整页面按“上传 ZIP → 数据定义 → 类别与划分 → 检查并提交”推进。文件上传后识别与预检查是后台操作，不等同于提交正式数据版本。

检查阶段保留 bak1 的可读内容：包摘要、目录树、图像/标注计数、匹配关系、类别映射、划分及错误定位。只在当前步骤展开对应内容，不在一个弹窗堆满所有步骤。文件树和报告各有有界滚动，底部返回/提交可达。

阻断错误使提交不可用；警告显示事实与处理选择。成功后进入导入详情，可查看生成版本。离开尚未提交的表单需提示；关闭或离开已提交任务详情不取消后台任务。

### 导出向导

完整页面按“来源版本 → 目标格式 → 类别与划分 → 兼容检查”推进。来源固定，目标类型按能力选择。图上可展示未来完整支持能力，落地时按已注册能力开放；不会因设计图存在就默认所有格式已实现。

显示目标文件结构预览、映射、划分、预计规模及兼容问题。复杂格式差异在检查步骤展开，不常驻技术架构说明。导出不修改源版本。

### 向导各步骤的字段与边界

| 流程步骤 | 核心内容 | 前进条件与返回行为 |
| --- | --- | --- |
| 导入：上传 ZIP | 文件选择/拖入、文件名、大小、上传进度、取消和重选 | 完整上传且可读取后继续；上传失败保留错误与重选入口，不显示已创建版本 |
| 导入：数据定义 | 新数据集或已有数据集的新版本、名称、任务类型、识别格式与手动选择 | 名称有效、类型与格式支持；已有目标显示明确名称，返回不重复上传有效包 |
| 导入：类别与划分 | 类别映射、train/val/test 来源及计数、保留或重新划分 | 映射无冲突、必需划分满足规则；未配置可选 test 不阻断 |
| 导入：检查并提交 | 来源包结构、图像/标注关联、检查结果、目标确认 | 阻断错误为零才允许提交；提交后进入独立详情，不将关闭页面视为取消任务 |
| 导出：来源版本 | 明确数据集、不可变版本、任务、样本范围 | 来源存在且可用；不隐式跟随“最新”版本变化 |
| 导出：目标格式 | 格式、任务、输出名称及能力约束 | 格式支持当前数据类型；格式不兼容时说明原因 |
| 导出：类别与划分 | 类别序号/名称映射、导出划分、选定范围与计数 | 映射与范围有效，保留源数据，不原地重写版本 |
| 导出：兼容检查 | 目标结构、预计规模、检查事实、来源与输出确认 | 无阻断错误才创建；估算不当作实际包大小，完成后在详情显示实际产物 |

两个向导四步的主状态现已生成亮暗配对。上传中断、预检查阻止、生成版本失败、格式不兼容、产物已清理及两个最后检查步骤的短屏布局见[向导与状态规格](dataset-wizard-states-design.md)。输入校验、提交中、取消、未知提交结果等状态仍按契约落实，不把代表性图稿当作全部错误覆盖。

### 详情报告

导入详情展示状态、阶段、来源、检查、生成版本与下一步。导出详情展示来源版本、格式、类别/划分、文件清单、产物可用性、下载和适用训练入口。原始请求、长路径、完整 checksum 放次级详情。

执行中、失败、取消和部分产物状态清楚，不用全局成功标记掩盖缺失文件或未完成检查。错误可清除界面提示，但原始执行事实仍在记录详情。

## 8. 统一交互状态

| 场景 | 必须表达 |
| --- | --- |
| 首次无数据 | 一处简洁引导与导入动作，不重复空表、空任务和无意义分页 |
| 筛选无结果 | 保留筛选并提供清除，不误导为数据集已空 |
| 加载 / 刷新失败 | 局部状态；有旧结果时保留并标明未刷新，不能冒充最新 |
| 大数据量 | 服务端索引检索、分页、缩略图懒加载；不全量扫盘再响应 |
| 权限 | 只读可查看；不能编辑/删除的原因明确，不能靠隐藏按钮代替服务校验 |
| 删除导入记录 | 清理记录、关联任务、ZIP 和导入暂存；保留版本、图片、标注 |
| 删除版本 | 列出图片、标注、关联记录的影响；存在外部引用时阻止 |
| 版本删除 / 文件被清理 | 深链接显示资源不可用及返回入口，不显示其他版本冒充 |
| 保存 / 提交冲突 | 保留输入，重新检查；不自动重试写操作或重复创建 |
| 键盘 / 焦点 | 操作可达；抽屉关闭返回来源按钮；查看器 Esc 按层关闭，输入框不触发快捷切图 |

## 9. 新视觉类型的统一承载

- classification：图像类别或多标签；没有 boxes 就不画假框。
- detection / segmentation / pose / OBB：分别绘制真实框、mask/轮廓、骨架或旋转框，叠加与对象表同源。
- 异常/瑕疵：正常、异常、未知分开；有缺陷区域才显示区域。模型热图属于预测层，不充当真值。
- 连接器 2D：查看原图、已提供几何/参考值、单位和来源；合成真值与独立实测参考分开。定位、测量和判定仍由 Workflow 与节点包承担。
- 深度 / RGB-D / 点云：通过同一工作区切换对应查看器，明确单位、坐标系、无效值和媒体配对。没有单位时不显示物理测量结论。
- 标定图和模板可以独立作为 Workflow 资源；不强制先建立训练数据集。

这些是完整产品设计覆盖，不代表当前均已实现，也不新增连接器或 3D 的左侧业务入口。

## 10. 视觉与短屏约束

继承[通用要求](prompts/通用要求.md)：11 个平级导航、无独立顶栏、品牌 #00D992、主按钮白字、hover/focus 中性灰、选中品牌色、危险 #DC2626。亮暗使用同一内容、同一状态与布局。

图片标注颜色按类别稳定分配，带文字/编号；不为统一品牌而把所有类别画成同一种绿。图像背景使用中性查看器底色，亮暗切换不改变原始像素或标注含义。

目录树、文件、返回、关闭、折叠、排序和普通导航图标统一使用中性灰线条；不使用亮蓝实心文件夹和蓝色普通文字。选中项才使用品牌软底及品牌图标，主按钮图标为白色。来源包、版本资产、导出包三种文件树遵守同一规则。普通 COCO 关联说明使用中性信息样式，不借蓝色横幅抢占层级。

1920×1080 为主要设计视口；1366×768 时减少网格列数与低优先表格列，保留名称、版本、主要操作。目录树可收起，抽屉覆盖主内容，向导正文滚动且底部动作始终可达。不能依赖把字体缩小或强制固定三栏来适配。精确 token、缩放和键盘交互需在后续可运行原型验证。

## 11. 出图步骤与通过条件

截至 2026-10-24，已完成 23 组亮暗、46 张静态稿。新增 13 组覆盖两个向导前面六步、五种关键异常和两种短屏布局；具体范围见[状态设计](dataset-wizard-states-design.md)。每张完成后检查再进入下一张，当前待用户审阅。其他管理子页与剩余异常需继续设计，静态图不等同于真实交互验收。

1. 数据集列表：先确认管理主体、局部标签和查看入口；随后生成同数据暗色配对。
2. 版本样本网格：确认图片直接叠加标注、筛选与版本上下文；随后配对。
3. 数据结构：确认目录、文件和样本关系；右侧检查抽屉独立展开状态；随后配对。
4. 样本大图：确认标注与对象联动、关闭抽屉及返回路径；随后配对。
5. 已补两类抽屉、导入/导出四步主状态及完成详情；后续补版本/记录列表、类别/划分、质量、来源和创建新版本。
6. 已补五种关键异常与两个短屏检查页；继续补空态、权限、样本缺图、引用阻止，以及其他页面的短屏状态。

每张核对：旧稿内容保留是否正确、导航、顶栏、抽屉、主色、样例数字、标注来源、文件关系、下一步操作及亮暗一致性。任何主结构不通过，先修正本页，不扩散到后续页。

生成图片放入直观目录“数据集”；仅保留最新有效图与总览/清单。完整中文请求按最终场景保存；不得恢复已删除的错误请求。静态图的检查与真实产品功能、性能、长期稳定性验收分别记录。
