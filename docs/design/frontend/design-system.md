# 视觉与组件系统

> 修订说明（2026-10-23）：以 `bak1` 合理页面为基础统一组件风格。简洁平级左导航、无独立顶栏、右侧按需展开抽屉，见[修订方案](frontend-redesign-plan.md)。五入口合并和固定列表详情方案已否决。以下 token 用于核对当前实现，品牌和交互语义继续保留。

## 1. 视觉方向

界面应像一套由视觉工程师长期使用和逐步打磨的专业工作台：安静、紧凑、准确，有真实数据和明确反馈。未来感来自精密和实时，不来自装饰。

亮色和暗色是同一套工作台的两种外观，普通页面、流程编辑器、运行监视和应用模式均随外观切换。图片内容可以置于中性深底，不能因此把整个编辑器固定为暗色。

核对日期：2026-10-22。颜色及基础尺寸以 [tokens](../../../frontend/web-ui/src/shared/styles/tokens)、[公共样式](../../../frontend/web-ui/src/shared/styles/content.css)和现有共用组件为依据。以下组件规则也是后续出图与实现的评审要求，不表示每个页面已经完成全部交互验收；新增能力须先核对页面与 API。

## 2. 色彩

### 2.1 品牌与中性色

| 用途 | 浅色主题 | 深色主题 |
| --- | --- | --- |
| 页面背景 | `#F6F7F9` | `#101010` |
| 主表面 | `#FFFFFF` | `#171918` |
| 柔和表面 `--am-surface-soft` | `#FFFFFF` | `#1A1A1A` |
| 弱化表面 `--am-surface-muted` | `#ECEFF2` | `#242825` |
| 强文字 | `#171A1F` | `#FFFFFF` |
| 正文 | `#344054` | `#F2F2F2` |
| 次要文字 | `#667085` | `#A7B0AB` |
| 边框 | `#E4E7EC` | `#3D3A39` |
| 品牌填充色 | `#00D992` | `#00D992` |
| 品牌填充上的文字与图标 | `#FFFFFF` | `#FFFFFF` |
| 文字强调色 | `#00D992` | `#00D992` |
| 选中软底 | 品牌色 12% 与表面色混合 | 品牌色 12% 与表面色混合 |
| 选中悬停底 | 品牌色 17% 与表面色混合 | 品牌色 17% 与表面色混合 |

品牌绿用于主要操作、当前选择、进度和正常运行。不能把所有图标、数字和边框都染成绿色。

主按钮在两种外观下统一使用品牌绿底、白色文字及图标；悬停使用 `#2FD6A1`，按下使用 `#10B981`，禁用沿用公共禁用样式。导航、设置、页签、单选、多选、节点选择控件的已选中状态及正常运行状态统一引用品牌色，不再单独使用深绿色强调文字。危险按钮保留错误语义色。品牌亮绿在浅底上及配白字时的对比度有限，现场显示器可读性需单独核对，不据此声明无障碍对比度达标。

普通悬停与选中必须分开：未选中的导航、菜单、下拉选项、次要按钮和列表行使用中性灰色背景（亮色 `#F0F1F3`，暗色 `#303030`），文字保持普通颜色。导航、单选、多选控件的选中状态使用品牌色文字或勾选标记及品牌软底；再次悬停只轻微调整选中背景。下拉菜单的 `is-active` 表示鼠标或键盘当前定位，不代表 `is-selected`，确认选择前只显示中性背景。键盘焦点通过轮廓标明，禁用项不响应悬停。颜色过渡采用约 120–140ms 的短缓动，不加入缩放、位移或页面切换动画；减少动态效果偏好下关闭过渡。

项目、运行实例及其他资源列表的选中行统一使用品牌软底，未选中行悬停使用中性灰底。已选中行悬停只轻微调整品牌底色，不能覆盖选中提示。列表标题和数据保持正常文字色，运行状态徽标继续表达独立的状态语义。列表使用 `--am-row-selected` / `--am-row-selected-hover`，分别引用公共品牌选中背景，避免另行写死旧暗绿色。

表单单选、多选输入使用统一绘制的品牌绿选中底与白色标记，避免浏览器原生控件自动调整 `accent-color` 后出现不同深浅。保留原生输入的键盘、标签、禁用和焦点行为；系统强制颜色模式恢复原生绘制。多选下拉框收起时的值标签使用普通文字与中性背景，菜单内已选中项使用品牌色。

输入框、文本域、搜索框、单选/多选下拉框及 Workflow 节点参数的焦点边框使用独立的 `--am-input-focus-ring`：亮色 `#98A2B3`、暗色 `#8B8B8B`。焦点仅表示正在编辑，不使用品牌绿色；选中值和勾选标记继续遵循品牌色规则。

应用列表只显示应用名称，完整 ID 在详情中显示。触发入口列表展示名称、类型、状态、触发时间及操作；无触发记录时显示“未触发”。操作列的“详情”打开右侧抽屉，展示入口 ID、运行实例 ID、健康计数和最近错误，避免诊断字段挤占列表。

运行时和触发入口详情共用 `SideDrawer` 及 `resource-details` 样式：基本信息采用两列卡片，窄屏改为一列；健康详情和最近错误采用独立分区，结构化健康信息使用格式化 JSON，长 ID 可换行，诊断区域限高并允许滚动。

### 2.2 语义色

- 成功：品牌绿色，配对勾和“成功/健康”。
- 警告：琥珀色，配三角图标和可恢复说明。
- 错误：红色，配错误图标、错误摘要和处理入口；错误提示软底与危险主按钮的实色填充分别定义，不混用。
- 信息：冷蓝色，用于提示和非阻断状态。
- 中性：灰色，用于排队、停止、未配置和历史状态。

协议等类别标签可使用独立的品牌色样式，不表示服务健康状态。图像标注、用户配置的结果颜色和图表系列色不随交互主题色统一而改写。

### 2.3 视觉叠加色

- 搜索 ROI：天蓝。
- 参考区域：紫色。
- 检测结果：橙色。
- 当前选中：绿色。
- 不合格结果：红色。
- 草稿或未确认几何：琥珀色。

叠加图形必须配标签或图例，不能只依靠色彩表达类别。

## 3. 字体与数字

项目图标固定使用 `#00D99B` 背景与 `#10221D` 的 AM 字样，不随主题切换。AM 在 Inkscape 中使用 Arial Bold 文本工具排版，保持字体原始宽高比例，按可见字形边界水平、垂直居中。图标颜色独立于页面操作按钮的主题色。

可编辑母版为 [am-icon-master.svg](../assets/am-icon-master.svg)，保留文字对象；在 Inkscape 中将文字转换为路径后另存为 [favicon.svg](../../../frontend/web-ui/public/favicon.svg)，作为前端侧栏、登录页、启动页与启动器 SVG 的共同来源。发布用 SVG 不依赖目标机器字体。

PNG 使用 Inkscape 按页面导出，保持圆角外透明；256 像素版本用于 `favicon.png` 和启动器 `Assets/app.png`。ICO 在 GIMP 中按独立尺寸图层导出，包含 16、20、24、32、40、48、64、128、256 像素，使用 32 bpp 与 8 位透明度；不能合并这些尺寸图层。前端 `favicon.ico` 与启动器 `Assets/app.ico` 使用同一文件。图标制作工具仅用于开发资产维护，不加入产品运行时依赖。

- 中文正文：系统无衬线字体优先，风格中性、字面清楚。
- 英文和界面数字：Inter 或等价无衬线字体。
- ID、路径、JSON、日志、时间戳：等宽字体。
- 对话框、详情等必要标题按现有组件使用；普通 `.page-header h1` 保持隐藏，不根据旧图恢复 `24–28px` 页面大标题。
- 区域标题：`16–18px`，字重 `650`。
- 正文：`13–14px`，行高 `1.5`。
- 表格和密集字段：`12–13px`。
- 关键指标：`24–32px`，使用 tabular numbers。

不使用超大营销标题。页面首屏重点是操作和状态，不是口号。

### 导航栏品牌

展开导航栏时，顶部显示固定的 `AMVAR` 与轮换词缀，不重复显示 AM 图标；收起时只保留原有 AM 图标与展开操作。品牌链接始终指向 `/`，沿用启动页面路由，不添加下划线或悬停背景。

词缀按 `Vision → Workflow → DeepLearn → Connect → Identify → Control → Motion → Label → Agent` 循环，首次显示 `Vision`。AMVAR 与词缀作为整体在顶部品牌区域居中，折叠按钮固定在右侧。词缀保持品牌绿底、白色文字，AMVAR 默认继承当前外观的正文色，悬停和键盘聚焦时使用当前主题的文字强调色；不增加下划线或品牌链接背景。词缀容器宽度随文本平滑伸缩；整个文字组合的位置使用相同弹簧参数过渡，文字不缩放变形，导航栏整体宽度保持稳定。词缀仅表达品牌能力方向，不代表当前页面、服务状态或已经提供的功能。

动画按 [Vue Bits Rotating Text](https://vue-bits.dev/text-animations/rotating-text) 的 Vue 示例适配：轮换间隔为 2 秒，从末字符开始按 25 毫秒错开，采用 `damping: 30 / stiffness: 400` 的弹簧动画；旧词向上退出后，新词由下方进入，不叠加淡入淡出。悬停、键盘聚焦和页面隐藏时停止轮换；恢复后重新等待完整间隔，不补播后台动画。减少动态效果偏好下静态显示 `Vision`，关闭布局动画。收起或卸载时释放计时器和监听器。

导航栏、图编辑空画布和“设置 → 关于 → 应用名称”共用 `AnimatedBrand` 组件。导航栏保留原有大小写、品牌绿底和白字；图编辑空画布使用相同样式居中显示，不显示额外图标，添加节点后隐藏；只有关于页面使用 `plain` 展示：前缀和词缀全部小写、词缀无背景、字体与相邻 Community Edition 元数据一致（不加粗）、文字继承当前主题颜色，不提供导航链接。

使用本地安装的 `motion-v` 中的 `Motion` 与 `AnimatePresence` 实现，按当前 API 使用 `as="span"`，不沿用参考代码中的旧 `tag` 属性。依赖随 Vite 构建一起分发，不依赖 CDN 或外部字体。动画限制在品牌词缀内，不改变业务页面切换、Workflow、Runtime 或 Trigger 行为。

宽度取自当前词的不可见测量元素，并由 Motion 弹簧直接驱动真实宽度；居中的 Flex 组合随宽度连续移动。不能只给父容器添加 `layout`：`AnimatePresence mode="wait"` 在退出完成后替换内部文字时，父容器可能没有同步更新，从而导致宽度硬跳。测量元素不占布局空间，ResizeObserver 随组件卸载清理。

## 4. 网格、尺寸和密度

- 全局间距基于 `4px`，常用 `8 / 12 / 16 / 20 / 24 / 32px`。
- 左侧导航：展开 `220px`，收起 `64px`。
- 不预留全局顶部栏高度；图编辑工具栏、页内操作栏按对应组件布局。
- 页面左右边距：宽屏 `28–32px`，窄桌面 `20–24px`。
- 常规表单字段高度：`36–40px`。
- 紧凑表格行高：`44px`；含两行说明时 `56px`。
- 圆角：`4 / 6 / 8px`，只在标签和状态徽标上使用胶囊圆角。
- 阴影只用于浮层、菜单、对话框和可拖动检查器；常规内容区使用边框分层。

字段 `36–40px`、表格行 `44/56px` 是出图的默认密度目标，不是所有现有页面的实测值；具体组件确定后同一批图复用，不逐张改变字号与控件高度。页面内容边距来自 `clamp(20px, 2vw, 32px)`，全幅图工作台不套普通页面边距。

## 5. 工作台外壳

### 5.1 左侧导航

- 顶部为品牌名称与折叠按钮，收起时以 AM 图标作为展开入口。
- 不增加全局 Project 切换器；沿用项目页和业务表单的选择上下文。
- 当前 11 个平级入口见[信息架构](information-architecture.md)；修订参考当前简洁形式，不显示功能域分类标题，不擅自合并入口或新增项目选择栏。
- 当前项使用品牌软底、品牌色图标/文字及适度字重；未选中悬停为中性灰。不额外补旧图中的左侧色条。
- 用户菜单位于底部；折叠按钮在顶部。版本和服务诊断在设置中查看，不添加虚构版本、授权级别或常驻连接栏。

### 5.2 页内上下文

- 当前 `WorkbenchShell` 没有全局搜索、面包屑、活动数量和用户菜单顶栏。生成设计图不能凭空补上第二套导航。
- 详情保留必要返回入口和资源名称；各页筛选、项目范围、运行状态放在自己的操作区。
- 图编辑器、Runtime 监视和 App Mode 使用各自已有工具栏；工具不因换主题改变位置或业务含义。

### 5.3 页面操作区

- `.page-header h1` 不显示，`.page-header` 不设置原有 `min-height: 44px`；没有内容时不占空白标题行。
- 设置二级导航的 `.settings-workspace__sidebar-title` 同样不显示。
- 保留相关操作、必要说明和状态。主操作数量服从业务，不因没有页面大标题而补宣传文案或资源 ID。
- 对话框标题、资源详情名称、节点名称和图编辑器应用名称不属于上述隐藏范围。

## 6. 核心组件

### 6.1 状态徽标

包含状态图标、文字和轻色背景。任务状态与运行实例状态分开命名：

- 任务：排队中、运行中、成功、失败、已取消。
- 运行实例：已停止、启动中、健康、性能下降、失败。
- 资源：草稿、可用、已归档、不兼容。

### 6.2 指标块

用于样本数、mAP、时延、吞吐、运行次数等。最多一行四到六个，数字清楚，单位紧邻数字，趋势只在确有时间序列时显示。

### 6.3 数据表格

- 长表按实际组件提供滚动和分页；排序、固定表头和列显示设置仅在实现支持时绘制。
- 第一列为名称或 ID，第二列通常为类型/版本。
- 状态、更新时间、来源和操作靠后。
- 行选中使用品牌软底；未选中行悬停使用中性灰底，已选中行悬停只略微改变品牌底色。
- 批量操作仅在选中后出现。
- ID 和路径允许一键复制。

### 6.4 筛选栏

搜索和适用筛选在左，刷新在右。仅绘制当前页面支持的条件；“保存视图”、列设置和批量操作不能作为每张图的默认装饰。可移除筛选标签用于确有多条件组合的场景。

### 6.5 表单与向导

- 先选择影响后续选项的关键字段：任务类型、模型类型、来源资源。
- 不兼容选项直接隐藏或禁用并给出原因。
- 只对确有复杂度的参数分组；File Summary、Load Local Image 等已明确简化的节点配置不强加折叠。
- 多步操作最后展示摘要与校验；简单表单沿用直接提交，不为了设计稿统一改成向导。

### 6.6 右侧检查器

资源详情优先复用 `SideDrawer`；工作流节点沿用属性面板，图形配置沿用专属编辑器。三者共享字段、按钮和状态规则，但不能互相替代。可调整宽度、固定底栏等能力须按具体组件确认，不假设所有抽屉都支持。

### 6.7 日志查看器

使用主题对应的代码表面和等宽文本。时间、级别、搜索、自动滚动、下载和复制按实际日志组件提供；错误行不能使用大面积高饱和红底。

### 6.8 空状态

使用小型线性图标、直接标题、原因和一个主操作。避免大型人物插画。例：“还没有可用的 DatasetExport。先从数据版本创建与 YOLO11 detection 兼容的导出。”

### 6.9 确认对话框

明确显示对象名称、影响范围、是否可恢复和正在运行的依赖。危险操作按钮使用红色，默认焦点不落在危险按钮上。

项目删除设计稿的危险主按钮在亮暗外观均采用饱满实红 `#DC2626`、白色文字；悬停可用 `#B91C1C`，不能把错误提示的浅红软底当作可用删除按钮。确认 ID 未匹配、预检未完成或存在阻止项时仍禁用，用中性禁用背景与文字并说明原因，不能为了颜色鲜明而放开操作。确认后的主图显示真实输入值，不以占位符冒充已填写。

删除反馈按实际步骤分别着色：“项目已移除”可以配小绿勾；“文件清理待完成”使用琥珀时钟和浅/深琥珀提示面板，仍明确尚未确认完成。“检查结果”或“重新检查”作为主要查询动作使用品牌绿白字，关闭和取消保持中性次按钮。查询按钮绿色不代表清理成功；不存在未完成就显示“全部完成”、强制删除或自动重试的含义。此项为最新设计规范，不代表当前产品样式已同步实现。

### 6.10 资源列表状态边界

列表的状态边界保持页内操作、筛选和表头稳定，只替换内容区。这里描述交互规则，不要求新增名为 `ListStateBoundary` 的组件；仓库目前没有这一公共组件：

- 首次加载：显示表头与行骨架，不使用整页 spinner，不伪造百分比。
- 筛选无结果：保留筛选标签，说明资源可能仍存在，主操作为清除筛选。
- 后端重连：若当前页面仍持有已加载结果，保留并标为旧数据，显示连接提示和允许的恢复操作；无缓存时明确不可用。不承诺硬刷新后能恢复历史结果，也不默认显示不存在的自动重试次数。

首次空状态保留页面稳定结构，但主操作和前置关系必须按领域定义：

| 页面 | 首次空状态主操作 | 必须说明的前置关系 |
| --- | --- | --- |
| 任务 | 打开对应业务工作台 | 任务从所属业务页创建；长期 runtime 不进入任务中心 |
| 触发源 | 打开流程应用 | FlowApplication → healthy WorkflowAppRuntime → TriggerSource |
| 自定义节点 | 重新扫描目录 | 本地 Node Pack manifest、版本、依赖、runtime 要求与启用状态 |

### 6.11 有限任务生命周期

任务状态与进度复用已有 `TaskStateBadge`、`TaskProgress`，动作与事件遵循以下语义。状态映射和动作权限以对应任务 API 为准：

- `queued`：没有百分比和 ETA，可取消。
- `running`：显示真实阶段与已知进度，可取消。
- `succeeded`：显示产物或结果入口，不再提供取消。
- `failed`：显示结构化错误和诊断入口；只提供实际支持的重新提交动作，不能自动重放业务。
- `cancelled`：终态节点为 cancelled，保留日志和安全中间产物，不恢复旧任务。

### 6.12 长期实例生命周期

DeploymentInstance 与 WorkflowAppRuntime 的状态、动作和诊断使用各自真实字段，不能套用 TaskRecord 的 `succeeded` 或 `cancelled` 终态。以下是概念分组，不是新的组件清单或 API 状态枚举：

- `stopped`：进程和 endpoint 均不可用；允许启动，依赖检查通过后才允许删除。
- `starting`：展示后端实际提供的启动阶段，不伪造模型加载百分比；控制操作遵守当前资源状态。
- 可用：真实健康状态与实际支持的操作；PID、heartbeat、uptime、endpoint、耗时放在适当详情中。
- 业务忙或满载：明确显示容量拒绝或正在工作，不因此把全局服务改为未就绪；同步 Runtime/Trigger 没有额外等待队列。
- 降级或失败：显示后端报告的具体组件、原因和可执行恢复操作。恢复预算、下次重启、P95 等只有真实字段支持时才显示；监视连接丢失不能直接推断执行进程退出。

停止或删除前必须检查 `WorkflowAppRuntime` 与 `TriggerSource` 引用。REST 提供资源最终状态，WebSocket 只补充实时状态与事件。

### 6.13 危险操作确认

危险操作通过现有对话框与后端预检表达资源、影响范围和阻断原因，不要求新建一套命名组件或为每次操作增加输入确认词：

- 删除前展示对象类型、名称、ID、资源数量、不可恢复范围和不会删除的关联资源。
- `DatasetImport`、`DatasetExport` 删除不得暗示会删除 `DatasetVersion`。
- 训练或转换结果已登记、被使用或被部署时，确认按钮保持禁用并提供依赖入口。
- 停止 `DeploymentInstance` 是可恢复操作，按实际控制流程提示影响，不强加删除确认词或额外勾选。
- 删除 `WorkflowAppRuntime` 前先停止 runtime、删除绑定的 `TriggerSource` 并等待 active run 结束，不静默级联。
- 禁用 `NodePack` 不删除包文件，但必须显示节点、Workflow 引用以及运行中 Runtime 的影响。
- 取消为默认焦点；后端预检存在 blocker 时不能以确认框绕过。确有确认词的动作才检查其匹配。

## 7. 数据可视化

### 7.1 训练曲线

- train loss、val loss、主指标分面显示，避免不同量纲混在同一纵轴。
- 支持 epoch 游标、best epoch 标记、平滑开关和原始值。
- 当前 batch 指标与完成 epoch 指标分开。
- 断线恢复后曲线以服务端快照为准。

### 7.2 评估视图

- 顶部为核心指标：mAP50-95、precision、recall、F1 或任务对应指标。
- 下方为按类别表格、混淆矩阵、PR 曲线和错误样本画廊。
- segmentation 显示 mask，pose 显示 skeleton，OBB 显示旋转框。
- 指标名称必须标明任务语义，不能统一写成“准确率”。

### 7.3 部署监视

- 显示健康、启动时间、runtime、device、precision、平均/P95 时延和吞吐。
- 实时折线只保留最近窗口，长期统计另用时间范围选择。
- 资源占用不是装饰，只有后端有可靠数据时才显示。

### 7.4 图像画布

- 黑灰或棋盘底，图片居中适配。
- 支持缩放、平移、原图/适配、叠加开关、置信度阈值和类别筛选。
- 选中结果后右侧检查器显示类别、score、坐标、mask/关键点信息。
- 保留像素坐标和图像尺寸，不使用只适合摄影作品的沉浸画廊样式。

### 7.5 流程画布

- 跟随亮色/暗色的中性背景和低对比网格，复用现有画布；不添加无功能的坐标尺或 HUD。
- 节点以功能分色，但保持低饱和；标题栏比节点主体略深。
- 输入在左，输出在右，端口类型颜色稳定。
- 选中节点显示品牌绿边框；错误节点显示红色角标和错误摘要。
- 节点组使用半透明边界和标题，不遮挡连线。

### 7.6 热图、深度与 3D 结果（扩展设计）

- 热图色标与主题交互色独立，显示单位/范围/阈值语义；算法判定与查看器显隐、透明度分开。
- 深度数值与伪彩图分开，点云明确坐标和单位。点大小、方向视图、适配/重置属于查看器工具，不改算法参数。
- 点云、几何和表格共享本次观察身份；选中表格项才高亮对应几何，不沿用旧帧或按名称猜绑定。
- 亮暗主题改变面板和中性场景底色，不改数据类别色、公差或异常阈值。3D 不自动旋转，不使用装饰性场景动画。
- 节点内优先轻量摘要，专属编辑器/App Mode 才按需启用完整查看器；场景关闭释放资源，context lost 局部恢复。详细行为见[视觉扩展设计](workflow-vision-ui-plan.md)。

## 8. 动效与实时反馈

- 按钮和选择态：`120–160ms`。
- 抽屉和检查器：`180–220ms`。
- 进度变化平滑但不伪造进度。
- 状态灯默认静态；只有真实执行进度可使用必要动态提示，不用永久呼吸动画制造“健康”感。
- 新日志或事件不移动用户当前阅读位置，不额外增加持续淡入、闪烁或页面切换动画。
- 支持 `prefers-reduced-motion`，关闭非必要动效。

## 9. 响应式策略

### 9.1 宽屏 `≥1600px`

普通资源页由导航和主工作区组成；资源详情默认关闭，打开时从右侧覆盖主区，不将列表压缩为固定三栏。表格可展示完整列，图像画布优先占宽度。Workflow 的节点库、属性和结果按编辑器专用可收起面板处理，不能与资源详情抽屉混为一类。

### 9.2 标准桌面 `1280–1599px`

导航可折叠；资源详情使用覆盖式抽屉，保持底层列表列宽和位置，不压缩主区。次要表格列可隐藏，表单可单栏；编辑器面板需按画布空间单独检查。

### 9.3 窄桌面 `1024–1279px`

出图优先检查折叠导航、表单单栏和图表纵排；这是窄屏排版建议，不是当前自动折叠断点。当前 `WorkbenchShell` 自动折叠条件为 `max-width: 899px`，并保存用户选择。不得在设计稿中暗示 1366px 必须收起导航。

### 9.4 小于 `1024px`

设计重点为查看结果和已有控制。复杂图编辑优先在工作站使用；是否显示尺寸建议按现有页面核对，不新增强制阻断弹窗。新图需单独注明侧栏展开/收起及浮层状态。

## 10. 可访问性与工业环境

- 正文可读性、焦点、键盘操作和状态辨识作为后续实现验收项；静态设计图不能证明 WCAG AA 达标。品牌亮绿配白字及浅底绿色小字的对比度风险已知，不通过私自换深绿掩盖，应单独评估并记录取舍。
- 所有操作可通过键盘到达，焦点环清楚。
- 图表提供数据表或可读 tooltip。
- 触控工作站上的关键按钮点击区域至少 `40px`。
- 不依赖 hover 才能发现关键操作。
- 弱网时显示最后更新时间和重连状态。
- 离线时写操作显示不可用原因；只有页面实际持有缓存时才允许只读查看，不虚构离线缓存或 Preview 历史恢复。

## 11. 视觉禁区

- 大面积蓝紫渐变、霓虹青光、赛博朋克背景。
- 每个模块都是悬浮大圆角卡片。
- 夸张 3D 图表、等距服务器插画、机器人头像。
- 面向营销的 KPI 大屏、销售漏斗、订阅套餐。
- 苹果式超大留白导致工业数据密度过低。
- 无意义的波形、雷达圈、十字准星和随机代码雨。
- 随机英文、乱码、重复按钮、不可辨认小字。
