# 前端设计修订要求

项目图更新：当前有效稿统一从[设计总览](generated/项目/设计总览.html)进入，清理范围与执行状态见[检查记录](project-complete-design-review.md)。下文确认结论只对应当时版本及设计方向，不代表新版图片自动获确认。
更新：2026-10-23。依据最新用户纠正；本文件优先于此前的导航合并、固定分栏和生成图方案。

## 1. 设计依据

`generated/bak1/` 中大部分页面设计是正确的。后续以这些设计的合理内容、操作和页面结构为基础，统一风格并修正少数错误。不能将整批旧图只视为反面资料，也不能因为个别错误推翻全部页面。

现有产品用于核对真实功能、参数与状态；左侧导航参考现有简洁形式。旧图和当前页面各自承担不同参考职责，不要求整页照搬当前实现。

旧图中的未实现功能仍是规划，示例数据不是真实验收结果。`bak1/90-archive/` 内已明确否决的历史图仍不作为有效母版。

## 2. 导航和顶部

- 左侧导航采用与当前产品类似的简洁平级形式，不增加功能域分类标题或复杂折叠菜单。
- 撤销上一轮五入口合并、顶部新增项目选择等未确认的改动；不因出图擅自隐藏项目、任务、推理、图编辑或节点入口。
- 顶部没有独立的全局栏。不加入全局搜索、面包屑、项目选择、任务计数和账号组成的另一条顶栏。
- 页面自身的搜索、筛选和操作放在内容区，不能画成与页面分离的全局顶部壳层。
- 品牌、导航展开/收起和底部账号参照现有简洁语义；普通页面不恢复重复大标题和空标题高度。

## 3. 右侧面板的正确含义

旧宽屏图最右侧的详情/配置区域表示右侧展开的抽屉，不是默认常驻的第二列，也不是必须将页面压缩成“列表 + 固定详情”的布局。

- 默认关闭，按详情、新建、编辑等明确动作打开。
- 有清楚的标题和关闭入口，按任务需要显示底部动作。
- 打开时主页面保持上下文；关闭后内容区恢复完整可用宽度。
- 抽屉正文独立滚动，必要底部操作可见；存在未保存修改时保护草稿。
- 后续必须同时画关闭和展开两个状态，避免再次误读。
- 图编辑器的节点属性面板属于编辑工作台已有交互；不能把所有右侧面板不加区别地改成同一种抽屉。

## 4. 修订范围

保留逐页合理的功能与主体结构；统一亮暗色、品牌色、字体、字号、间距、表格、表单、按钮、下拉、抽屉与状态样式。普通悬停和输入焦点用中性色，选中与主要动作沿用品牌语义。

错误字段、无依据的状态/数值、重复说明、旧命名和不符合真实功能边界的操作逐项修正。通用节点、行业节点包、Preview、Runtime/Trigger 和模型部署的关系保持不变。异常/连接器/3D 继续通过现有工作流及专业节点界面扩展，不新增行业主导航。
