## 状态与行为边界

- 资源选择为模态抽屉，整页统一遮罩；结果检查为非模态覆盖面板，底层无遮罩、不重排。二者不能混用。
- URI/Base64/文件来源互斥。校验失败禁用执行。切换输入、部署或影响推理的参数后，清空旧预测，显示待执行；显示过滤不改原始结果。
- 异步提交中锁定重复动作。连接中断且提交结果未知时查询原请求，不能自动重提；实现前必须建立请求状态查询契约。
- 取消确认→取消中→已取消分开。取消中不承诺立刻中断正在进行的推理；保留已完成结果，未执行不计失败。
- 删除记录须先检查任务终态和引用。只删除该任务拥有的结果资产，保留输入文件、部署、模型和共享资源；部分清理失败保留可继续清理的反馈。
- 记录存在不保证结果文件一直存在；文件过期不改写历史推理状态。预览加载失败也不能改写推理成功。
- 同步调用无队列、无自动重试，不把实例满载当服务异常。异步页面不改变Runtime/Trigger数据面。
- 当前图中128MB为示例输入限制，正式界面应读取服务能力；输入尺寸不手工覆写部署契约。

## 公共状态复用规则

- 成功完成：复用任务详情，成功数=总数，失败/执行中/未执行=0，移除取消；单张任务总数为1。
- 零目标：沿检测工作台，照片无框、目标0、推理成功；对象tab空态未检出目标。不是推理失败，不显示业务NG。
- 不支持格式、URI无权访问、Base64类型不匹配、像素超限：复用输入字段错误模板，原因精确到字段，保留更换/移除，执行禁用。
- 部署停止/版本变更：目标状态更新并停用提交；必须重新选择/确认当前版本，不能静默换版本或后端。
- 筛选无结果与首次空任务分开：前者保留筛选并提供清除筛选，后者提供创建入口。
- 单项失败：复用任务详情的查看原因入口，在非模态抽屉显示样本、错误阶段、短原因、诊断标识；只对失败项显式新建任务。
- 记录清理失败：任务已移除与文件待清理分开，显示重试清理，不能恢复推理或误删输入。
- 长列表采用分页/虚拟滚动；JSON独立滚动/换行与复制下载；大图沿既有查看器，批量来源提供上一项/下一项、当前位置与失败跳转。

## 实现核对清单

- 来源选定、部署变更、推理参数变更会使当前结果失效；仅显示筛选和叠加选项不使结果失效。
- 草稿按来源保留，但请求只发送当前来源；Base64大小校验先于解码，实际限制来自能力契约。
- 提交未知查询原请求；查询超时保留未知，不能因前端时间到期宣布失败或自动重提。
- 取消请求失败恢复可操作的真实状态；任务已完成时以完成结果为准，取消按钮不重复发送。
- 下载权限、任务终态及共享文件引用由服务端核对；前端禁用不是唯一保护。
- 本地临时预览与显式保存分开；文件失效只禁用文件操作，仍可查看留存的结构化记录。
- 普通输入焦点/悬停中性，选中品牌绿；模态统一遮罩全背景，结果检查面板完全无遮罩。
- 只读参数可查看完整值，不能被“禁用表单”阻止复制或查看高级参数明细；图稿中折叠值是摘要。
