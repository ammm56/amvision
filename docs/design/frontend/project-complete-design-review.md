## 2. 已发现并修订的图像问题

1. 项目概览初稿缺少部分跳转入口，补回最近更新“查看全部”、任务“任务”、服务“部署/应用”。
2. 暗色编辑抽屉背景过亮，修正背景文字、图标和状态的遮罩强度。
3. 保存失败稿把取消画成禁用，改为可用；失败不剥夺退出能力。
4. 清理待完成稿曾把查询按钮改为中性描边，并限制使用状态色，造成整体过灰、难以理解。本次按不同结果阶段重新分配颜色：项目移除小绿勾、文件待清理琥珀时钟、查询操作品牌绿；不把文件清理未确认画成全部完成。
5. 短屏初稿增加了多余“项目概览”标题和装饰图标，修正背景；随后纠正应用/部署标签和普通文字偏蓝。

6. 非空删除原稿未填写 ID，因此删除按钮处于浅红禁用状态，无法展示可用危险操作。最新亮暗稿填写正确的 `offline-check`，使用与空项目确认一致的实红白字按钮，并上移对话框，避免贴近底边。空值、不匹配和预检阻止仍必须禁用删除，不因视觉调整解除保护。
7. 两张删除补充图统一列表“说明”列、移除无意义单页翻页；依赖阻止图补“当前”标识、绿色运行状态和品牌绿“重新检查”，空项目确认改用中性文件夹及小型红色删除图标。
8. 本次新增删除暗色稿的初稿背景过亮，已只压暗弹窗外导航、品牌、列表和按钮，保持弹窗内部清楚；未改变确认条件或阻止规则。
9. SDK 长列表初稿滚动条误入固定搜索区，长名称没有换行。修订后滚动提示位于资源区，长名称明确分行，底部操作完整。暗色从修订亮色稿配对，数量、选择、顺序、关联说明和行高一致。栅格中的轨道端点为示意，真实组件必须让整个资源区滚动，精确高度不可从图反推。
