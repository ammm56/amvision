## 应用模式批次

实际浏览器依次核对塑盒满盘图的应用模式入口、显示工作流的图片/数据关联以及Runtime等待结果页，保留3张JPEG参考。配置查看后取消，没有修改草稿、执行工作流或发布。代码核对覆盖配置模型、对话框、运行页、显示网格、Value Display、大图及结果订阅。

发现并纳入目标设计：无输入时的独立运行块占用结果空间；配置重复技术标题、行高偏高、短屏底部操作需滚动；独立数据面板勾选与随图数据的含义需要明确。配置选择、排序、宽度继续使用现有公开结构，不增设图片绑定机制。
