# 集成详情抽屉：信息层级与标识

更新：2026-10-30。适用于本轮设计图修订，不代表已经修改前端代码。

## 默认显示

- 概览：名称、状态、关联实例与必要运行摘要。配置与诊断不重复堆在概览。
- 配置：常用连接参数；输入映射、返回结果、其他配置及技术信息按需展开。保留所有字段，避免同时展开。
- 诊断：一条明确结论、一句必要处理动作、相关对象、时间。原始错误与完整路径按需查看；故障与运行状态分开。
- 标题只显示一次；不再使用检查结果、失败原因、关联信息、入口配置多组重复表格描述同一问题。
- 抽屉覆盖底图，统一遮罩；长文本换行、复制完整值；滚动正文、固定底部。短屏Logo为唯一导航展开入口。

## ID来源

核对源码：`frontend/web-ui/src/modules/integrations/pages/TriggerSourcePage.vue` 的 `applyProtocolTemplateDefaults`、`createShortUuid`；`backend/service/application/workflows/runtime_service.py` 的创建逻辑。

- Runtime 默认格式：`workflow-runtime-<32位uuid十六进制>`。
- 目录监听默认格式：`directory-watch-<完整Runtime ID>-<8位uuid十六进制>`。
- ZeroMQ / 本机共享内存默认使用对应协议前缀加完整Runtime ID。ID允许调用方指定，因此这是默认规则，不是服务端唯一校验格式。
- 界面标签使用“触发入口 ID”“运行实例 ID”；值取服务响应，保留原样并支持复制，不从显示名称重新生成。
- 格式示例：`workflow-runtime-6a48e0fd12b34c5e8f907d61b234a890`；对应目录监听 `directory-watch-workflow-runtime-6a48e0fd12b34c5e8f907d61b234a890-7c31a2d9`。仅设计示例，不指向现有生产资源。
- 默认收起技术信息，不在常用首屏展示长字符串。不能用业务名称冒充当前默认ID。

## 保留的交互

展开映射保留完整字段与来源；技术信息保留ID和版本；错误详情保留完整路径、原始异常与可复制诊断。减少文字不等于删功能。没有错误时不显示异常解释。错误提示保留必要恢复条件，不提供自动重试、忽略错误或强制启用。


## 本轮收尾结果

ZeroMQ与本机共享内存均默认展开常用参数，四个次级区块收起。技术信息展开图保留完整ID、原始异常和路径，正文独立滚动、底部固定，不缩小字号。

背景遮罩覆盖导航、Logo、头像及内容；抽屉遮住右侧列，不挤压底图。亮暗采用相同布局和动作；精确样式以主题Token为准，不能从生成图片吸取近似像素作为颜色值。

待确认状态显示实际缓存值并标“上次”；只有受当前命令影响的行显示具体操作待确认。关联实例运行和触发入口停用/异常分开。扫描进度恢复与启用也是两个独立动作。
