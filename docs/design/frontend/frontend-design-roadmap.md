## 3. 出图步骤及检查

1. **核对旧稿并修订母版。** 逐页记录保留内容、风格差异与错误，使用简洁平级左导航、移除独立顶栏。G01 必须区分抽屉关闭和展开状态，再按 G01–G03 统一亮暗组件；不强制重排全部页面。
2. **验证代表复杂场景。** 优先 D02/D04、R01、X01、V02、W06/W07，覆盖表格、对话框、抽屉、图编辑和现场结果；先确保同套组件可以承载这些内容。
3. **补新视觉类型。** V01/V03/V04 及对应应用模式，补热图/点云/坐标/资源状态；使用标记清楚的开发数据，不生成虚构精度或性能数字。
4. **扩展标准页面。** 覆盖表中其余页面和数据集全部子页。一个工作台内共用的结构不逐张重新设计。
5. **成对审查。** 1920×1080 主工作站、1366×768 窄桌面、1280×720 复杂对话框；100%/125%/150% UI 缩放在可运行原型中验证。亮暗同数据，同场景同布局。
6. **固化出图清单。** 记录页面 ID、状态、来源、目标/当前属性、母版版本、主题、尺寸、数据与审核偏差。生成图的文字、连线和数值仍需人工/代码核对。

## 4. 后续代码实施顺序

| 步骤 | 实现范围 | 完成后必须检查的结果 | 依赖 |
| --- | --- | --- | --- |
| 1 | 精简导航与统一层级 | 完整功能可达、深链接 active 正确、权限过滤、收起/滚动、键盘与亮暗 | 新 G01 确认；不改 API |
| 2 | 共享表单/抽屉/状态规则整理 | hover/选中/focus 区分、长内容/多语言、单多选及页面空态；不引入业务回归 | G03 及现有组件盘点 |
| 3 | 资源/结果契约盘点与类型注册 | 当前 2D 结果不破坏；缺失类型/单位/旧结果有明确状态；节点包来源可查 | 现有 Catalog、发布及观察协议 |
| 4 | 数据集只读管理 | 分页版本/样本、缩略图、标注/划分/来源、无权限/缺文件；浏览器无全量文件列表 | API、授权、索引和媒体读取能力先就绪 |
| 5 | 数据派生与质量检查 | 新版本不可变、引用保护、任务取消/失败不覆盖、报告来源；导入/导出删除回归 | 步骤 4，持久化/迁移方案 |
| 6 | 模型页重组与评估 UI | 训练/转换/导入仍可用；支持矩阵真实；同任务指标可比较 | 现有 API 审核，M01–M05 |
| 7 | 异常与连接器 UI 完善 | 资源/配置/执行层级清楚，缺陷与几何/表格同帧，临界/缺测不误报 | 实际已实现节点与样例，不新增行业核心规则 |
| 8 | 3D 最小完整链路 | 单位/frame/属性/引用契约、一个真实可执行流程、WebGL 失败与资源释放 | 与开发中 3D 分支核对，测量定义和样例齐备 |
| 9 | 共用运行显示与打包回归 | Preview/Runtime 边界不变；纯图、数据叠加、3D、扩大视图一致；离线发行可用 | 已完成类型逐项接入，不要求等待所有未来功能 |
| 10 | 全页面验收与后续维护 | 页面清单逐项状态记录、性能/资源预算、真实数据与故障恢复证据 | 上述对应功能实现完成 |

每步遵循“契约核对 → 小范围实现 → 自动检查 → 浏览器功能验证 → 更新状态”。失败先修复，不凭静态图进入下一阶段。步骤 7 的已有连接器改进不必等待全部数据集功能；步骤 8 必须等待自己的 3D 契约和样例，不能借二维测试报告跳过验证。

不借 UI 重构改写同步 Runtime/Trigger、增加排队重试、切换模型加载方式或强制持久化预览结果。新公开 payload/API 的版本化与节点包迁移另行记录；保留 Vue 3 和离线发行边界。

| 内容 | 当前可决定的部分 | 实施前必须补齐 |

| 连接器二维 | 现有节点/资源与完整用户路径 | 当前源码/样例回归，实物参考量值与现场成像另作计量验收 |

简洁导航、项目页面布局和亮暗视觉方向已获确认；其余业务页面仍需逐页审阅。当前中文提示词覆盖全部场景，出图先核对数据集主页面亮暗配对，再推进其他页面；实际产品代码实施另行安排。未来算法与数据服务不能因 UI 设计完成就视为已实现或已经验收。

## 6. 最小验证矩阵

- 导航：普通/只读/管理员权限、直接 URL、刷新、后退、项目切换、窄高窗口。
- 数据：空版本、百万级分页、损坏图片、无标注、重复/近似样本、非法标注、被引用版本删除、派生中断。
- 执行：预览长任务、模型满载、Runtime 同步调用并行、页面关闭/重连；服务启动正常与业务忙分开。
- 2D 结果：原图/显示图区别、分类/区域/热图/测量、缺测、边界值、旧帧、绑定与未绑定数据。
- 3D：缺单位/坐标、不合法或缺少属性、空/大点云、配准失败、显示降采样、context lost、反复打开关闭。
- 发行：无外网、资源缺失、profile 能力差异、前后端/节点 UI 版本不匹配、无 GPU 查看器能力。

业务性能与精度独立于 UI 可用性验收；设计确认、开发样例通过、短时性能与长期稳定性分别记录。
