# 推理任务结果详情设计

更新：2026-10-27。本轮修正折叠导航，并补齐六类任务的结果详情抽屉。此前61组图覆盖了任务主视图，但没有覆盖各任务的详情内容；不能以目标检测抽屉代表所有模型结果。当前文档为完整目标设计，非新增API或推理实现。

## 1. 导航核对

当前[AppSidebar](../../../frontend/web-ui/src/shells/workbench/components/AppSidebar.vue)在折叠状态只提供顶部Logo按钮，点击发出toggleCollapsed；正常状态仅显示Logo。[样式](../../../frontend/web-ui/src/shared/styles/index.css)在同一位置用hover/focus替换成展开图标，不存在旁边第二个展开按钮。[测试](../../../frontend/web-ui/src/shells/workbench/components/AppSidebar.test.ts)覆盖了Logo点击展开。

已通过内置浏览器查看当前部署页：折叠栏顶部确实只有AM Logo。设计稿的独立双箭头与实现不一致，两个短屏场景共四张图已同名修订。静态图采用非悬停状态，不显示替换图标；键盘聚焦仍需中性轮廓与“展开导航栏”可访问名称。

## 2. 公共容器与入口

工作台或批量样本大图的“结果详情”打开同一非模态右覆盖抽屉；图像、参数区和左导航不加遮罩、不缩窄或重排。抽屉常规宽约520px，关键点多列详情可用约640px；窄屏以可用宽度约束，容器行为相同。标题固定“结果详情”，右上关闭，正文滚动，短屏固定操作可达。关闭回到同一输入、缩放、选中项和筛选，不重新执行。

页签固定保留概览、耗时、JSON；第二页签按任务结果分别为对象、类别、实例、类别层、关键点、异常。能力来自执行结果快照，不能凭当前部署型号猜字段。点击图像实体可打开对应第二页签；分类没有可点击对象。初次点击“结果详情”默认显示该任务第二页签，显式切换后的偏好仅在同次结果保留。

概览复用来源/输入/执行/保存状态，增加各任务实际摘要；耗时按实际阶段显示，未知为—；JSON复制/下载规则共用，内容必须是当前任务真实结构，不能复制检测示例schema。相同容器的共用页签不重复生成整套图片。

## 3. 各任务字段与操作

| 任务 | 第二页签 | 主要内容 | 联动与约束 |
| --- | --- | --- | --- |
| detection | 对象 | 对象ID、类别、分数、原图xyxy/xywh | 既有详情图；选择对应框；不等于物理计量 |
| classification | 类别 | 单标签/多标签、Top-K、类别/分数、模型类别数/返回数 | 图像级结果，无对象数/框/裁剪；单标签最高分不自动等于OK，多标签逐类判定且不强制分数和为1 |
| instance segmentation | 实例 | 实例ID/类别/分数、掩膜尺寸、像素面积、图像占比 | 选中mask联动；透明度/仅显示此实例只影响显示；实例重叠面积不强行相加为整图面积 |
| semantic segmentation | 类别层 | 类别ID、像素数、占比、有效/无效像素、统计范围 | 显隐不改统计；没有实例ID/对象数量或默认置信度；区域聚合结果不是检测框 |
| pose | 关键点 | 对象选择、点编号/名称/分数/状态、原图坐标、骨架元数据 | 选点高亮，缺失点坐标和分数为空；不补点、不连缺点；模型未提供可见性时仅显示检出状态 |
| obb | 对象 | 对象ID/类别/分数，中心、长短边、角度、角点 | 单位px/度明确，方向和角度范围来自规范化契约；不套左上角xywh，不冒充毫米测量 |
| anomaly | 异常 | 图像分数/阈值/判定、热图范围；有输出时显示区域面积/分数和生成规则 | 图像阈值与像素/区域阈值区分；分数不冒充概率；没有区域能力时不显示假区域0或固定缺陷类别 |

正常说明保持短字段；坐标规则、掩膜信息和原始数据折叠查看。无法提供的值显示—并在需要时解释，不填0。结果详情不能编辑预测、改变模型或隐式重跑。

## 4. 同构状态与查看路径

| 状态 | 行为 |
| --- | --- |
| 多标签分类 | 复用类别表增加各类阈值/命中状态；未提供阈值只显示分数，不伪造分类决策；Top-K限制与返回范围明确 |
| 分类低分/未知类 | 按实际返回类显示；unknown是模型类时保留原名，不自动当错误；不根据最大分数生成未知类 |
| 实例为空或mask失效 | 0实例为成功空结果；mask显示失败保留实例元数据、局部重载，不改推理成功，不自动再次执行 |
| 语义分割无效区域 | 无效像素单列，不并入background；分母为明确统计范围。背景隐藏不改合计；ROI统计必须显式切换范围 |
| 多目标关键点 | 对象下拉切换后清除旧选中点；名称/点数取该对象模板。缺失全部点仍按结果状态显示，不画完整骨架 |
| OBB角度边界 | 明确规范化方向，长短边及角点互相一致；原始后端坐标可从JSON查看。退化框标为无效几何，不画假框 |
| 仅图像级异常 | 保留图像判定与分数，区域/热图入口按能力隐藏；正常且0区域不等于服务失败。区域提取失败局部报错 |
| 大结果与筛选 | 搜索/分页或虚拟列表；显示n/总m，筛选不改原始统计。被过滤的选择清除，不把另一项值当旧选择展示 |
| 切样本/换任务 | 面板根据新结果任务类型更新，清除旧表格和叠加；过期响应不能覆盖当前对象，无共用字段污染 |
| 加载与文件过期 | 保留允许查看的元数据；局部重载/下载按能力开放，源结果过期不得承诺恢复，不重复推理 |
| 大图与短屏 | 使用同一详情组件与同一结果状态，关闭/返回不丢选择；短屏覆盖右侧而非永久三列，Logo负责展开导航 |

同构变化有明确容器和动作，不为每个错误复制完整页面；具有不同结构的六类详情必须分别提供亮暗图。

## 5. 样例与核对

- 分类：normal 0.982、defect 0.014、unknown 0.004；单标签Top-3，不是三件产品。
- 实例分割：scratch 0.95/6240px²，dent 0.91/13440px²；原图1920000像素，前者占0.325%。
- 语义分割：background1536000、bolt288000、nut96000，合计1920000；占80%、15%、5%，无效像素0。
- 关键点：1左上(350,200)/0.99，2右上(1150,200)/0.98，3左下(350,700)/0.97；4右下未检出。点坐标是设计样例，不是生成照片的计量证据。
- OBB对象1：中心(440,440)，长560、短180，角度−30°；对象2为20°。采用图像坐标、长边方向、顺时针为正、范围[−90°,90°)。四角由同一参数计算，不能手填不一致的另一组几何值。
- 异常：图像分数0.87/图像阈值0.60；示例模型另提供热图及区域，区域阈值0.55、区域1最高分0.93、面积18432px²、占整图0.96%。图像分数是模型输出，不假设等于区域最高值。

完成顺序：中文规格 → 四张短屏修订 → 六类详情逐类亮暗配对 → 逐图检查 → 清单/总览/索引同步 → 配对、哈希、链接及目录校验。图片是布局与字段定义示意，键盘、实际尺寸、长列表和模型契约仍需真实实现验证。
