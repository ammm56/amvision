## 1. 来源与恢复方式

旧 Image 2、Google Stitch 及出图流程文档从 Git 历史读取，整理为[中文页面提示词](prompts/README.md)。来源提交、原文件名及旧编号映射见[历史来源](prompts/历史来源.md)。保留合理页面内容，按最新要求重新组织提示词；这些是修订稿，不冒称生成每张旧图时实际发送的请求。

本轮整理 13 份文档，覆盖[场景清单](frontend-design-roadmap.md)的全部 45 个场景，包含 61 段提示词。页面文档分别说明旧图来源、保留内容、修正项、容器、已有或规划属性、关键状态和单页提示词。Google Stitch 的原英文要求改为中文结构化提示，引用同一套页面定义。

提示词恢复阶段未重生成当时四张已确认图；原英文请求只作历史记录。现按要求将英文请求纳入清理，当前中文请求统一保存在 `prompts/项目完整设计请求/`，清理状态见[检查记录](project-complete-design-review.md)。

## 2. 统一修订

| 范围 | 当前约束 |
| --- | --- |
| 左导航 | 11 个平级入口，无分类标题或新增项目选择栏；不按行业增加入口 |
| 顶部 | 无独立全局顶栏，无普通页重复大标题或空标题高度；必要资源名和页内工具保留 |
| 详情 | 资源详情为可关闭的覆盖式抽屉，不把旧宽屏图解释成固定第三栏 |
| 其他容器 | 编辑器节点库/属性为可收起面板；管理数据集、部署导入保留适当对话框；不强行把所有内容改成抽屉 |
| 主题 | 亮暗使用同一品牌色 `#00D992`，主按钮白字；普通 hover、输入 focus 为中性灰，选中状态使用品牌色 |
| 内容 | 保留各页合理主体，不把项目列表套到所有业务页；既有能力、扩展与未实现规划分开 |
| 新视觉能力 | 异常、连接器、3D/点云通过 Workflow、节点专属 UI、结果查看器和扩展包承载 |
| 语言 | 当前提示词正文中文，AMVAR、Workflow、Runtime、Trigger、COCO 等专有名称保持英文 |

已同步修正设计系统中“宽屏固定三栏”“抽屉压缩主区”等冲突表述。已否决资源页面不再作为依据。项目四图的确认范围仅是项目页面及公共导航、主题参考。

| 检查项 | 结果 |
| --- | --- |
| 导航 | 11 项名称、顺序和选中位置一致；项目为文件夹、模型为芯片；折叠按钮在品牌右侧 |

| 修订 | 当时初稿折叠按钮位置和图标存在偏差，已修订；过程图不作为当前设计依据，纳入清理范围 |
| 限制 | 静态生成图不能证明 hover、focus、键盘操作、精确 token 或响应式实现正确；这些留待原型验证 |

内置浏览器的 URL 安全策略阻止 `file://` 图册预览。本轮通过图像工具直接检查生成图；未绕过限制，也未宣称完成浏览器交互验收。

## 4. 文档与资源核对

- 45 个场景均有页面提示词，没有缺项。
- 61 段提示词均含中文正文，无纯英文当前提示词。
- 设计文档的本地 Markdown 文件引用已核对；生成清单、图片和实际请求单独检查。
- `bak1` 的 59 张图与归档清单 SHA-256 一致。
- 项目已确认的 4 张图与原清单 SHA-256 一致。
- 新数据集稿、初稿的尺寸、字节数、SHA-256 记录在清单中。
- 本轮没有创建仓库 `.tmp/` 临时文件，不清理其他任务产物。
- 代码差异仅涉及设计文档；不变更前端、后端、节点、Runtime 或 Trigger 行为。

## 5. 后续顺序

先审阅数据集主页面亮暗配对，再依次制作管理数据集对话框、版本与样本工作区、部署导入、触发详情，以及编辑器/公共控件状态板。每个场景先核对中文提示词和旧稿，再出图、检查、修正；未确认稿不能成为其他页面的布局依据。

后续异常、连接器二维、3D/点云与 App Mode 的专属状态按各自文档推进，不因本轮提示词覆盖完成就视为图片、功能或生产验收完成。
