## 统一规则

- 普通导航、文件与工具图标使用中性灰；品牌绿用于选中、主操作与成功，红色用于阻断/失败，橙色用于可恢复警告。错误同时配文字，不依赖颜色。
- 导入上传、预检查、正式生成版本分别表达。返回保留有效输入，换包后重算依赖结果；最终提交前必须再次核对。未生成版本不能提供查看版本。
- 导出固定来源版本，目标能力检查决定是否可提交；不静默丢失分割/关键点等标注，不把旧包当新产物。已完成是历史任务状态，可下载是当前产物状态。
- 人工重试通过明确操作发起；未知提交结果先查记录，不自动重复创建。失败行保留上下文，不能用清除消息替代修复。
- 短屏目标1366×768，收起导航和目录，正文滚动、底部动作可达；不靠整体缩小字体，不新增固定右侧栏。
- 本批短屏是静态布局设计，不代表真实视口、键盘、滚动及功能已验收。时间样例沿用2026-10-23；生成日期为2026-10-24。
- 使用内置图像生成，最终图保存到 generated/数据集，当前中文规格一图一份，实际末次请求和检查写入清单。旧 bak1 和项目图不变。

## 后续范围

本批覆盖导入/导出全部四步的主状态及代表性异常，不穷尽所有后端错误。数据集空态、缺图、权限、版本引用阻止、质量与版本来源等管理场景仍按完整页面方案补充；不得把本批图数当作数据集完整产品验收。

## 本轮核对后固定的细节

- 上传页不虚构上传大小上限，也不把当前 COCO 示例当成唯一允许格式。中断状态的表格标题为“上传文件”；“重新选择”只在上传区出现一次。
- 步骤条完成状态使用圈内对勾，当前步骤使用数字，不能出现悬空重复对勾。
- 类别表的选择列不使用与行状态矛盾的全选框；test 未配置时禁用且写明原因。
- 缺图阻止页将源 JSON 中数量写为“声明图像数 / 声明对象数”。“JSON 格式解析成功”与“引用图片存在”分别检查，不能一边缺图一边写关联完整。
- 失败详情保留已经通过的校验事实，明确生成版本失败；不提供查看不存在版本或创建导出。
- 格式不兼容页同时阻止任务兼容性和标注类型检查；目标矩形框只作要求示意，不表示已自动转换。返回修改保留配置；初步筛选通过后仍需最终检查，防止来源变化或保留配置失效。
- 产物清理后，保留历史清单，不暗示还能查看文件内容。完成状态与橙色产物警告并列；亮暗均保留警告横条及行状态。
- 短屏折叠结构的按钮写“展开”，不写“收起”；主要动作留在底部，内容溢出时滚动。图稿不是精确浏览器视口截图，当前实际像素1672×941，与1366×768布局参照分开记录。
