# 应用异常与管理状态设计

更新：2026-10-30。沿用已确认母版。本批35组70张亮暗配对已逐张静态核对，累计61组122张；待用户审阅，正式文件以生成清单为准。设计面向完整产品，不表示API与交互已实现。

## 状态语义

- 取消服务对已成功/失败/超时/取消终态返回当前记录。UI提交取消后先显示请求状态，只在服务确认时显示已取消；迟到的取消反馈不得覆盖成功结果。
- 已有run_id且有持久记录时，断线仅查询原记录。同步none且回执丢失时无法凭空恢复结果；准备新调用必须确认可能重复副作用，不自动重发。
- 浏览器等待结束与服务端timed_out分开。未知状态禁止重复启停/切版；读取最新状态后重新判断。
- 输入错误在字段附近定位，无请求时不创建失败记录。业务NG、容量拒绝、执行失败分别呈现。
- 空记录不等于从未执行；搜索无结果、加载失败、无权限、对象不存在分别呈现。权限失效清除敏感快照，普通断线保留带时间的旧快照。
- 版本删除必须检查Runtime历史revision和WorkflowRun引用，不能只检查当前版本。归档可恢复，已引用实例继续运行；恢复需公开契约校验。
- 应用删除需无Runtime及活动Preview；独占资源与关联记录按服务端影响清单显示，共享资源与模型保留。物理删除无产品恢复入口，不画回收站。
- 实例删除检查服务端合法状态、活动执行及Trigger关联；停用不等于解除关联。切版/回退仍要停止、无活动执行和触发停用及契约兼容；成功仅设置目标版本，另行启动。
- 本次核对runtime_service.cancel_workflow_run、app_version_service.delete/archive/restore和application_deletion；部分页面能力如历史检索、元数据冲突比较等仍需后端支持。

## 共用状态与操作规则

| 状态 | 界面和动作 | 复用方式 |
|---|---|---|
| 编辑保存失败 | 保留输入、短错误、手动保存；网络不确定先核对最新 | 编辑冲突抽屉布局，替换提示，不显示强制覆盖 |
| 复制名称错误/提交失败 | 字段红边、输入保留、创建禁用或手动重新提交 | 复制应用抽屉 |
| 文档导入通过 | 同一依赖表全部可用，导入启用；成功返回新草稿 | 缺依赖图的正常状态；不复制模型、Runtime、Trigger |
| 应用搜索无结果 | 保留筛选、清除筛选，非初始空态 | 记录筛选无结果结构替换为应用列表字段 |
| 未创建实例/无关联触发 | 名称和版本保留，分别创建实例/添加触发；集成返回保留实例 | 未发布空态和已有详情的局部空态组件 |
| 归档/恢复成功 | 列表状态就地更新，短反馈；不会启停已有Runtime | 已有发布版本列表，不开多余成功对话框 |
| 删除版本允许 | 展示vN和删除不可恢复，取消/红色删除；引用为0才可用 | 删除实例确认同款对话框，禁止误用实例文案 |
| 回退校验通过 | 依赖/契约全通过，设置目标版本启用；停止状态不变 | 原切换运行版本和待启动图，目标改历史版本 |
| 启动/停止失败 | 保留实际状态、短错误、查看诊断；失败实例先复位 | 启动失败图与控制待确认图；不假造已停止 |
| 异步提交明确拒绝 | 表单保留、明确未受理原因；手动修改再提交 | 输入错误/满载回执；无结果编号不伪造 |
| 取消失败/超时 | 已有run_id继续查状态，不能宣布已取消 | 断线待确认图；最终以服务器终态为准 |
| 历史载入/发布失败 | 进入图编辑专属流程，未保存保护、校验定位 | 图编辑专题，应用页不新增第二套编辑器 |
| 触发配置与异常 | 集成抽屉管理；带返回应用/实例上下文 | 集成专题，应用只显示关联状态和入口 |
| 长schema/长JSON | 树状或代码区域独立滚动、复制、无隐式调用 | 输入输出与请求示例长内容图 |
| 异常退出/失效依赖 | 实例真实failed、原因/时间/部署入口，恢复先复位 | 既有启动失败抽屉语义 |
| 无操作权限 | 查看权限保留内容、修改动作禁用；无查看权限不披露数据 | 本批只读/无权限两图 |

共用不是省略行为：最终组件用相同结构和颜色，文案、资源作用域与按钮权限由实际状态决定。图中未全部绘制的短反馈、tooltip、loading/disabled、分页边界等由此表定义，不为每条文案复制整页图片。
