# 数据集工作区、版本演进与状态补全

更新：2026-10-25。对象为未来完整产品设计，不改变现有产品代码、实际数据或运行链路。

## 1. 本次复核

原32组/64张覆盖管理和导入导出主路径，但工作区可见的类别与划分、质量检查、版本与来源尚无去向图，样本列表和逻辑结构未展示，多种媒体被detection示例代替，保存/取消/清理失败语义还不够明确。因此复核时尚不完整。

“编辑数据集信息”亮色图的左导航偏灰，与白色列表母版不一致，修正为白色；遮罩仅作用于内容区。样本网格已有勾选却没有选择范围/动作，补齐工具栏；文件结构未提供批量操作，移除无用途复选框，以行选中表示当前文件。

## 2. 本批图稿清单

逐张执行：中文规格 → 亮色生成 → 检查修订 → 暗色配对 → 数据、动作及布局复核 → 最终同名文件入库。状态板是独立组件示例，不冒充一个页面同时出现多种错误。

| 场景 | 内容与验收重点 |
| --- | --- |
| 类别与划分 | 类别、样本与对象计数分开，现有划分只读，变更创建新版本。 |
| 质量检查 | 已检查项、问题与未检查项分开，候选问题不自动修改数据。 |
| 版本与来源 | 当前资源的版本历史、来源与引用，切换版本不更新外部引用。 |
| 样本列表-批量选择 | 明确本页与全部筛选结果选择，批量动作不原地修改版本。 |
| 样本结构 | 按样本逻辑组织，共享 COCO 文件不会被伪造为独立 JSON。 |
| 文件关联样本抽屉 | 共享标注文件的有界关联样本列表，关闭保持文件选择。 |
| 创建新版本-配置 | 映射与划分明确创建新版本，保留源版本和现有引用。 |
| 创建新版本-检查 | 展示变更影响与分组结果，提交成功前不冒称新版本已可用。 |
| 版本比较 | 比较固定版本的新增、移除和修改，保留引用不自动迁移。 |
| 外部标注-交接 | 选定样本与格式交接到外部工具，不在核心平台制作标注。 |
| 外部标注-回传检查 | 按交接清单匹配，重复、未知与缺失分别处理，不覆盖原版。 |
| 样本查看-分类 | 分类真值只显示标签，不虚构检测框或置信度。 |
| 样本查看-分割 | 显示导入轮廓/掩膜与对象列表，图像不会随主题改变。 |
| 样本查看-关键点 | 可见与遮挡/未标注关键点区分，骨架规则可核对。 |
| 样本查看-OBB | 旋转框明确坐标与方向定义，不简化成水平框。 |
| 样本查看-异常 | 异常真值与模型预测层分离，未提供区域不伪造。 |
| 样本查看-连接器参考 | 合成几何与独立参考量值分开，测量执行仍在 Workflow。 |
| 样本查看-RGB-D | RGB 与深度配对、标定/单位和无效值明确。 |
| 样本查看-点云 | 点云坐标系、单位与颜色模式明确，查看与测量功能分界。 |
| 列表与资源状态 | 统一空态、筛选无结果、旧数据提示与失效资源的恢复动作。 |
| 保存与任务状态 | 保存错误保留输入，未知提交先查状态，取消请求不冒充完成。 |
| 删除与清理状态 | 前置阻止、失败、部分清理和完成分别显示真实结果。 |
| 样本大图-短屏 | 短屏使用覆盖抽屉与可达操作，不缩小文字挤压图像。 |
| 数据结构-短屏 | 短屏收起目录树，文件表与上下文仍可操作。 |

## 3. 浏览与选择契约

- 列表和网格共享版本、筛选、排序和选择集；勾选与打开样本分开。点击“查看”或双击进入大图，信息动作打开抽屉。
- 本页选择与全部筛选结果选择必须分开说明；全部筛选选择保存筛选快照与版本，不向浏览器加载所有样本ID。筛选或版本变化清空旧选择，并提示数量已重置。
- 多选动作限导出所选、外部标注交接、基于所选创建版本。不原地删除或修改已发布版本中的样本。单张查看不要求先勾选。
- 数据结构文件表只选择一行，没有批量动作，因此不放复选框。COCO共享标注按image_id关联，TXT/XML也按真实资源关系查看，不能假设所有格式同名一对一。
- 图像失败保留样本身份、来源和重试；坏标注保留原图与明确错误，不冒充“无目标”。该规则与资源失效状态组件、现有导入检查阻止页面共用。
- 只读可浏览、筛选、复制已授权信息；写动作不可执行并说明原因。服务端仍需验证权限。
- 大数据列表采用分页/虚拟化、按需缩略图和有界关联查询。统计尚未完成用“计算中/暂无数据”，不能补零。

## 4. 类别、质量和版本

类别包含图像数可以重叠，不求和作为总图片数。对象数、按split的图像数和对象数明确区分。test未配置为中性信息。类别、标注、划分改变都创建新版本。

质量报告标明版本、检查时间、范围、规则与未检查项。机器可判的结构错误和需要人工判断的候选分开；近似重复不能自动删除。每项“查看样本”携带版本与问题筛选，返回恢复原列表位置。来源文件清理或版本失效时保留报告事实，不用其他资源冒充。

版本与来源只列同一数据集；顶层版本列表跨数据集检索。查看、比较、导出、依赖详情都绑定不可变版本。来源是导入/派生/外部回传的明确关系，不把派生版写作直接ZIP导入。历史引用不自动升级。

版本更多菜单：查看来源、查看引用、创建导出、创建新版本、删除版本。危险动作与普通动作分隔；只读或被引用时说明原因。数据集更多菜单：详情、编辑信息、导入新版本、创建导出，不提供整数据集删除。

## 5. 创建新版本与比较

配置来源版本、样本范围、类别映射和划分策略，进入检查后计算实际影响。合并类别、排除类别/样本须列出影响，不因映射为空而隐式丢弃。映射目标名/ID冲突阻止提交。

划分总比例必须100%；固定随机种子保证同输入同结果。按采集批次、序列、工件等可用分组键保持同组，不拆分为train/val；没有分组键时明确“未配置分组”，不声称已排除数据泄漏。严格分组可能导致比例偏差，以检查结果为准。用户可返回修改，不能静默调整规则。

检查通过只是预检查，不是创建成功。提交后才获得任务与新版本身份；取消/失败不影响来源和历史引用。再次提交前重检版本存在、权限和输入签名。未知响应先查询该次提交，不自动重复创建。

版本比较按稳定样本标识分新增/移除/修改；修改进一步为图像、标注、类别、划分变化。摘要与行详情对应，不将内容hash相同的不同样本直接合并。比较不是覆盖或合并，用户仍需显式创建新版本。

## 6. 外部标注交接

使用现有导出与导入基础流程，增加交接清单与返回匹配，不建设内建通用标注绘制系统。交接固定来源版本、范围、格式和类别；生成中不可下载，完成后沿用导出详情及可用性状态。

回传按稳定ID和清单匹配，不只依赖文件名。缺失可显式保留源标注；重复ID、未知ID、非法几何、类别冲突须先处理。图像修改需要明确确认，不能仅凭文件名替换原图。检查报告分匹配状态与标注差异，重复组数不与图像数随意相加。成功形成新版本并记录来源链。只读、失败、取消、结果未知复用统一任务状态。

## 7. 类型查看边界

| 类型 | 查看与字段 | 禁止误导 |
| --- | --- | --- |
| classification | 图像级标签、多标签按实际数据呈现 | 无框不造框，真值没有预测置信度 |
| detection | box、类别、原图坐标 | 不混用图片与对象数 |
| segmentation | 轮廓/掩膜、透明度、对象列表、px² | 像素面积不冒充物理面积 |
| pose | 关键点名称、可见/遮挡/未标注、骨架模板 | 未标注不画原点，遮挡不直接算失败 |
| OBB | 旋转四角、方向定义、原图坐标 | 不用水平框替代旋转几何 |
| 异常/瑕疵 | 正常/异常/未知，图像级与区域级分开 | 不把预测热图当真值，无区域不伪造 |
| 连接器参考 | 合成/实拍来源、单位、参考和标定资料 | 合成设计值不等于独立实测，测量仍在Workflow |
| RGB-D | 媒体配对、分辨率、单位、映射、无效值 | 无标定不声称对齐；无单位不输出物理距离 |
| 点云 | 坐标系、单位、点数、着色、视角、无效点 | 查看不替代测量及生产判定 |

多对象密集标注可关类别文字但保留框/编号，选中对象提高轮廓可见性；图层显隐不改变样本筛选。照片/几何图在亮暗间保持原色，二维对象随原图坐标变换，三维测量不在查看器内临时添加。

## 8. 通用状态与恢复矩阵

| 状态 | 可见反馈 | 操作与数据保护 |
| --- | --- | --- |
| 首次空/筛选空 | 不同文案 | 导入/清除筛选；空分页隐藏 |
| 初次加载/刷新失败 | 局部骨架/旧数据时间 | 不清空有效列表，手动重试 |
| 无权限/失效资源 | 明确当前资源不可用 | 返回有效上层，不静默切换版本 |
| 输入错误 | 字段旁说明 | 保留输入，定位首个错误 |
| 保存失败/并发冲突 | 明确未保存 | 保留输入；查看最新后人工合并，不静默覆盖 |
| 上传或提交未完成时离开 | 简短离开确认 | 继续编辑/放弃未提交内容；不误取消已提交任务 |
| 提交中/结果未知 | 禁止重复提交，查询已有请求 | 先确认结果，不自动重投 |
| 执行中/取消请求中 | 进度仅有真实总量时使用百分比 | 请求已发不等于已取消；关闭页面不取消 |
| 成功/失败/取消 | 各自真实终态及可用产物 | 有效资源入口按实际情况开放 |
| 删除前出现新引用 | 阻止并刷新依赖 | 不强删、不隐式解除其他任务 |
| 清理失败/部分成功 | 已完成与待处理逐项区分 | 仅重试剩余；未删文件不假报已清理 |
| 已清理/记录已删 | 保留符合契约的历史或返回列表 | 不能继续下载失效产物 |
| 网络恢复 | 保留选择和上下文后刷新 | 不自动重放写操作 |

动作菜单、表单错误、toast、tooltip和加载骨架使用统一组件定义，不为每条文案增加整页图。组件板呈现代表状态；具体参数和服务契约需实现时验证，不能凭静态稿宣布所有组合已测试。

## 9. 短屏与可达性

常规1920×1080；短屏1366×768优先折叠左导航和目录树，工具按重要性保留，长表正文滚动，抽屉为覆盖层且头尾动作可达。抽屉/对话框打开管理焦点、Esc按层关闭，关闭后焦点回触发按钮；有未保存输入需离开确认。图片快捷键在输入控件中失效。选择、状态不能仅靠颜色，提供文本/图标/编号。

品牌绿和白字按已确认要求保留；精确对比度、200%缩放、真实键盘、屏幕阅读器和性能需原型验收，静态图不宣称通过。生成PNG实际像素与设计视口分开记录。

## 10. 完成口径

本轮补充目标页面与代表状态。只有每个主要可见入口有确定去向、核心数据变更保护规则明确、新场景有亮暗图和中文规格、失效资源有恢复入口，才可标记“目标设计主流程已覆盖”。不能因此标记真实交互、后台能力、性能、工业精度或生产验收完成。图稿微小文案及像素仍以该规格及后续统一组件为准。
