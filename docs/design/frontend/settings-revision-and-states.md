# 设置母版修订与操作状态

日期：2026-11-02。承接完整性核对，保留当前设置导航与页面布局。

## 输出方式

ImageGen修订试稿仍出现背景纹理，未作为合格资产进入正式目录。本轮使用仓库现有Vue 3、Vite、Lucide图标和品牌文件建立隔离设计样稿；同一DOM仅切主题变量，保证亮暗几何一致。浏览器截图作为设计图，不对PNG做重绘、滤镜或拉伸。样稿不连接后端，所有提交仅改变示例状态，不修改真实用户、Token、部署或服务。

设计样稿位于`prototypes/settings/`。共用当前前端依赖，不引入React或新运行框架。它是设计与交互验证资产，不是产品功能实现。日期、用户与服务数值为设计样例；Token只使用无效占位文本。

## 母版修订

- 全局导航64px、设置导航220px；无独立顶栏，保持当前分组与缩进。
- 正常视口1133×1142，短屏1366×768；正文14px、表格13px、局部标题18px，普通文字400字重。
- 亮色页面#F6F7F9、面板/导航#FFFFFF；暗色页面/全局导航#101010、面板/设置导航#171918。无渐变、暗角、噪点。
- 品牌绿#00D992不变；选中软绿，普通hover与输入focus中性。已配置/已安装/未配置为中性，已验证健康/可用为绿点配正文，错误红色，待确认黄色。
- 可选NPU未配置不显示故障。检测失败与明确不具备硬件能力分开。
- 表格数字不拆行，长路径按字段换行；主体和弹窗正文可滚动，弹窗底部操作保持可见。

## 中文提示词模板

为AMVAR工业视觉工作站制作“设置／{页面或操作}”的{亮色或暗色}UI设计图。保持当前左侧64px全局导航、220px设置导航及内容分工，无独立顶部栏。视口{1133×1142或1366×768}，按当前实现的字体、图标和控件比例排布。仅改变本图指定状态，不更改相邻模块。亮暗只替换颜色，几何和数据保持一致。纯色背景，品牌#00D992，正常正文中性；安装与配置事实中性、运行健康绿色、异常红色、待确认黄色。正常状态少说明；失败只给短原因与直接操作。弹窗覆盖完整背景且不挤压内容，正文可滚动，取消和提交按钮可达。所有数据是设计样例，无真实密码或Token。输出单张完整界面。

各图具体字段由样稿中的场景定义补充，独立中文规格与截图一起登记到生成清单。ImageGen不合格试稿不替换原图。正常运行不因满载或长任务而改为异常；页面断线保留上次状态与检查时间。
