# 设置分类细节优化

更新：2026-11-02，替代上一轮“保持布局即合格”的过窄判断。

## 保留与优化

保留现有全局导航、设置分组、九页分工、用户目录与详情、确认弹窗以及纯色亮暗主题。优化信息层级、表单对齐、控件和表格密度，不重新拆导航或增加顶部栏。

| 范围 | 具体修订 |
|---|---|
| 所有选择控件 | 复用产品已有显式绘制：选中品牌绿底，白色勾/白色圆心；未选中中性边框。禁用降低整体亮度但保持白色标记。保留原生input语义、键盘、focus与强制颜色支持。 |
| 偏好与启动 | 控件宽度受约束、标签和值统一基线；分段选项共用中性容器，选中绿底白字；底部动作与其他表单一致。 |
| 运行状态 | 保留六项服务概况；Worker首屏突出运行数量和状态；Topology、Epoch等放本区技术信息展开；消费者列表可在对应行展开，不删除字段。Profile用直观名称，完整技术名保留。 |
| 环境与关于 | 字段网格间距统一；路径自然换行；依赖和设备表格有清楚的中性表头；版本、数值对齐。安装事实和健康状态继续区分。 |
| 会话权限 | 各面板标题、表格、只读字段统一；普通内容不全加粗；关键状态用徽标。 |
| 用户管理 | 编辑权限归入账号操作区；权限区、Token区、密码区边界清楚；Token输入和按钮等高，表格时间不拆字。 |
| 创建/编辑权限 | 权限分组标题与计数清楚，选择行有足够点击空间；全部操作时所有单项正确显示选中并禁用；项目范围横排单选。全部/指定使用互斥radio name。 |
| 模态与短屏 | 统一遮罩、标题、正文和固定操作；错误就近出现；短屏正文滚动、按钮可达，不能用缩字压缩整个表单。 |

## 中文补充提示词

以当前设置页合理结构为基础，做看得见的细节优化，不只是复制旧界面。参考已确认分类的中性表头、分组分隔、输入间距和状态层级。品牌#00D992保持；所有选中单选/多选为品牌绿色底与纯白标记，不允许黑色圆心或勾。表单标签和输入对齐，选择行易点击，标题突出但普通值不加粗。主状态先读，技术细节可在本区展开。纯色亮暗背景，同一DOM仅换主题；普通hover和focus为中性。保留字段和操作，正常页少描述文字。

## 核对顺序

先创建用户与权限，确认控件白色标记、互斥及全部操作语义；再运行状态和用户管理，核对信息顺序与展开功能；之后同步九页与所有现有状态，逐组检查亮暗几何和短屏。更新正式图、中文规格、总览和QA，只有本轮核对后的图片进入有效目录。

消费者数量可点击；在对应表格行下方展开全宽明细，三列排列完整名称，避免窄单元格碎行和超高行。
