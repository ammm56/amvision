## 2. 页面结构

全局11个平级入口保持一致，选中“节点”。无独立全局顶栏和重复大标题。页内三页签：**节点目录 / 节点包 / 问题诊断**。切换保留各自搜索、筛选与滚动；页面刷新不触发节点包重载。

| 页签 | 高频内容 | 动作与去向 |
|---|---|---|
| 节点目录 | 名称+一句用途、来源、输入/输出、节点版本；搜索名称/用途/ID，来源与用途筛选 | 详情→右抽屉；包名称→包详情；专业编辑→图编辑，不能隐式更改已有草稿 |
| 节点包 | 名称+短用途、包版本、节点数、启用状态、加载结果 | 安装节点包；详情；校验；更多中的启用/禁用/版本/诊断 |
| 问题诊断 | 节点包、问题、发现时间、操作；错误与提醒分开 | 查看原因、定位依赖、复制错误、重新校验；不以清除显示掩盖有效故障 |

目录不默认展开分类树和第三列详情。高级筛选在筛选弹层内：节点包、端口类型、能力、运行方式。原始 dotted category 转为易读用途标签，并可在技术信息中复制原值。页面结果有分页或虚拟滚动，不能一次渲染所有未来节点。

## 3. 详情与节点包操作

### 节点详情

右侧宽约620px，标题为正式节点名，一句用途，来源包与节点版本。页签：输入输出、参数、使用说明。端口逐行标明名称、类型、输入必填/可选，输出是否条件产生；单位/frame只有契约声明时显示。参数是只读说明表：名称、类型、默认值、取值规则；长参数可检索和滚动。不要把默认值画成可编辑输入。

技术信息默认折叠：完整 node_type_id、category、implementation/runtime kind、runtime_requirements、原始 schema。参数调节回到图编辑；复制节点标识必须得到反馈。模板示例必须指向真实兼容模板，无模板时不出现无效按钮。

### 权限

依据当前路由：`workflows:read`允许查看状态、版本、日志、审计和单包校验；`workflows:write`允许安装、启用、禁用、回滚和整体重载。只读不能把单包校验误禁用；无读取权限不显示资源与假零计数。

### 节点包详情

页签：概览、版本、依赖、记录。正常概览仅展示用途、版本、节点数、启用/加载状态、兼容条件、超时；manifest/入口/路径/哈希展开再看。版本列表有当前标记、安装时间、操作者及回滚动作；节点版本与包版本不能混为一个字段。

安装目标流程：选择本地 ZIP → 校验与变更摘要 → 明确确认安装 → 执行结果。校验摘要包含包身份、版本、节点数、依赖、兼容性、是否替换已有版本；只有错误才展开解释。来源确认与安装后启用分别表达，不默认为任意ZIP已可信。来源确认前仅允许静态检查文件结构、schema、兼容与已安装依赖，不执行Python入口；需执行代码的注册验证在确认安装后进行。当前 install API是一体化提交，分离预校验及可追踪操作结果是实施前需要补齐的契约，不虚构现有端点。

禁用/回滚先展示引用影响，包含直接引用应用、反向依赖包及传递依赖影响，不能只按画布中的节点类型查找。OpenCV被禁用会使依赖它的Connector Nodes不可用，确认框应标为“受影响节点包”，避免颠倒依赖方向。正在运行的直接或间接关联实例不能被静默热切换；目标设计在服务无法证明安全时阻止变更，要求显式停止相关实例后重新检查。仅草稿引用时说明下一次校验/启动影响，可确认禁用；不自动修改 Workflow、不删除文件、不重放运行。引用关系/运行影响检查目前须补服务能力，静态图不代表保护已实现。

结果未知时保留上次确认状态及时间，查询操作结果，不重复提交安装/回滚。并发变更需检查目标版本仍一致。包已禁用与包加载失败分别呈现；缺依赖不能被“已启用”覆盖。

## 4. 当前事实与设计数据

2026-10-31本地manifest：`opencv.nodes`为0.1.10，195个定义；`connector.nodes`为0.1.8，2个定义，依赖`opencv.nodes >=0.1.8 <0.2`；其manifest含`developmentOnly: true`。Connector包详情必须显示开发用途，不能据静态设计暗示生产计量验收。

| 节点 | 节点版本 | 输入/输出 | 来源 |
|---|---|---|---|
| Caliper Edge | 0.1.8 | 2 / 3 | opencv.nodes |
| Circle Diameter | 0.1.8 | 1 / 2 | opencv.nodes |
| Image Decode | 0.1.10 | 1 / 1 | opencv.nodes |
| Mapped ROI Crop | 0.1.10 | 7 / 2 | opencv.nodes |
| Pin Array Locate | 0.1.8 | 2 / 5 | connector.nodes |
| Connector Measure | 0.1.8 | 2 / 4 | connector.nodes |

Caliper Edge输入为Image(image-ref.v1)必填、ROI(roi.v1)可选；输出Lines(lines.v1)、Summary(value.v1)、Debug Preview(response-body.v1，可选)。Caliper Line设置后优先于轴向ROI。调试图用于编辑预览；目录不能把它等同正式Runtime图片输出承诺。包超时默认/最大均30秒来自manifest，不套用旧稿5000ms。

版本回滚、缺依赖、引用数量、安装日期为情景样例；历史包文件是否存在必须由实际versions响应决定。仓库中存在节点不表示外部设备或厂商SDK已经可用。

以下按累计49组交付区分独立出图与结构复用。文件以[清单](generated/节点/生成清单.json)为准；场景契约见[生命周期、使用说明与短屏](node-lifecycle-states-design.md)和[剩余状态与复用规则](node-remaining-states-design.md)。

| 范围 | 已出亮暗配对图 | 复用与约束 |
|---|---|---|
| 能力发现 | 目录、高级筛选、无匹配、Core/扩展详情 | 来源/用途即时筛选；高级条件应用；清除重置页码；Core-only复用目录 |
| 使用说明 | 输入输出、参数、使用说明、复杂参数、详情短屏 | 单位/frame未声明显示—；未知类型展示原始schema；参数只读 |
| 包管理 | 列表、概览、版本、依赖、记录 | 正反依赖明确；审计无删除；无依赖/无记录复用中性空态 |
| 安装 | 选ZIP、校验中、确认、安装中、成功、失败恢复、文件无效、版本冲突、兼容失败、依赖不满足、未知结果 | ZIP/schema错误复用文件无效；身份/目录冲突复用冲突；相同内容不重复覆盖 |
| 生命周期 | 启用确认/失败、禁用影响/完成、运行引用阻止、回滚确认/完成/恢复失败/失败已恢复、变更处理中、版本变化、权限变化 | 启停处理阶段复用处理中；启用成功复用已加载详情；网络未知不猜结果 |
| 诊断 | 问题列表、依赖缺失、注册冲突、外部依赖、无问题、技术信息展开 | Python/厂商运行时缺失复用外部依赖；技术信息按需展开 |
| 共享状态 | 初次加载、连接中断、空扩展包、只读/无权限、目录/详情短屏 | 刷新保留旧数据；无缓存失败不显示假0；无读取权限不显示旧资源 |

扩展任务类型通过筛选与节点详情结构复用，不按每个算法制造独立管理页。仅当端口/单位/frame/资源配置或专属编辑入口有实质差异时补代表图。

## 6. 统一交互与验收

- 1672×941配对图匹配已确认样式。亮暗同行数、字段、按钮与状态；主色#00D992，普通图标/文本/悬停/焦点中性，错误红、警告琥珀并有文字。
- 抽屉覆盖原有列表，原表宽度及坐标不变；统一遮罩覆盖品牌、导航和账号。关闭回原行焦点；Esc遵守有草稿确认；正文独立滚动，标题和必要底部操作固定。
- 1366×768导航收起只留AM Logo作为展开入口；保留名称、状态及操作列，次要字段入详情；不缩小字体。键盘筛选、页签、表格选择、弹层焦点循环待Vue原型验证。
- 校验/刷新不自动启用或回滚；有副作用的操作使用明确按钮和结果。不能将HTTP失败猜成操作失败，也不能把无诊断数据当零问题。
- 前端未来沿Vue3+TypeScript实现，离线资源随包分发。不动Runtime/Trigger同步数据面，不引入队列或自动业务重试。
- 当前亮绿白字是用户确认的品牌方向，图稿不证明WCAG对比度通过；实现需按真实颜色、字号、边界与非颜色提示逐项评估。

实施顺序：目录/详情组件 → 包管理与生命周期契约 → 安装/版本/引用保护 → 诊断恢复 → 异常/短屏/键盘验证。每步先核对schema，再实现和实测，不用静态图当功能验收。
