# 项目分类页面与操作设计

更新：2026-10-23。范围：项目列表、项目概览及其操作容器。状态：目标 UI 规格与静态稿，不修改产品代码、项目数据或运行服务。主页面延续[项目概览](project-overview-design.md)，同一套亮暗主题，不新增导航分类或全局顶栏。

**最新修订：** 界面以完整产品实现为目标。下文对当前接口缺失的描述属于开发差距，不再限制出图；时间信息、SDK 范围选择、删除操作查询等目标能力按[完整产品设计](project-complete-design.md)补齐。当前实现与目标设计需分开判断。

| 场景 | 已有设计 | 需要补齐的 UI 与状态 | 容器 |
| --- | --- | --- | --- |
| P01 项目列表 | 亮暗主图 | 无项目、无搜索结果、加载失败、只读、长名称、操作菜单、分页及当前项目 | 独立主页面，沿用 `/projects` |
| P01 新建项目 | 亮暗抽屉 | 必填校验、重复提交、创建失败/结果不明；仅名称表单与当前必填 ID 的差异 | 右侧抽屉 |
| P02 SDK 配置包 | 正常、范围选择、长列表及短屏亮暗稿 | 空配置、搜索无匹配、生成反馈、失败和预览过期 | 居中对话框 |
| P03 项目概览 | 正常与空项目亮暗主图 | 部分失败、只读、资源失效、最近更新展开与返回 | 独立主页面，目标 `/projects/:projectId` |
| P04 项目信息 | 亮暗正常稿 | 复制反馈、缺失值、长 ID/路径、配置项目只读、读取失败 | 右侧抽屉 |
| P05 编辑项目 | 修改中及保存失败亮暗稿 | 校验、未保存退出、并发修改、无权 | 右侧抽屉 |
| P06 删除项目 | 阻止、空项目确认、非空影响、清理待完成亮暗稿 | 保护原因、执行中、结果不明、清理完成 | 居中对话框 |

完整结构是 2 个主页面、3 类抽屉、2 类对话框。剩余状态见第 11 节和[补充提示词](prompts/项目补充状态.md)，未出图状态不得标为视觉验收通过。不为每个错误新建路由，不增加项目仪表盘、项目设置中心、成员管理或独立资源浏览系统。

## 2. 项目分类完整使用路径

1. 项目列表：查找/选择项目；“查看”进入概览；操作菜单提供编辑、删除，权限与保护规则仍有效。
2. 项目概览：了解当前项目资源和运行情况；跳转对应数据集、模型、应用、部署和任务模块。选中项目和 URL 范围必须一致。
3. “项目信息”：右侧查看身份与来源；不改变当前项目，不把后台 JSON 直接展示给普通用户。
4. “编辑项目”：右侧修改展示名称和说明，保存后返回原概览；不改 ID、目录、模型、Runtime 或 Trigger。
5. “生成 SDK 配置包”：居中预览配置范围和文件，明确生成并下载；不进入独立全屏页面。
6. “删除”：从列表明确发起，预检允许后再次确认；被阻止时查看阻止项，不提供强制删除。

一次只打开一个项目操作抽屉。从信息抽屉点“编辑项目”时替换为编辑内容，不叠第二层抽屉。取消编辑关闭抽屉并回到原页面；保存后更新同一项目的标题、列表名称与只读缓存，不重新执行工作流。

## 3. 项目信息抽屉（P04）

标题为“项目信息”，右上关闭。正文不做输入框外观，不使用禁用表单模拟只读详情。

| 字段 | 展示方式 | 来源/边界 |
| --- | --- | --- |
| 项目名称 | 正文首项，支持换行 | `display_name`，空时回退 `project_id` |
| 项目说明 | 多行文字；无内容显示“未填写” | `description` |
| 项目 ID | 等宽、可换行，同行复制按钮 | 稳定 `project_id`，不能重命名 |
| 来源 | “本地目录”或“配置项目” | `project_source`，不转换为健康状态 |
| 存储位置 | 相对路径和复制按钮 | `storage_prefix`；说明为“相对于服务存储目录”，不能当客户端磁盘路径打开 |

信息抽屉显示创建时间与更新时间，分别表示项目创建和元数据最后修改时间。公开 API 需要补齐可靠来源，不能用 summary 的 `generated_at` 替代。创建人、负责人、容量占用不属于本轮必要信息；不因当前接口缺字段删掉合理的目标设计。

底部：左侧“关闭”，右侧“编辑项目”；只读时不显示编辑动作。信息页不重复四项资源计数，不放删除，不添加原始 metadata、token 或无法使用的“打开本地文件夹”。复制成功在按钮旁短暂显示“已复制”，复制失败保留可选文字并给简短提示。

读取失败只影响抽屉，不清空主页面；有上次值时显示过期提示，不能用其他项目缓存替代。来源为配置项目且尚无合法编辑服务时，保持只读并说明“此项目由配置提供”。

## 4. 编辑项目抽屉（P05）

与信息抽屉同宽，标题“编辑项目”，标题下可显示当前名称以明确对象。正文仅两个可编辑字段：

- **项目名称**：必填，去除首尾空白；显示名可以包含中文。同名是否允许以契约为准，不把显示名当唯一 ID。
- **项目说明**：选填，多行。字段长度由统一公开校验契约约束，前后端一致；不在 UI 单独发明限制。

底部固定“取消”“保存更改”；未修改或校验失败时保存禁用。输入焦点为中性灰，主按钮品牌绿白字。无“恢复默认”、无运行启用开关、无磁盘路径和 ID 编辑器。简短说明“仅修改名称和说明”可以放在字段区下方。

交互规则：

1. 打开时读取目标项目当前元数据及版本依据；不能直接覆盖当前选中之外的项目。
2. 保存期间防重复提交，显示“保存中”；不跳转、不闪空内容，也不提前显示成功。短暂提交期间保持对象不变。
3. 保存成功再更新页面与缓存、关闭抽屉、轻提示“项目已更新”。这是元数据更新，不发布工作流、不重启服务。
4. 保存失败保留草稿，错误放抽屉内；校验问题贴字段，服务问题贴底部动作上方。
5. 有未保存修改时，关闭、遮罩、Escape、返回或切页都先确认“放弃未保存的修改？”；默认动作“继续编辑”，另一个“放弃修改”。无修改时直接关闭。
6. 并发修改用版本/条件更新核对。冲突时保留本地草稿，提供“查看最新内容”，不自动覆盖；不得借 bootstrap 接口更新已有项目。
7. 超时或断线使提交结果不明时先读取同项目当前值核对，再允许重试；不自动重发写操作，不将失败描述为一定未保存。
8. 过程中被删除、失权或项目变为不可编辑，停止提交并保留清晰原因；不得降级到另一项目或直接改配置文件。

## 5. SDK 配置包对话框（P02）

沿用项目上下文，建议约 760–840px 宽；长文件清单在正文滚动。标题“生成 SDK 配置包”，右上关闭；正文显示项目名称、服务地址、配置范围、文件清单和说明，底部“取消”“生成并下载”。

- 采用当前受支持的默认输入：模型调用模式 `sync`、包含未启用触发源、按已有策略包含当前调用凭据。用简短文字说明当前范围，不增加逐资源复选框或不存在的导出选项。
- 默认全部可调用资源；“调整范围”在同一对话框内进入资源选择，选择 Runtime、调用型 Trigger 与模型部署，必要依赖同步关联。应用选择后返回派生文件预览，不允许任意挑选 ZIP 文件。当前接口缺少选择契约，作为开发要求补齐；示例资源不是线上数据。
- 长列表仍在同一对话框中：资源区统一滚动，标题、搜索、选择摘要和底部操作固定。每组已选/总数与全局选择集合一致；滚动或搜索不取消不可见项。关联 Runtime 有锁和来源说明，长名称换行，不缩小字体、不逐组嵌套滚动。搜索无结果、空分组及加载失败的边界见完整产品规格。
- 数量标为“Workflow Runtime”“调用型 Trigger”“模型调用配置”；模型配置数量不能冒充实际健康模型/实例数，也不能与项目概览总数强行相等。
- 普通说明保持：“目录监听触发源由后端自动执行，无需 SDK 调用配置，已省略。”置于中性信息区；真实 warnings 另按具体配置问题呈现，不把省略当异常。
- 若 `contains_access_token` 为真，文字提示“配置包包含当前访问凭据”；不显示 token。预览内容也不是 SDK 连接已成功的证明。
- `preview` 与 `download` 都基于当时资源重新构建；不是点击生成就复用旧文件。若要求严格锁定预览，应显式扩展配置 revision 核对契约；现有下载接口不支持传入预览版本，UI 不能假装已经锁定。
- 生成/下载失败保留对话框与上下文，提供手动重试；浏览器开始下载只提示“已开始下载”，不声称用户磁盘写入已完成。不自动重新触发生成。
- 没有可生成配置时禁用主动作，说明缺少可调用资源并提供相关业务入口；不能仅靠 `files` 含有说明文件就认定有可用调用配置。部分省略但仍有可调用配置可以继续。

SDK 对话框可以从列表或概览打开，内容锁定发起时项目；不能跟随背景项目选择悄悄切换。取消读取请求、关闭对话框不改变任何模型或 Runtime 状态。

## 6. 删除项目对话框（P06）

复用当前删除预检与精确 ID 确认，不引入回收站、自动停止服务或强制删除。

| 状态 | 主内容与操作 |
| --- | --- |
| 检查中 | “正在检查项目资源”，可取消检查；不先显示可删除 |
| 不允许删除 | 标题“暂时无法删除项目”；列出阻止项的类型、名称/可复制 ID、状态、业务入口；“重新检查”“关闭”，无可用删除按钮 |
| 允许删除 | 标题“删除项目”；明确目标和将删除的关联资源摘要，输入完整项目 ID 确认，取消与危险色“删除项目” |
| 删除中 | 防重复操作；不提供“撤销”或声称关闭即可取消服务器删除 |
| 已逻辑删除、待清理 | 按 `cleanup_pending` 提示“项目已移除，文件清理待完成”，保留可排查的操作标识；不说磁盘已全部清空 |
| 已完成 | 按 `deleted` 展示完成，刷新列表并清理该项目选择及缓存 |
| 失败或结果不明 | 显示可理解原因和核对入口；重新获取预检/删除状态后决定下一步，不自动连续重试 |

状态与按钮颜色以[确认对话框规范](design-system.md#69-确认对话框)为准：列表移除小绿勾、清理待完成琥珀时钟、主要查询操作品牌绿、可用删除实红白字。非空确认当前图展示 ID 已匹配状态；输入为空或不匹配仍禁用删除，禁用状态不能画成可点击的危险按钮。

当前默认项目和 `configured` 来源受保护，不能画为普通可删除项。非活动资源是否随项目删除由真实预检范围决定，不能概括成“只删名称、不删数据”，也不能编造“所有外部引用都会自动检查”。当前删除服务已在执行阶段复核活动资源，后续 UI 接入必须保留；静态图不能证明并发路径已验收。

无活动资源但仍有数据时，确认区展示真实影响类别及其数量，不能套用空项目示例。`resource_counts` 中不同层级的计数不相加。返回 `cleanup_pending` 时提供关闭、复制操作 ID 和“检查结果”；目标实现须补可授权的操作查询契约，不绘制假进度、自动完成倒计时或“立即清理”。刷新列表只能核对项目是否还可见，不能证明文件清理完成。

打开阻止项可离开对话框并进入其业务详情，不在对话框中直接停止生产服务。用户手动处理后返回并重新检查。删除当前项目后按有效权限选择其他可用项目，或进入无项目状态，不沿用已删除项目资源。

## 7. 跨页面状态与抽屉规范

### 7.1 容器

- 信息/编辑/新建使用同族右侧覆盖抽屉，建议桌面宽 480–520px，上限 560px；窄窗可到视口宽，正文保持可读。生成图为视觉参考，不反推精确 CSS。
- 底层主内容不缩窄、不重排；遮罩弱化背景，右侧抽屉不被遮罩变暗。关闭后恢复原布局、滚动和触发按钮焦点。
- 标题、关闭按钮和底部动作固定，正文独立滚动；字段不贴边、不被底栏遮挡。一个抽屉内不嵌套多层抽屉。
- 无修改时 Escape、关闭按钮和遮罩关闭；有草稿遵循放弃确认。焦点留在打开的模态容器，背景不可操作；Tab 顺序和屏幕阅读标签在后续实现验证。
- 两主题使用同一结构与同一数据；品牌色 #00D992，中性 hover/focus。危险删除使用危险色，不与普通主操作混淆。

### 7.2 补充状态

| 状态 | 页面行为 |
| --- | --- |
| 真正无项目 | 明确“暂无项目”；有创建权限给新建入口，无权给只读说明；不画假资源/空分页 |
| 搜索无匹配 | 保留搜索词，“未找到匹配项目”与“清除搜索”；不与无项目混用 |
| 空项目概览 | 真实零计数、最近更新为空、暂无执行任务/常驻服务；继续工作入口提供下一步 |
| 计数读取失败 | 用“—”及局部重试，不显示 0；其他可用内容保留 |
| 只读 | 查看与复制可用，编辑/创建/删除依权限处理；SDK 按自身读取权限判断，不与编辑权限绑定 |
| 无权或不存在 | 不泄露项目元数据，返回列表；不加载其他项目替代 |
| 过期/断线 | 保留上次结果及观察时间，明确非实时；连接恢复只刷新读取，不重放写动作 |
| 最近更新查看全部 | 在同一概览扩展有限分页列表，保留返回摘要入口；不增加独立全局资源页 |
| 1366×768 与长内容 | 资源入口允许紧凑重排、主内容上下排列；抽屉覆盖而非挤压；长字段换行/复制 |

## 8. 当前代码差异与实施顺序

核对来源：[项目列表](../../../frontend/web-ui/src/modules/projects/pages/ProjectListPage.vue)、[项目请求服务](../../../frontend/web-ui/src/modules/projects/services/project.service.ts)、[目录/删除 schema](../../../backend/service/api/rest/v1/routes/projects/schemas.py)、[SDK 接口](../../../backend/service/api/rest/v1/routes/projects/sdk_config_packages.py)、[初始化与 manifest](../../../backend/service/application/project_bootstrap.py)。

1. **先补契约**：合法单项目读取、元数据编辑与条件更新；已有 manifest 时间如需展示再公开。`configured` 项目无更新路径时保持只读。
2. **解决新建 ID 差异**：旧设计只填名称/说明，但当前 bootstrap 必填 `project_id`。目标保留简表单，由明确的创建服务分配稳定 ID，不能用可改中文名称直接当目录。创建请求需要防重复结果核对；未补服务前不得把两字段稿当可直接上线。
3. **实现共享抽屉**：P04/P05 共用尺寸、焦点、草稿退出规则；只写项目元数据，不增加模型加载、推理、目录扫描或执行队列。
4. **整合 SDK 对话框**：复用实际预览/下载契约、notes/warnings；保持同步调用默认，准确处理空配置和生成结果。
5. **整理删除反馈**：复用预检和 ID 确认，准确显示 `cleanup_pending`，不将“请求成功”直接等同“文件清理完成”。
6. **补齐列表/概览状态**：准确项目范围、分页、返回、并发更新、失败不变成零、只读与长内容。
7. **按步核对**：字段/请求契约 → 单流程功能检查 → 亮暗与窄屏 → 实际浏览器。未实现阶段只做设计审阅，不宣称运行验证通过。

## 10. 本次明确的交互细节

### 10.1 选择、查看与返回

- 行选中表示当前业务项目，名称旁用“当前项目”标记；不增加多选列。空白行区域点击可以选择，项目名称应有可聚焦的选择入口，查看链接独立。
- “查看”在确认访问权后选择该项目并进入概览。更多菜单的信息/编辑/删除绑定该行项目，不因为打开菜单改变当前业务范围。菜单点击不触发行选择。
- 更多菜单顺序为“项目信息”“编辑项目”，分隔后“删除项目”。无权项不显示；受保护但有删除权限时保留禁用删除并提供明确原因。没有动作时不留空菜单。
- 返回列表恢复搜索、页码、滚动；过滤/翻页不偷偷改当前项目。当前项目被过滤时在页内工具区显示必要的名称及“定位”，不增加全局顶栏。
- 项目只剩一页时隐藏前后翻页按钮或显式禁用，不能显示两个像可用的箭头。当前页删除为空时退到仍存在的最后一页；搜索变化回到第一页。

### 10.2 名称、说明和时间

- 新建/编辑字段统一“项目名称”“项目说明”，列表列名“说明”。新建初始为空，使用灰色提示；示例文字不能当真实默认值提交。
- 项目名称重复不直接判错，是否允许以公开契约为准；重名时用 ID 辅助区分。字段上限由统一契约确定，UI 不自行发明另一套长度。
- 列表更新时间只指项目元数据最后修改时间；当前尚无公开来源时显示“—”。最近更新中的时间属于对应资源。摘要生成时间不能替代任何一个。

### 10.3 创建及结果不明

- 创建成功后关闭抽屉、选择新项目并在列表定位，显示“项目已创建”及“查看”入口；不自动开始训练、部署或切到强制首页。
- 创建中只提交一次，保持已填内容；收到明确失败后才能按原因允许手动重试。断线不自动重新创建。
- 目标简表单需服务分配稳定 ID，并有稳定创建标识用于核对。不能按显示名称判断刚才是否创建成功；没有核对依据时明确“创建结果暂时无法确认”，提供返回列表核对，不能伪造确定失败。此能力属于创建契约前置工作。
- 新建与编辑共用未保存退出规则；无改动直接关闭，草稿不跨项目复用。

### 10.4 最近更新展开

“查看全部”在同一概览切换为最近更新的全宽列表，保留顶部项目标题与资源入口；该状态暂不显示“当前运行”和“继续工作”，避免两套列表挤在一起。列表顶部提供“返回概览”、资源类型筛选和搜索；下方有界分页。原摘要位置在返回时恢复。不新增路由类别、固定第三列或多层抽屉。字段仍为名称/类型、状态、更新时间、打开；没有事件审计、操作人或操作次数等虚构字段。

### 10.5 权限和异常

- 只读不是全页灰化：查看、复制、具有权限的资源跳转仍可用；编辑/创建/删除按各自权限处理，SDK 使用自己的读取权限判断。
- 无权与不存在使用不泄露元数据的“无法打开此项目”与返回列表；资源失效只影响其入口，不切到别的项目替代。
- 部分数据失败保留正常模块；未知计数“—”，无权模块“无访问权限”，真实无资源为 0。过期结果标记“尚未更新”，只显示确有来源的观察时间。
- 编辑冲突保留草稿并显示服务器最新值，可逐项比较；“载入最新内容”丢弃草稿前需确认。未完成核对不提供强制覆盖；重新编辑基于最新版本再保存。
- 列表/概览刷新只发读取请求；重连不恢复执行任何此前的创建、保存、生成或删除动作。

### 10.6 对话框与短屏

概览顶端 SDK 改为与信息/编辑同级的次按钮，SDK 对话框内“生成并下载”是主动作。生成中关闭对话框不声称取消后端处理，关闭后不触发迟到的自动下载；重新打开重新预览。预览和下载目前不是同一固定快照，资源变化需要重新核对，不能展示已锁定的假象。

桌面抽屉以 520 CSS px 为统一参考，标题/底栏一致；最大高度受视口约束。1366×768 时概览两模块可上下排列，SDK 对话框正文滚动。长 ID/路径换行并可复制，不横向撑宽页面。150% 缩放时先减少次要列并折叠导航，不能缩小全部文字。最终需在真实原型验证，不能仅凭生成图判断。
