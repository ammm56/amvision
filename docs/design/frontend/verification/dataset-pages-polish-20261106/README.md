# 数据集管理列表与版本工作区核对

2026-11-06。本轮对照已确认的[样本网格](../../generated/数据集/标注样本网格-亮色.png)、[版本列表](../../generated/数据集/数据集版本列表-亮色.png)、[导入记录](../../generated/数据集/导入记录列表-亮色.png)、[导出记录](../../generated/数据集/导出记录列表-亮色.png)、数据结构及版本来源设计，沿用[数值色块规则](../dataset-count-badges-20261106/README.md)。后续用户确认的手动版本创建、精简操作及矩形提示优先于旧图。

## 实现

- `DatasetCountBadges` 与 `useDatasetCounts` 统一样本、类别、对象和划分统计。颜色关系、24px 色块、6px 圆角、无箭头矩形提示保持一致，零值保留，未知统计显示破折号而非虚构零。
- 版本列表补齐任务与来源；导入记录显示来源文件、统计和目标 vN；导出记录显示版本、格式、统计与导出文件。原始记录 ID 不作为名称下的重复副标题。搜索靠左、筛选靠右，列表单行省略长名称、格式、文件名与时间。
- 导入／导出数量来自当次任务的快照；当前版本更新不会改写历史显示。列表补充 `display_name`、`version_number`；导入列表增加可空的 `source_file_name`、`sample_count`、`category_count`。接口仍在现有 v1 内，以单页批量编号查询提供展示字段，不加载完整样本聚合，无持久化结构变化。
- 版本工作区使用紧凑横向统计条；筛选标签在控件上方；网格／列表和标注开关与筛选同组；样本卡片文件名截断、菜单降噪。未选择样本时不显示一排禁用的批量按钮；空数据或无搜索结果时仍可添加样本。
- 数据结构保留左侧“版本资产”目录树，返回和路径面包屑位于右侧文件区。类别与划分、版本来源的统计复用相同色块。
- 添加／删除样本仍保存当前版本；创建新版本仍是独立操作。未增加外部标注交接、人工复核或关联样本入口。Runtime、Trigger 与 .NET SDK 数据面未在本轮修改。

前端数据集回归 **10 文件 / 22 项通过**；TypeScript 通过；数据集工作区 API **3 项通过**；`git diff --check` 通过。新增断言覆盖未知值与真实零值、固定划分顺序、导入快照与版本编号。
