## 最新要求优先于旧图

- 保留现有公共导航、标准字号、主题令牌和纯色暗背景；不复刻生成图中的暗角和纹理。
- 不恢复已经取消的人工复核、外部标注交接、回传和关联样本功能。
- 文件结构显示当前版本的真实受控路径，不伪造设计图中的 COCO 文件结构。
- 增删样本仍作用于当前版本，新版本由使用者手动创建。本轮没有更改该行为。
- 数据集信息抽屉保持模态遮罩与焦点保护；大图中的对象检查面板无遮罩且允许继续操作图片。Esc 优先关闭对象面板。
- 原图尺寸、样本 ID、类别和坐标来自实际记录；不填充虚构置信度、轮廓或文件路径。

## 验证

- 真实开发环境：609 张图像、982 个对象、2 个类别，train 520、test 89、val 0。检查双击大图、缩放、对象选择、目录与文件叶子、结构切换、页码跳转、亮暗切换和窄屏。
- 1024×768 与 1672×941 检查；1024px 的 document.scrollWidth 为 1024，表格与容器 scrollWidth 不超过 clientWidth。导航展开与收起分别核对。
- 数据集与共享抽屉／图像视口 45 项前端回归通过；TypeScript 检查通过。
- 文件树及工作区 API 4 项测试通过。受限环境最初卡在 Python socketpair 初始化；正常本机权限重跑通过，非业务接口挂起。
- 最终刷新后的操作未新增浏览器 warning/error；记录中的一条旧 HMR 属性警告发生于 `undimmed` 替换为 `nonmodal` 的中间状态。Esc 实测只关闭对象面板，大图保持打开。
- 没有对实际生产样本执行删除、覆盖或新建版本。后端、Worker 和前端开发服务继续运行。

## 接口与兼容边界

版本文件列表新增可空的 `has_children` 字段：目录为是否含非链接子项，普通文件为 null；探测失败也为 null，由实际展开请求报告错误。只检查直接子项，发现第一项即结束，不递归扫描。原 `directories_only` 和 `has_directories` 语义保持不变。

共享抽屉的 `plain`、`nonmodal` 和分页的 `numbered` 均为默认关闭的可选项，不改变其他页面默认行为。无数据库迁移，无新前端框架、外网资源或运行环境依赖。
