# 数据集分组表头实施与验证

2026-11-06。采用用户确认的第 2 张[分组表头设计](../../generated/数据集/列表数值分组表头-亮色.png)；[中文提示词](../../prompts/数据集完整设计请求/列表数值分组表头-亮色.txt)。本次替代此前的彩色数值块。

## 实现范围

- 数据集、数据集版本、导入记录、导出记录的样本/类别改为两层表头与独立子列；数据集划分固定为训练、测试、验证三个子列。
- 正文普通数字、14px、常规字重、右对齐，使用 tabular-nums。无彩色数值底块、徽章、数值边框；亮暗复用主题正文色。表格使用 colspan、rowspan、scope 表达分组关系。
- `DatasetCounts` 复用于版本统计、类别与划分、来源、导入/导出详情及相关记录。同类数值显示统一；已有状态徽章、标注类别色点保留原有含义。
- 提示使用 Reka Tooltip 的中性矩形浮层，没有箭头。完整名称、数值和单位同时提供给键盘与读屏。未知数为“—”，真实零值保留，缺失的样本数不能使类别数左移。
- 搜索靠左、筛选靠右，行高 44px，少量数据按内容结束；原有查看、更多菜单、分页规则保持。长名称、时间可省略并保留完整 title。
