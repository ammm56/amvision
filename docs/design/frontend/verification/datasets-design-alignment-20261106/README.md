# 数据集页面设计对照与实际验证（2026-11-06）

## 范围与有效规则

对照 `generated/数据集` 中的数据集列表、样本网格、数据结构、对象抽屉、类别与划分、版本与来源、创建新版本配置/检查、管理列表及导出向导，修复现有 Vue 3 页面。复用项目公共表格、按钮、抽屉、确认框和主题。

最新用户要求优先于旧静态图：添加 ZIP、删除所选在“保存修改”后更新当前版本，版本 ID 和 vN 不变；“创建新版本”独立执行，复制当时数据并分配下一个 vN。不恢复关联样本、人工复核、外部标注交接/回传检查。列表不重复项目名称或划分；1024px 桌面无水平滚动。

## 发现与修复

| 问题 | 修复 |
| --- | --- |
| 创建版本表单缺少设计层级、单选受通用输入宽度影响 | 统一字段和品牌色单选；配置/检查两步，检查页展示真实样本、对象、类别及划分前后变化 |
| 版本说明没有落盘 | 写入 metadata，在版本列表呈现；修剪空白，限制 500 字符 |
| 快速切换版本混合新统计与旧图片 | 工作区与样本一起更新，加载时旧内容不可误操作；丢弃过期响应，清空旧选择和大图 |
| 选择版本重复载入选项 | 只在数据集/项目变化时载入，保持 vN 列表稳定 |
| 版本历史翻页再返回错误 | 移除错误的“已载入”短路，按实际页读取 |
| 内容修改后仍可提交旧选择 | 前端拦截过期范围，后端核对内容标识，实测返回 409 |
| 目录切换闪动 | 保留文件表，局部加载反馈；旧响应不能覆盖新目录，叶目录首次无展开箭头 |
| 选择、排序、大图对象交互不完整 | 图片左上角选择框、选择反馈、文件名正反序/导入顺序；大图使用同排序，对象选择高亮标注，释放 Blob URL |
| 历史导入报告受当前版本影响 | 读取持久化报告；API 透传新增/移除计数，合并后划分不再误用上传 ZIP 的局部统计 |
| 历史任务重开被旧选择阻断 | 使用任务当时配置和结果，不重新查询已删除样本 |
| 更新样本首次加载失败无重试 | 原页重试恢复草稿，不自动提交 |
| 版本/导出摘要包含多余技术 ID | 版本列表用 vN，导出摘要用数据集名称与 vN，完整标识保留详情/title |

## 真实环境结果

使用现有开发 HTTP、dataset worker 和真实条码 ZIP，在独立验收副本 `dataset-5996dd3c8b7e421dbe9ad64bd2ee2585` 操作；生产数据只读。原始结果见 [live-validation.json](live-validation.json)。

1. 浏览器从 v8（5 样本）创建 v9，配置 80/20/0、seed 42 和说明，经检查后明确创建，结果 4 train、1 val。
2. 浏览器向 v9 添加 ZIP 的 2 个样本，5 → 7，版本 ID 和 v9 不变。
3. 浏览器核对删除所选草稿、取消保护；通过 API 删除验收副本中选中的 1 个样本，7 → 6，仍为 v9；v8 保持 5，v7 保持 4。
4. 过期写入返回 409。当前 6 个样本的原图和缩略图共 12 个响应均为 200，媒体类型正确。
5. 浏览器完成 COCO 导出向导并下载；ZIP 为 6 图片、10 标注，split 内图片 ID 唯一，所有标注引用有效。
6. 历史导入报告仍为当时的 7 样本、新增 2、train 6 / val 1；不随当前版本变成 6。
7. 生产数据集 `dataset-barcodeqrcode-20261024222550` 保持 1174 样本。
8. 最后服务 ready，部署 6/6、Runtime 10/10、Trigger 8/8；worker generation 54。HTTP、worker、daemon、Vite 按要求保持运行。

## 交互与自动化

- 样本网格、目录树、版本列表、文件抽屉在 1024×768 亮暗与导航展开/收起时无水平溢出；长文本按列省略或详情换行。
- 编辑抽屉整体遮罩、不挤压背景，未修改时保存禁用。创建版本可返回修改，离开保护草稿。大图对象联动与上一张/下一张正常。
- 数据集、版本、导入、导出四个管理标签及详情入口核对通过。检查后恢复亮色和默认视口。
- 后端 6 文件 14 项通过；补充报告字段后 API 文件 3 项通过（其中 2 项为重复核对）。覆盖工作区任务、当前版本样本修改、版本编号、选择、API 与导出清理。
- 前端 9 文件 20 项通过，覆盖切换竞态、版本分页、旧选择、历史任务、加载重试、目录、标注、资源回收和信息抽屉。
- TypeScript、Vite 生产构建、修改范围 Ruff、`git diff --check` 通过；既有 Workflow/CloudViewer 大分包提示仍在。
- 本次没有修改 Runtime/Trigger/.NET SDK 执行链路；就绪检查不代替这些链路的长期负载验收。

## 接口与兼容

`/samples` 新增可选 `sort`（默认 `image_id`，另有 `filename`、`filename_desc`），后端白名单和稳定次序。版本配置新增可选 `description`；导入报告新增可选 `added_count`、`removed_count`、`retained_count`。旧调用不提供新参数仍按原默认行为运行。

本轮字段使用现有 metadata/报告，无新增数据库表或 DDL；HTTP 与 worker 使用同一代码。Vue 3、本地部署及 conda/同目录 Python 运行方式无新增外部依赖。
