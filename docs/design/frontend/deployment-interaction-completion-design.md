## 1. 核对发现

1. 导出已完成/失败/已取消已有图，但生成中和取消中只写复用，无法直接核对重复提交、取消确认与下载可用性。
2. 文件清理已有确认，却缺少历史成功但当前文件消失的详情，容易混淆生成结果和文件可用性。
3. 版本回退已有确认，但正向切换的来源选择与确认未独立呈现。
4. 参数行内错误、未保存离开、记录占用阻止和包类型不符需要具体代表状态。
5. 当前开发页面还有手动预热与重置入口。源码reset释放推理会话并归零实例计数，存在执行中的请求时拒绝；它不是重启HTTP或删除模型/生产记录。应保留专业操作入口与明确影响。

## 3. 完整路径与复用规则

- 创建：来源→参数→检查→提交→阶段反馈→可用或失败。行内参数错误不丢输入；切项目或改来源后旧检查失效。提交响应丢失先查询原操作，不重复创建。
- 版本切换：选择来源→运行配置→检查确认→停止/加载/预热/服务检查。第二步复用创建参数表，沿用当前值并明确新产物；最后一步使用切换确认图。成功复用恢复完成布局并把“手动恢复”改为“切换版本”；失败复用变更失败，旧配置可追溯但不谎报旧服务仍运行。
- 导出：范围确认→生成中→校验→可下载；取消确认→取消中→已取消或最终已完成。若完成先于取消，按服务事实展示已完成，不把完整文件误删。状态查询不是重试生成。
- 记录：完成记录→下载/文件清理/删除。下载占用或其他拥有者存在时阻止清理/删除；重新检查只读，解除后需重新确认，不自动执行。
- 导入：选择包→只读分析→配置/映射→检查→登记→独立启动反馈。包类型、版本或必需文件不符在写入前阻止；登记阶段不可伪造可取消。不携带软件环境或执行任意包内脚本。
- 预热：部署详情“诊断/更多”提供入口，不挤入每个列表行。已完成禁用；执行时显示预热中、已就绪数，成功重新获取健康信息，失败显示具体实例与诊断；不把预热计为真实生产请求。不隐式创建等待队列。
- 重置：进入影响确认→提交前检查在途→成功刷新状态或明确拒绝。完成后标识“会话已重置，待预热”，旧实例计数不可冒充当前值；服务正常与会话是否预热分开表达。操作响应未知仍先查询。
- 读取中/无匹配/无权限沿用公共列表规范：保留筛选、不能将读取失败显示成没有数据；旧数据标最后更新时间且禁止用旧状态提交危险操作。权限不足保持只读查看，服务端仍校验权限。
- 关闭/Esc恢复原位置与焦点；编辑离开须确认，取消中关闭不撤回请求。详情在窄屏可全宽覆盖；正文滚动、标题及动作固定。
