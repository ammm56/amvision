## 4. 实现阶段的明确约束

### 目录轮询

当前源码在checkpoint不存在时返回空进度，损坏时拒绝加载；写入失败会记录错误，但不必然停用入口。因此：

- 区分首次使用和历史进度丢失需要服务端持久化事实，不能靠前端猜测。
- “恢复原进度”检查来源、规则和有效结构；失败保留原数据与选择。
- “重新扫描”显式确认后准备新进度，仍停用；之后单独启用才会处理候选文件。
- 恢复结果未知时只查询，禁止重复提交；运行中写入失败必须显示实际运行状态。
- 图稿不表示这些恢复接口已经实现；本轮不改Adapter或高性能数据面。

### 共享界面

抽屉遮罩覆盖整个底图，表格不缩窄；最上层弹窗有自己的焦点范围。Esc关闭最上层，焦点回到触发按钮；抽屉正文滚动、操作区固定，关闭后恢复筛选和列表位置。长ID复制完整值，不复制省略号。亮暗用同一布局、字段、动作和语义颜色。

这些行为已写入设计规格，需在Vue 3实现时验证；静态PNG不能证明键盘、读屏、状态竞态或运行性能正确。
