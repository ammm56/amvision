同时查看已确认项目列表、数据集样本大图/对象抽屉、模型版本详情、部署列表的新风格参考。当前开发环境推理页通过内置浏览器只读检查，仅用于能力核对；未上传图片、未执行推理、未修改部署或运行实例。新的紧凑输入区与图片工作台不是照搬当前堆叠表单。

## 2. 首批交互覆盖

| 场景 | 入口和状态 | 完成检查 |
| --- | --- | --- |
| 工作台待输入 | 已选运行目标，尚无图片 | 推理和图片工具禁用；保留一个上传入口；不显示假计数、旧时间 |
| 工作台待执行 | 已选图片，尚未推理 | 原图可缩放和打开大图；预测/详情禁用；不残留旧框和分数 |
| 工作台检测结果 | 同步调用成功，有3个对象 | 输入、模型来源、图片、目标数、类别数与耗时对应，详情默认关闭 |
| 结果详情对象 | 结果详情→对象 | 非模态右覆盖面板；3行与分数一致，nut原图坐标及宽高一致；只读 |
| 结果详情耗时 | 结果详情→耗时 | 请求与服务端分开，阶段2.0+3.2+12.4+1.8+2.6=22.0，无虚构网络分段 |
| 样本大图 | 打开大图 | 完整图片工作区，保留来源/预测/详情/下载/返回；无无效上下张 |

单张结果与异步任务入口明确分开。图片联动详情无任何底层遮罩；资源选择和危险确认的模态遮罩另按公共规范使用，不能套用到图像联动面板。

## 6. 验证范围与限制

- 每张图由生成结果直接逐张查看，修订后再保存最终文件；亮暗配对核对导航、字段、输入状态、对象数据、层级和文案。
- PNG实际尺寸、字节数、SHA-256和当前中文规格哈希记录在[生成清单](generated/推理/生成清单.json)；目标视口1920×1080与实际生成像素分开。
- 生成图中的框位置、图像比例、条形长度和控件尺寸是排版示意，不能作为像素级测量或精确色值证据。实现必须使用原图1600×1200及真实bbox/阶段数据，验证坐标映射、等比缩放和不变形；不得硬编码图中的屏幕坐标。
- 文档中的38.0/22.0 ms仅为设计数据，不是性能测试。推理成功不等于产品合格，不等于模型准确率通过。
- HTML文件链接及内容结构可校验；浏览器对本地file页面的访问受限，未绕过限制，也未声称完成HTML渲染测试。静态图片通过本地查看工具核对。
- 真实键盘/焦点、关闭恢复、图片平移/选择、下载、125%/150%缩放及短屏交互需Vue 3原型验证。

首批归档校验为6组12张、284处本地链接有效；本批扩展后的校验结果见第9节。本任务未在仓库.tmp创建临时产物。

## 8. 第二批修正与实现约束

- 分类摘要改Top-3；分割工作台恢复页签/目标行，删除固定右栏；语义分割和异常热图移除错误的YOLO11名称。
