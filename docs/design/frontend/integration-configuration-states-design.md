## 2. 主路径与参数

关联实例 → 协议配置 → 输入映射 → 结果绑定 → 确认保存 → 已创建且停用 → 详情 → 明确启用。

- 应用/实例显示业务名、发布版本和状态。切换目标会影响映射，人工编辑先确认；ID在技术信息。
- 协议来自实际注册能力；未提供Webhook显示不可用及短原因。扩展不等同默认可用核心驱动。
- ZeroMQ为bind_endpoint、默认图片输入、响应超时、记录和诊断。同步完成后回复，不增加SUB、Topic、队列、等待或重试。
- 本机共享内存连接参数由SDK配置提供，不为每个源设置全局槽位池，不增加32-bit/Base64兼容分支。
- 目录监听为服务端路径、递归、隐藏、过滤、变化类型、最小触发间隔、事件样本。高级项含轮询方式/间隔及权限策略；不混入文件稳定时间。
- 目录轮询独立显示排序、去重、扫描进度、单批、扫描间隔和文件稳定时间。当前去重支持path/file_name/file_name_and_size，示例选择文件名和大小；不能虚构mtime去重。该机制不是物料条码复检管理。
- 输入映射为来源字段、固定值、可选不传。必填不可跳过；重新推断不覆盖人工值；不支持类型必须提示。
- 结果绑定取实例公开输出。下拉收起中性字、选中项品牌色。事件源无同步回包时隐藏回复控件；保存结果仍由Workflow节点负责。
- 预检不执行生产流程。保存后停用，启用是单独动作；不隐式监听/业务调用。

## 3. 状态与防误操作

编辑只允许源停用，后台原子检查配置修订、目标契约和观察状态。冲突比较不强制覆盖；读取最新涉及丢弃本地值时复用未保存确认。修改不能变为删除重建。

启停行内处理中且禁重复点击，以实际观察结果更新。停用不强杀已开始执行。超时/断线为待确认，刷新真实状态，不自动重发。地址占用不自动换端口或重启Runtime；修改前先停用。

满载为容量拒绝，入口仍可运行；不加自动重试或等待队列。诊断计数不当生产物料数，各字段语义独立、缺失显示暂无。

映射错误定位字段；目录按服务进程权限检查，不用浏览器选目录冒充可达。失败保留输入。删除只移除入口配置，保留应用、Runtime和文件；运行中阻止。结果未知先查询存在性。

断线保留旧数据但明确过期，不把缺失显示为未触发。只读可浏览授权信息且不显示修改动作；无查看权限用共享权限页。
