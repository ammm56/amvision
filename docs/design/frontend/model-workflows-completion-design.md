# 模型完整流程补图规格

更新：2026-10-25。继承[页面规划](model-pages-design.md)与[通用要求](prompts/通用要求.md)。本轮47个场景、94张亮暗图已完成逐张内部查看；连同原12组，当前累计59组、118张，待用户审阅。实际文件与哈希以[生成清单](generated/模型/生成清单.json)为准。

当前覆盖训练、转换、导入导出、评估、版本管理的主要操作路径和代表异常。部分能力条件分支仍需专门图稿，见[剩余设计范围](model-design-review.md#8-完整性结论与剩余范围)；不能将59个场景称为全部交互已验收。

## 交互约束

- 完整向导保留前一步填写，提交前确认来源与固定版本；提交结果未知先查询已有任务，不重复提交。
- 权重初始化与断点恢复分开；恢复检查通过才继续原训练状态。取消中不是已取消，失败保留真实完成部分与日志。
- 模型包可来自其他项目，导入目标采用本地模型/版本关系；来源版本保留为元数据，同名不表示允许覆盖。
- 删除任务记录保留登记产物；删除版本需无外部引用。停止部署不等于解除引用，清理失败单独处理。
- AP协议与工作点阈值分开；其他任务按各自指标，比较先核对数据、规则和预处理。
- 模态弹层使用一层整屏遮罩，包含左导航；图像对象浮层非模态，照片保持正常亮度。
- 短屏固定底部动作与正文滚动区域分开。117张图实际为1672×941，创建训练-数据暗色为1671×941；均不作为1366×768或1920×1080的像素验收。
- 所有数值为设计样例。曲线、照片及叠加不作为训练或准确率测试证据。

## 通用状态的行为补充

以下是实现时必须遵守的交互规则。已有代表状态可复用，但文字规则不算该分支已单独出图。

| 条件 | 呈现与动作 | 返回与保留 |
| --- | --- | --- |
| 训练数据导出缺失、类别或模型结构不兼容 | 在对应步骤的字段附近说明；下一步禁用；查看数据/资源可用；不在提交后才显示笼统失败 | 保留任务、参数与有效选择，修正后重新检查 |
| 权重初始化与恢复不兼容 | 初始化按结构能力检查；resume缺优化器/调度器等必需状态时阻止，允许另建初始化任务 | 不把重训冒称恢复，不自动修改原任务 |
| 转换目标不支持、工具链缺失 | 保留目标选项但不可选并说明；只读环境详情提供证据 | 切换目标时清除不适用字段，保留来源版本 |
| ONNX条件参数 | opset、静态/动态维度、导出器能力及输出检查；不显示TensorRT workspace | 切回其他目标时不提交隐藏的ONNX专属字段 |

| CoreML/ARM NPU条件参数 | 按适配器能力显式目标工具链、输入形状/精度约束；不可用说明具体缺项 | 不因有下拉选项就表示已实现或任意模型均兼容 |
| 模型包导入冲突或中断 | 明确目标模型兼容性与本地新版本；已完成登记不允许重复确认；中断先查询任务 | 保留包名、可读错误和最近检查；重新选包后清除过期检查 |
| 模型包导出生成/失败/失效 | 可下载只在文件完成且存在时启用；失败有阶段、错误与重新生成；不复用旧缓存包 | 固定源版本与选择范围，返回版本详情 |
