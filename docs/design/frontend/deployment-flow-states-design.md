## 2. 操作去向与保留范围

1. 创建检查提交一次后转实例启动状态；结果未知先只读查询。已创建记录不重复创建。
2. 导入检查后转登记中，再区分登记完成与服务启动。登记完成但启动失败保留资源，进入部署诊断。
3. 导出每次新生成；记录列表区分生成结果和文件可用性。已清理不能下载，重新导出重新收集资源。
4. 编辑配置先检查差异，确认影响再停机重启；并发修改保留本地输入，禁止旧版本覆盖新配置。
5. 回退是明确的来源与运行配置变更，需要预检及停机确认。新版本失败不假装旧版仍运行；恢复旧版本是显式新操作。
6. 引用分直接与间接，不能重复统计。删除前同时检查运行状态、在途和引用；仅删除实例不删除模型资产。
7. 设备/后端选项来自目标能力；未安装或平台不匹配说明原因，不静默切后端。运行时参数不包含转换构建参数。
