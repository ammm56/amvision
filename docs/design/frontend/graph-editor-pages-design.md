## 2. 层级与入口

- 左导航“图编辑”表示编排工作；“应用”负责资源列表、发布版本、Runtime与运行界面。两处进入同一个编辑器，不创建另一套流程编辑页。
- 编辑对象为应用草稿：应用 → 草稿图 → 发布版本 → Runtime → Trigger。保存不是发布，发布也不自动切换已运行Runtime。
- 画布占满导航以外空间。名称与编辑位于画布左上局部工具，预览/保存/发布位于右上局部操作。工具之间可看见画布，不形成横贯整个应用的独立顶栏。
- 节点库、属性、预览结果都是可关闭编辑面板。资源选择/危险确认是模态容器；复杂ROI、标定、PIN、规则编辑进入专属工作区，不层层套抽屉。
- ID、节点type、payload/schema、包版本在必要详情展开查看，不常驻页头或每张节点标题。普通正文和操作中文，正式节点名、端口/参数名按Catalog保留英文。

## 3. 共享面板规则

1. 覆盖式面板仅增加显示层；不改变底层画布容器尺寸、节点坐标、相机变换、缩放和平移。打开前后以同一底图核对，不靠“无遮罩”代替此检查。
2. 节点库从画布左侧打开，属性从右侧打开；可分别关闭，背景与导航无遮罩。可以遮住部分节点，但不会为了让所有节点可见而自动适配。用户点击“适配”才调整视野。
3. 首次打开面板可定位其当前对象，但不会自动改写配置或执行。结果选中与编辑选中区分；原图坐标/耗时等只读值使用标签和值，不能画成可编辑输入框。
4. 底部预览结果面板同样覆盖而不挤压画布；内部滚动、可调整高度、可收起。关闭不取消执行。短屏优先只展开一个大面板，另一个可显式切换，不将三面板塞成三窄栏。
5. 启用开关统一品牌绿轨道/白色滑块，禁用与未选用中性样式。任何面板不使用页面蒙灰“伪禁用”。真正模态资源选择统一整屏遮罩及焦点约束。
6. 适配全部节点按扣除覆盖面板后的可见区域计算；只有用户显式触发适配才改变变换。面板开关不会暗中改变适配状态。
7. 面板与画布局部操作避让：顶部预览/保存/发布和右下缩放保持可达。库列表与属性正文各自滚动，不通过缩小字体或扩大到遮住工具来容纳长内容。

上述规则同步用于推理短屏抽屉修订；真实零位移、键盘焦点和缩放另需Vue原型验证。

## 4. 完整页面和状态规划

以下为目标设计清单，状态数不等于图片数。同构错误复用明确容器与恢复动作；有结构差异的场景单独亮暗出图。

| 批次 | 页面/容器 | 必需状态与操作 | 本批范围 |
| --- | --- | --- | --- |
| A 母版 | 空图、已有流程、节点库、属性面板 | 新建/已保存/未保存、面板开关、无选中/单选、亮暗 | 节点库卡片局部亮暗完成；其他面板待设计 |
| B 基本编排 | 节点搜索与菜单、连线、节点组、多选 | 搜索无结果/包缺失；端口兼容/不兼容/替换；框选、内部边和完整组复制、删除与撤销 | 原稿撤回；先对照当前组操作 |
| B 基本编排 | 普通参数与资源选择 | 固定值/已连输入只读、未设置/null/0/false区分、错误值、资源失效/无权、长名称 | 后续 |
| B 文档编辑 | 输入输出与导入导出 | 公开输入类型/必填/绑定，公开输出和预览内容分开；导入检查、失败保留当前图、冲突处理 | 后续 |

| D 保存发布 | 首次保存、普通保存、发布检查、发布结果 | 校验失败定位、保存失败/冲突、草稿已存但发布失败、依赖失效、只读、离开保护 | 后续 |

| D 应用模式使用 | 多图/值/表格、手动输入、大图、连接与异常 | 按发布快照显示，不隐式执行、不自行统计；保留图片数据身份 | 双图结果亮暗2图；其他状态待补 |
| E 专业节点 | ROI/几何/标定/坐标/规则编辑器 | 编辑与显示分开、应用/取消/恢复默认、缺图/无效标定/缺单位/过期结果 | 后续 |

## 5. 节点字段与画布依据

[节点契约](graph-editor-node-contracts.md)保存Load Local Image、Detection、Detections To Regions、Draw Regions和Image Preview等字段研究。它们只用于核对参数/类型/端口，不能被用作固定五张大卡片的整页布局。

实际工作台使用现有塑盒流程的大小、位置、缩放和分组；不重新排布。端口完整显示，参数控件保持右对齐，长字段按现有规则换行。100% CSS尺寸随画布缩放，禁止直接放大低缩放截图中的节点。

通用与专用节点的范围见[节点库依据](graph-editor-node-library.md)。未来ROI、标定、连接器PIN、异常检测及3D/点云编辑在节点专属工作区规划；不为这些能力另造全局导航或扩大所有普通节点。

## 6. 行为与架构边界

### 连线、色彩和画布工具

- 直接采用现有[图编辑主题](../../../frontend/web-ui/src/shared/styles/tokens/graph.css)：亮色连线#D99018、hover/选中#B87300；暗色连线#F2B84B、hover/选中#FFD166。金色表达数据连接，品牌绿表达主要动作和选择。
- 连线不做避障：单段三次贝塞尔直接连接端口，首尾水平切线，跨节点时在卡片后被遮挡。禁止高拱绕顶、沿底边绕线、直角折线、圆角折线和箭头。
- 节点和属性面板采用中性色；节点组整框为半透明组色，标题条与组面同色相且有间隔。仅当前选中节点强调边框。小复选框选中保留品牌绿，普通标签和数值保持中性文字。
- [现有视图工具](../../../frontend/web-ui/src/workflows/workflow-editor/components/WorkflowGraphViewportControls.vue)统一紧凑浮条：缩小放大镜 → 百分比（重置视图） → 放大放大镜 → 分隔 → 四角适配 → 折页地图。小地图不能画成实心方框或新开关。属性面板不能遮住工具。

### 执行与显示

- 目标设计包含通用撤销/重做、节点库检索和未保存保护等完整体验；当前编辑器文档注明未实现的能力记录为开发差距，不因此删除目标UI，也不能声称已实现。撤销不回滚已经发生的磁盘写入或外部副作用。
- Preview按编辑快照异步执行并逐节点更新；模型节点调用已部署服务，不自行加载模型。显示JPEG不回流算法，临时数据不隐式落盘。文件保存节点的副作用应按节点明确配置，不能由关闭预览代替回滚。
- Runtime/Trigger保持同步高性能调用边界；UI不增加排队、自动重试或依赖浏览器确认才返回的逻辑。Runtime监视不复制Preview逐节点实时语义。
- 参数变更使已有结果标为“来自上次预览”，旧结果不可冒充当前；新请求/切图需阻止过期响应覆盖。长图仅渲染可见节点、结果缓存有界、关闭查看器释放资源。
- 图编辑不直接管理硬件；连接器和3D能力沿自定义节点包。标定、模板、坐标和单位来自正式资源，精度由后台输出及实物验收，不由图片小数位证明。
- Vue 3与本地离线分发保持不变；原型、前后端契约和性能验收独立于静态图。

## 7. 实施顺序与验收

共享规则与首批中文规格 → 推理覆盖抽屉纠正 → A组亮暗母版逐张核对 → B编排 → C预览 → D保存发布/应用模式配置 → E专业编辑器 → F跨状态收尾。

每张检查：正确导航/无独立顶栏、可关面板/无重排、节点与连线类型、参数可编辑性、状态/数据一致、亮暗组件与图片原色、可见主要操作。每批更新生成清单、文件哈希、中文提示词和设计总览，仅保留同名有效稿，不改bak1。实际响应式、连线、快捷键和长时间资源释放仍需实现后验证。
