# ADR-0013：Workflow 多节点选择与复制

- 状态：已实现；自动化与真实流程验证范围见实施验收文档。
- 日期：2026-09-21。
- 范围：Vue 3 Workflow App 图编辑器。

## 背景

当前编辑器使用单节点选择状态，剪贴板只保存一个节点，不包含连线；拖动节点也会切换为单选。复杂编排需要复用一段包含参数、节点和内部连线的流程，逐个复制后重新连线容易遗漏关系。

本决策固定多节点选择和复制的边界。当前行为见[编辑器说明](../architecture/workflows/editor.md)，实施与验收证据在[多节点复制实施方案](../development/workflow-multi-node-copy.md)维护。

## 决策

- Ctrl＋左键拖动画布或节点组空白区域框选节点；Ctrl＋点击节点增减选择。普通左键拖动画布继续平移。
- 框选以节点完整落入矩形为准；多选不等于创建节点组。拖动已选节点标题栏时整体移动并保持相对位置。
- Ctrl+C 保存选中节点、完整框选且成员全部选中的节点组，以及两端都被选中的连线；Ctrl+V 为整段内容生成新 ID，保留参数、启用状态、端口关系和相对位置。
- 复制是当前编辑文档内的内存快照，不使用系统剪贴板，不提供跨文档或跨浏览器复制；文本控件保留原生复制粘贴。
- 外部连线、公开输入输出绑定、应用模式布局、说明便签和执行结果不自动复制。片段缺少外部输入时明确校验，不自动连接原节点或补齐依赖。
- 完整组保留名称、颜色、尺寸和配置，组 ID 与成员 ID 重映射；部分组不自动补选，便签不复制。粘贴新组直接采用片段成员，重叠位置不关联原图节点；整体移动完成后保留仍在原组中的成员，避免重叠组抢占。
- 粘贴先完整准备和检查，再一次性修改编辑图；默认选中新副本，支持整体移动和批量删除。
- 复制、粘贴和移动只影响编辑草稿，不触发节点执行、自动保存、发布或 Runtime 切版。

## 未采用方案

- 只增加框选外观：不能解决内部连线丢失和拖动退回单选的问题。
- 自动复制全部上下游：扩大选择范围，可能复制模型调用、文件写入等非预期节点。
- 粘贴后连接回原图：形成隐藏依赖，破坏片段复用的明确边界。
- 自动复制应用接口与显示布局：容易产生重复绑定、重复显示或改变外部调用契约。
- 借本次功能增加通用 Ctrl+Z 撤销系统：当前版本管理不等于编辑撤销；完整撤销栈另行设计，本次不承诺该能力。

## 影响

复用现有 Vue 3 图数据、Catalog、连线规则、文档校验和保存接口，不增加前端框架、服务或外网依赖。持久化继续使用现有 v1 Template 节点与连线结构，无数据库迁移和公开 API 变更。

Preview、Runtime、Trigger、模型推理与 LocalBuffer 数据面不属于修改范围。复制模型节点仅复制部署引用等配置，不复制或加载模型；复制文件节点保留其路径配置，实际执行仍具有原有写入语义，不能误认为副本自动获得新的输出路径。
