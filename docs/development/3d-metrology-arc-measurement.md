# B10 圆弧量值设计与实施步骤

## 1. 当前进度与目标

2026-11-12 在 `43594cd6` 基点完成 B10 实施。源码包为 `0.1.32`、28 个节点；连续开弧、支持角区并集、圆与量值保存读取、公开节点、参数与证据联动、双平台完整样本发布均已接通。实测结果及本轮未覆盖范围见第 12 节；第 2 节保留开工时的复用分析，第 9–10 节是验证设计，不等于全部组合已逐一执行。

B10 的目标是在已有拟合圆及完整有序支持上，交付端点、方向、扫角和弧长，而不是再次拟圆或将部分扫描解释为完整实体轮廓。原工件 111 节点、317 条边、50 项结果配方不替换；S1/S2 作为新增圆弧方法的完整样本对照，不恢复旧 S2 稳定性阻塞项。

本轮已确认：

1. 两种显式方法：连续、角度单调的单条实测开弧；一个或多个片段的实测支持角区并集。后者没有虚构的整体起终点或统一方向，不自动切换方法。
2. 主量值为已有圆上的模型弧长 `radius × angle`。实测支持折线长度、支持端点另存证据，圆上的径向投影端点是构造点，不冒充采集点。

不修改模型拟合损失、权重、残差限值、邻接条件和生产运行预算；不新增几何依赖。当前样本 float32 保存/传递、角度和累计长度局部 float64 计算，外部精度保留边界不变。

## 3. 节点与接线

已注册 `custom.metrology3d.measure-arc`，名称 Measure Arc / 圆弧测量，归现有 measurement 类别，节点数 27 → 28。沿既有节点包显式启用与预算配置，不新增生产阈值。

- 输入：沿 Measure Hole 使用 `features3d.v1` 多值端口，以 `feature_id` 精确选择一个 CircleFeature；重复 ID、错类型、跨 Run/observation/坐标/单位、失效引用按输入错误拒绝。
- 输出：`measurements: numeric-table.v1`、`evidence: measurement-evidence3d.v1`。方向及端点来源等结构放类型化证据，不用数字编码伪装方向。
- 不再接原云重新检索圆、不提供第二份拟合半径/中心/损失参数、不隐式裁剪和重拟合。
- 评价面直接继承选中圆的已解析 U/V/N；不按屏幕方向、世界 Z 或当前查看器朝向猜顺逆时针。
- 三维契约仍为 v1；同批更新所有受影响读取方，不修改与三维无关的平台协议及生产摆盘机语义。

标准图：Read/输入 → 原预处理与 Extract Boundary → Fit Circle → Measure Arc → 原数值/三态/结果输出；Cloud Preview 接原云、圆 features 和圆弧 evidence。显式保存时 Fit Circle.cloud 与 features 接 Save Cloud，B10 evidence 可一并保存；Read Cloud 恢复同一圆及证据后，可重新测量而不拟圆。

## 5. 几何与缺口规则

### 5.1 坐标、端点与来源

取同次 CircleGeometry 中心 C、半径 r 及评价面列向量 U/V/N。对支持点 p，角度使用 `atan2((p-C)·V, (p-C)·U)`，圆上构造点为 `C + r*(cos(theta)*U + sin(theta)*V)`。核对 N 与圆法向一致，不重新建立评价面。

每个连续开段的支持端点是原有序拓扑的首末点，不是残差最小点、最左点、最近显示点或拟合器推测的实体端点。证据同时保留支持 XYZ 和圆上投影 XYZ，以及面外/径向偏差。

- 原始/有序源点：沿既有 source_indices 给出最初行号，source_point_count 不改变。
- 生成截线点：保留生成顶点身份、源边/面和插值关系；不能写成原始采集点。可见包络估计支持继续遵守既有 Fit Circle 拒绝边界。
- 圆上投影端点：标记为圆模型构造几何，指向对应支持端点；不分配伪造原始行号，也不注册新点云 owner。
- 点投影到圆心导致角度无定义时返回无效；不选任意角度。
- 首末点仅是当前所选支持的端点，不声明它们就是实体边的设计终点。

### 5.2 连续开弧

只沿已声明的相邻边分析最短有符号转角，复用原角步校验 `max_arc_step < pi`。每条边必须保有真实拓扑支持；0/2π 分支切换不是断口。

1. 角度有符号累加产生 sweep，不取首尾角度模差，不自动选短弧或长弧。例如 350° → 10° 的正向采样为 +20°，不是 -340°。
2. 正方向按 U→V、关于 +N 的右手规则定义；从 +N 一侧朝评价面观察为逆时针。摄像机旋转不改变方向。
3. 显式反序交换端点，方向及 signed_sweep 反号；绝对扫角、模型弧长、弦长和支持折线长度不变。
4. `model_arc_length = r * abs(sweep)`；`chord_length = 2*r*sin(abs(sweep)/2)`，也校对两投影端点的欧氏距离。
5. 仅允许一次、非零、单调开弧。真实角回折、超过一周、内部拓扑断开、不足支持或过大角步返回明确无效；不得自动切成成功小段来输出有效整弧。
6. 数值零转角沿原共享浮点判别处理，不引入“忽略小回折”的工程容差。相邻重复点导致零长度边时返回 `degenerate_arc_edge`，不靠删点通过；整段只有零转角仍无效。
7. 稳健圆不自动失效：使用原支持逐边核对；单调且其覆盖与原 pieces 一致时可量值化。稳健圆有效不代表每个支持段都是连续单调弧。

### 5.3 支持角区并集

复用现有逐边角区和 merge_spans。每个已选片段先独立保留来源，再按同一圆上的角区求并集；不能先把不同片段首尾连接。

- `coverage_angle = measure(union(spans))`，取值在 0 到 2π 内；`model_supported_length = r * coverage_angle`。
- 重叠角区只计一次，保留重叠角度及所有贡献片段身份。片段顺序置换不改变总量。
- 片段可以顺向、反向、混合或局部回折；并集量只声明覆盖，不声明方向。逐段保存可判定的方向状态及回折诊断，整体方向和端点缺省，不编造统一方向。
- 不能以包围弧、两个最远端点、占用扇区数或最大覆盖片段代替实测并集。稳健拟合的内点角区只是质量证据，不静默剔除其他候选后计算较好量值。
- 几何角区并集连接不等于点云拓扑连接。两个片段端角相接仍保留各自 ID，不补一条跨片段边；360° 角覆盖也不能证明实体是闭孔或拓扑已闭合。
- 按原有合并比较规则，不增加合并小缺口的阈值，不用预览采样角区替换完整支持。

### 5.4 缺口、闭圆和全周

| 情况 | 明确处理 |
| --- | --- |
| 一段跨 0/2π | 连续法保留展开扫角；持久规范角区按既有规则拆两块，但不新增拓扑缺口 |
| 两片段之间无相邻边 | 不计跨段长度、不画连接实线。保留来源断开，不推断缺材料还是缺扫描 |
| 整圆补集 | 名称为“全周未观测角区”，不是默认“工件缺陷”或“圆弧内部缺口” |
| 配方已有显式目标角域 | 复用原稳健拟圆目标域及 target_gap，显示“该目标域内未覆盖”。原目标域绑定其原定义中心，不擅自换成拟合中心；若以后需要另一中心的目标域，另作显式规格 |
| 未定义目标域 | 不猜应有角范围，不输出目标内覆盖率或把开弧外侧全周补集视为测量失败 |
| 真正闭合且单周的拓扑 | 连续开弧方法明确拒绝；使用支持角区法报告完整覆盖与圆周长。没有唯一物理起终点，数组首点只是存储接缝 |
| 开段端点接近、覆盖近一周 | 不自动标 closed，不补末点到首点；按实际边及覆盖报告 |
| 对径跳变、重复绕圈 | 沿原角步/拓扑判别拒绝方向不唯一的边或不合法单弧；不放宽到 π，不用 unwrap 猜连接 |

实测支持折线长度按原三维相邻点距离累加，仅拓扑 closed 才计闭合边。并集模式保存各片段折线长度及其总和，明确它可能包含重复覆盖，不称去重实体弧长。投影模型弧长和原三维折线长度因噪声、离散和面外残差不同，不强制相等。

## 6. 结果、有效性与所有读取方

复用 MeasurementEvidence3d 增加 `measure-arc` 分支；证据包含 CircleSnapshot、DimensionSupport、方法/参数摘要、评价面、选中稳定 ID、逐段端点/来源、角区及拓扑断开、模型量值、折线诊断与原质量结果。不新增独立 ArcFeature 圆模型或资源服务；圆弧几何作为该量值证据的类型化组成。

- 原圆无效、原质量不达标或支持不可用：原原因传播；所有已配置量值保留 ID，value 为 null，不能只返回成功项。
- 输入身份/契约损坏、未知 ID、重复 ID、方法输出不匹配：输入错误，不伪装正常缺测。
- 连续法回折/闭环/多段：方法条件不满足，几何无效，不自动改为并集法。
- 并集法只有方向不唯一不导致其覆盖量无效，因为该方法不承诺方向；其他质量失败仍完整传播。
- 同一测量调用中不按输出类型跳过坏支持；上游原圆的质量必须整体可用，不靠选子段“救活”无效圆。
- 产品 OK/NG/INVALID 仍由既有 Check Limits/Result Record 根据显式产品限值判定。几何有效不等于产品合格。

同批检查并更新：dimension 参数/证据分发、MeasurementEvidence3d、NumericTable 转换、Preview、历史结果/文件记录/API、前端 measurement-display/dimension-display/MeasurementSummary/geometry-overlay、参数编辑目录、A10 配方资源依赖、发布契约指纹。Trigger/SDK 若只透传现有 numeric-table/结果结构则不新增协议分支，但必须增加端到端断言；遇到显式种类白名单则同步更新。核心平台与摆盘机已发布语义不借 B10 修改。

## 7. 保存读取与资源生命周期

### 7.1 两条保存路径

1. **结果保存**：复用原 Result Record 和结果文件/数据库输出，保存量值、圆快照、有限端点/角区/质量证据。默认不保留完整原云；结果可以查看，但原支持不存在时不能伪称可重新精确测量。
2. **显式可复算资产**：在原点云资产增加可选拟合特征/圆弧测量证据，复用 CircleSnapshot 与 MeasurementEvidence3d，支持数组和来源仍走原 blobs。Fit Circle.cloud 输出其现有只读 support；Save Cloud 接同一 cloud/features，并可接 B10 evidence。Read Cloud 恢复云、CircleFeature 和 evidence，无重新拟圆；测量重算另行显式调用 Measure Arc。

保存首批范围是同一支持云、一个拟合圆及引用该圆的 B10 量值，不顺带建立任意异构特征集合资产。当前边界保存保持原行为；不适用的多云/多模型组合明确拒绝，不悄悄漏存。无效圆及失败量值若有真实 ready 支持则保存其失败快照；不可用云仅能保存有限结果，不能创建伪造可复算资产。

CircleSnapshot 当前位于尺寸证据模块。接入资产时先核对依赖方向；需要共用时将同一快照及校验提取到既有契约层的独立模块，更新全部导入，不复制两个模型，也不形成资产、运行引用、尺寸证据之间的循环导入。

### 7.2 完整性要求

- 校验所选支持的内容摘要、原始总点数、source/generated 身份、拓扑、评价面、圆模型、原 solver/权重/质量与 interval 一致性。父边界摘要与当前选中支持摘要分别保留，不错误要求二者相等。
- 资产不得保存运行中的 owner、Run 访问权限或浏览器能力令牌；读取按现有 Scope 重新绑定观测身份和嵌套质量，参数/模型/实测来源不变。
- 圆模型端点、扫角、弧长的代数一致性在读取时复核；角区与存储拓扑/实际支持的关系沿共享角分析复核，不能只改摘要即可伪造量值。此核对不调用拟圆优化器。
- 原始字段和精度完整保留，生成来源沿原追溯布局保存。模型投影端点不进入点云数组，不产生额外原始行号。
- 成员/字段缺失、额外成员、长度/摘要/类型错误、伪造闭合/方向、跨观测引用拒绝；失败回滚沿既有资产提交事务。
- A10 依赖闭包和引用映射随同更新，空库导入后恢复为新资源引用；不依赖源机器临时目录或原 Run。

### 7.3 预算与释放

只借用 CircleFeature 的所选支持，按现有块处理并检查取消，不扫描完整 14,745,099 点去重新找圆。复用角区合并，成员和证据输出受现有工作/显示预算限制；不能静默截断角区、返回不完整总量或先只算成功部分。

每片段及块边界取消检查；借用、临时角数组、排序数组和显示叠加释放沿原 Scope/前端 disposer。最大片段/角区边界与现有契约一起审计，不擅自新增生产容量。超预算明确失败；超显示预算保留计算结果并标明证据不可显示。保存取消/磁盘失败不得留下半资产，卸载/切换不能保留旧圆端点。

## 8. 前端操作与显示

复用现有参数工作区和三维查看器，不改应用列表、节点分类或平台管理页面。

1. 从连线选“拟合圆”，显示其有效性、半径、评价面与支持类型；选择“连续开弧 / 支持角区”，再选择稳定片段或片段组。无本次 Preview 时允许配置来源，但不能显示旧 Run 数值。
