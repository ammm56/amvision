## 3. 已确认的测量定义

| 问题 | 已确认规则 | 约束原因 |
| --- | --- | --- |
| 点的来源 | 当前云原始行号、已有圆心、当前坐标中的配方指定点，三种显式来源；分别标为实测、拟合构造、指定坐标。生成点拾取单独定义 | 指定坐标和圆心不是采集点，不能伪造 source_index；当前没有独立 PointFeature |
| 有限支持 | 先求模型最近点/垂足，再检查真实支持；越界、缺口或无覆盖返回无效，不自动夹到端点。无限模型为独立显式模式 | 与“计算到有限集合的最近距离”不同，例如垂足越界后改测端点会改变数值及含义 |
| 角度方向 | 无向 0–90°、有向向量 0–180°；只有显式评价面投影提供绕 +N 的有符号角 −180–180° | 三维两向量没有天然的正负转角，不能由屏幕或任意叉积决定 |

三项规则均由本轮确认答复定稿，未改变已有有限支持规则。生产邻域、条件数与质量阈值仍由配方明确提供，测试数值不写入节点默认值。

## 4. 参数与计算设计

参数在 `relation3d_parameters.py` 实现，节点为 `custom.metrology3d.measure-relation`；持久化与公开链路见第 9 节。

| 字段 | 规则 |
| --- | --- |
| `space` | `spatial` 指定 frame_id/length_unit；`projection` 指定现有评价面及 min_direction_norm |
| `relation.reference/target` | 稳定角色；源点为 source_index，圆心/线/面为 feature_id，指定点为 position |
| `relation.kind` | point-point、point-line、point-plane、line-line、line-angle、plane-angle |
| `support_mode` | finite 或 model，仅用于点线、点面、线线；没有自动切换 |
| `coverage` | 仅有限点面测量填写：support_radius、min_support_count、max_triangle_edge、max_plane_residual；无限模型必须为 null |
| `min_crossing_sine` | 线线显式病态条件；数值平行与非平行病态分别处理 |
| `value_mode` | 点面 absolute/signed；signed 正号取目标平面正法向 |
| `angle_mode` | unoriented/oriented/signed；signed 只允许显式评价面投影 |
| `item_id/quality_policy` | 固定输出身份；geometry_usable 必须要求 1；比较复用现有 Check Limits |

点面垂距当前明确为三维空间方法，不把一般平面投影后的二维区域冒充直线；投影方法覆盖点点、点线、线线和线/面法向夹角。角度协议单位为 rad，页面显示转换不得改变存储值。角度没有最近点对，禁止配置 contacts_unique 条件。

1. 输入 A/B 分别声明来源和角色；线/面/圆按稳定 feature_id 选择。同一调用要求运行、观测、坐标与长度单位一致。点云原始点必须校验原始总数与在当前支持中真实存在；不可用或重复身份明确处理，不擅自取第一点。
2. 方法明确选择点点、点线、点面、线线、线角度、面角度。不提供隐式“自动识别关系”或失败后切换算法。圆心到线解析为已有圆的中心与既有线模型。
3. 空间模式使用当前三维坐标；投影模式必须提供明确评价面 U/V/N，不能继承当前摄像机方向。投影后的模型、原三维模型及构造落点分开记录；线/法向投影退化不能换成空间测量。
4. 点点、点线、线线输出非负最短距离，不新增定向分量方法。点面法向符号来自选中平面的正法向；投影有符号角绕评价面 +N，反向共线规范为 +pi。既有沿查询线求交方法保持不变。
5. 有限线按各段区间保留缺口；平面覆盖复用原局部实测支持机制，邻域/残差质量由显式配方提供。无限模型只表示对有效拟合模型的数学评价，不声明该落点存在实测表面，也不降低原特征质量。
6. 平行/重合两线先核对实际区间是否存在模型最近点对。无支持对返回无效；多个落点或连续重叠保留数值与不唯一标识，不任取端点；恰好只有一个共同参数时输出唯一构造落点。多个段组合计入运行工作预算，不构建无限大小的配对证据。
7. 所有输出具有固定 item_id、单位、valid、value、reason。合法零距离/零夹角不误判缺测；无效输出保留 ID 和 null，不仅返回成功项。产品三态仍由现有 Check Limits 负责。

### 4.1 失败分类

| 类别 | 处理 |
| --- | --- |
| 错 ID、错类型、重复 ID、跨 Run/观测/坐标/单位、失效权限、参数组合非法 | 输入错误，不能伪装成正常缺测 |
| 上游拟合无效或质量失败 | 沿用原原因与失败对象，不重新拟合或改用另一特征 |
| 零方向、投影退化、病态最近点计算 | 几何无效，保留诊断，不填零或沿用上次结果 |
| 支持域外、片段缺口、平面支持不足 | 按已确认有限模式返回无效；不扩大支持或夹到端点 |
| 最短点对不唯一 | 距离可以有效，构造端点为 null，contacts_unique=false；配方要求唯一时质量失败。角度的该指标不适用 |
| 预算不足、取消、存储失败 | 执行失败/取消，沿现有 Scope 和原子保存回滚，不改为几何 NG |

## 5. 来源、保存与前端

### 5.1 两种保存不能混淆

- 结果证据沿既有 MeasurementEvidence3d/结果记录保存模型快照、参数摘要、A/B 来源和质量、单位、构造落点、失败定位；不包含运行 owner、令牌或临时路径。历史可查看不等于可以重新测量。
- 可复算保存必须包含每个参与对象的完整真实支持、拓扑和源身份，而非仅保留几何系数。A/B 可能属于同一观测的不同子集；需要在现有资产内容与引用机制内明确成员映射、去重、重新绑定和事务回滚。B10 同云单圆路径不能被当作已具备异构双支持能力。
- 先核对既有资产写入/依赖闭包的最小扩展，再决定参数和端口。不得隐式合并两个支持导致原始行号或缺口丢失；不得新建平行资源系统。读取校验支持摘要、模型和量值一致性，不再次拟合。完整复算保存路径未通过时不宣称 B13 保存读取完成。

### 5.2 页面操作

复用尺寸参数工作区：先选关系类型，再选 A/B 对象与空间/投影模式；显示实际方法可用的符号/角度/支持选项，不保留隐藏的不适用参数。显示点选只填写候选身份，正式测量沿完整输入显式 Preview 重算。

查看器同时区分原支持、模型线/面、投影/垂足构造点和尺寸线；缺口与无限模型不画成实测连接。对象列表、结果项和三维高亮沿现有共享选择状态。切换方法/对象/Run 时旧草稿和异步晚返回不能串入新结果；保存重开必须恢复同一方法定义，而不是只恢复标签。

### 8.2 保存边界审计

当前 save_cloud 只提交一个完整云资产，特征附件接受同支持边界/圆，圆弧附件依赖该圆。当前 register_asset 为每次独立读取创建新的 observation_id。因此把 A/B 分别保存、分别读取，再强行改成相同观测 ID，会绕开运行来源边界；不能作为 B13 完整恢复方案。

后续扩展必须同时完成：

1. 复用既有资产写入和依赖闭包，明确当前主云与 A/B 完整支持的成员映射及去重。不将 bounds、模型系数或证据 JSON 当作完整点支持。
