## 验证中发现的问题

- .NET 首版测试夹具用隐式 null 构造 JValue，内部 token 类型与实际 JSON null 不同，导致 DeepEquals 失败但序列化文本相同。修正夹具为 JValue.CreateNull，未修改 SDK 来迁就夹具。
- PLC 首次审计发现“先解析后逐项编码”仍可能在前一字段写入后才发现后一字段 null/越界。已改为连接前全部使用正式编码器预检，增加后字段错误/两个 continue_on_error 分支回归；网络故障继续策略另用真实写操作异常测试，不能用配置错误冒充网络错误。
- 初版 Windows 组合为 242 通过、1 失败：返回本次显示帧后，TestClient 上下文发送 disconnect 随即取消服务协程，出现 concurrent.futures.CancelledError。改为等待服务端 close 后再退出测试上下文，明确断言订阅集合为空且捕获信号清除；未吞异常、加 sleep 或放宽超时。随后定向 4 项、最终组合 245 项与 Ubuntu 2 项通过。这个关闭握手问题不改变 A02 的 Preview 启动窗口结论，也不能将一次测试异常推断为生产 worker 泄漏。
