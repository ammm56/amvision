# 完整离线部署包：后续考虑

状态：暂缓。此前将模型、部署、Workflow 发布版本、Runtime 和 Trigger 一起迁移的方案不作为当前实施要求，也不冻结包格式、接口或通用迁移框架。

当前优先工作是 [模型部署实例导出与导入](model-deployment-import-export.md)。先完成单个部署实例及必要模型文件的独立交付，并逐阶段测试、验证。

当前跨机器使用流程：

1. 导出、导入模型部署实例，确认目标机器能够正常推理。
2. 使用现有 [Workflow JSON 导出与导入](../design/frontend/workflow-document-import-export.md) 载入流程，核对模型和部署引用，保存、发布。
3. 根据源机器参数，使用现有页面创建 Runtime 和 Trigger，测试调用。

模型部署实例的文件格式不要求现在兼容一个尚未定义的完整部署包；实现也不提前引入 Workflow 依赖收集、版本迁移、Trigger 地址映射或跨系统统一启停协调。

只有上述独立能力稳定、实际使用仍有明确重复操作时，再评估完整部署包、Runtime/Trigger 配置导入导出、现场原位升级或在线发送。后续设计应复用已经验收的能力，另行明确范围和门禁，不以一次完成全链迁移为当前目标。
