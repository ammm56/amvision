# B09 实体边与扫描缺口区分

## 1. 当前状态和目标

2026-11-12 最新实施：高度/法向实测边与采样诊断内核已有，三类必要证据已接入现有点云资产。第 17 节记录采样与受控依赖，第 18 节记录高度/法向完整证据存读；三种公开方法、前端与真实发布仍待接通。第 14–16 节保留历史状态，不作为当前缺口清单。

2026-11-07 核对基点 `0b774320`。源码节点包 `0.1.31`、27 个公开节点。B08 已交付。B09 已实现内部高度/法向候选、显式双侧 ROI、A/B 实测互近邻、连续链、目标级选择及逐段/逐组质量。法向实测连续边见第 14 节；受控 Open3D 双平台原生修复及候选验证已完成，见第 15 节。采样诊断、公开特征存读、节点/页面及真实发布仍待接通，不能据此宣称 B09 已交付。

目标是在已有 Extract Boundary 中增加明确的几何突变与采样边界方法，使后续拟线、拟圆和尺寸节点不会把缺测轮廓当成真实材料边。当前完整工件仍使用原 111 节点、317 边、50 项配方，不自动替换其包络或部分弧方法。十秒节拍、实体计量证据和下一离线装配均不作为 B09 开工前置。

必须分开三件事：

1. **观测事实**：双侧高度跃变、双侧法向变化、单侧没有支持、输入无效记录、裁剪边界。
2. **几何可用性**：支持、连续性、定位分辨率及质量规则是否允许该目标用于拟合和测量。
3. **物理原因**：材料边、遮挡、扫描漏测或未知。单份散点中的空白不能唯一证明原因；即使轮廓闭合，也不能自动称为孔或崩边。

原始记录标为无效，只证明该记录没有有效测量，不证明传感器故障或材料缺失。既无采集掩码又无第二视角的 PLY，在相同缺点布局下无法区分真实孔与漏扫；必须保留未知，不靠改阈值制造结论。这是结果语义，不阻塞其他可判定边的提取。

## 3. 算法和输入方法

以下为拟实施的方法范围，字段名在契约落地时统一确认；不增加新的节点 ID，不自动在方法之间回退。首个实现顺序为高度跃变，再法向折边，最后采样边界诊断。三者完成前不宣称 B09 全范围交付。

### 3.1 高度跃变：先服务当前工件

推荐接线：完整云 → 明确 ROI/本次基准 → 已有 Cloud to Height Map → Extract Boundary。高度图与 cloud 必须是同次、同一输入引用，不允许“点数相同即可”。方法继承高度图实际评价空间，不能另填不同的 Pose 或重复聚合网格。

1. 使用 B08 的完整格数组和成员偏移。按显式邻接方式枚举有数据格对，使用物理步距而不是图像颜色或显示像素计算候选高度差；每对只计算一次，遍历顺序确定。
2. 有效/空格邻接只形成缺支持诊断，不与有效/有效跃变混用。格外、ROI 截断、已知无效观测与原因不明分别记录；禁止跨空格找一个远点补成相邻对。
3. 对候选收集显式有限窗口内的**完整原始贡献点**，由配方的 `support_a`、`support_b` 两个有限 ROI 指定拟面支持，允许复用既有 ROI 并集。ROI 在输入点云的 frame/unit 中求值，再沿高度图实际评价空间拟面；不按格中线、格边或高度中位数隐式分侧。记录窗口总数、A/B 各点数、未归属数和重叠数；双侧重叠即无效，未归属比例超过显式 `max_unassigned_fraction` 则无效。没有归属的点仍在诊断中，不把剔除后的低残差当完整数据通过。复用已有 QR/SVD 拟面和退化检查，两侧及合并单面残差只是支持模型检查，尚不能直接证明实体边位置。
4. 单一斜面若能在质量条件内由同一局部面解释，不按大梯度报台阶；噪声、稀疏、重叠层或窗口无法满足局部模型时给出明确无效/不确定原因。格内最大最小差本身不能证明多层，也不能自动挑一层。
5. 边位置采用明确的高侧或低侧**实测邻边点**，保留配对的另一侧和支持间距证据，不输出两侧中点作为实测边，不在空格中插值。并列候选若产生不同几何位置，返回选择歧义；同坐标重复记录保留来源。
6. 沿原格邻接与实测连接条件组织候选链，再复用 `order_segments` 和目标 ROI。连接必须同时满足物理间距及候选拓扑，不允许只靠空间近邻跨越缺口、连接两侧或闭合断环。

这是离散支持上的跃变边带，不是自动取得无限精度的材料理论边线。拟线/拟圆继续在实际位置上工作，结果保留边定位尺度；不能把拟合 RMS 当成实体边的位置准确度。B09 不顺便增加台阶尺寸算法，尺寸仍使用现有量测节点。

### 3.2 法向折边：双侧支持的方向变化

输入使用已有 B03 输出，法向必须属于当前点和当前坐标；不复制 Estimate Normals。2026-11-06 已确认：法向差只找候选，双侧拟面也采用显式 A/B 支持 ROI，不自动按法向聚类猜两侧。按显式半径和连接条件查询完整邻域，再复核局部平面、夹角和实际连续支持。无定向法向仅比较 `acos(abs(n1·n2))` 的无符号平面夹角；需要凸/凹或有符号分类时必须有一致定向及评价方向，不能猜符号。

曲面平滑转动、邻域横跨两个不相接表面、法向无效或点密度不足不能直接叫折边。有限窗口的双侧模型无法明确分离时返回不确定；不以邻域截断后的少量点代替完整支持。输出仍为实际采样边带，理论双平面交线属于估计几何，本项不新增该输出，也不冒充 B14 曲率或 B18 缺陷检测。

### 3.3 采样边界诊断：区分缺支持与真实突变

采用已有 Open3D 的切平面邻域边界候选能力，复用 B03 法向和现有有限 ROI/空间索引。候选说明邻域支持有缺口，不直接说明材料原因。来源分类同时参考实际存在的栅格/轮廓观测和裁剪域。

- 原始有效掩码明确无效：`invalid-observation`，不改称传感器漏扫。
- 原采集行表明确缺行：`missing-acquisition-row`；编码器位置仍使用实际值，不能压缩间距。
- 已知裁剪界面：`roi-cut`；已知原采集域外沿：`acquisition-limit`。
- B08 空格或无组织 PLY 的支持空白，无法查明原因：`unknown`。
- 只有在明确标定的观测空间且具备相应支持时，才可附近侧/远侧遮挡证据。B09 首批不增加专门的针孔遮挡求解方法，正交工件高度不得改叫相机深度。该更强物理原因识别不包含在本项承诺中。

该方法的未知边界只用于诊断，不作为实体边传给尺寸节点。若一个目标仅命中这些候选，保持 `valid=false`、无可消费几何；候选摘要和显式调试仍可显示。真实物理外缘若没有足够信息，也诚实保留未知，不自动改用包络或等高线。既有包络等方法继续是可主动选择的独立方法。

### 3.4 依赖核对与算法取舍

仓库已锁定 SciPy 1.18.0、Open3D 0.20.0；不引入 PCL、额外 C/C++ 适配或新的解析器。PCL 仅作为分类概念的源码参考，其有组织边检测分别输出无效边界、遮挡两侧和高曲率标签，而不是将空白一律当材料边，见[官方接口](https://pointclouds.org/documentation/organized__edge__detection_8h_source.html)。不移植其跨无效邻域搜索作为本项目默认连接策略。

[Open3D 0.20.0 源码](https://github.com/isl-org/Open3D/blob/v0.20.0/cpp/open3d/t/geometry/PointCloud.cpp#L734)的 `ComputeBoundaryPoints` 要求法向，使用 radius/max_nn 的 HybridSearch，返回边点及掩码；**没有提供材料边/漏扫原因判定**。其入口会对调用点集建立索引和邻域数组，不能直接对 1474 万点整云调用并忽略预算。

先对显式有限 ROI 验证该原生入口的预算、邻域饱和与取消边界；需要分块时必须带完整半径邻域，按原行号只输出块内点，分块与整体结果逐点等价。达到 max_nn 的邻域需检测是否被截断；截断未核实不能通过质量检查。若现有原生入口不满足预算或停止约束，先报告具体差距，不静默减半径/减点数或复制一套边检测算法。

错误分类保持现有框架：参数不合法、错误端口、身份/单位不一致是输入错误；有效输入上的支持不足、邻域截断、质量失败、目标歧义是几何无效并保留原因；取消、预算不足、底层故障是执行失败，不能包装成正常“未检测到边”。三类都不保留上一次有效几何。物理原因 `unknown` 不是产品 NG，不改变公开 OK/NG/INVALID 的既有汇总方式。

沿 `BoundaryFeature/BoundaryEvidence` 增加仅用于新方法的边证据，三维契约仍为 v1，不加独立结果服务。实现前逐字段锁定以下表及二进制布局；名称可统一，语义不得省略。

| 内容 | 必须保留的身份和语义 |

| 方法快照 | 方法、完整参数/摘要、解析评价面、输入观测身份、输入来源摘要；高度图的网格/聚合及 Pose 证据 |
| 目标结果 | feature_id、segment_id/group_id、观测类别、物理原因及其依据、有效性、失败阶段与原因 |

| 质量 | 双侧计数/覆盖/残差、格距/定位尺度、法向/邻域状态、真实连续范围、被拒原因计数；无值为明确不可用，不用 0 代替 |
| 诊断证据 | 未入选候选和缺支持区域复用 I2；同次 capture 身份，默认关闭、有界，不是新的测量输入 |

选中边仍使用 CloudRuntime 有序只读子集，坐标和其他字段保持输入 dtype；局部拟合按现有内核使用 float64。不生成空白补点，不把两个断片拼成一条连续测量支持。保持每个边点的支持对和连接边来源，不用一个总体分数代替逐段检查。

保存延续现有有效边界保存条件。小型方法/分类/质量证据进入原 `BoundaryEvidence`；规模随候选增加的成员表沿同一资产的受预算二进制块保存，描述符、长度、索引范围和摘要严格校验，不在 JSON 内复制完整两侧点云。选中几何的必要证据不依赖调试是否开启；全部未选候选仅按既有 I2 显示生命周期处理。

未保存的完整原云不因新增证据自动持久化。保存的支持、来源表和指标可追溯当次计算，但再次提取或改变窗口必须重新提供完整源资产；不能从少量边点反算已不存在的两侧完整云。无效目标不绕过 `freeze_boundary` 保存成有效特征，可由已有结果/显示记录保留失败摘要。

重读只校验并重绑当前运行引用，不重算、不补分类。历史 projection/section/contour/envelope 仍是其真实方法，不能被读取器追认成实体边；这是保留合法方法语义，不是旧代码兼容分支。错误或过时格式明确拒绝并要求重建，保留原始数据。A10 搬运沿既有闭包/引用映射，不能写入磁盘绝对路径或运行 ID 作为持久权限。

同批读取方清单：方法/参数/解析校验、质量单位表、handler/Catalog、Runtime、边证据存读、特征联合类型、Fit Line/Fit Circle、尺寸证据的边方法快照、Preview/显示校验、I2 二进制字段、前端表单/摘要/查看器、资产摘要及 A10 包校验、生成节点目录和文档。SDK 继续传原有云/配方/结果，不为三种方法新建传输协议。

## 6. 所有权与预算

完整输入、高度图、法向数组各沿原 owner 借用；候选/索引/成员数组由当前 Scope 登记，失败发布不得留下半个特征。取消、节点超时、切版、客户端异常和关闭 Preview 继续使用现有整组停止及恢复准入。

内存账本至少分为：借用输入与高度图的既有占用、候选邻接对、局部索引/原生邻域、双侧拟面暂存、排序/段表、持久来源块、调试/编码副本。网格枚举按有限邻接是格数线性；邻域数组可能达到 ROI 点数×max_nn，必须按实际 dtype 计入，不能只算 XYZ。Open3D 转换的连续副本和子集索引也不能漏计。

分块只改变临时存储，不改变窗口、参与点数或连接条件。已保留输出和下一块工作集同时计费。调试预算不足只让调试明确不可用；算法预算不足必须拒绝，不能采样后继续测量。生命周期验收既检查 Scope 账本，也检查测试进程树和原生 RSS，不把 Python 对象释放等同全部原生内存归还。

## 12. 实测配对、连续链与法向支持复用

### 12.1 实现范围

- `edge_pairing.py` 用 SciPy 精确 KDTree 查两侧互为唯一面内近邻。相邻两格的全部贡献记录保留；等距、多面归属、未归属、超间隙和非互近邻分别诊断。不合并重复坐标、不取中点、不从 ROI 边缘造点。
