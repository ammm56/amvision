## 3. 通用功能修正设计

### 3.1 可见投影包络：优先补齐现有节点方法

在现有 extract-boundary/measure-extents 体系增加明确的高度场/可见包络方法，不创建钢片专用算法节点。

1. 使用本次 pose 的 U/V/N 与已确认动态高度；局部 ROI 中全部原始支持参与计算。不得把源 XY 当倾斜工件的最终度量平面。
2. 以显式网格原点、步长、聚合统计和有效计数建立局部高度场。原云仍 float32；局部运算按需要 float64。空格为缺测，不默认为零。
3. 区域选择由配方 ROI/种子和物理条件确定，不把“当前最大区域”默认为目标。形态学只能按显式方法参与分区，不制造原始测量点；分区支持与测量支持分别记录。
4. 分别支持可见占据包络与有两侧支持的等高交点。前者允许无低侧邻居，边界注明格分辨率/估计方法；后者仍要求真实插值支持。方法由配方选择，不以失败触发切换。
5. 长宽复用现有评价面、轴向跨度/最小矩形和 NumericTable；新增稳健分位范围时明确分位数、四侧支持长度/点数、离散区间和阈值敏感性，不能将其标成原始极值跨度。
6. 补齐来源表达：源点视图保留原始行号；格聚合、格边界和统计端点记录实际来源/运算，不能伪造为两原始点间的截线顶点。沿现有 CloudRuntime、资产及三维 v1 消费方同批扩展，不另建资源系统。

SciPy 分箱统计、已有 OpenCV/SciPy 区域处理负责成熟基础算法；等高线候选使用 ContourPy 等成熟实现前须核定版本、许可、支持来源及双平台发行，不能使用 Matplotlib 绘图流程作为生产测量内核，也不自写通用轮廓算法。

第一轮按原报告 0.03 mm 网格及明确的包络方法作对照，并检查 0.06 mm、网格相位和高度变化；这些只属于此工件配方/敏感性验证，不成为所有工件默认。输出量值不要求和不同坐标/支持定义的旧报告逐字一致，差值必须解释。

### 3.2 多片段圆弧与直边

- extract-boundary 增加显式“片段集合”选择：使用 ROI、环带/角区或方向规则，保留各片段及缺口。一个集合可以有多段，多个物理候选仍应报歧义，不自动取最长段或连线填洞。
- 稳定身份属于配方目标组；运行段 ID、数量与来源属于本次观测，不要求工程师预知每次产生多少碎片。
- fit-circle/fit-line 复用现有求解入口，按明确方法增加稳健损失及权重；同一圆的实际段联合拟合，不复制拟圆算法到 measure-hole。直边拟合宽和可见包络宽是不同输出。
- 角度覆盖区间、实际占用角区、目标弧域内缺口、整周缺口分别计算，不能混用。本工件 S2 不能机械套用 S1 的覆盖参数。
- 稳健方法同时记录全部候选、实际支持、剔除比例、残差和可辨识性，不能靠删到少数点得到小 RMS。圆心/半径对采样、噪声和删段扰动的稳定性独立验证。
- 圆的缺测部分可以显示为拟合几何虚线，不能宣称实测圆弧；直边测距若仍要求真实站位支持，保留现有站位/缺口规则。

### 3.3 基准应用范围

现有有限延伸算法保留。重新依据本工件五窗台面、查询区域、基准残差和空间分布确定该配方的使用范围，不以“刚好高于两次失败距离”调整 10/30 mm。

先明确台面参考适用的有限工件区域，再检查其覆盖、距离和留一支持区拟面对查询高度的影响，形成该区域的工程范围依据。被测顶面始终保留实测支持。若现有最近支持距离无法表达所需参考定义，再提出明确的基准应用域方法；不能暗中取消延伸上限或改变全平台规则。已有工程参数授权不再转回要求外部逐个填写。

## 4. 计算速度改进

优先顺序是计算热路径，其次文件解码，不先开启无约束并行或更换 GPU 算法。

1. **固定计算计时边界。** 在已有 GraphExecutor/node_records 记录点云就绪时刻、预处理、ROI、拟面、支持查询、边界、尺寸、数值封装，以及显示构建耗时。同机数组路径测完整调用，内存图定位内核；两者不互相冒充。传输、ASCII/二进制读取和显示独立列出。
2. **本次运行内复用。** 在现有 CloudRuntime/Scope 中按不可变云身份、坐标/pose 和必要参数复用包围盒、只读索引和支持摘要；不是跨调用保留原云。按预算登记、按需构建、失败/取消释放，源/pose 改变不得命中旧结果。
3. **局部查询替代反复全扫。** 优先复用成熟空间索引进行 ROI 候选筛选、平面邻域和最近投影支持查询，候选后仍执行现有精确条件。平面坐标的距离语义、相等距离按原始行号选点等规则不变。索引不划算时应依据明确成本策略决定是否构建，不能配置失败后悄悄降级。
4. **ROI 处理。** 同一原云多个 ROI 共享粗索引/预筛；单 ROI 收集改为预算内分块索引拼接或其他经验证的单遍策略，不能在拼接时双倍分配绕过预算。轴对齐框使用数学等价的直接比较，不强制矩阵乘法；旋转框仍走正确变换。
5. **针对数据类型选择方法。** 当前工件是具有扫描结构的高度场；可见包络和扫描线交点不应每次先做全局局部点集 Delaunay。严格散乱表面截线继续保留其算法。不得由显示采样替代全部原始支持。
6. **证据与数值解耦。** 正式测量输出小型数值及必要质量；仅在配置的显示支路构建有界图形，不复制十二份完整台面/平面支持。沿既有 Preview 机制实现，不制造后台等候队列或执行完成后无人持有的点云会话。
7. **最后优化文件读取。** 受控 PLY/PCD 读取器减少逐行位置查询和重复缓冲，继续以成熟 NumPy 解码；保持坏行、截断、字段、精度及尾随数据拒绝。合并摘要计算与读取只有在不可变快照及完整验证语义不变时实施，不通过关闭验证提速。

性能比较必须冻结同一方法、支持、原始行号和结果；新包络方法与旧截线方法分别命名，不能拿计算量不同的任务宣称同算法加速。只做有界、可复现的针对性测量，不重跑模型 P99 或长稳。
