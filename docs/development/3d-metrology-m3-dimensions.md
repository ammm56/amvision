### 3.3 失败分类

- 非法配置、歧义接线、错 run/observation/frame/unit、损坏的支持或伪造质量：沿现有执行错误，不写成正常缺测。
- 配方引用的合法目标本次缺测、有效支持不足、几何退化、交点不受支持或质量不通过：该启用项保留 item_id，`valid=false/value=null/reason` 明确；不得补零、消失或复用上次结果。
- 取消、超时、预算拒绝、原生异常：执行状态保持原语义，不能捕获后返回一个看似正常的无效测量。
- 无效项的有效结果 geometry 为空；可以保留失败阶段、目标/段 ID、已完成的质量和有限诊断。候选几何不得出现在有效尺寸层。
- 代码中的原因标识在严格 DTO 阶段定稿，优先复用已有标识；必须区分目标缺失、质量拒绝、求交病态、支持域外、缺口、退化包络和并列尺寸不一致。

## 4. measure-extents：长宽

### 4.1 参数和计算定义

| 参数 | 轴向跨度 | 最小面积矩形 |
| --- | --- | --- |
| source | cloud 或 boundary 显式二选一；boundary 指定完整选段 | 同左 |
| evaluation | 确定工件 U/V 方向和投影平面 | 确定二维评价空间；矩形方向由算法求得，不由相机决定 |
| mode | `axis-spans` | `minimum-area-rectangle` |
| 输出身份 | U 跨度、V 跨度分别配置，不按数值大小交换标签 | 长边 L、短边 W 分别配置，L >= W；不将求得的方向当固定工件 X/Y |
| 数值条件 | 完整支持有限性、有效二维跨度/退化检查 | 除前项外，显式面积并列比较、尺寸一致性及等价方向判定条件 |
| quality_policy | 支持数量、投影跨度及所需几何可用性；边界输入保留上游逐段质量 | 另含凸包点数、候选数、并列候选数及尺寸一致性；方向唯一性单独记录 |

最小矩形的数值条件逐项配置：`area_abs_tolerance` 使用长度平方单位、`area_rel_tolerance` 无量纲；候选并列定义为 `A-A_min <= max(area_abs_tolerance, area_rel_tolerance*abs(A_min))`。`dimension_abs_tolerance` 使用长度单位、`dimension_rel_tolerance` 无量纲；候选 L、W 分别按全体最大值减最小值与对应绝对/相对容差核对，不能只比较相邻候选。方向等价使用独立的角度条件。所有条件均记录到方法证据，不取显示小数位数作为判定容差；具体数值留待配方显式提供和独立测试。

有限 ROI 继续由 crop-roi 提供；不在该节点新增一套 ROI。cloud 输入不偷偷提取边界，boundary 输入不偷偷扩大为整个父云。质量检查失败不改选另一输入。

**轴向算法：** 对完整选定支持计算 `u=(x-o)·U`、`v=(x-o)·V`，分块累积 `u_min/u_max/v_min/v_max`，尺寸分别为差值。保留极值对应的源支持身份、三维位置与投影位置，以及四条支撑线；并列接触只提供确定且有界的代表和完整计数，不把全部整云极值点装进 JSON。接触代表变化不影响尺寸定义。

**最小矩形算法：** 对同一完整支持作局部中心化与尺度规范化，调用受控 trimesh 的二维凸包边方向投影/面积比较路径，恢复物理坐标和单位。凸包只用于包络，不输出为真实凹边界。不得替换为 PCA 框、简化轮廓或显示 LOD。

上游 5.1.1 实现构建候选方向与凸包顶点的乘积投影数组，最终只取一个 `argmin`。它不能直接提供本设计要求的所有并列解证据；已经批准局部扩展，不把现有 I/O 修复当作已实现此能力。[固定版本源码](https://github.com/mikedh/trimesh/blob/5.1.1/trimesh/bounds.py)

扩展范围限于该计算路径及必要的结果/控制参数：

1. 保留成熟 ConvexHull 与边方向枚举，不新写另一种包络算法；显式核对 Qhull 参数及退化，不能默认 QJ 扰动后继续。
2. 凸包、局部点数组、候选、投影块、结果数组均计费。投影按现有可用工作预算分块，时间复杂度仍可能为平方级，不能宣称分块后算法变为线性。
3. 第一遍完整求最低面积，第二遍依据同一显式面积比较条件收集并列候选和尺寸范围；不能用不断变动的当前最优值累积产生顺序相关的并列集合。
4. 去掉只差轴符号、重复边方向等同一矩形表示；正方形的等边轴身份不强行唯一化。几何方向等价与“多个真实矩形方向”分别记录。
5. 所有并列候选尺寸在显式一致性容差内时，保留 L/W 并标明方向是否唯一；尺寸不同则量值无效。保留候选总数、L/W 范围和最终可追溯代表，代表选择规则确定，不能将代表说成唯一姿态。
6. 并列集合和阶段内存超预算时明确拒绝，不只检查前若干候选后宣称一致。取消在可分块阶段检查；Qhull 原生调用仍由已有执行器超时/整组停止控制，不宣称可在其内部即时取消。
7. 局部规范化及逆变换覆盖 mm/m、大平移和尺度变化，不修改库全局容差。更新受控补丁说明、wheel 锁与发行装配后独立回归，保留原 PLY 修复验证。

退化输入包括空支持、重合点、共线及不可成立的二维包络。可见缺边通常导致可见跨度缩小，不凭空返回完整工件长度；只有明确的可观测覆盖/质量条件可以拒绝，不能通过算法猜测被遮挡长度。

### 4.2 显示与验证

界面先选择“轴向跨度 / 最小面积包络”，再选择输入与评价面。U/V 或 L/W 输出名称和 ID 分开显示；模式切换需明确重新确认相应输出/限值绑定。预览分层显示原支持、投影支撑线、构造矩形和尺寸线。矩形角是计算构造点，不填写伪造 source_indices；方向歧义有明确状态，不输出 Pose。

独立真值包括已知旋转长方形、正方形、等面积不同形状候选的三角形、凹形、圆角边和细长轮廓；验证固定轴跨度与最小包络不混用。测试点顺序/等价轴反转、mm/m、大平移、float32/float64、缺边、重合/共线、并列比较临界、预算/取消；候选最优性用小规模独立穷举/解析支撑核对，不能用被测函数生成期望值。

## 5. measure-edge-pair：边间距

### 5.1 参数

| 字段组 | 规格 |
| --- | --- |
| 选择 | A 为 reference、B 为 target，两个不同的稳定 line feature_id；按 kind 精确判断，不能因为 CircleFeature 继承关系而接受 circle |
| evaluation | 明确评价平面，与线模型/拟合评价面核对几何共面；同观测和空间 |
| query_position | 评价平面内的明确位置 p；候选拾取后由完整 Preview 重算 |
| direction | 平面内单位方向 v，不默认使用屏幕、法向或两线的公垂线 |
| value_mode | `signed` 或 `absolute` 显式二选一 |
| numerical/quality | 共面条件、与测量方向求交的最小可用角度条件、有限支持及线质量；数值/单位含义明确，数值不预填 |
| output | 一个稳定 item_id；多位置测量沿现有多个节点/配方组合，不新增扫描服务或隐式连续最小间隙算法 |

### 5.2 解析路径与支持检查

1. 解析指定两条有效 LineFeature，复核实际质量和支持，不因存在 geometry 就认为可用；不再次读点重拟合。
2. 将等价共面模型转换到同一评价基。第 i 条线写为 `a_i+s_i*d_i`，测量线为 `p+t_i*v`；解二维方程 `[v,-d_i] [t_i,s_i]^T=a_i-p`。
3. 用显式无量纲角度条件核定求交稳定性；近乎平行时无效，不以无限大距离或另一算法替代。两拟合边重合、评价空间不成立分别给原因。
4. 两侧 `s_i` 必须落在各自现有 `intervals` 的并集内，保留命中的 segment_id。不能用所有段的整体 min/max 代替区间并集，也不能将端点舍入容差用作允许外推的距离。
5. 支持域外或段间缺口内返回无效，沿已确认边界不提供外推开关。位置合法但模型质量不足仍无效。
6. `d=t_B-t_A`，绝对值模式输出 `abs(d)`；证据保留有向差、角色、位置、方向、两个模型交点与实际支持区间。交点是拟合模型在支持范围内的求交，不声称恰为传感器实测点。

非平行边的结果随 p 变化，界面必须保留位置。两条不同且质量成立的边在评价位置相交时几何距离可以为零，不能将零与缺测混淆；是否满足产品间隙要求交给现有限值链。重合的两条边不作为两个独立边缘目标。首批没有失败后自动切到平行最短距离的路径。

### 5.3 显示与验证

原特征列表选择 A/B，视图高亮对应支持；交换图标只交换配置并使旧结果失效。显示 p/v、两交点、有向箭头及读数，线段缺口不连接成实线。标注避让只改变标签位置，不改变 p 或算法端点。

独立解析验证平行边、斜边、楔形边随位置变化、交叉处零值、方向反转/交换变号、绝对值不变；有限端点、缺口、域外、求交病态、重合/错类型、错观测及面外；刚体变换和单位换算等价。先用独立构造的合法 LineFeature 验测距公式，再用 extract-boundary→fit-line→measure-edge-pair 验真实组合，避免拟合误差掩盖测距错误。

## 6. measure-hole：孔径与圆心

**接线已确认。** 直接消费 M3.2 已有 CircleFeature，替代总设计第 4.8 节原有“边界输入”定义。不并行维护便捷内拟合和外部圆特征两种模式。

### 6.1 参数和计算

| 字段组 | 推荐规格 |
| --- | --- |
| selection | 唯一 circle feature_id；保留 fit-circle 实际选段、方法摘要、求解终态及质量 |
| target_kind | `closed-hole` 或 `open-arc`；闭孔要求明确 inner 角色和闭合拓扑，开放弧要求明确开放支持；unknown、混合内外角色或多目标不自动解释为孔 |
| evaluation | 明确输出 frame/unit；如需另一工件坐标系，先沿现有 build-frame/transform-cloud 再拟合，不在本节点隐式转换 |
| outputs | 直径、center_x、center_y、center_z 按需启用，各自稳定 item_id；坐标是该 frame 中的 XYZ，不悄悄混成评价平面 UV |
| display_direction | 显式选评价面方向或给定面内单位方向，确定直径辅助线；与实际支持弧分层，不随相机改变测量定义 |
| quality_policy | 复核上游点数、面外/径向残差、连续角覆盖、最大缺口、Jacobian 可辨识性、求解成功且未碰半径边界；保留测量角色检查 |

仅计算 `diameter=2*r` 和声明坐标中的圆心分量；不再次优化、不自动补全缺弧，也不增加另一套拟合器。已有圆质量不足时，直径/圆心等全部启用项保留并无效；合法零坐标保持有效零。

闭合拓扑及 inner 角色说明配方选中了“孔边目标”，不自动证明孔是真实实体而非缺扫。圆拟合的半径约束和残差不是图纸尺寸公差，也不是标准圆度或圆柱度。开放圆弧可以给明确的拟合圆直径，但名称和证据必须标明圆弧，不能表述为完整闭孔观测。

不得重选该圆的部分段后仍复用旧拟合质量。需要改变支持段时修改上游 fit-circle，再完整 Preview。显示直径两端为 `c±r*w` 的模型构造点，没有实测身份；不受边间距“模型交点必须在线段内”规则误约束，但必须同时显示实际支持弧和角覆盖。

### 6.2 显示与验证

推荐操作顺序为“选择已有圆 → 确认闭孔/圆弧 → 查看支持与质量 → 配置直径/圆心输出”，选择列表来自当前连线和 Preview，不要求现场人员输入内部 ID。多个圆逐一显式选目标，不按当前画面左/右或连通域顺序固定业务身份。

独立圆模型先验 `2r`、坐标、任意姿态和刚体等价，再串真实拟合；覆盖完整孔、半圆槽、短弧/病态、半径边界、不收敛、多圆/混合角色、未知角色、缺目标、法向翻转和显示方向变化。后者只能改变辅助线，不改变直径。样本人工 ROI 圆不是实体孔径真值，不能据此给准确度结论。

| 证据内容 | 长宽 | 边间距 | 孔径/圆心 |
| --- | --- | --- | --- |
| 方法 | source/mode/evaluation、完整参数及摘要 | A/B ID、p/v、符号定义及条件 | 目标圆、角色、原拟合方法/终态、输出坐标及辅助方向 |

| 几何 | 投影支撑范围/构造框、尺寸方向与支撑线；并列最优和方向唯一性 | 两个受支持的模型交点、t/s、命中区间/段 | 圆心/法向/半径、真实支持弧、构造直径方向；圆心量不伪造点对 |

无效项不带可用 geometry，诊断分支保留失败阶段和实际原因。几何构造角/直径端点/模型交点不伪造原始点身份；源点代表可记录最初行号，生成顶点代表记录逻辑顶点及有界来源摘要。生成顶点数量可能超过原始点数，不能复制旧实测支持 `point_count <= source_point_count` 的限制；也不放松实测点的原始行号约束。

历史证据不包含活 CloudReference 或全量来源数组。运行期借用现有支持，稳定追溯沿已有内容摘要/方法引用；有显式保存的资产才携持久 ResourceReference。重复数量项引用同一有限模型证据时须保持一致，不为每个圆心分量复制完整点云。
