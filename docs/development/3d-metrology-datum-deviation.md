## 1. 范围与状态

2026-11-13 已确认首批定义：评价现有有效基准平面到显式目标 ROI 内实测点的有符号法向偏差；输出最小值、最大值、峰谷、均值和 RMS。基准支持采用实测覆盖或有最大距离的有限延伸；完整目标通过才有效。

2026-11-13 当前实现已接通五项统计、正式 Measure Datum Deviation 节点、参数编辑、结果/极值显示，以及显式 Save/Read Cloud。节点包为 0.1.34、30 节点，原工件 50 项配方不变。第 7–10 节保留分批历史；最新使用与验收见第 11 节。正常测量不要求保存整云或开启详细捕获。

- 不重新拟合基准、不自动去趋势、不删离群点、不补洞、不自动选择目标。
- 不把偏差峰谷称为正式平面度，不直接把结果命名为经认证的翘曲量。
- 不开发 CAD、报告或 SPC。十秒、实体精度及新发行独立管理，不阻塞本项。
- 首批目标为保留实测来源的云或显式 ROI 子集；体素质心、插值截线等生成点不能冒称实测表面。刚体变换后的实测点可用，但必须与基准处于同一当前坐标系。

## 4. 算法、支持与失败

对完整目标中的每个点 p，使用已有单位法向 n 和平面 offset：`d = dot(n, p) + offset`，垂足为 `p - d*n`。不通过重新拟合使偏差趋于零。

1. 实测覆盖：垂足须落在原局部三角支持内，并满足原计数、边长、残差规则。保留 RANSAC 原始邻域复核，不能只用筛出的内点掩盖另一层。
2. 有限延伸：先进行相同覆盖检查；未覆盖时，沿原 reference_coverage 定义计算垂足到投影基准实测支持的最近面内距离。距离不大于显式上限才允许延伸；保留原最近点/原行号及平局规则。不是目标到基准的高度，不是到 ROI 包围盒的距离，也不改成新的无限面模式。
3. 完整目标均满足条件，且已有基准/质量可用，五项才输出有效数值。任一点失败，五项均 `valid=false,value=null`；保存完整失败分布，不从成功子集生成有效量值。
4. 诊断统计可以覆盖全部可计算有限点，但明确 `diagnostic_only`、总数和实际参与数；不能填入正式五项，也不能隐去失败点后称全目标结果。
5. min/max 为有符号偏差；峰谷=max-min；均值为逐实测样本等权平均；RMS=`sqrt(mean(d*d))`，不是去均值标准差。非均匀采样不会自动面积加权。法向反转使 min/max 对调取负、均值取负，峰谷和 RMS 不变。
6. 极值保留真实来源。相同数值按原始行号及逻辑行号稳定选择展示代表，记录并列数量；不生成虚假的唯一极值位置。空目标没有数值，零偏差是合法零值。

### 计算与资源约束

目标按块处理，原字段和 float32 存储不改；偏差/累积按需要局部 float64，使用稳定的分块统计并与独立真值核对，不保留每块的重复大数组。

现有 plane_coverage 每查询都会扫描有限支持并创建选中掩码。直接对百万目标点逐次调用会形成重复整云扫描，不能作为 B17 完整实现。应先在原支持模块提取一次性准备/有界查询，再共享原局部三角和残差判定；索引覆盖完整有限基准，不以采样替代。工作索引、邻域列表、三角剖分、输出证据及借用同时计费；预算不够明确拒绝，不提高上限、落入等待队列或静默改算法。

首先对单点原实现与批量实现比较覆盖、失败原因、最近点、三角来源、延伸距离和临界包含关系，再允许用于整批。块内外均检查取消；失败关闭本次新资源，旧资产仍可读。缓存只属于同一 Scope，不沿历史 run_id/云 ID 复用。

## 5. 证据与保存

摘要使用原 MeasurementEvidence3d 集合中的新判别项；五项共同引用一份计算证据，不把每点复制五次。

| 内容 | 必须保留 |
| --- | --- |
| 身份 | 本次 observation、frame、unit、完整目标引用、基准模型及其完整支持、方法参数摘要 |
| 规模 | 目标总数、可计算数、覆盖数、延伸数、失败数和逐原因计数；各分类与完整目标一致 |
| 数值 | 五项共同有效性、正式值或 null、全目标诊断统计、极值来源及并列数 |
| 按需内部诊断 | 显式捕获时记录目标逻辑行/原始行号、法向偏差、支持状态、三角或延伸来源；默认运行仅保留分类计数与极值，不分配全量详细表 |
| 追溯 | 不以坐标相等认定同源；输入/原始字段完整保留，不给生成点伪造原始行号 |

正式结果是有界摘要和五项 NumericTable，不能携带裸路径或运行权限。内部 `capture_details=true` 的类型化表用于诊断测试，并不是公开节点默认输出或必须持久化的附件。当前 UI 展示完整分类计数、诊断统计、极值与基准，不宣称已有逐点失败色图。

仅显式连接 Save Cloud 时，验证目标与基准完整支持同一真实根，收集并去重派生链，将原云、成员和有界测量证据通过现有资产提交保存。新 Scope 恢复后按原参数核对五项及摘要，不拟合平面、不重写旧观测。五个输出只触发一次复核，不重复扫描五次。普通交换文件不携带完整证据；可选复算资产沿现有资源包搬运。

显式保存失败/取消不公开半个资产，读取损坏或支持不一致时释放本次新资源；这是既有 Save/Read 行为，不是撤销 Workflow 运行，也不自动保存执行错误的数据。目录、契约和读取方同批更新，沿既有发布准入，不另建发布或迁移框架。

## 8. 全目标统计与逐点证据（2026-11-13）

在第 7 节基础上完成内部参数、逐点计算、五项摘要与二进制一致性检查。复用现有 PlaneFeature、支持查询、质量比较器、OwnedCloudArrays 和 Scope；没有新建资源系统、没有重新拟合基准。**本节不是 B17 资产、公开节点或前端已经交付的声明。**

### 参数与失败定位

- `DeviationParameters` 显式提供基准 ID、frame、unit、支持半径、原实测/有限延伸策略、完整 reference 质量规则，以及五个不同的输出 ID。不允许删除某个量值或关闭必要质量规则。
- 正法向仅来自已选基准；目标和基准检查当前运行、观测、坐标、单位及同一实际原云。不以修改 observation_id 拼接两云，只接受 measured/source 支持，生成点或混合来源不冒充实测点。
- `target_state/target_reason` 保留上游不可用状态；其结果为 `target_unavailable`，与可用但零行的 `empty_target` 分开。基准不可用为 `reference_unavailable`，目标支持失败为 `target_support_failed`。
- 非有限位置或 `validity=0` 的目标仍保留原始行号及失败行，不进入可计算诊断统计；其余支持失败点的偏差仍参与诊断统计。任何失败使正式五项全为无效/null，不把成功子集写成完整结果。
- 统计包括最小/最大、峰谷、逐样本等权均值、未去均值 RMS。使用有界读取与归一化 `fsum`，避免直接平方/同号累加先溢出；无法表示为有限值时拒绝。极值平局按原行号、逻辑行号选代表并记录并列数。

### 逐字段二进制布局

所有列按完整目标的逻辑行排列，逻辑行号由行位置确定，不另复制；每行 243 字节。小端 float64/uint64，状态为 uint8。原始点字段和 float32 坐标不改，只有偏差和证据计算使用 float64。

| 列 | 类型/每行分量 | 含义 |
| --- | --- | --- |
| source_index | uint64 × 1 | 最初原始行号 |
| deviation | float64 × 1 | 有符号法向偏差；不可计算为 NaN |
| status / failed_checks / covered | uint8 各 1 | 互斥终态、原质量失败位、实际三角支持标志 |
| coverage_count | uint64 × 1 | 完整支持邻域点数 |
| direction_cosine / nearest_distance / triangle_edge / max_residual | float64 各 1 | 复用原覆盖质量证据 |
| triangle / triangle_source_indices | float64 × 9 / uint64 × 3 | 实测三角坐标及原始来源 |

终态顺序为 covered=0、extended=1、invalid_target=2、invalid_reference=3、outside_support=4、support_quality_failed=5、extension_limit_exceeded=6。255 只用于尚未计算的内部行，完成证据中拒绝。质量位从低到高依次对应 reference_count、covered、direction_cosine、nearest_distance、triangle_edge、max_residual、extension_distance。

缺失浮点几何仅在二进制表使用 NaN；缺失原行号使用 uint64 最大值，不能当真实来源。JSON 摘要仍只允许有限数值。字段集合、dtype、行数、来源范围、三角完整性、终态和计数必须一致；读取校验重建既有 CoverageEvidence/ReferenceExtension，通过同一个限值比较器重算失败位，并从完整偏差列重算摘要。不只相信存储的 valid 或通过位。

此校验负责表内一致性，**不代替尚待接入的资产来源绑定和原始坐标复核**。后续恢复还需核对目标/基准真实成员、重算逐点偏差及支持，不能仅凭摘要/表自洽认定资产正确。
