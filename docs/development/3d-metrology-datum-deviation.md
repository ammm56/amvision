# B17 基准偏差实施契约

## 1. 范围与状态

2026-11-13 已确认首批定义：评价现有有效基准平面到显式目标 ROI 内实测点的有符号法向偏差；输出最小值、最大值、峰谷、均值和 RMS。基准支持采用实测覆盖或有最大距离的有限延伸；完整目标通过才有效。

本文件是实施契约，不表示算法、公开节点或资产附件已经实现。当前节点包仍为 0.1.33、29 节点，原工件 50 项不变。B13 风险补验见[关系测量](3d-metrology-relations.md#11-风险代表补验2026-11-13)。

- 不重新拟合基准、不自动去趋势、不删离群点、不补洞、不自动选择目标。
- 不把偏差峰谷称为正式平面度，不直接把结果命名为经认证的翘曲量。
- 不开发 CAD、报告或 SPC。十秒、实体精度及新发行独立管理，不阻塞本项。
- 首批目标为保留实测来源的云或显式 ROI 子集；体素质心、插值截线等生成点不能冒称实测表面。刚体变换后的实测点可用，但必须与基准处于同一当前坐标系。

## 3. 参数与输入

下列名称为拟实施字段，开发中三维契约保持 v1；不为尚未实现能力注册空节点。

| 字段/输入 | 语义与校验 |
| --- | --- |
| cloud | 当前目标云；来源、单位、坐标和运行权限沿既有检查；ROI 在上游显式确定 |
| features | 同次输入的 Features3d；基准 ID 必须唯一，原质量必须可用 |
| reference_feature_id | 基准平面 ID；不自动选择第一个平面 |
| frame_id / length_unit | 与目标及基准一致；不隐式换单位或变换坐标 |
| reference_policy | 原 `measured-support`，或原 `plane-extension` 加显式正数 `max_extension_distance` |
| coverage | 支持半径、最少支持点、最大三角边长、最大平面残差；复用原有限支持定义和比较器，不填写通用生产默认值 |
| outputs | min/max/peak-to-valley/mean/rms 五个不同 item_id，均为长度单位；默认不替工件新增必检或公差 |
| quality_policy | 现有限值规则；基准有效、目标完整及全部覆盖为必需条件，不能由配方关闭；工艺条件另由明确配方填写 |

本方法方向固定为基准平面的正法向，不再提供任意测量方向。正法向来自既有拟面参数，不能从屏幕方向猜测。

空目标或目标含非有限位置返回明确无效，保留输入计数和原因；不在此节点隐式调用 Filter Valid。输入 schema 错误、过期引用、跨观测/单位/空间冲突、预算不足、取消和存储损坏沿平台错误路径处理，不伪装为产品 NG。

## 4. 算法、支持与失败

对完整目标中的每个点 p，使用已有单位法向 n 和平面 offset：`d = dot(n, p) + offset`，垂足为 `p - d*n`。不通过重新拟合使偏差趋于零。

1. 实测覆盖：垂足须落在原局部三角支持内，并满足原计数、边长、残差规则。保留 RANSAC 原始邻域复核，不能只用筛出的内点掩盖另一层。
2. 有限延伸：先进行相同覆盖检查；未覆盖时，沿原 reference_coverage 定义计算垂足到投影基准实测支持的最近面内距离。距离不大于显式上限才允许延伸；保留原最近点/原行号及平局规则。不是目标到基准的高度，不是到 ROI 包围盒的距离，也不改成新的无限面模式。
3. 完整目标均满足条件，且已有基准/质量可用，五项才输出有效数值。任一点失败，五项均 `valid=false,value=null`；保存完整失败分布，不从成功子集生成有效量值。
4. 诊断统计可以覆盖全部可计算有限点，但明确 `diagnostic_only`、总数和实际参与数；不能填入正式五项，也不能隐去失败点后称全目标结果。
5. min/max 为有符号偏差；峰谷=max-min；均值为逐实测样本等权平均；RMS=`sqrt(mean(d*d))`，不是去均值标准差。非均匀采样不会自动面积加权。法向反转使 min/max 对调取负、均值取负，峰谷和 RMS 不变。
6. 极值保留真实来源。相同数值按原始行号及逻辑行号稳定选择展示代表，记录并列数量；不生成虚假的唯一极值位置。空目标没有数值，零偏差是合法零值。

### 计算与资源约束

目标按块处理，原字段和 float32 存储不改；偏差/累积按需要局部 float64，使用稳定的分块统计并与独立真值核对，不保留每块的重复大数组。

现有 plane_coverage 每查询都会扫描有限支持并创建选中掩码。直接对百万目标点逐次调用会形成重复整云扫描，不能作为 B17 完整实现。应先在原支持模块提取一次性准备/有界查询，再共享原局部三角和残差判定；索引覆盖完整有限基准，不以采样替代。工作索引、邻域列表、三角剖分、输出证据及借用同时计费；预算不够明确拒绝，不提高上限、落入等待队列或静默改算法。

首先对单点原实现与批量实现比较覆盖、失败原因、最近点、三角来源、延伸距离和临界包含关系，再允许用于整批。块内外均检查取消；失败关闭本次新资源，旧资产仍可读。缓存只属于同一 Scope，不沿历史 run_id/云 ID 复用。

## 5. 证据与保存

摘要使用原 MeasurementEvidence3d 集合中的新判别项；五项共同引用一份计算证据，不把每点复制五次。

| 内容 | 必须保留 |
| --- | --- |
| 身份 | 本次 observation、frame、unit、完整目标引用、基准模型及其完整支持、方法参数摘要 |
| 规模 | 目标总数、可计算数、覆盖数、延伸数、失败数和逐原因计数；各分类与完整目标一致 |
| 数值 | 五项共同有效性、正式值或 null、全目标诊断统计、极值来源及并列数 |
| 逐点 | 目标逻辑行/原始行号、法向偏差、支持结果与失败码；覆盖三角及来源，或延伸最近支持点/距离等原支持证据；每个目标都有记录 |
| 追溯 | 不以坐标相等认定同源；输入/原始字段完整保留，不给生成点伪造原始行号 |

逐点表作为现有 Runtime/资产体系内的类型化二进制附件，不塞进 JSON，不新增独立资源系统；摘要不得携带裸本地路径或旧进程访问身份。固定列/可选列、偏移、dtype、计费和校验须在契约实现时明确；这属于 B17 必做代码，不声称现有关系资产已经可直接装入任意证据。

保存前验证目标与基准完整支持同一真实根，收集并去重真实派生链。主描述、支持成员和逐点表一次事务提交；新 Scope 从根和成员重建，不修改旧 observation_id。恢复后按原参数重算并核对五项及逐点证据，不拟合平面。普通交换文件不承诺携带全部测量证据；完整恢复使用平台无损资产和现有资源包。

保存失败/取消不公开半个资产；损坏长度、摘要正确但越界索引、错误状态计数、伪造全目标通过、丢失基准支持均拒绝。旧开发资产保留，不新增旧算法分支。具体附件 schema、目录/包指纹及所有读取方同批提交，沿原受影响发布准入，不另建协议迁移框架。

## 6. 前端与验证步骤

1. 参数工作区选择现有输入基准，目标来自已连接的 Crop ROI；同屏查看目标范围、基准正方向与支持。支持模式切换显式清理互斥值，延伸上限未填不能应用，不能通过显示开关改变测量域。
2. 五项摘要区分有效零值、正负值和无效 null。失败时优先展示失败数与原因；诊断统计标注用途，不用产品绿灯表示几何未通过。
3. 偏差色标以物理零为中心语义；显示范围/截色只改变渲染。失败区域、极值与原点来源可选中联动；有界显示必须告知采样，完整统计仍来自全部目标。
4. 参数保存重开、输入/Run/版本切换、迟到返回、关闭页面及窄屏复用既有生命周期保护。历史证据无原支持时可查看，不能假装能够重新测量。

| 阶段 | 验证出口 |
| --- | --- |
| 契约 | 五项完整性、错空间/单位/观测、生成点误标实测、重复/失效基准、空目标和坏参数；不填生产阈值 |
| 支持准备 | 与原标量检查逐项对照；边/角/孔洞、RANSAC 多层、最近点平局、距离刚好在上限及两侧、法向反转、取消和预算拒绝 |
| 数值 | 独立构造水平/倾斜面、已知台阶和正负起伏、零值、非均匀采样、极值并列、大坐标局部精度；独立公式计算五项，不以新算法生成期望 |
| 全目标失败 | 一个点失败、全部失败、非有限点、坏来源；五项均无效，逐点与计数完整，成功子集不得输出有效结果 |
| 持久化 | 同根多层子集/变换、无损字段/原行号、ZIP 搬运空环境、写失败/取消/坏表回滚、恢复重算与 Scope 归零 |
| 公开链路 | 正式节点、目录/schema、NumericTable/Check Limits、Save/Read/Preview、SDK/结果读取方、三维显示同时接通；不留下只有内核的空公开节点 |
| 平台与工件 | Windows 真实页面编辑→Preview→保存→发布→调用→停止/切版；WSL 原生数据目录后端同图/恢复；完整工件显式目标与已有基准，不改原 50 项配方 |

顺序固定：契约测试 → 共用支持准备与单点等价 → 分块统计/失败证据 → 事务保存恢复 → 节点/全部读取方/前端 → 双平台完整样本与发布 → 审计和清理。现有依赖足够，不因 B17 安装 CAD 或新拟合库。

尚待实现的不是另一轮测量定义讨论，而是上述每项代码与验证。无生产容量、工艺公差或节拍新默认值；实际工件基准和 ROI 可复用已确认配方，新增偏差合格界限需单独给出，不能从当前点云自证产品合格。
