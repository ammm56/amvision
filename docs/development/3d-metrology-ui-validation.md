## 2. 实现边界

### 2.1 结果和参数

- `MeasurementSummary` 明示“几何结果，未作产品公差判定”。S2 显示“部分实测圆弧估计”，不显示产品 OK/NG，也不伪造稳定性通过。无效值不替换为零。
- 显示小数仅使用现有格式化函数，默认原值；原始值保留在详情/标题和数据契约中，不修改导出或正式数值。
- `CloudPreviewSelector` 沿现有当前成功 Run 取数，显式选择节点/端口，并显示空间和单位；未选择、运行中、失败、过期与已修改草稿分开。其他显示作为背景不自动成为合法测量来源。
- `GeometrySettingsForm`、`RoiForm` 从既有编辑器提取，不维护第二份转换和几何算法。同一事件周期多字段更新合并当前草稿，避免 origin/axis 或成员更新覆盖。
- 修复打开片段组拟圆参数时重建 selection 键顺序造成的假“已修改”；只有确实移除失效选择时才更新。

### 2.2 三维编辑和证据

- 一个 CloudViewer 继续承担旋转、平移、缩放、轴视图、投影、拾取、聚焦与复位。详情改用一个受限高度的页签区，不叠放三张独立长表。
- ROI 缩放转换为既有 size/radius/length，按拖动开始时原值计算，避免累计缩放；不保存 Three.js scale，不接纳非正尺寸。并集只能编辑其实际成员，不伪造一个包围盒。
- 拟圆均衡权重由后端完整所选支持和同一角区算法产生，按 solver 中的权重摘要与角区计数复核；不是浏览器抽样重算。径向残差来自保存的拟合几何，标为“拟合几何径向残差”，不宣称与优化器内部中间数组逐位相同。
- 显示正文携带 `radial_residuals`、`angular_weights`、`angular_sectors`；后端校验长度、有限值、正权重、分区和残差分类，前端读取方同步。20 行分页只构造当前页对象，不为长表重复创建全量行对象。
- 完整所选支持序号不是原始 PLY 行号。原始/生成来源沿现有 CloudRuntime 保留，不混用两种序号。
- 渲染对象沿既有 CPU/GPU 预算登记、替换与释放；回调核对 generation/payload，切 Run、关闭和晚返回不能修改新编辑器。

### 2.3 真实页面发现的显示传输错误

完整点云的算法已成功，但拟面显示出现 `preview_structure_limit`。原因有两处：

1. 通用 JSON 元数据的 100,000 项限制误计入平面每点 classes/residuals；50 万显示点会产生 100 万个这类标量。
2. 分页正文已经生成 Blob，控制摘要仍重复携带完整 geometry，继续占用控制消息限额。浏览器又对点云正文沿用了普通表格的 16 MiB 上限，而既有 Runtime 点云通道为 64 MiB。

修复只识别当前 `amvision.point-cloud-preview.v1` 中与 `display_point_count` 一一对应的已知平面标量数组；普通元数据仍受 100,000 项和深度约束，未知嵌套数组没有豁免。Runtime 64 MiB 字节上限、父会话内存预留和节点点云策略保持不变。

分页控制消息仅保留格式、状态、原因和 Blob 描述；完整数据与 geometry 只在现有 Blob 中传一次。浏览器点云分支与既有 64 MiB Runtime 上限对齐，普通表格仍为 16 MiB。非法数组、额外嵌套内容和超字节限额仍明确失败，不截断显示证据。

### 2.4 保存和读取

本批没有修改点云资产、特征存储或 Workflow 发布格式。稳健圆的新增字段属于当前 v1 显示正文；旧开发显示正文缺字段时明确拒绝，使用保留的输入/特征重新 Preview 生成，不添加旧格式读取分支，不删除旧数据。保存的拟合几何及完整支持仍是显示重建来源。

SDK 的正式测量响应和同机点云协议没有变更。本轮发布显示测试使用既有协议客户端与 Runtime WebSocket，不把它宣称为新的 .NET 逐点显示接口验收。

## 5. 审计结论与下一出口

本批没有改变测量算法与质量门禁；实际 50 项结果一致，显示数据来源可追溯。发现的真错误是大规模显示证据受到不匹配的结构/控制消息预算限制，以及参数编辑的同事件覆盖/假修改状态，已附对应回归。

性能影响限于显式 Preview 的完整证据构造与有界渲染，不进入关闭 diagnostics/Preview 时的正式数值主链路；没有新建常驻点云会话或等待队列。本轮不是性能或长稳验收，未重跑 P99/soak。

下一批按原计划剩余项推进：先补当前评价面上的环带/角域和包络格网证据，补 ROI 显示开关及窄屏操作；再逐项完成 A_top_L → S1 → S2 最终页面配置、保存、发布运行链。只有真实证据字段足够时才能显示未选候选/空格，不能从屏幕采样编造。

S2 删除角块稳定性（直径 0.078548 mm、圆心 0.053682 mm 超过 0.03 mm 诊断线）、秒级节拍、M3.4 产品三态仍未验收通过，本批不覆盖这些结论。
