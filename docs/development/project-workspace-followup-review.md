## 需要补齐的细节与优化

1. **重名辨识**：列表只显示名称和说明，没有重名时的 ID 辅助。正常列表不堆长 ID，仅在需要区分时显示并允许复制。
2. **受保护项目菜单**：目前菜单只按删除权限显示入口，保护原因到预检对话框才出现。服务端仍会阻止删除；可按设计在已知保护状态时禁用并说明原因，未取得状态时仍必须预检。
3. **编辑冲突选择**：“读取最新信息”会展示服务器值并更新 expected_revision，保留本地表单；再次保存可提交原草稿。不是自动覆盖，但应明确区分采用服务器内容与保留本地修改后保存。替换草稿需要确认，不能暗中丢弃。
4. **SDK 空态**：已有无配置提示和禁用生成，缺少按权限前往应用/部署的下一步入口（P02-2）。保留单层对话框，不增加向导。
5. **复制反馈**：信息抽屉共用一个永久 `copied` 状态，复制 ID 后再操作路径仍显示相同“已复制”。可改成具体字段的短反馈，不增加提示正文。
6. **短屏与缩放**：列表仍设有 920 px 最小宽度。横向滚动不是功能故障，但与设计中缩窄时减少次要列的要求需要最终核对；原生 125%/150% 缩放和完整键盘路径尚未本轮验收。
