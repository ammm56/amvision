## 2. 已确认与待审核

### 已确认，不再重新询问

- 高度采用本次台面法向，在同一固定 U/V 测量线上求两平面交点差；不是固定源 XY 的 Z 差。
- 台面由五个分离 ROI 联合拟合，沿现有 union 去重，不改成大包围盒或串联裁剪。
- 拟合支持采用显式工程 ROI，不复刻手工脚本的栅格侵蚀、补边或隐藏抽样。
- 源原点投影到本次台面为坐标原点，源 +X 投影为 U，源 +Z 决定正法向；当前样本/固定装夹，不声称自动来料定位。
- 钢片等高面取本次有效基体/顶面同线交点的中间高度，比例 0.5；S1/S2 取本次台面以上 0.25 mm。这些是工件值，不是节点默认。
- 钢片比例等高使用 `target-above`；通用节点仍保留已实现的两种显式顺序，错误顺序/重合无效。
- 被测表面和有限边段必须有真实支持；基准延伸显式配置最大距离；缺口不补齐、不外推、不自动取最长段。
- CircleFeature 由 fit-circle 生成，measure-hole 不重复拟合。完整输入用于算法，有界显示不参与测量。

### 4.2 实施动作与保存

1. 通过既有文件入口载入完整 PLY，确认单位、源坐标、字段、点数、摘要和有效性。使用正式节点配置，不运行手工报告脚本替代生产节点。
2. 在现有 Workflow 参数编辑器和 CloudViewer 中配置候选。显示全件位置、局部实测点和支持/残差；核对当前视图、单位与坐标，不从截图像素推测精确 ROI。
3. 对候选保存参数、支持点数、原始行摘要、坐标范围、拟合指标和排除理由，配套有界证据图。先记录失败，不边试边自动调阈值。
4. D 联合支持按所有原始行去重；B/T 与 D 共享同一输入观测。固定 U/V 在本次台面坐标内审核，不能把报告源 XY 原样输入。若此时 D/P 尚未通过质量条件，查询位置只记候选；D2 完成后用有效的本次基准计算并审核最终 U/V，再进入 D3，不能用无效平面或报告系数提前冻结。
5. 工件参数落在既有 Workflow 草稿/发布参数及资产引用中；复用 save-cloud/read-cloud 保存支持或边界。不把某次运行的云引用、lease 或 PlaneFeature 当永久资源复用；拟面支持重读后按相同配方重新计算。
6. 当前 box/cylinder/section-band/union 若无法表达必要排除区，记录具体点集冲突并暂停该分支，先审核最小必要扩展；不暗中新增差集、多边形或环扇区算法。

验证：独立分块布尔真值逐行对照，重叠并集不重复计权，原始行号/总点数保持；保存读取后支持内容一致，旧运行引用拒绝；ROI 扰动、边界恰好命中和缺失成员回归。使用已有 [候选审计](../../tests/integration/metrology3d/test_recipe_candidates_full_sample.py) 扩展，不复制一套裁剪器。

## 5. D2：核定容量、质量，按证据优化现有内核

### 5.1 先解释预算，再决定改什么

沿已有 [fit_plane.py](../../custom_nodes/_metrology3d_nodes/shared/fit_plane.py)、[boundary_runtime.py](../../custom_nodes/_metrology3d_nodes/shared/boundary_runtime.py)、[boundary_surface.py](../../custom_nodes/_metrology3d_nodes/shared/boundary_surface.py)、[extract_boundary.py](../../custom_nodes/_metrology3d_nodes/shared/extract_boundary.py)、[boundary_topology.py](../../custom_nodes/_metrology3d_nodes/shared/boundary_topology.py) 逐项核查生命周期。

列明同时存活的输入物化、float64 局部数组、源行、Delaunay/Qhull 数据、三角面、交点、连接关系、Python 容器、输出和显示副本。区分保留数组计费、工作预算和整个进程 RSS；不能把 `12544*N` 或 RANSAC 公式当成实测内存。

先在原门禁内测代表子规模和已确认支持；大规模超限须明确记录并拒绝。需要更大测试预算才能测峰值时先提交资源估算与机器余量请求确认，不能为了通过临时改常量。

### 5.2 允许的优化与禁止事项

- 只有确认存在重复副本、不必要的长生命周期或高开销容器时，才在原内核中减少副本、提前释放、采用紧凑数组/索引；同一计算阶段仍纳入原预算与取消检查。
- 若估算偏大，只有完成分配生命周期推导和独立资源回归后才能修正估算公式；不能仅凭一次 RSS 较低就降低保护系数。
- 保持同一完整支持及连接/排序规则。不能把独立分块 Delaunay 直接拼接冒充全局等价，不能抽稀拟合、填洞、重选最大段或悄悄改稳健算法。
- 容量不足应沿已有错误通道说明阶段、点数、需求估算和配置上限，不只建议“缩小 ROI”；不得转换成几何缺测或返回旧值。优先复用既有错误详情结构，不引入独立诊断服务。
- 不预先承诺必须改写这些文件；若实现无冗余且满足所需容量，只交付有依据的测试容量结论，生产数字仍另行确认。

### 5.3 质量与验证

平面、覆盖、延伸、表面连接、线方向可辨识性、圆角覆盖/最大空弧、半径约束和残差分别列依据；数值容差、几何质量和产品公差分表。正式配方若尚无有效质量依据，暂停该配置，不继承测试的 0.001 mm RMS 等门槛。

每项代码优化先跑独立解析几何/退化/坏输入，再核对同一支持的输出、原始行、生成顶点来源、拓扑及失败原因；稳健算法按其随机语义比较合法支持与量值范围，不要求随机内点行逐位相同。随后执行分配前拒绝、分块取消、原生阶段超时/整组停止、保存读取与资源回收测试。Windows 和 Ubuntu 分别记录耗时、峰值 RSS、释放后状态，不增加队列、不设定生产节拍。

完成标准：已确认的 A_top_L/S1 配方有可执行的显式测试容量，质量参数依据明确，且对应内核/生命周期验证通过。否则不进入批量测量。

## 6. D3：A_top_L 代表钢片闭环

### 实际节点链

1. read-cloud → normalize-units → filter-valid，保留同一观测和只读云。
2. D 五 ROI union → crop-roi → fit-plane(D) → build-frame(P)。
3. 分别 crop-roi(B.A_top/T.A_top_L) → fit-plane(B/T)；T 同时供 H/Z 使用，不重复拟面。
4. measure-step(`directional-planes`) 求 H：reference=B、target=T；求 Z：reference=D、target=T。两者消费同一 P 和固定 U/V，沿 +N；各自基准延伸策略/上限显式设置，被测面真实覆盖始终必需。
5. extract-boundary 消费原云、D/P、H 证据及 live B/T，用现有 `measurement-ratio`、0.5、`target-above` 解析实际截面。不能直接把 H/2 当台面高度，必须包含基体位置。
6. measure-extents 消费该有序边界并继承实际评价面；按审核后的 U/V 与 L/W 映射输出，不自动按数值大小交换名称。
7. 需要边距诊断时，同一边界两个有名连续 target → fit-line ×2 → measure-edge-pair；查询处双方必须有支持。height-query 的局部方法也是单列诊断，不替代全支持 H/Z。
8. 数值表、cloud-preview、已有 App 输出组织结果，显示无效原因与真实支持；拟合线、基准延伸和物理实测边段区别绘制。

### 逐层验收

独立解析倾斜面先验证 pose 方向、同线交点、H/Z 和中间高度；真实样本再以相同支持、坐标和定义独立计算，手工报告只作参考。源 XY 与台面 UV 混用、反向法线、上下顺序、失效/跨观测来源必须拒绝。

边界检查三角面支持、候选数量、共面/退化、目标歧义、缺口、实际评价面和有名段；长度检查真实极值点和单位，不以闭运算边界替代缺测。保存后重读边界重新拟合/测量，数值和来源按既定精度核对。任何失败停在对应层，不从下游结果猜上游错误。

| 失败类别 | 定位证据 | 处理原则 |
| --- | --- | --- |
| 来源/身份/配置错误 | 输入端口、所选 ID、观测、坐标、单位、支持摘要 | 修接线或契约实现；保持任务错误，不包装成缺测 |
| 容量拒绝 | 阶段、实际点数、分配前估算、当前配置 | 回 D2 核定/优化，不调质量门槛或截掉支持 |
| 拟面/覆盖失败 | 实际支持、残差分布、查询位置、最近支持和延伸距离 | 区分数据与配方定义；不擅自外推/缩窗 |
| 多段/缺口/退化 | 全部候选段数、所选区、实际连接与失败目标 | 审核明确目标；不自动取最长段或填洞 |
| 显示失败 | 显示输入摘要、画布/CPU/GPU 限额和当前观测 | 单独修显示，不修改算法结果或把预览采样当输入 |
| 超时/停止/释放失败 | 对应运行身份、所属进程、Scope/Broker 状态 | 在现有生命周期边界复现并修复，不新建管理器 |

完成标准：H/Z/L/W 每项都有真实节点输出、支持证据及独立核对。合法无效行为可通过软件测试，但不能计为该工件尺寸已可测；影响四个正式量的未解释失败解决前，不扩展十二片。

## 7. D4：S1 代表半圆闭环

复用同一 D/P 与原云：extract-boundary(`pose-contour`、fixed=0.25 mm) → 有名连续实测弧 → fit-circle → measure-hole(`open-arc`)。使用实际截面，不拿底部台面作为拟圆评价面；圆节点按配置多段联合拟合，直径节点直接消费结果。

参数审核包含搜索支持、逐段 ROI/segment_id、正方向、半径范围、数值求解参数、角覆盖、最大空弧、可辨识性和残差。报告的扇区缺口与节点整周 max_gap 定义不同，不能照抄阈值。

独立真值先覆盖已知圆/半圆/多段/短弧、噪声和退化；完整样本检查实测弧与模型圆分开显示，直径端点不能伪装实测点。保存恢复继续保留缺口和来源，反转边界顺序/法向时按已定义方向语义验证。CloudCompare 可作为辅助显示/数值对照，但须记录单位、坐标、同一支持和拟合定义；不能作为运行依赖或生产真值来源。

完成标准：S1.D 由真实节点得到可解释的有效量值并经同定义对照，或者明确证明数据/已确认质量条件不支持测量并提交审核；不能只以“返回无效正确”宣布 S1 目标完成。

## 8. E1：扩展十四对象与覆盖矩阵

按六组钢片逐片审核，不把 A_top_L 的 ROI、U/V、延伸上限或质量限值复制到其他片。S2 单独审核缺失弧，保留实际缺口，不为得到直径放宽质量要求。
