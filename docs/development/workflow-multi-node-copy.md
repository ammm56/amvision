# Workflow 多节点复制实现与验收

> 状态：代码已实现；自动化与真实流程验证已完成。浏览器组合手势验证限制见文末。验收日期：2026-09-21。
> 决策依据：[ADR-0013](../decisions/ADR-0013-workflow-multi-node-copy.md)。本页保留设计约束、实现分步门禁与验收证据；稳定行为已合入[编辑器说明](../architecture/workflows/editor.md)。

## 目标与范围

实现选中多个节点、连同内部连线整体复制粘贴，并保持相对布局。交互简洁，继续支持单节点操作，不引入运行时调度、队列或执行数据复制。

实现前的代码基线（以下限制已在本次修改中解决；通用撤销仍不实现）：

- `useWorkflowSelectionState.ts` 只保存 `selectedNodeId`、单条边和单个应用边界选择。
- `useWorkflowNodeClipboard.ts` 保存单节点深拷贝；当前文档加载和页面卸载会清理剪贴板。
- `useWorkflowNodeDrag.ts` 拖动前选择单节点，只更新该节点坐标。
- `useWorkflowCanvasPan.ts` 使用普通左键拖动画布。
- `WorkflowGraphGroupLayer.vue` 的未锁定组会拦截鼠标并启动组拖动；Ctrl 框选必须处理此冲突。
- 现有版本面板管理保存版本，不是编辑操作的撤销栈。

以上文件均位于 `frontend/web-ui/src/workflows/workflow-editor/` 下；后续维护以实际源码为准，不依据旧行号修改。

## 固定交互规则

| 操作 | 结果 |
| --- | --- |
| Ctrl＋左键拖动画布或节点组空白处 | 新建框选，替换原节点选择；完整包含的节点选中 |
| Ctrl＋左键点击节点非控件区域 | 加入或移出选择，不启动节点拖动 |
| 普通点击节点 | 切换单选；拖动已选节点标题栏时保留多选集合 |
| 普通左键拖动画布 | 保留画布平移，不启动框选 |
| Ctrl+C / Ctrl+V | 复制选中片段 / 粘贴片段 |
| 拖动已选节点标题栏 | 所选节点一起移动，保持相对位置 |
| 点击空白处 | 清除选择；已完成的框选不能被随后产生的 click 清除 |
| Esc | 正在框选时取消并恢复框选前选择；否则清除选择，保留现有关闭临时操作的行为 |
| Delete / Backspace | 在非文本编辑区域批量删除选中节点及关联连线，复用现有删除清理规则 |

框选采用现有主题色的细边框和半透明填充，不增加复杂动画。选中节点统一高亮，属性面板在多选时显示“已选中 N 个节点”，不把某一个节点参数伪装成批量编辑入口。右键已选节点保留多选集合并提供复制；右键未选节点按单节点选择处理。提示文本支持现有语言切换。

输入框、textarea、JSON 编辑器、contenteditable、下拉控件、弹窗、菜单与侧栏内不启动图框选或节点复制快捷键。端口连线、节点组创建/缩放等进行中的操作与框选互斥；一次鼠标手势只启动一种操作。

框选使用统一 screen-to-world 转换，支持反向拖动、当前缩放和画布平移。组的 locked 只约束已有组移动/缩放语义，不禁止框选其节点。框选不选择应用入口/结果边界和便签；组框完整落入矩形且非空节点成员全部选中时进入片段。

## 片段快照与粘贴

### 快照内容

- 复制所选节点的持久配置：类型、参数、启用状态、必要 metadata、尺寸与布局；保留参数缺省、显式 null、false、0、空字符串等差异。
- 复制源和目标节点都在选择集合中的连线及端口、连线 metadata。
- 记录片段边界，用于布局与可见区域定位；所有快照深拷贝，不与原图共享可变参数对象。
- 不复制运行状态、预览图像、预览值、Blob URL、执行临时引用或已释放资源。不得因此删除用户明确配置的合法文件路径、部署引用或业务参数。
- 不复制外部连线、Template 公开输入输出、Application 布局配置或说明便签；节点组按完整框选规则复制。

例如 A→B→C 只选择 B、C，则只复制 B→C；新 B 的外部输入需要显式重新连接。Value Display 和 Image Preview 同时选中时保留显示数据连线；只选 Image Preview 时不关联原 Value Display。

### 粘贴过程

1. 提交并校验全部所选节点的待应用参数后生成复制快照；任一失败时不替换已有剪贴板，并明确提示失败节点。
2. 粘贴前确认文档可编辑、Catalog 类型可解析，生成整批唯一节点与连线 ID，建立旧 ID 到新 ID 的映射。
3. 重映射内部边端点。若发现平台明确声明的节点引用配置，同样按契约处理；不得对任意业务 JSON 字符串做全文替换。
4. 计算片段统一位移、构建全部新节点视图、检查内部引用和端口，再一次性加入图。失败不留下半段节点或连线。
5. 鼠标在可用画布区域时，以鼠标位置定位片段左上角；否则以扣除工具栏、属性侧栏和底部控件后的可见区域居中定位。
6. 同一锚点连续粘贴，每次沿用现有 32 个画布坐标单位的偏移；换锚点或重新复制时重置偏移计数。
7. 粘贴后选中新节点，清除互斥的边、便签、组与应用边界选择，标记草稿修改；不自动保存、执行、发布。

条件分支、ForEach、Parallel 等节点沿用现有结构与连线校验。区分“内部副本引用损坏”（拒绝粘贴）和“编辑片段暂缺外部连接”（允许继续编排，由现有校验提示）；不得自动扩大复制范围或复用原控制结构中的引用。

节点组成员仍按现有完整包含规则计算，含组片段粘贴时直接保留重映射后的成员；拖动结束时统一同步并优先保留仍在各自组内的已有成员。保留节点 enabled，不因落入某组而额外触发启用/禁用操作。文件写入路径、汇总状态文件路径等按参数原样复制，测试前须改为隔离目录，防止重复写入实际生产记录。

## 状态与性能边界

- 使用一个节点 ID 集合维护多选；单选节点详情由集合只有一个成员时派生，避免两套选择状态失步。
- 多选拖动从各节点初始坐标应用统一位移，不逐次累加舍入误差；放下后保持多选，不能被随后的 click 降为单选。
- 复制与粘贴只使用当前文档内的内存快照；切换/加载文档和卸载编辑器时清理。不扩展到系统剪贴板、跨 App 或跨浏览器。
- 保存、发布、文档读取等现有 documentBusy 状态阻止粘贴和批量修改；运行时只读视图不提供编辑操作。
- 空选择复制和空剪贴板粘贴不改变图；快捷键重复事件不造成意外重复粘贴。
- 正常松开鼠标完成手势；失焦、取消或卸载清理事件监听和框选覆盖层，避免永久拖动。失焦取消未完成框选。
- 鼠标移动不请求 API、不序列化整张工作流、不复制参数对象、不触发保存；几何计算和重绘按帧合并，边界尺寸复用现有测量。
- 不增加后端接口、持久化 schema 或依赖，不修改 Preview / Runtime / Trigger、模型或共享内存链路。
- 本次不实现 Ctrl+X、跨文档粘贴、便签批量复制或通用撤销栈。批量删除提供副本移除能力，不宣称等价于完整撤销。

## 验收矩阵

- 选择：单选、Ctrl 加选/取消、不同方向框选、完全包含边界、空框、不同缩放、组内/跨组、锁定组、窗口失焦。
- 输入：节点参数、JSON 编辑、下拉选择、弹窗中 Ctrl+C/V 仍操作文本；框选结束 click 与拖动结束 click 不破坏集合。
- 复制：1 个、多节点、不同节点类型、禁用节点、零内部边、普通计算链、条件/循环/并行片段、多个连线和缺少外部输入。
- 关系：Value Display 与 Image Preview 一起复制保留内部关联，单独复制图片节点不保留原关联；不新增公开输入输出或 App Mode 显示配置。
- 原子性：参数错误、缺失类型、无效内部引用等失败不产生部分副本；原参数对象和原节点位置保持独立。
- 生命周期：连续粘贴无 ID 冲突；拖动整批保持相对布局；批量删除清理连线、公开绑定等既有删除关联项；切换文档剪贴板失效。
- 保存：新节点和连线保存后重新打开仍保持一致；复制动作不发执行请求、不产生磁盘记录。
- 性能：以真实图及其可控扩大片段检查框选/拖动响应，记录节点数、连线数、缩放、浏览器与耗时；不得用未测量的帧率或延迟宣称达标。

真实参考工作流：`workflow-app-20260910030132`（摆盘分拣3570显示结果）。先在隔离副本验证良品率计算链、条件分支和数据显示链；涉及 File Summary 等有状态节点时替换为隔离文件路径，再执行预览。不得覆盖原草稿、发布原应用、切换其 Runtime 或向生产 JSONL 写入测试数据。

完成后记录实际通过/失败项及验证范围，将当前行为同步到编辑器文档并收拢本实施清单；确认本任务进程不再使用临时文件后清理本任务临时产物。

## 2026-09-21 节点组片段扩展

上一轮“组框不复制”的验收记录只描述当时行为；本节与 ADR、编辑器文档定义更新后的行为。

- 组框完整落入框选矩形、非空节点成员全部选中时，组框随节点和内部连线复制。部分组、空组、仅含便签的组不复制，不自动扩大节点选择。
- 组名、颜色、尺寸、locked、enabled、collapsed 和 metadata 保留；节点 enabled 独立保留，不因组配置二次批量切换。新组 ID 唯一，member_node_ids 映射到副本，member_note_ids 清空。
- 整个片段共用几何边界和偏移，重复粘贴继续偏移 32。已选组框高亮；从已选节点标题或组背景移动时组框与节点同步，未选组不移动。锁定组仅在明确的完整片段移动时参与，原单组锁定操作不变。
- Esc/失焦取消框选会恢复节点及组选择；取消某个组成员的选择会取消该组框选择。重新选择节点、连线、便签、公开边界或空白时清理组片段选择，单组编辑选择仍独立。
- 粘贴组使用明确的重映射成员，不立即按重叠位置重新分配；移动结束后保留各组仍在框内的已有节点，防止重复粘贴到原处时成员串组。
- 批量删除明确选中的完整片段时删除相应组框；未选组框保留并清理节点引用。组框删除按钮继续只删除组框。
- 复用现有 v1 groups 字段，无 schema、数据库或公开 API 变更。修改仅在 Vue 3 编辑器，不改变运行数据面，不新增在线依赖。
