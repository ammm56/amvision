## 4. 页面显示与配置

使用非业务端口 5620/5621、独立空库和测试节点包。通过现有页面登录、初始化项目、导入工作流、编辑参数、保存和选择完整 457.5 MiB 文件；没有通过 API 或数据库预置页面状态。文档生成器为 `tests/integration/metrology3d/export_representative_document.py`。

显示配置只用于本轮验收，不是生产默认值：总览 500,000 点，平面支持检查 1,000 点；共用完整原云及一次测量。两者均复用 Cloud Preview。密集总览显示真实边界、模型圆及测量证据，另一个视图显示 D/B/T 的逐点支持分类，避免在密集总览中同时存放三份全长度分类列表。辅助视图仅检查分类与质量，不代替密集总览或完整云的算法支持。
