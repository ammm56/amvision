# 数据集样本更新与目录浏览

## 当前交互约定（2026-11-06 修正）

- 样本页提供“添加样本”和“删除所选”。选择是草稿；点击“保存修改”才直接更新当前版本的图片和标注，版本 ID、vN 编号保持不变。
- “创建新版本”是页面顶部的独立操作。由使用者决定何时创建，复制当时的完整数据并分配下一个 vN；后续修改当前版本不会改变其他版本。
- ZIP 沿用格式校验和 worker。同名类别按精确名称合并，新类别追加，同名文件作为独立样本添加，不自动覆盖。保留已有样本和标注 ID，新样本使用独立 ID，导出时图片 ID 不重复。
- “更新样本”显示当前版本、删除数量和可选 ZIP；允许同时添加、删除。没有新 ZIP 时不允许删至零样本，页面明确提示。关键点定义冲突拒绝合并。
- 写入先生成完整受管内容目录，再将数据库中的样本、类别、内容位置与任务成功状态一次提交。取消抢先、写入失败不会发布半成品。
- 本机共享读／排他写保护覆盖预览文件响应、导出与工作区任务；已有训练使用导出的独立数据。提交时检查内容标识，过期页面或同时排队的旧修改返回明确错误，不能覆盖最新内容。没有新增等待队列或自动重复提交。
- 更新成功后清理旧内容；文件被其他程序占用时保留受管清理记录，下次修改继续清理。内部内容标识只用于一致性，不是用户版本，不出现在版本列表。
- 离开未提交页面保护草稿；提交结果未知时查询本次任务或查看导入记录，不重复写入。
- `_verified` 只是此前验收副本中人为重命名的类别后缀，不是标注属性或人工复核状态。平台原样保留类别名。

## 页面简化

- 数据结构为可展开目录树和文件列表；支持目录逐级浏览、图片预览和文本预览。
- 切换标签保留目录、展开位置、分页和缓存；刷新或切换版本重新加载，异步旧响应不能覆盖新目录。
- 移除关联样本、人工复核、外部标注交接和回传检查的前端入口与闲置组件。既有公开后端接口保持兼容。
- 复用公共表格、按钮、抽屉、主题和 1024px 桌面适配；不增加水平滚动条。

## 接口与边界

- POST `/api/v1/datasets/imports` 支持 `base_version_id`、`exclude_selection_json`、`expected_content_revision`。指定 base 时更新当前版本；未指定时正常导入新版本。
- POST 数据集版本 `/jobs` 新增 `revise` 操作，`config.exclude_selection` 为要移除的样本；返回 `updated_version_id`，沿用任务身份、权限、取消和提交事务。显式 `derive` 返回 `created_version_id`。
- 版本 `/files` 支持 `directories_only`，目录项包含 `has_directories`，叶目录首次显示就没有展开箭头；`/file-image` 仅返回受管目录内支持的图片，不执行或暴露任意文件。
- 新增内容标识写入已有 metadata JSON，无新增数据库表或 DDL。旧目录在首次修改成功前保持原样，修改后通过统一路径解析读取受管内容；已创建版本不合并、不重排。HTTP 与 dataset worker 需同时更新。Runtime/Trigger 和 .NET SDK 调用路径不变；Vue 3 与本地部署无新增外部依赖。
