### 7.1 有界显示索引（已实施）

以下保留开工时的根因与设计。实际代码、磁盘/工作账本和本轮证据见[有界索引记录](3d-metrology-bounded-details.md)。旧整云 KDTree 和固定双 uint64 布局已删除，不再按下文开工前状态重复实现。

### 11.2 A01：十秒还差什么

现有结果是 Windows `10.094 / 9.984 / 10.000 / 10.047 / 10.063 / 9.953 s`，4/6 未满足 `<10.0 s`；Ubuntu `7.881 / 7.711 / 7.841 / 8.110 / 7.904 / 7.934 s`，6/6 满足。CPU 非独占，不能将 Windows 最多约 94 ms 超限归咎于未经证实的系统抖动，也不能改门槛为 10.1 秒。

源码入口：[性能用例](../../tests/integration/metrology3d/test_compute_cycles.py)、[正式配方生成](../../scripts/metrology_workpiece.py)、[半圆建面](../../custom_nodes/metrology3d_nodes/shared/boundary_surface.py)、[截面](../../custom_nodes/metrology3d_nodes/shared/boundary_section.py)、[精确距离分区](../../custom_nodes/metrology3d_nodes/shared/envelope_selection.py)。

2. 当前合并候选每平台先一次受控分项定位，正式耗时不启用诊断。单列 S1/S2 的原生 Delaunay、面筛选/截面来源整理，及十二钢片的 count_neighbors、query_pairs、稀疏转换/连通分量；另外列出新判定、保存和交付成本。旧分项报告不能充当当前候选热点排序。
3. 只修改已量到成本且未做过的重复分配、遍历或数据转换。局部面处理若分块，仍检查全部面、退化和共面；邻接若优化表示，仍保留全部 eps=0 边、分配前计数预算及相同目标标签。不得改 Qhull 选项、删点、减邻居、改变 ROI 或扩大数值容差。已失败的逐行邻域、距离矩阵、直接 CSR 排序和树叶参数对照不原样重试；若大头确在原生库且无可证明等价收益，报告具体成本和所需决策，不能宣称确定可达十秒。

### 11.3 A09：1 GB 不是把单个配置改大

`MAX_POINT_CLOUD_INPUT_BYTES=1_000_000_000` 是现有文件/数组输入契约。下面是实际本机与已跟踪[工作站示例](../../custom_nodes/metrology3d_nodes/workstation.example.json)的值，不是新建议的生产数值。

| 层 | 当前边界 | 必须补齐 |
| --- | --- | --- |

| 解码/规范数组 | `max_decoded_bytes=400,000,000` | 同机数组在 `borrow_cloud_buffer` 直接按此拒绝；文件解码与字段重排也受此约束，必须形成可审计的全容量配置 |
| Run 活跃数组 | 1 GiB | 文件读取明确同时预留 `decoded_bytes + normalized_bytes`；再加源索引/派生数组，不能只按输入文件大小计费 |
| 算法临时工作 | 4 GiB | 保留各算法预算及原生库峰值观测；该值不是进程 RSS 硬限制，也不保证任意密集邻接图可计算 |
| Preview 文件暂存 | 单会话 500,000,000 B、总量 1,000,000,000 B | 贯通服务准入和前端公布上限；保留总量限制、取消、短传/超传和清理 |
| 资产/交换导出 | 各 600,000,000 B | 覆盖原件、规范数组、来源与派生内容；输出可能大于输入，不能共用一个载荷上限 |
| 资产 ZIP | 610,000,000 B | 独立显式包容量，计入 manifest、所有 blob 与 ZIP 开销；不限制为恰好 1 GB |

代码依据：[I/O 策略](../../backend/service/application/workflows/point_cloud/policy.py)、[同机借用](../../backend/service/application/workflows/point_cloud/local_array.py)、[文件重排](../../custom_nodes/metrology3d_nodes/shared/io/read_file.py)、[Preview 文件准入](../../backend/service/application/workflows/preview/buffers.py)、[资产归档](../../backend/service/application/workflows/documents/cloud_resource_archives.py)。

5. 在上传、解码、ROI/派生、保存、导出阶段覆盖取消、磁盘不足、坏摘要/截断、客户端异常退出及下一次调用；Windows/WSL 原生目录记录运行中峰值、收尾 RSS/线程/句柄/mmap/临时磁盘和租约归零。

### 11.4 A08：全分辨率点云显示

已提交的正交顶视、Z 色标、比例尺、叠加开关、OrbitControls 和资源释放继续使用。当前[生产显示构建](../../custom_nodes/metrology3d_nodes/shared/preview.py)对逻辑行均匀抽样、整块 base64 输出；[前端解码](../../frontend/web-ui/src/workflows/workflow-editor/point-cloud/preview-data.ts)创建完整显示副本，[renderer](../../frontend/web-ui/src/workflows/workflow-editor/point-cloud/renderer.ts)渲染这些固定点。当前正式工件输出 500,000 点，本机策略最大 1,000,000 点；缩放不能补取未传输的原点。

当前 `bounds` 是抽样后显示点的范围，不是全云精确包围盒。全分辨率设计须分别表达全云范围和当前块范围，不能仅把原字段替换成全云极值而漏改前端严格校验。全部 14,745,099 点仅 float32 XYZ + uint64 行号就约 295 MB，未含颜色、base64、浏览器复制和 GPU；现有 32 MiB 正文、128 MiB CPU、64 MiB GPU 预算无法用一块内嵌正文承载它。

1. **明确数据存在性。** Run 引用仍在 Scope 结束释放；默认结果只保留数值和有界证据。运行后全分辨率细节从配方显式保存的现有点云资产读取，不因打开查看器自动保存全云、不延长 Broker lease、不恢复已释放引用。未保存原云的历史结果只能显示已有证据并标明原因。若要求动态输入不保存却在运行后任意查看全云，需要另行确认有界临时副本的保留策略，当前未批准该扩展。
2. **在现有资产内派生显示索引。** 为受支持的原件/数组建立可重建的空间分块索引和多分辨率摘要，完整叶块保留原始坐标精度、字段、原始行号与摘要；生成顶点使用既有顶点身份/来源，不能伪造原始行号。索引按源资产版本/摘要固定；父资源删除、索引损坏和取消沿既有资源管理处理，不增加第二个资产/发布系统。重计算量值仍走完整 Preview。
3. **扩展现有读取/显示接口。** 通过已有鉴权/项目/资源访问边界传输 manifest 和有界二进制块，传输与 API handler 的重计算分开；补源身份、块序号、字段、偏移、长度、摘要、范围、层级及完整性状态，同批更新读取方。沿当前开发三维 v1 约定，不保留过时双路径或把全云 base64 放入通用显示通道。
4. **扩展现有 viewer。** 相机移动时使用明确标示的交互 LOD，停稳后补取当前视域原始叶块；复用既有 CPU/GPU 预算做分块释放与淘汰，晚返回按资源/视图 generation 拒绝。不自动把容量失败伪装成全分辨率成功，不默认增加任何运行请求等待队列。
5. **可检验的页面语义。** 区分总点数、当前显示点、已加载块及当前视域是否达到原始分辨率；源色/坐标色标、全云范围和局部范围明确。标准视图、旋转/平移/缩放、ROI 和测量证据仍同屏；拾取回到原始点身份，量值不从 LOD 云计算。复用已有大坐标局部原点与显示误差校验。EDL/SSAO 属于单独显示增强，不是完整点加载或测量正确性的替代，本项不悄悄扩成 CloudCompare 全功能克隆。
6. **实测验收。** 对完整 14,745,099 点资产及容量批样本验证叶块总数/去重/原始行号、坐标与字段一致；精查边缘、孔区、稀疏孤点和全局极值。Desktop/窄屏截图与非空像素、旋转/缩放、LOD 切换、点选、取消、切换任务/资产、关闭重开、WebGL 丢失、源删除/损坏、CPU/GPU 回收全部覆盖；相同数据同视角与 CloudCompare 比较，不用合成小云替代。Windows 浏览器与 WSL 后端分别如实标注。

全分辨率按视域分块达到原始点细节，不等于全部点同时常驻显存；如果一个视域超过显式预算，应保持可识别的未完整状态，不能继续称为全原始点显示。本项具体块大小、同时加载数和显示缓存容量由 A09 账本与本机验收确定，本轮不设置生产默认值。
