### 3.2 有序边界：扩展已实现

M3.2 开工前核对的约束：`register_subset` 只接受只读、范围内严格递增的父逻辑索引；`register_derived` 的新数组点数必须等于父云点数。这两项约束目前仍保持，新增能力沿独立的有序/生成操作接入同一 Runtime；不能把“源行号顺序”当边界顺序，也不能把任意数量的截面交点塞入旧派生操作。

已确认在现有 CloudRuntime 内扩展两种明确操作，不增加 owner 系统：

1. **有序源点视图**：逻辑行按边界拓扑排列；每个被选点仍映射到最初输入的 `source_indices`，`source_point_count` 仍是原始总点数。允许的重排与现有 crop/filter 的递增子集区分，不放松后者的校验。
2. **生成顶点**：截面/等值线/投影产生的新点不是传感器原始行。使用生成点来源分支，记录父内容、方法、必要的支持边/面及插值关系；不得给它伪造一个原始行号，也不能为凑点数复制父云字段。

二者沿现有 Scope 分配、借用、取消、预算和关闭；索引、拓扑、生成坐标、映射都计费。新字段是否需要版本化，必须按实际对外契约及资源 v2 schema 定稿，不让旧严格消费者猜测新含义。不修改已有实测点“最初原始行号”的约定。

保存时沿现有资产写入/原子发布边界保留语义和必要映射；关闭原运行后，在新运行恢复同一顺序及来源。未显式保存时只交付有界证据，不能从历史结果访问旧数组。普通点云导出不能声称保留了边界连接关系或全部测量证据。

**状态：M3.2 已按上述边界接入原 CloudRuntime。** 有序视图、生成位置/源边/权重/CSR 源面及拓扑随资产 v2 保存恢复，不另建索引/顶点仓库；当前字段与验证以 M3.2 实施记录第 5 节为准。

### 3.3 精确拾取：已确认

已确认沿现有调用方式：点击有界显示只填写候选查询位置，显式 Preview 重新读取完整输入并由后端计算。预览采样点不是原精度测量结果；相机射线也不直接当测量方向。

草稿、输入资源版本或 observation 改变后，已有结果标为失效并禁止当当前结果提交。未保存原云的历史结果只能查看数值与证据，不能重新测量；显式保存的输入可沿现有文件/资产入口重新 Preview。不增加常驻原云会话、实时查询服务或另一条 WebSocket。

## 4. 八节点详细规格

以下参数均为必须明确的语义，不是已批准的生产默认值。数量/预算沿现有策略；配方阈值、求解停止条件和生产时间/内存限制分别管理，不混作一个“精度”设置。

### 4.1 height-query：查询高度

**输入与配置**：目标云、指定参考平面特征；稳定 item_id、评价 frame/unit、查询位置 `p`、单位测量方向 `v`、有限搜索 ROI/邻域范围、轴向搜索区间、局部拟合方法及质量规则。查询坐标来自数值输入或已确认的候选拾取，不能默认使用源 XY、源 Z 或点云质心。

**计算步骤**：

1. 核对本次运行、observation、坐标和单位；参考平面缺测时直接生成该 item 的无效值，不借用上次平面。
2. 在完整目标云中按有限搜索域选支持点，分块扫描并计入成本。局部数据足够小时才创建本次 Scope 内的索引，不预建整云 KDTree 或持久缓存。
3. 调 M2 同一正交平面拟合与质量函数；邻域内有多个不明确的表面、支持不足或局部拟合不成立时无效，不改用最近点。
4. 沿 `q(t)=p+t*v` 求目标面和参考面的交点。平面为 `n·x+d=0` 时，`t=-(n·p+d)/(n·v)`；输出 `h=t_target-t_reference`。
5. 用明确的邻域覆盖、最近距离和最大三角边长检查交点支持；仅落在凸包内部不证明空洞处有数据。M3.1 已确认支持域外无效、不允许外推；局部搜索域不能自动扩大直到得到结果。

**输出与失败**：NumericTable 中保留配置的 item；有效时附两个真实交点、测量线、支持和拟合质量。无支持、质量失败、方向近平行、超支持等保留具体支持/质量证据。非法参数/错接线为任务错误，取消/超时沿执行状态，不改成正常缺测。方向及覆盖质量由显式配方给定；没有允许外推开关或外推默认值。

**前端**：基本区显示查询坐标、坐标系、方向、参考面、搜索范围；高级区显示拟合与质量。拾取后只更新同一草稿，应用后才可 Preview；结果表选项联动测量线和实际支持，未重算时不展示旧值为新值。

**独立验证**：倾斜面、竖直面、大坐标平移、方向反转、不同查询位置；空洞、多层、边缘外推、局部缺失；解析交点与算法独立构造。显示采样数量变化不改变测量值。

### 4.2 measure-step：测量高差

两种互斥模式在 schema 和 UI 中分开，不以隐藏参数改变“高差”定义。

| 模式 | 输入/计算 | 证据与质量 |
| --- | --- | --- |
| 同位置方向面差 | 两个指定平面特征、同一 `p/v`；沿 4.1 的交点公式作有符号差 | 两交点、方向、双方支持范围和质量；非平行面必须显示评价位置 |
| 两 ROI 统计差 | 两个有限 ROI 云；同一坐标原点和单位方向，计算 `s=v·(x-origin)` 的明确统计量，再作 target-reference | 双方支持、点数、统计量、离散程度和方法；不是两实际表面交点间距 |

统计方法在配方中显式选 mean/median/quantile；分位方法与分位概率在方法契约中明确，不能按库默认暗换定义。mean 使用稳定分块计算；median/quantile 计算完整支持的精确统计，临时投影数组计入预算，不用采样或近似摘要替代。

统计差没有唯一物理端点，`endpoints=null`，显示两支持区域及统计参考标记，不能把质心连线冒充实测距离。这是基线 5.8 “无适用端点不填虚构几何”的具体分支。参考/目标均应沿同一种统计定义，不能悄悄一侧均值、一侧中位数。

前端用分段模式控件切换，只显示相应字段；切换后原结果失效，隐藏模式的字段不得继续生效。验证交换两侧变号、整体平移不变、法向变化、不同位置平面差、偶数中位数、分位边界、单侧空 ROI 和双方错单位。统计差不强制满足在不同位置计算的 `H+t=Z`。

### 4.3 extract-boundary：提取边界

**输入与配置**：有限目标云、明确评价平面/坐标与正向、方法、期望特征 ID 和选择约束、邻接/跨缺口条件、质量。不是任意三维云自动生成“真实轮廓”。投影、截面和等高边界必须可区分。

| 方法 | 计划计算路径 | 不能隐藏的条件 |
| --- | --- | --- |
| 投影边界 | 局部坐标投影；SciPy Delaunay/Qhull 建立邻接；按显式 alpha/边长/支持规则选择三角面；从边界边组成有序段 | 这是基于采样的边界估计。不能用凸包代替凹形/孔，也不能把缺扫自动当真实孔 |
| 有限截面 | 在显式有限 ROI 和可成立的局部表面邻接上构造网格；trimesh 平面相交产生线段，再按明确连接规则组织 | 不将邻近散点直接投影成“精确截面”；多层、非单值或跨缺口邻接不成立时拒绝，不自动重建闭合实体 |
| 等高边界 | 相对指定基准的带符号高度；在有效局部三角表面上用相应等高平面相交，保留插值来源 | 等高阈值及方向显式给定；不套样本 0.25 mm，不在无支持区域补线 |

Delaunay 是成熟三角剖分内核，不是完整的计量边界算法。应用层负责方法定义、支持检查、拓扑和追溯；需用凹形、多孔、缺扫、重复点与退化用例核定。上游说明未必每个输入点都进入三角剖分，须检查遗漏/重复映射，不能默认开启扰动来改变输入后继续。[SciPy Delaunay](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.Delaunay.html)

trimesh 的 `mesh_plane` 可返回相交线段及源面号，但源码使用库内数值容差。适配必须局部中心化、核对单位/尺度、映射源边/面并验证共面/顶点交线；不能把库容差当图纸公差或修改全局容差。需要扩大受控修复到几何算法时先确认，既有授权只覆盖 I/O。[trimesh 5.1.1 intersections](https://github.com/mikedh/trimesh/blob/5.1.1/trimesh/intersections.py)

输出遵循基线 5.10：逻辑顶点按拓扑排列、段之间不连接、闭段不重复末首点、稳定 ID 不取连通域返回序号。期望槽/孔通过显式区域、角色和唯一匹配约束选择；多个候选未消歧不能取第一个。未知角色不得当孔使用。不能仅凭点云缺口判断是物体孔还是扫描遗漏。

前端展示方法、评价面和显式参数；多段列表与视图双向选择，实测顶点/插值线、开口/闭合、支持/缺口可区分。只画拟合支持的段，不跨缺口画实线。验证原始输入顺序打乱、凹形、多个孔、开放圆弧、缺行、非均匀采样、重复坐标、近共线、截面过顶点/共面边、单位换算及预算拒绝。

此节点已随 M3.2 接入 3.2 的逐字段契约、运行资源和保存显示；实际实现、既有验证与剩余真实发布验收以 M3.2 实施记录为准，不将本节早期算法规划当作额外通过证据。

### 4.4 fit-line：拟合直线

输入仅接受指定 boundary/segment IDs，沿拓扑取完整支持；不把外部任意无序点云当边缘。配置稳定 feature_id、评价面、正方向、拟合和质量规则。

采用中心化总最小二乘：对支持坐标做 SVD，最大主方向给出正交拟合线；按显式正向确定符号，投影最小/最大值得到有限 `parameter_range`。残差是点到线的正交距离，不用某个源坐标轴的回归误差。若按评价面拟合，先检查面外残差，再在面内拟合并返回三维坐标。

质量包含点数、实际支持跨度、方向分离/可辨识性、RMS、最大残差及段间缺口；无限线模型不表示缺口已被观测。第一条方法完整实现 TLS；稳健方法只有在完整定义、参数和回归完成后才开放，不对失败自动切换算法。

界面选择边界与段、正向，显示真实边和拟合线，支持区间外用明确不同样式。测试水平/竖直/任意旋转直线、重合点、短段、非共面、断段、方向反转；与独立解析线距离核对。

### 4.5 fit-circle：拟合圆

输入为指定边界段及评价平面。先检验面外偏差，再局部中心化，代数求解只用于初始化，最终优化目标为几何径向距离平方和：`sum((||p_i-c||-r)^2)`。使用现有 SciPy `least_squares`，约束正半径，明确求解终止条件、最大求值次数及失败状态；不直接将代数结果当最终几何拟合。[SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)

配方配置 feature_id、边界/段、评价面正向、允许的半径/搜索条件和质量。残差、点数、连续支持角跨度、最大缺口、Jacobian 秩/病态性分别记录；角度分箱占有率不等于连续支持角跨度。短弧即使 RMS 很小也不能跳过可辨识性检查；求解器“成功”不等于测量质量合格。M3 先交付明确的几何最小二乘方法，不隐式附加另一种 robust loss。

输出圆心、法向、半径及实际支持弧证据；展示完整拟合圆时用辅助线样式，实际支持弧单独突出。验证完整圆、半圆、短弧、大缺口、非均匀采样、大坐标偏移、共线、面外点、无收敛及半径边界；使用独立解析圆/噪声敏感性，不用本拟合器生成期望值。

### 4.6 measure-extents：测量长宽

输入为明确的点云支持或指定边界，两种输入源显式选择，不同时生效；配置评价平面、稳定尺寸 ID 和方法。

1. **轴向跨度**：在固定工件轴上计算完整支持投影的 max-min。轴是配方定义，不使用源屏幕方向。输出轴向尺寸及接触支持点/支撑线。
2. **最小面积矩形**：在评价面内调用 `trimesh.bounds.oriented_bounds_2D`，核对返回矩阵方向、实际支撑边和尺寸。凸包用于包络计算是允许的，但不反向充当真实边界；PCA 框不是最小面积矩形。

已核对 5.1.1 源码会分配凸包顶点数与候选方向数的乘积数组，且只返回一个最优框。已确认并在受控 trimesh `.2` 局部扩展同一函数，补分块预算、取消和全部并列候选，双平台独立回归见[实施记录](3d-metrology-m33-acceptance.md)。节点已接入：凸包及工作数组按现有预算计费，不够则按容量错误拒绝，不降采样、不静默换近似方法；这不是原生库 RSS 硬上限保证。并列候选长短边一致时保留尺寸并标识方向歧义，尺寸不一致则无效；比较条件显式配置。详细参数、证据和验证见 M3.3 第 4 节。[trimesh 5.1.1 bounds](https://github.com/mikedh/trimesh/blob/5.1.1/trimesh/bounds.py)

前端明确显示“轴向跨度”或“最小面积包络”，两项尺寸可独立命名和配置限值。支撑线、接触点与尺寸线关联；矩形角不冒充实测点。验证旋转长方形、带圆角/缺边轮廓、正方形方向歧义、凹形和细长退化；报告的是可见支持包络，不推断遮挡后的实体长宽。

### 4.7 measure-edge-pair：测量边间距

输入为两个指定 line 特征；稳定 item_id、评价面、评价位置、测量方向和符号显式配置。必须消费同观测、同评价空间且质量可用的线。已确认首批不允许外推，不增加外推配置。

在评价面内，测量线 `p+t*v` 分别与两拟合边求交，结果为有符号 `t_B-t_A`；需要间隙大小时显式选择绝对值定义。每个交点必须落在相应逐段支持区间的并集内，域外或段间缺口内无效，不能用整体 min/max 填平缺口。近平行于测量线、共线重合、线在面外、无共同有效范围等分别无效。

非平行两边的距离随评价位置变化，不能只返回一个不注明位置的“槽宽”。首批按显式配置的位置逐项测量，不用有限采样冒充连续全区间最小间隙。平行距离方法若开放，必须明确平行质量条件和测量方向，不能在失败后自动切换。

前端选 A/B 两边和评价位置，清楚显示测量方向、两交点和符号；交换按钮只交换配置并使旧结果失效。验证平行解析距离、楔形边的位置效应、交换变号、有限段未覆盖、交点在缺口、面外边和旋转/单位等价。

### 4.8 measure-hole：测量孔与圆弧

接线已确认：直接消费 fit-circle 输出的 CircleFeature 及质量，不再次拟合。替代原设计的边界内拟合路径，不并行实现两种接线，详见 M3.3 第 6 节。

无论接线选择，评价面、闭孔边/开放圆弧、内外角色、唯一选择和质量条件都须明确；不调用 fit-circle handler、不复制拟合器。开放圆弧允许用于半圆槽，但不能称为完整闭孔或完整圆周观测。输出配置的直径和圆心坐标项；直径为 `2r`，坐标在明确评价 frame 中。证据保留圆模型、支持弧、缺口、选定显示方向和方法；显示直径辅助线不表示两端均有实测点。

前端按确认的输入组织“目标 → 评价空间 → 支持与质量 → 输出项”，列表和视图选择一致；常规操作不要求手输内部 ID。多个候选需显式选择，不固化当前样本两个槽，也不按左到右自动配对业务身份。

验证完整孔、半圆槽、短弧病态、边缘阈值改变、相邻多个候选、内外圈混合、面外支撑、目标缺失。圆心坐标和直径使用不同稳定 item_id，失败时全部启用项仍存在且 value=null，不消失或补零。

### 6.1 三态

| 启用且必检的项目 | 总状态 | 布尔放行 |

### 10.3 先完成 extract-boundary

节点按三个显式互斥方法组织，同一时刻只接受当前方法参数。先实现投影分支及实际消费它的有序源点能力，再实现有限截面/等高及生成顶点；三个分支通过后才把节点记为完成，不注册空壳方法。

| 方法 | 完整计算步骤 | 必须验证的拒绝条件 |
| --- | --- | --- |
| 投影边界 | 在有限 ROI 中核对有效点和评价空间；局部投影；SciPy Delaunay；按配方的三角支持/边长/alpha 条件保留面；提取有向边、组织段；执行显式目标匹配 | 重复投影对应不同层、无法解释的遗漏、退化、自交/分叉、跨缺扫、候选不唯一；不换凸包或扰动点坐标兜底 |
| 有限截面 | 沿上述共享支持检查建立可成立的局部三角面；调用 trimesh.mesh_plane 并取源面索引；恢复源边与插值关系；按真实邻接连接、断段、裁定目标 | 仅散点投影不算真实截面；无支持面、相交语义不唯一、跨缺口、非单值表面不能自动封口或重建实体 |
| 等高边界 | 指定基准/高度和方向；在同一有效局部表面上作等高平面相交，复用截面连接与来源映射 | 多层或退化不输出假等高线；不套样本阈值；不能以改变颜色阈值修改算法定义 |

SciPy 明确指出 Delaunay 可能遗漏输入点，且 simplex 返回顺序可能变化。实现必须核对来源/遗漏并与稳定目标身份分开，不能默认启用 QJ 来隐藏退化。[Delaunay 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.Delaunay.html)

trimesh 5.1.1 的相交入口能返回源面索引，但使用 `tol.merge`，共面三角形也有专门的排除规则。实施的第一组算法探针必须覆盖穿过顶点、整条共面边、整片共面面、法向反转、mm/m 与尺度变化，明确哪些情形可唯一求交、哪些属于合法缺测。仅查询到 API 不算这一项已验证；不修改全局容差或偷偷扩大已批准的 I/O 修复范围。[固定版本相交源码](https://raw.githubusercontent.com/mikedh/trimesh/5.1.1/trimesh/intersections.py)

上述方法只处理配方明确的局部表面，不承诺从任意无序多层点云恢复完整实体。数值去重的来源映射、共面处理、连接容差与目标匹配是编码前的字段/算法核定项，不用未经确认的生产阈值填空。若成熟内核无法满足已定范围，先提交证据和调整选择，不自行更换为近似算法。
