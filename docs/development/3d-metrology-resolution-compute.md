# 长宽分辨率与计算热点核对

日期：2026-10-31。承接 [界面计划第 12 节](3d-metrology-ui-plan.md#12-i4-提交后的进度与下一步2026-10-31) 和 [连续边长拟圆对照](3d-metrology-circle-support.md)。本批不再调整 S2 权重，不修改工件质量门禁，不改变前端或测量方法。

## 1. 范围与修复

1. 修正测试诊断的两处语义错误。原 `selected_points/source_membership` 实际统计的是选中栅格内的所有点，并非实际距离分区的目标点；现明确区分目标原始行摘要与选中格支持。格边估计原来将本格作为邻格展示，现分开记录实际邻格和来源第二格。
2. 对 A_top_L 固定相同 pose、动态高度、连接距离和完整局部支持，核对名义格、半格相位、两倍格距的四侧分位端点。未对多相位结果取平均，未修改正式格距或量值。
3. 仅优化 `boundary_surface._boundary_edges`：从 `unique(axis=0)` 的结构化行比较，改为稳定整数列字典序排序与相邻分组。Delaunay、完整输入、面顺序、四项面支持条件、边方向及非流形拒绝均保持不变。没有新增缓存、资源系统、抽样或等待队列。

## 2. A_top_L 结论

完整输入仍为 14,745,099 点，原始文件 SHA256 为 `ff2b9e0ef2d6c45af02c4bf8d474cd82f77f86ad92bd371a4c0f71b1b90d116b`。

Windows 与 WSL Ubuntu 三种设置下，真实目标均为 **56,698 行**，排序后的原始行号 SHA256 均为 `482b23437cdb3de05719f7ded1b8a2808430c945128b5e04b6502218c548e6b4`。选中格支持点数分别为 56,433、56,426、56,769；它会受格聚合/高度符号影响，不能用这个数的变化证明目标归属跳变。

| 0.03 mm，名义相位 | -36.960000 | -29.963697 | -22.380000 | -14.463870 | 6.996303 | 7.916130 |
| 0.03 mm，半格相位 | -36.945000 | -29.978695 | -22.365000 | -14.448870 | 6.966305 | 7.916130 |

所有坐标和尺寸单位为 mm。四侧分别定位如下：

- U 最小、V 最小的分位端点均为缺低侧邻居的格边估计，真实邻格点数为零。半格相位使边界坐标平移 0.015 mm。
- U 最大的分位端点均为相邻格中心间插值。名义格与半格相位的两个统计端点插值系数分别相同，约为 0.707313、0.710989；格中心位置变化导致该侧移动约 -0.014998 mm。两侧变化相减，W 改变约 -0.029998 mm。
- V 最大也由插值端点决定，半格相位与 V 最小近似同向移动，L 基本抵消；粗格改变高度聚合和插值，L 范围差约 0.004322 mm。
- W 三种设置范围差仍为 **0.044701 mm**。已经具体定位为当前格中心/格边估计的分辨率敏感性，不是再次选错目标，也不是求解器随机漂移。

独立连续矩形测试验证格边估计、缺邻格标识与原始行语义；它不提供本工件缺测真实边的位置，也不把格宽变成通用准确度保证。当前可见包络方法保持显式 `estimated` 来源。若现场精度不能接受该敏感性，应另行确定真实边点估计或采样要求，不能通过修改门禁、平均相位或填入手工报告值处理。

## 3. 优化依据与等价边界

优化前开启 cProfile 的完整数值图计算为 19.967 秒：边界提取 10.782 秒、显式 ROI 节点 4.115 秒、高差节点 3.338 秒。文件读取 68.502 秒是被 profiler 放大的独立阶段，既不计入计算，也不拿来与未插桩结果比较。该剖析仅用于选择热点，不是正式节拍。

S1/S2 分别有 457,040、494,592 个保留三角面。同一份面数组交替执行原排序和新排序各三次，边集合、方向和顺序逐元素完全相等：

| 平台 | 对象 | 原排序中位秒 | 新排序中位秒 |
| --- | --- | ---: | ---: |
| Windows | S1 | 0.655 | 0.169 |
| Windows | S2 | 0.750 | 0.220 |
| WSL Ubuntu | S1 | 0.622 | 0.143 |
| WSL Ubuntu | S2 | 0.671 | 0.182 |

这是边排序子步骤的收益，不是整图四倍加速。没有声称解决所有计算热点。

原 `point_count * 2048` 建面工作预算不变；排序工作集仍为面数线性规模，不使用点号乘法打包，避免大行号溢出。所有边均参与统计，超过两个面共享边仍返回 `nonmanifold_surface`。在排序前后、分组后保留取消检查；没有让原生排序变成可抢占操作的虚假承诺。数组只存在于当前调用，沿原 Runtime/Scope 收尾。
