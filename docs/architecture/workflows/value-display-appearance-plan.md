# Value Display 颜色与尺寸配置方案

状态：已实现并验证。2026-09-17 完成节点校验、颜色编辑器、外观表单、共享渲染及开发环境 App Mode 验证。

## 目标与边界

Value Display 提供通用字段选择、颜色及尺寸配置，不识别固定生产字段、模型分类或 OK/NG 业务。小图叠加与双击大图使用同一正文和显示组件。保留左上角纵向布局与当前默认效果，不修改模型推理、生产计数、文件汇总、Runtime/Trigger 调度及数据面。

## Context 配对

Extract Value Field 提取选中分支对象的 context，分别连接 Value Display.Context 和 Image Preview.Presentation Context。前端在 generation、sequence、snapshot_revision 三项一致，且两端不是过期结果时才组合显示；缺失或不匹配显示关联不可用，不猜测配对。complete 标记用于提示部分汇总，不可因外观配置而隐藏或篡改。

Context 是小型关联元数据，不是图片内容、显示样式或生产数值。现有连线保留。空数据分支继续使用一致的空 context。

## Fields 编辑

每项保留 Path、Label、Format、Precision，增加 Label Color 与 Value Color。空颜色代表主题默认值，按钮显示实际默认色及“自动”；选择色块、预置调色板或输入 #RRGGBB，支持恢复默认。使用 Draw Regions 已有调色板及颜色校验能力，避免另建一套色彩规则。

Format 为 Status 时显示 State Colors，使用“状态值 + 颜色”的行编辑器替代手写 JSON。状态值不限于 ok/ng，可以是 pass、fail、alarm 或应用自定义值。默认保留原始状态值的精确匹配，不改变字段值，也不依据颜色反推业务状态。

数值颜色优先级：命中的状态颜色 > 本字段 Value Color > 主题默认。标签颜色独立使用 Label Color。无匹配状态按普通数值颜色显示，null 仍显示占位符，不自动当成 OK 或 NG。Precision 仅在 Number / Percent 下显示。

保留 states 的现有语义色作为内置预设，编辑器显示可读名称和色块，不要求输入 success/danger。新增自定义颜色采用严格校验的十六进制颜色；已有已发布版本不需改写。新增 label_color、value_color 为可选字段，v1 缺省行为不变，不建立平行协议或专用生产显示节点。

## Appearance 编辑

节点增加 Appearance 配置入口，通过独立面板编辑，避免把复杂设置展开在画布节点中。参数名称沿用简洁英文风格，单位放在控件提示中。配置结构使用可选 appearance 对象，由节点正文透传至共享显示组件。

| 参数 | 默认 | 行为 |
| --- | --- | --- |
| Panel Width | Auto | 默认保持内容自适应，最大 280 CSS px；显式宽度可大于此默认上限，但不超出图片容器 |
| Panel Height | Auto | 默认保持当前内容自适应和滚动限制；显式高度约束面板，不拉伸文字，不截掉字段 |
| Font Size | 13 | 普通字段标签与数值字号，单位 CSS px |
| Status Font Size | 20 | Status 格式值的字号，单位 CSS px |
| Background Color | Auto | 默认主题面板色，可通过调色板覆盖 |
| Background Opacity | 78% | 仅改变背景透明度，不影响文字透明度 |

宽高的 Auto 在存储中使用 null 或省略，不能把 0 当成有效面板尺寸。校验边界：宽 100–1600，高 80–1200，普通字号 10–72，状态字号 10–120，透明度 0–100。尺寸和字号均为整数。不得通过缩小用户字号来掩盖容器不足。空间不足时面板限制在当前容器内，正文滚动，收起按钮仍可访问。

不使用 transform:scale 放大整个面板；文字大小与面板宽高独立生效。默认保留内边距 10/12、行间距 5、标签与数值间距 18。首期不增加每字段字号或任意 CSS 编辑器，避免重复控制。颜色严格接受预设或十六进制，尺寸严格接受有限数值。

Appearance 中字体与字段颜色可用于普通 Value Display；面板宽高、背景透明度作用于图片叠加。普通节点预览沿用画布尺寸，不因大尺寸配置撑开节点。小图和大图采用同一配置，但分别按各自容器约束，不按图片像素尺寸或缩放比例缩放文字。
